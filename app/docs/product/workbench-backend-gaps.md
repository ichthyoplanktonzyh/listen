# 工作台重构 · 后端 / 数据缺口台账

> 工作台重构里凡是「UI 能做全、但真功能缺后端契约或数据字段」的地方，都记在这里，
> 而不是在界面上伪造成功。每条写清：**参考产品要什么 · 前端已做到哪 · 缺什么 · 落地前的诚实降级**。
> 这不是排期表，是「为什么这个入口现在是禁用/占位」的单一真源，供接后端时逐条消账。

规则（AGENT.md）：契约定义、Rust 后端行为、`.listenpkg` schema、`listen-gen` 内部实现属于别的仓库。
app 任务里不动它们——需要新数据就先用 typed fixture 顶着把 UI 做出来，之后 pin 一个 release 进来。

---

## 1. 媒体来源层级 / 双语标题字段（P0-b 已触发）

- **参考**：顶栏 / 媒体区有来源面包屑「当前频道：Vox 观点」——媒体挂在一个**来源层级**下（频道 / 合集 / 栏目），且标题常是**双语**。
- **前端现状**：`_SessionHeader` 的面包屑（`media_workbench.dart:_Breadcrumb`）已就位，渲染 `媒体库 / <当前媒体名>`。
- **缺什么**：媒体对象上没有「来源 / 频道 / 合集」层级字段，也没有双语标题字段。只有一个文件名（`playerController.mediaPath` 的 basename）。
- **诚实降级**：面包屑根固定为 `媒体库`，第二段用 `displayMediaTitle(mediaTitle)`（清洗过的单语标题）。**不伪造频道名**。
  接入来源层级字段后，把根替换为真实的「来源 / 频道」路径，标题接双语字段。

## 2. 导出 / 打印 / 离线（P0-b 入口占位）

- **参考**：顶栏下载图标下拉——导出视频 / 音频 / 字幕 / PDF / 讲义 PDF / 打印。
- **前端现状**：顶栏 `workbench-export` 入口已就位，**禁用**，tooltip `导出与打印暂不可用`。
- **缺什么 / 分层**：
  - **打印、字幕 / 文稿文本导出、讲义 PDF**：**纯前端可做**，属 P1 实作范围（非后端缺口），到 P1 兑现即可去掉禁用。
  - **导出视频 / 音频**：需后端 / 大文件能力，属真缺口。
- **诚实降级**：整个入口先禁用，不弹「Coming soon」，不产生成功提示。P1 起先点亮纯前端那几项。

## 3. 分享（P0-b 入口占位）

- **参考**：顶栏有分享入口。
- **前端现状**：顶栏 `workbench-share` 入口已就位，**禁用**，tooltip `分享暂不可用`。
- **缺什么**：分享目标 / 载荷契约未定（分享什么：媒体链接？片段？跟读录音？）。
- **诚实降级**：入口禁用并说明。

> **注（P0-c 修正）**：选词模式**不是**后端缺口。对照真图，候选词就是当前句被挖掉的词打乱，
> 题目自带在句子 token 里，无需外部干扰项/答案数据。已按真图实装（挖空句 + 候选 chip + 点选填空）。
> 早先「选词缺数据、做占位」是照 gap-analysis 文字臆测的，被真图推翻。

## 4. 跟读顶栏入口 → 录音 / 评分绑定当前 cue（P0-b 已接一半）

- **前端现状**：顶栏 `workbench-shadow` 麦克风入口已就位，接 `practiceActions.startShadowingPractice()`，
  由 `subtitleController.currentPrimaryCue != null` 门控（无当前句时禁用，tooltip 说明）。
- **缺什么**：跟读录音与**评分**绑定到当前 cue 的契约（录音存哪、评分回传结构、与 cue 的关联）。
- **诚实降级**：入口只负责「进跟读并聚焦当前句」；评分闭环待后端契约。

## 5. 精听浮动窗「倍速 ｜ 次数 ｜ 间隔」自动重复循环（P1 已触发）

- **参考**：`单句精听.png` 顶部药丸 `1x ｜ 3 次 ｜ 间隔5秒`——「以速率 R 自动重播当前句 N 次、每次间隔 I 秒」的听力循环设置。
- **前端现状**：`intensive_practice_window.dart` 浮动窗的 `_settingsPill()` 已就位，显示 `1× ｜ 3 次 ｜ 间隔 5 秒`，
  **非交互、诚实占位**，tooltip `自动重复设置（即将支持）`。不写入 practice state。
- **缺什么**：`PracticeController` 里「按次数/间隔自动重播」的调度（现有只有连续 loop 与手动重播），以及这三个值的持久化/设置项。
- **诚实降级**：药丸只做预览，不接线；点了不改变任何行为。接调度后再让它可编辑并驱动重播。

## 6. 精听浮动窗「返回前 2 秒」（⌘L seek-back）（P1 已触发）

- **参考**：`单句精听.png` 底部键盘条 `Cmd L 返回前2秒`——把播放头回退 2 秒的微调。
- **前端现状**：底部键盘条已就位，实装 `⌘P 播放/暂停`（→`onTogglePlayback`）与 `⌘R 重听本句`（→`onReplay`）；
  **未做** `返回前2秒`——现有回调里没有「相对 seek -2s」的动作，只有「重听整句」。
- **诚实降级**：先不呈现 `返回前2秒` 键，用已存在的 `重听本句` 顶着。补一个相对 seek 回调后再加回该键。
