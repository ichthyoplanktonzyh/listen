# 工作台 IA / UX / UI 差距对照（vs《每日英语听力》桌面端）

> 目的：在动手重做播放器工作台之前，先把「参考产品怎么组织任务」和「当前
> `feat/ia-restructure` 分支实际长成什么样」逐面摆在一起，找出真正的差距。
> 结论先行：**当前分支在"功能清单"上已覆盖大半，但在信息架构与体验质感上，
> 离《每日英语听力》还有明显距离**——差距集中在四个体验性根因（见 §4），
> 不是"再抽一层 controller"能解决的。

| 听写·工作界面 | 全覆盖卡：`2/10`、`错词/漏词/正确率/时长`、大输入框、底部键盘提示。 |
| 文本高亮以及解析 | 当前句蓝字，句尾内联 `ⓘ 解析` 小入口；每句下方一条译文位（参考里是 VIP 门禁占位）。 |
| 双击解析唤醒词典气泡 | 双击单词 → **锚定气泡**（欧路词典）：词 + 收藏星 + 英/美双音标+发音 + 英汉-汉英释义 + `AI解释`（语境/例句/助记/词根/词源/搭配/同义词/形近词 多 tab）+ `详细释义 →`。不替换文稿。 |

| 跟读训练 | 全覆盖卡：`17/61`、`上传并分享`、`跟读设置`、当前句、`< ▶ 🎤 ))) >`（播放/录音/回放/切句）。 |
| 离线/导出/打印 | 顶栏下载图标下拉：导出视频/音频/字幕/PDF/讲义PDF/打印。 |
| 设置 | 弹窗，四 tab：通用 / 播放设置 / 桌面字幕 / 快捷键设置。 |

**参考产品的 IA 精髓**：
1. **右区永远是文稿**，所有辅助（词典、解析、译文）都是**非破坏式覆盖**在文稿之上。
2. **学习模式分两层**：`阅读态`（阅读/盲听/选词，改变文稿如何呈现）与 `精听态`
   （单句精听/填空/听写/跟读，**全覆盖接管右区**成为专注练习面）。二者都在**一个下拉**里，靠分组标题分层。
3. **顶栏是有标签、有 tooltip、有快捷键的工具带**，不是匿名图标堆。
4. **底栏三段式**：左媒体信息（缩略图+标题）｜中全局进度｜右学习控制（AB/倍速/播放列表/字幕）。

## 2. 当前实现的信息架构（从代码归纳）

- **顶栏** `_SessionHeader`（`media_workbench.dart:212-289`）：`返回首页 + Spacer + [听力菜单][翻译][学习菜单][字幕菜单][设置]`。
  **无面包屑、无"当前频道/来源"、无媒体名、无跟读入口、无导出/打印、无分享。**
- **左媒体区** `_MediaPane`（`media_workbench.dart:356-407`）：大标题 + 16:9 视频。**无频道/来源上下文行。**
- **右文稿区** `SidePanel`（`side_panel.dart`）：`原文/笔记` 两 tab（`side_panel_tabs.dart`）
  ＋可选 ContentFitCard ＋ `TranscriptPanel`。
  - `TranscriptPanel`（`transcript_panel.dart`）：每句一个 `ListTile`，**左侧 58px 时间码列**（:191-202），
    当前句用 `primaryContainer @0.5 填充块` 高亮（:188-189），译文行、内联解析 toggle、
    **底部"返回当前句"横条**（`_BackToCurrentBar`，:502-549，非 FAB）。
- **学习模式** `StudyMenu`（`study_menu.dart`）：**单个分组下拉**——阅读组（听力/阅读）｜精听组（跟读/填空/chunk听写/整句听写）｜任务组（口语/写作）。
  精听项各自打开对话框/窗口（`intensive_practice_window.dart` 等）。**无盲听、无选词、无 typed 模式状态。**
- **底栏** `PlaybackControls`（`playback_controls.dart`）：**两行**——进度行（时间/滑块/时间，:470-527）＋
  控制行 `_fullControlRow`（:644 起）：`上一句/(重播)/播放/下一句/句循环/AB/chunk菜单/字幕 · Spacer · 倍速下拉/静音/播放设置`。
  **非三段式；无媒体缩略图+标题；无播放列表；prev/next 是"句"不是"项"；倍速是原生 Dropdown 不是 `1x` 药丸；无全屏。**
- **词典气泡** `WordBubble`（`word_bubble.dart`）：锚定、可点外关闭、有加载/失败/无义状态；
  内容 = 词 + 单音标 + 发音 + 一条释义 + 来源 + 3 个状态 chip + `详细信息`链接。

| 维度 | 参考 | 现状 | 差距 | 级 |
| --- | --- | --- | --- | --- |
| 盲听 | 隐藏文稿正文+进度计数 | **不存在** | 缺整个模式 | 🔴 |
| 选词 | 句子挖空+候选词 chip | **不存在** | 缺整个模式 | 🔴 |

| 模式状态 | 阅读态是文稿的一种显示 | 用 `ContentChannel`+string+回调，**无 typed `WorkbenchStudyMode`** | 模式不是一等状态，难做盲听/选词/精听的统一切换与持久化 | 🟠 |
| 菜单分层 | 一个下拉分两组（阅读态/精听态） | 一个下拉分三组（阅读/精听/任务） | 结构接近，但把"口语/写作任务"和日常听力模式塞一起（原指令想拆两菜单，你无偏好，建议见 §6） | 🟡 |
| 快捷键 | 模式带 ⌘1–6 | 部分快捷键在别处 | 缺模式级快捷键一致映射 | 🟡 |

> **重要更正**：早先本文写"各自弹独立 dialog"是错的。四个精听模式**已经共用一个** `IntensivePracticeWindow`，
> 背后 `PracticeController` + `PracticeActionsCoordinator` 完整（cloze / 整句听写 / chunk 听写 / 跟读，含录音·回放·ABA·切句·评测·倍速·步进）。
> **逻辑层是好资产，几乎全部复用**，要重做的只是外壳。

**方案（已定）：typed 模式状态 + 复用全部 controller/coordinator，只重做外壳，按参考分两族两形态。**

新增 typed 枚举（命名可调）：
```dart
enum WorkbenchStudyMode {
  normal, blindListening, wordSelection,           // 阅读态
  sentenceIntensive, cloze, dictation, shadowing,  // 精听态
}
```

**① 阅读态（normal / 盲听 / 选词）—— 不盖文稿，是文稿的渲染变体**（放进 `TranscriptPanel` 渲染分支，不开新窗）：

| 模式 | 做法 | 复用 | 缺口/降级 |
| --- | --- | --- | --- |
| normal | 现有文稿 | 全部 | — |
| 盲听 | 隐藏句子正文，保留视频 + `N/总` 进度 + 临时"显示当前句"；退出恢复滚动位置 | cue 数据，纯渲染 | 无 |
| 选词 | 当前句挖空 + 下方候选词 chip | token timing / cloze 分词 | **干扰项/答案数据可能缺** → UI 做全、禁用"开始"、记后端缺口，**不偷偷映射成 cloze** |

**② 精听态（单句精听 / 填空 / 听写 / 跟读）—— 接管右区的全覆盖专注面**（逻辑全复用，浮动窗 → 全覆盖壳）：

一致外壳 = 顶部 `N/总` 进度 + `倍速｜次数｜间隔` 设置 + 中间提示区 + 底部键盘提示条。

| 模式 | 接线 | 复用 | 缺口/降级 |
| --- | --- | --- | --- |
| 单句精听 | 聚焦当前句 + 句循环 + 上/重播/下一句，保留文本 | `loopRange` + rate，无写入 | 最轻，可能是薄新增 |
| 填空 | `startClozePractice()` | ✅ 直接 | — |
| 听写 | `startSentenceDictation()`（chunk 听写作进阶保留） | ✅ 直接 | **"先选句"多选队列**：先做当前句听写，选句队列做 UI+禁用或后置 |
| 跟读 | `startShadowing()`；顶栏麦克风接当前句进这里 | ✅ 录音/回放/ABA 已就绪 | — |

**诚实占位（本轮不做真功能，只做 UI 态 + 记缺口）**：
- `次数 / 间隔`（参考 `3次｜间隔5秒`）——现有是连续 loop，**先诚实占位**，不动 practice state。
- 听写"先选句"队列；选词干扰项/答案数据。

**复用 vs 重写**：复用 `PracticeController`/`PracticeActionsCoordinator`/`IntensivePracticeWindow` 的 body 渲染器（答题框/差异/跟读控件）；重写外壳（浮动窗→全覆盖面）、给 `TranscriptPanel` 加盲听/选词分支、新增 typed 模式状态替换字符串/回调派发。

### 3.7 句子解析（**修正：原判定过高**）

参考里的 `解析` 是：播放到当前句后，**句尾出现 `ⓘ解析` 按钮 → 点开一个完整的「AI解析」覆盖面板**，
内容含：句子原文 + 整句译文、📚 语法分析（逐成分讲解）、✍ 搭配积累（词组+例句+近义/反义）等——
是**文字/语法层面**的深度解析。

我们现状只有 `DiagnosisCard`（`side_panel.dart:333-400`）那套 **语音层面**解析
（发音、节奏帧、检测音素、可循环证据），**没有任何文字/语法/搭配/整句译文层面的 AI 解析**。

| 维度 | 参考 | 现状 | 差距 | 级 |
| --- | --- | --- | --- | --- |
| 面板形态/pending/失败/切句清理 | 覆盖式 AI解析面板 | 选中句下方内联展开，有 pending/失败态（`transcript_panel.dart:257-274`） | 骨架在，但形态与内容层次和参考差一截 | 🟠 |
| **文字层面解析（语法/搭配/整句译文）** | **有**（核心卖点） | **完全没有**——待做 | 缺整块能力（AI 契约待定，属后端/LLM 缺口） | 🔴 |
| 语音层面解析 | 参考未突出 | ✅ 已有 `DiagnosisCard` | 我们反而更强，别丢 | ✅ |
| 缓存 | 按 cue 缓存？ | 待核实（可能每次重取） | 记入后端缺口 | 🟡 |

**方案（已定）**：复刻参考「解析面板」的体验，但面板**顶部加一个切换 toggle**：
- **文字层面解析**（语法/搭配/AI）→ 待做，做成**诚实的占位/不可用态**（说明缺 AI 契约，不伪造成功流程）。
- **语音层面解析** → 复用现有 `DiagnosisCard`。

切句时清理旧句状态；关闭不影响播放；无对应能力时对应 tab 禁用并说明原因。

## 4. 综合诊断：为什么"效果达不到每日英语听力"

抛开功能清单，四个**体验性根因**决定了观感差距：

1. **文稿面像"字幕编辑器"，不像"读物"。**
   逐行 58px 时间码列 + 整行填充块高亮，视觉密度和重心全错。参考是干净段落 + 蓝字轻高亮。
   → 这是最该先改的一处，改完观感立刻接近参考。（🔴 §3.3）

2. **顶栏没有身份与上下文。**
   匿名菜单簇，既不告诉用户"在哪"，也没有跟读/导出/分享这些参考里高频、有标签的工具。（🔴 §3.1）

3. **学习模式是"弹窗集合"而非"分层的态"。**
   缺盲听/选词两个阅读态；精听/填空/听写/跟读是各自为政的对话框，没有统一的"接管右区+进度/次数/间隔/键盘提示"外壳；模式不是 typed 一等状态。（🔴/🟠 §3.4）

4. **底栏是两行扁平工具行，不是三段式带媒体信息的传输条。**
   没有缩略图+标题的媒体身份，没有"项"级上/下一项与播放列表。（🟠 §3.5）

**当前分支真正做对、务必别回退的**：文稿=永久底层、查词锚定气泡、解析内联、翻译三态+只说一次、
自动跟随暂停/恢复、分栏比例持久化、诚实的不可用状态。这些是好资产。
