# Listen Ecosystem Documentation

This file is a navigation aid retained for existing links. It is not a fourth
source of product or architecture truth.

- [PRODUCT.md](PRODUCT.md) defines what Listen is, why it exists, its durable
  product principles, and explicit non-goals.
- [CONTEXT.md](CONTEXT.md) is the canonical cross-repository glossary.
- [CONTEXT-MAP.md](CONTEXT-MAP.md) assigns authority and defines the stable seams
  between `listen-app`, `listen-core`, `listen-gen`, and the required future
  Community And Sync context.

Repository READMEs and planning documents describe current code, validation,
and work status. They must link to these semantic documents instead of copying
their product definitions.
