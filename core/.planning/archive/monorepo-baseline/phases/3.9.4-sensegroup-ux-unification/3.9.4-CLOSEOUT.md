状态：COMPLETED
完成时间：2026-07-14 21:30 CST

## Outcome

修复了语义分组从语法分析到前端显示的四层断链，语义分组成为与韵律分组
UX 对等的一级能力，且 ADR 0016 的数据层分离与"SenseGroup 不存时间"边界
保持不变：

- **持久化**（Slice 0，`0433ceb4`）：application 新增
  `persist_sense_group_analysis_from_batch`，直接映射 batch 中已算好的
  sense groups（不重算、不合并 per-sentence SyntacticAnalysis），幂等
  （active 同 id 跳过）、provider 感知 fingerprint 使 syntax 结果可接管
  文本回退 active，Partial 轨道逐句混合来源。
- **接线**（Slice 1，`0cd1b755`）：track syntax 分析的新鲜与 cache-hit
  路径都持久化并激活；失败仅 warn，不影响 syntax 响应；capability
  unavailable 早退保持零副作用。
- **回退与反馈**（Slice 2，`4e55cc35`）：Flutter 加载语音增强时无 active
  分析则触发一次文本规则生成 + 激活（单次守卫、失败静默降级）；设置页
  semantic/compare 选项标注可用状态，未就绪时 helper 说明逐词回退。
- **播放对等**（Slice 3，`c18458b1`）：`senseGroupPlaybackRange` 纯函数
  按 ADR 0016 把 token span 投影到句内 WordTiming（容忍乱序/缺失，
  null 即不可交互）；TokenLine 缓存投影（列表 identity 失效才重算），
  当前组高亮跟随与点击跳转复用 chunk 高亮设置与 seekChunk 通路；
  semantic 纯模式升级为实线胶囊，compare 模式保持差异标记现状。
