# Phase 2.18 Closeout: Codebase Architecture Refactor

状态：COMPLETED
完成时间：2026-06-28 CST

## Summary

Phase 2.18 是一次非兼容式、代码层面的架构收口。用户已明确确认不需要历史兼容性，因此本阶段没有为旧数据库、旧 LLTimeline JSON、旧 WordProfile 资源或旧 API/UI adapter 保留长期迁移路径。

本阶段最终目标不是“换栈”，而是把快速增长后出现的双模型、全能 repository、动态 JSON 状态和巨型 orchestrator 压回到清晰的工程边界内。当前主路径已经完成，可以作为后续功能开发的新基线。

## Completed Scope

### 1. Contract And Route Hygiene

- 补齐 OpenAPI/generated client 中缺失的语言、字幕语言、phonetic job clear 等 route。
- `scripts/validate-contracts.sh` 与 API route parity 测试已能双向校验实现 route 与 OpenAPI path set。
- API event schema 已同步新的 lexical event 命名。

### 2. Learning Asset Model Convergence

- active code path 收敛为 `LexicalEntry + LexicalUnit + LearningStatus`。
- 旧 `WordProfile` / `WordObservation` domain、repository、HTTP route、OpenAPI schema、generated client、script 和 Flutter fixture 路径已从 active path 删除。
- `LearningAssetRepository` 成为 lexical learning asset 的一等 repository 边界。
- 诊断、lexical observation、vocabulary v5 export/import 均以 lexical entry 为权威模型。

### 3. Rust Boundary Refactor

- `AppServices` 不再依赖全能 `SubtitleRepository`。
- application repository 边界拆分为 subtitle track、pronunciation、timeline resource、LLTimeline resource、learning asset 等窄 trait。
- `application::dto` 不再以 public type alias 泄漏 `speech_analysis` DTO。
- SQLite word/chunk/phone timeline runs 增加每 track 单 active partial unique index，并有 schema-level 测试覆盖。

### 4. Timeline Envelope

- Rust domain 新增 `TimelineMetrics` / `ChunkEvidence` typed envelope。
- Flutter timeline model 同步解析 typed envelope，同时保留 wire/storage 字段名 `metrics_json` / `evidence_json`。

### 5. Flutter Typed State And Workflow

- 新增 typed `BackendEvent` 与 `BackendEventCoordinator`，`main.dart` 不再直接解析 SSE payload。
- `LearningController` 已 typed：
  - lexical entries
  - phrase candidates
  - selected lexical details
  - dictionary lookup
  - word pronunciation
  - language profile
  - diagnosis
- `SubtitleController` 已 typed：
  - pronunciation providers
  - sentence pronunciation analyses
  - phonetic analyses
- `WordLearningPanel` 和 `DiagnosisCard` 不再接收 dictionary、pronunciation、diagnosis、phonetic-analysis 业务 payload 的裸 `Map<String, dynamic>`。
- `LearningWorkflowController` 承接 diagnosis、phrase candidates、word entry load/open/update、lexical observation 和 learning-content save 流程。
- `SpeechEnhancementWorkflowController` 承接 timeline resource refresh、word timings、sentence pronunciation、chunk partitions、phone/sound-pattern analysis 加载解析。
- `main.dart` 从约 3471 行降到约 3235 行，核心 learning 与 speech/timeline refresh workflow 已迁出。

## Remaining Work

以下是当前仍没有“彻底完成”的事项。它们不阻塞 Phase 2.18 收口，但应作为后续阶段输入。

### 1. `main.dart` 仍然偏大

核心 learning workflow、SSE parsing、speech/timeline refresh workflow 已迁出，但 `main.dart` 仍包含较多 UI wiring：

- media open/drop/register/download。
- subtitle import/search/activation/archive/delete/export。
- timeline resource action callbacks。
- manual review dialog wiring。
- player/session level status text。

下一步可以继续提取 media/session/resource action controller，让 `main.dart` 更接近纯 composition root。

### 2. Route Manifest 仍未成为共享事实源

当前 route/OpenAPI drift 由 parity test 和 `validate-contracts.sh` 守护。这个已经能防止实现与契约继续漂移，但 route path 仍然由 Axum router chain 与 OpenAPI 分别声明。

后续如 route 继续增长，可以引入共享 route manifest 或更强的生成机制。

### 3. UI 状态仍缺少显式 loading/error/stale/session 模型

本阶段已经为 diagnosis 使用 generation guard，并在 speech/timeline refresh 上用 track id / mounted check 防止 stale result 落地。但整体 UI 仍有不少流程依赖：

- nullable value 表达 empty/loading/error。
- `status` 字符串表达异步过程结果。
- 局部 `setState` 表达 session 级状态。

后续如果继续扩展复杂异步流程，建议引入更显式的 `loading | ready | stale | error` 状态模型。

### 4. `speech-analysis` crate 仍然承载多个子域

本阶段已经阻断 `speech_analysis` DTO 向 application/public DTO 泄漏，但 crate 内仍包含：

- ASR timing。
- chunk partition。
- phonetic alignment。
- phonetic findings。
- learned prosodic provider。
- rich acoustic evidence。

当前可以接受；若后续模型继续扩展，应考虑按子域拆 crate 或至少拆更清晰的 module boundary。

### 5. 真实媒体 QA 不属于本阶段自动完成范围

Phase 2.18 完成的是架构、模型、契约和自动化守护。真实媒体听感 QA、真实 connected speech 样本包、长期回归素材仍应由 Phase 2.17 / 后续 QA 阶段推进。

## Decision Record

- 不保留历史兼容性。
- 旧 SQLite 数据和旧 LLTimeline JSON 可以失效。
- 旧 WordProfile/WordObservation 资源和旧 API/UI adapter 不再作为 active path 维护。
- 后续开发以 `LexicalEntry + LexicalUnit`、typed Flutter state、application-owned DTO、统一 timeline lifecycle 和 route parity guard 为基线。
- 过期 `.planning/DEFERRED-ITEMS.md` 已删除；跨阶段遗留项不再集中维护在旧总表中，而是进入对应 phase closeout、`.planning/STATE.md` 或新 phase plan。
