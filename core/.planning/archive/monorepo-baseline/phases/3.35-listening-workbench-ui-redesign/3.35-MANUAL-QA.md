# Phase 3.35 Manual QA

状态：WAITING_FOR_OWNER

执行人：owner。Codex 不代替操作 GUI 或生成验收截图。

## 准备

- 使用一段带主字幕的真实本地视频，建议 10 分钟以上。
- 如有条件，再准备副字幕、LLTimeline 和一个可合法访问的在线 URL。
- 保留一份无媒体启动状态。
- 截图中不要包含私人路径、API key 或未授权内容。

## A. 窗口尺寸

分别在 `1440x900`、`1280x800`、`900x700` 检查：

- [ ] 顶部工具栏无重叠、截断或不可达动作。
- [ ] 播放条不出现横向滚动，主播放动作始终可见。
- [ ] 媒体、文稿和右侧导航没有互相覆盖。
- [ ] 最长的中英文标签不越出按钮、tab 或设置导航。
- [ ] `900x700` 下工作台正确切换为紧凑布局。

## B. 首页与来源

- [ ] 无媒体时可理解本地文件和 URL 两种入口。
- [ ] 继续学习区显示当前/最近媒体和资源状态。
- [ ] “添加来源”能校验 URL，并识别 YouTube 或普通网页。
- [ ] 在线播放/下载到本机选择清晰，授权提示可见。
- [ ] 取消添加来源不会改变当前媒体。

## C. 播放工作台

- [ ] 从首页进入媒体后，视频与文稿首屏均可见。
- [ ] 拖动媒体/文稿分隔线时连续变化，无跳动和 overflow。
- [ ] 关闭重开 app 后分栏比例保持。
- [ ] 压缩媒体区和复位布局均有效。
- [ ] 当前字幕句随播放稳定滚入视口，长句不会破坏跟随。
- [ ] 上一句、播放/暂停、下一句、循环当前句和进度拖动正常。

## D. 学习面板

- [ ] 右侧当前 tab 有明确文字或 tooltip，切换不改变播放位置。
- [ ] 字幕资源首层只显示可用能力，技术详情可按需展开。
- [ ] 诊断先显示摘要，证据展开后音素、节奏和循环动作可用。
- [ ] 词汇页顺序为学习状态、释义与发音、来源原句、折叠历史。
- [ ] 练习、卡点、悬案区和 Listening Inbox 原有路径仍可完成。

## E. 设置与视觉

- [ ] 设置侧边分类可跳转到通用、字幕、学习、资源、外部工具、实验功能。
- [ ] 设置保存后立即生效，重新打开仍保持。
- [ ] 浅色工作面、深色媒体 overlay 和状态色对比清晰。
- [ ] 字幕、音素、节奏 ribbon 在亮/暗视频画面上均可读。
- [ ] hover、focus、selected、disabled 和 error 状态容易区分。

## F. 泛听回归

- [ ] 连续播放至少 30 分钟，无意外弹窗或强制任务。
- [ ] 软打断、硬打断和 Inbox 标记不破坏播放状态。
- [ ] 完成泛听后理解度自报与 Inbox 整理仍可使用。
