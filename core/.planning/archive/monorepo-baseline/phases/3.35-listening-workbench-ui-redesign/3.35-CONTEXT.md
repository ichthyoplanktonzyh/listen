# Phase 3.35 Context: Listening Workbench UI Redesign

状态：IN_PROGRESS

日期：2026-07-04

## Why This Phase Exists

Phase 3.1 至 3.3 已把精听练习、卡点闭环、泛听会话和 Listening Inbox 接入桌面端，
但当前 UI 仍主要沿用功能逐步叠加形成的工程布局。功能已经能用，视觉层级、导航心智、
控件一致性和高频操作密度却没有形成统一产品语言，继续直接叠加 3.4 之后的复习、难度、
词典和 dashboard 会进一步放大界面债。

Phase 3.35 因此插入 3.3 与 3.4 之间，先把桌面端整理为稳定的听力学习工作台：

```text
内容入口
  -> 播放与同步字幕
  -> 精听 / 泛听当前任务
  -> 诊断与练习上下文
  -> Inbox / 词汇 / 复习等资产入口
```

这不是单纯换配色，也不是重写已有业务逻辑。它要让用户无需理解内部资源名、controller
或 timeline 层级，就能自然找到当前最重要的内容和动作。

## Product Positioning Correction

`listen` 是**本地优先（local-first）**，不是**仅限本地（local-only）**：

- 本地媒体、学习资产和播放实时路径仍是默认基础。
- 产品后续会接入 YouTube 等在线内容来源，在线资源与本地资源应进入同一内容入口和
  播放学习工作台。
- 来源差异应通过 capability、可用性、缓存/下载状态和 provenance 表达，不应让 UI
  架构绑定“打开本地文件”这一种入口。
- 本 phase 不实现新的 YouTube 接入，但信息架构和组件必须为 `local / url / youtube /
  future provider` 保留一致位置。

## Reference Product

主要参考产品：每日英语听力。

当前参考范围基于官方产品页；实现阶段还必须补充实际界面审计和截图证据：

- 官方介绍：<https://www.eudic.net/mobile/ting.aspx>
- App Store：<https://apps.apple.com/cn/app/mei-ri-ying-yu-ting-li/id570118289>
- Google Play：<https://play.google.com/store/apps/details?id=com.qianyan2.ting.en>

重点吸收：

- 内容、播放、字幕和学习动作之间清晰的层级。
- 播放控制与同步文本保持空间关联。
- 单句精听、循环、查词、听写等高频能力可快速触达。
- 信息密度高但主要任务稳定，次级能力按上下文展开。
- 内容来源可以扩张，不把播放器限制为文件选择器。

明确不照搬：

- 品牌素材、图标、文案、具体像素布局或专有交互。
- 以订阅内容 feed、VIP 转化或打卡挑战为中心的首页结构。
- 将移动端底部导航原样放大到桌面端。
- 与 `listen` 的诊断、卡点、证据和本地资产模型冲突的功能组织。

## Design Direction

`listen` 应呈现为安静、紧凑、适合长时间使用的学习工具，而不是营销页或装饰性 dashboard。

- 第一视觉中心永远是当前媒体、声音和同步文本。
- 精听 / 泛听是一级模式，但模式切换不制造两个割裂应用。
- 诊断、Test、Shadowing、Inbox 是当前上下文动作，不堆成常驻按钮墙。
- 词汇、复习、听力词典和后续 dashboard 是稳定资产入口。
- 采用冷杉绿、雾灰与暖金：浅色工作面、近黑媒体画布、冷杉绿交互信号、暖金学习强调；
  避免单一深色蓝灰、刺眼纯白或满屏高饱和强调色。
- 桌面端优先采用可调整的工作台布局；概念和领域状态保持跨端可重组。

## Boundaries

### In Scope

- 每日英语听力参考审计与当前 UI 基线审计。
- 桌面端信息架构、导航、视觉令牌和共享组件体系。
- 主播放器、字幕文稿、学习上下文侧栏、播放控制条的整体重排。
- 精听 / 泛听 / Inbox / 词汇等现有入口的视觉统一。
- 空态、加载态、不可用态、降级态和错误态统一。
- 本地与未来在线内容来源的统一入口形状。
- 多窗口尺寸截图验证与真实媒体手工回归。

### Non-Goals

- 不实现 YouTube provider、内容推荐 feed、账号、订阅或云同步。
- 不实现 Phase 3.4 至 3.10 的新业务功能。
- 不重写播放器、practice、diagnosis 或 Inbox 领域逻辑。
- 不复制每日英语听力的品牌资产或完整界面。
- 不为了视觉改造破坏 controller + Store、capability gating 或 durable learning facts。

## Success Definition

Phase 3.35 完成时，第一次打开应用的用户应能迅速理解：内容从哪里来、当前在听什么、
字幕在哪里、如何进入精听或泛听、当前句能做什么、沉淀的学习资产去哪里找。现有 3.1
至 3.3 工作流必须全部保留，并在真实媒体中比改造前更容易发现和连续使用。
