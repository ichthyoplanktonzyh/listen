# Phase 3.35 Reference Matrix

状态：IMPLEMENTED

依据：2026-07-04 owner 提供的每日英语听力首页与播放学习界面截图，以及 listen 改造前后截图。
参考只用于信息层级和交互组织，不复制品牌、内容、文案或像素布局。

## 借鉴

| 参考特征 | listen 落地 | 取舍 |
|---|---|---|
| 首页与播放工作台分离 | 来源中立首页 + 当前媒体工作台 | 首页负责进入和继续，播放页负责听力任务 |
| 独立底部播放条 | 固定播放控制区 | 高频 transport 常显，学习和样式动作收入模式菜单 |
| 媒体与同步文本并列 | 可拖动媒体/文稿分栏 | 比例持久化，并提供压缩与复位 |
| 当前内容信息清晰 | 继续学习、当前媒体和资源状态摘要 | 不引入推荐 feed 或订阅内容 |
| 学习能力按上下文出现 | 词汇、诊断、练习、Inbox 右侧面板 | 保留 listen 自有的证据与卡点模型 |
| 高密度但稳定的桌面布局 | 紧凑 toolbar、labelled panel tabs、分组设置 | 次级技术字段默认折叠 |

## 不借鉴

| 参考特征 | 原因 | listen 方案 |
|---|---|---|
| VIP、账号和内容订阅入口 | 当前产品无账号/订阅模型 | 本地优先的媒体与学习资产 |
| 推荐频道与编辑 banner | 当前没有可信内容 feed | 继续学习、最近媒体、添加来源 |
| 专有品牌图标和文案 | 避免复制品牌表达 | listen 品牌与 Material 图标体系 |
| 移动端导航直接放大 | 不适合桌面重复操作 | app bar、工作台和上下文侧栏 |
| 翻译权限或会员状态语言 | 与本地能力模型冲突 | capability readiness 和明确降级原因 |

## listen 独有

- Understand / Test / Shadowing 三姿态与 capability gating。
- 诊断摘要、声音证据、节奏热点和区间复听。
- 卡点、悬案区、session summary 与 Listening Inbox。
- LLTimeline、WordTimeline、ChunkTimeline 和 PhoneTimeline 的本地资源生命周期。
- local-first 但 source-neutral：本地文件和 URL 共用内容入口，未来 provider 不改变工作台结构。

## 结论

Phase 3.35 吸收的是“内容入口 -> 当前播放 -> 同步文本 -> 上下文学习”的层级关系。
最终界面仍以 listen 的本地资产、证据模型和精听/泛听闭环为中心。
