# Phase 2.2 Audit: Timeline Resource Intake

更新时间：2026-06-19 17:05:00 CST

## Scope

本次 audit 从 handoff 指定的入口开始，检查 `.lltimeline.json` 导入/导出、
WordTimeline summary / activate、Flutter client、现有高亮绑定和无资源降级路径。

## Findings

- Rust API 已有核心路由：
  - `POST /v1/lltimeline/import`
  - `GET /v1/subtitles/{track_id}/word-timelines`
  - `GET /v1/subtitles/{track_id}/word-timelines/summary`
  - `GET /v1/subtitles/{track_id}/lltimeline/export`
  - `POST /v1/word-timelines/{timeline_id}/activate`
- SQLite `activate_word_timeline` 已把 active timeline 同步到旧
  `word_timings` 兼容缓存；archive/delete active timeline 时也会清理兼容缓存。
- `AppServices::word_timings_for_track` 已优先返回 active WordTimeline words，
  没有 active resource 时回落到旧 sentence word timings。
- Flutter 原有高亮路径读取 `LocalApi.trackWordTimings(trackId)`，所以切换 active
  timeline 后只需要重新加载 speech enhancements 即可刷新当前词高亮。
- Flutter client 之前缺少 LLTimeline import/export、summary 和 activate 方法。
- Flutter UI 之前没有可见的 LLTimeline resource 状态，也没有 candidate 激活入口。

## UI Entry Decision

最小入口放在 Transcript 面板顶部：

- Transcript 已经承载字幕句列表和词级高亮上下文。
- Timeline resource summary 与“当前字幕轨正在使用哪条词级时间轴”直接相关。
- 不需要新增重型生产工具页面，符合 Phase 2.2 轻量消费端边界。

## Implemented In This Pass

- 新增 SQLite `lltimeline_resources` 持久化，用于保存导入资源的 metadata 和
  production artifacts。
- `AppServices::import_lltimeline_document` 保存 document metadata/artifacts；
  `export_lltimeline_document` 回填持久化 metadata/artifacts，并同步当前 track/media
  信息。
- 新增 Flutter timeline resource model：
  `WordTimelineSummary`、`LLTimelineDocument`、`LLTimelineMetadata`、
  `LLTimelineArtifact`。
- 新增 Flutter LocalApi 方法：
  `importLLTimeline`、`trackWordTimelineSummaries`、`exportTrackLLTimeline`、
  `activateWordTimeline`。
- `SubtitleController` 持有 resource summary/document/error 快照。
- Transcript 面板顶部新增 Timeline Resource Summary：
  - LLTimeline present / legacy fallback
  - generator/version
  - human reviewed
  - production report readiness
  - active WordTimeline
  - candidate WordTimeline 列表
  - artifact chips
- 支持从 UI 导入 `.lltimeline.json`。
- 支持激活 candidate WordTimeline，并在激活后刷新 word timing 高亮缓存。
- 增加人工复核/校正入口占位，完整编辑器留给 Phase 2.3。

## Remaining Gaps

- 当前导入是“导入并载入为 primary subtitle track”，还不是严格的“关联当前打开媒体”
  UX。后续可基于 media fingerprint/title 做更明确的关联提示。
- Manual correction 和 ChunkTimeline editing 仍按计划留到后续阶段。

## No-Resource Fallback

无 LLTimeline resource 时，现有路径保持不变：

```text
Flutter current word highlight
  -> LocalApi.trackWordTimings(trackId)
  -> AppServices::word_timings_for_track(trackId)
  -> active WordTimeline words if present
  -> legacy sentence word_timings otherwise
```
