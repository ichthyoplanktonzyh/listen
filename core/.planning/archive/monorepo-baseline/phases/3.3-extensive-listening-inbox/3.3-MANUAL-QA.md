# Phase 3.3 Manual QA: Extensive Listening & Listening Inbox

状态：READY\_FOR\_QA

目标：用真实媒体验证泛听会话、软/硬打断、Listening Inbox 整理流、理解度自报和持久化信号是否足够闭环。此清单不是单元测试替代品；它专门检查连续听材料时的产品手感、零打扰约束和数据落库。

## QA Scope

必须覆盖：

- 真实媒体连续泛听 >= 30 分钟。
- 泛听进入/退出、理解度自报。
- 软打断：播放不中断，当前句被标入 Listening Inbox。
- 硬打断：暂停、标记、打开诊断/精听借用路径。
- Listening Inbox 整理：回听、存复习、升格微精听、收藏、丢弃。
- 重启后持久化：Inbox 项、处理结果和事件不丢失。
- 零打扰：未主动进入泛听/Inbox 时，不出现泛听学习提示或红点压力。

当前 MVP 已知限制：

- 系统级全局热键/媒体键未实现；本轮只验应用窗口聚焦时的快捷键。
- 片段收藏当前只作为 `favorite` resolution 归档；独立收藏浏览容器尚未实现。
- 本清单不验移动端或语音打断。

## Pass Criteria

全部满足才算通过：

- 30 分钟泛听过程中，软打断不暂停、不抢焦点、不展开学习 UI。
- 硬打断会暂停并进入诊断/精听借用路径，用户可以继续播放回到泛听。
- 结束会话可跳过或填写理解度自报；事件落库。
- Inbox 能完整展示标记项，含字幕 snapshot、上下文、可回听时间窗。
- 每个整理去向都能成功执行，处理后 active Inbox 不再显示该项。
- 重启后 active/archived 状态和处理结果一致。
- 默认播放器路径没有主动学习提示、红点压力或强制清零文案。

任何一条不满足，记录为 FAIL 或 BLOCKED。
