# Phase 3.6.2 Plan: Dictionary Inline Clip UX

状态：COMPLETED（2026-07-11 owner 收口）

上游：冻结的 `../3.6-listening-dictionary-mvp/3.6-CLOSEOUT.md`、Phase 3.5.7 的第二解码
播放核心、owner 对词典页截图的 UX 反馈。

## Objective

将词典详情中“根 Stack 上覆盖页面的 `SlicePlaybackWindow`”改为详情内容中的内嵌切片卡片。
当前选中切片在词条详情内显示原句、来源、时间、默认视频播放控制和可按需隐藏视频；多个切片通过
水平轨道切换。保留一个第二解码实例，切换卡片只重载同一个 controller，不为每张卡创建播放器。

## Product Decision

3.5.7 的独立**播放核心**继续复用；错误的是其浮窗 renderer 被词典页复用。词典详情的切片
播放器不是 modal、dialog 或 overlay，必须是页面文档流里的内容卡。侧面板/工作台来源句入口
不在本阶段改变。

## Scope

### In

- `VocabularyScreen` 移除词典页根 `Stack` 的 `SlicePlaybackWindow`。
- 新建内嵌 `DictionaryInlineClipPlayer`，绑定既有 `SlicePlayerController`，默认显示视频，
  支持播放/暂停、重播、循环和隐藏视频。
- `ListeningDictionaryEntryView` 维护当前选中 source occurrence；在“你的来源切片”下显示
  当前内嵌卡，并以水平可滚动轨道呈现多个切片。键盘/鼠标轨道操作不制造额外 decoder。
- 保留现有义项文件夹的手动归类、逐例标记、复习入口、语速排序与语料库搜索行为。
- 为 controller 绑定、内嵌卡、水平轨道与“无 overlay”补 Flutter widget 测试。

### Out

- 不改 Rust/SQLite/OpenAPI/词典资产数据模型。
- 不改变 3.5.7 工作台/侧面板来源句的浮窗行为。
- 不为每个卡片创建播放器，不做预解码缩略图缓存、AB loop 或新音频算法。

## Slices

1. **Renderer seam**：将词典播放选择状态与 `SlicePlayerController` 绑定传入详情视图，移除
   根层 overlay。
2. **Inline player + rail**：实现内嵌当前卡和横向切片轨道，保持全部既有操作出口。
3. **Verification + closeout**：Flutter analyze/test、真实词典页 QA；通过后单独收口，不回写
   冻结的 3.6 / 3.6.1 文档。

## Exit Signals

1. 点击某个词典切片后，播放器占据其详情内容区，不遮挡整个词典页面。
2. 选择另一张切片只切换当前内嵌播放器；任何时刻仅有一个第二解码实例。
3. 多切片可横向浏览，当前选择清晰且源句/来源/时间可见。
4. 视频展开、文件定位失败和主播放器音频焦点策略仍正确。
