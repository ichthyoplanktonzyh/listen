# Phase 3.6.2 Closeout: Dictionary Inline Clip UX

> 收口于 2026-07-11 08:37 CST  
> 状态：COMPLETED（owner 确认收口）

## Summary

本阶段纠正了 3.6 词典页错误复用 `SlicePlaybackWindow` 的问题。切片播放核心仍是同一个
第二解码实例和媒体 resolver，但词典详情不再使用根 `Stack` 覆盖页面；当前切片改为详情
文档流内的卡片，默认直接展示视频。

多个切片通过 `PageView` 轨道切换：鼠标/触控可左右滑动，左右箭头与键盘左右键可换片，空格
播放/暂停。旧的未归类竖向重复卡片移除；其显示原句、加入复习、播放操作收敛到轨道卡。

## Delivered

- `VocabularyScreen` 移除词典路径根层的 `SlicePlaybackWindow` overlay。
- 新增 `DictionaryInlineClipPlayer`：来源句、来源信息、时间范围与视频在一个紧凑内嵌卡中；
  视频默认显示，高度固定为 320px，音频模式是后续可选的“隐藏视频”控制。
- `ListeningDictionaryEntryView` 新增可翻页切片轨道；保留复习、显示句子和播放出口。
- 轨道支持鼠标/触控横向滑动、左右箭头、左右键切片与空格播放/暂停，切换时复用单一第二解码实例。
- 更新旧竖向卡片测试为轨道交互契约，并新增内嵌 renderer 不含 `Positioned` 的 widget 测试。
