## 方案要点（摘自上游文档）

- 把精听练习从右侧面板独立成**可拖动浮动小窗** + **迷你播放器**。
- 入口统一到姿态栏"测一下"下拉（挖空 / 语块听写 / 句子听写）;移除右侧面板底部的 Practice Tab。
- 小窗内：左侧练习区（题目/输入/提交/结果/词级 diff/加入复习队列），右侧迷你播放器（◀ ⏸ ▶ + 返回标签页），底部进度（第 N / 总句）。
- ◀▶ 切句天然替代"跳过";× 直接关闭并清除循环态，无 session 概念。
- **移除**：卡点标记 / 跳过 / 悬案区 / Session Summary / 精听完毕。
- 跟一下（Shadowing）入口保留禁用态，待 3.8 复用同一浮动小窗框架。
