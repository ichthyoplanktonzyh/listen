# Phase 3.5.6 Closeout: Intensive Practice Floating Window

> 收口于 2026-07-10 15:20 CST  
> 状态：COMPLETED（真实媒体手工 QA 已由 owner 豁免）

## Summary

本阶段把精听练习从右侧 `PracticePanel` 重构为可拖动的 `IntensivePracticeWindow`。用户现在从
姿态栏“测一下”直接进入挖空、语块听写或句子听写；浮窗内完成作答、diff、重试、加入复习队列、
播放器最小控制和相邻句连续练习，随时可关闭退出。关闭会清理练习范围循环与瞬态题目状态，消除
原有“练习完成后不知道如何退出”的 P0 问题。

同时，本阶段落实了对 Phase 3.2 精听卡点/session 机制的产品判断反转：卡点、跳过、悬案区、
session summary、diagnosis-viewed 与“精听完毕”产品 surface 全部移除。耐久学习事实没有删除：
`PracticeItem`、`PracticeAttempt`、`ReviewItem` 及历史 `learning_events` 仍保留；只是历史卡点事件
不再被聚合投影为用户可见的悬案或本次总结。

实现提交：`84e11aea feat(practice): add intensive floating window`。

## Key Decisions

- 精听不再拥有“完成 session”的用户心智；一题一结果与可随时关闭是唯一可见进度。
- 泛听 completion 不是精听撤回的附带删除对象，因此改为专名 use case/route，避免通用 practice
  completion 再泄漏回精听。
- 历史 stuck-point event kind 为序列化兼容而继续作为可解码的历史事实存在，但不再有写入口、
  读侧聚合或 UI 消费。
- 真实媒体手工 QA 未执行，按 owner 明确决定豁免；自动化验证作为本阶段收口证据。
