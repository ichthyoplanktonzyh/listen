## Questions And Real Implementations

### A. In-process local path: FastEmbed 5.17.3 + ONNX

- Runtime：Rust `fastembed 5.17.3`，`ort 2.0.0-rc.12`；关闭默认 feature，仅启用 rustls
  Hugging Face transport 与 rustls ORT binary。
- Model：`Qdrant/all-MiniLM-L6-v2-onnx`（对应
  `sentence-transformers/all-MiniLM-L6-v2`），revision
  `5f1b8cd78bc4fb444dd171e59b18f3a3af89a079`，ONNX blob SHA-256
  `bbd7b466f6d58e646fdc2bd5fd67b2f5e93c0b687011bd4548c420f7bd46f0c5`。
- Output：384-d float32；mean pooling；application 在 read 时做 cosine，不假设 provider 已输出
  unit vector。query/document 对本模型是 symmetric input、无 purpose prefix。
- 真实 smoke（四条英文句子）：首次下载+load 72,667 ms，embed 8 ms；热 load 81 ms，embed
  5 ms。cosine：large/enormous `0.759418`，large/coffee `0.051122`，large/weather

  footprint 约 187 MB。模型权重不进入 base bundle。
- Offline：下载完成后相同 cache 在断网条件可 load；产品构造/capability/search 不下载，只有显式
  install endpoint 调用模型 retrieval。
- production `ManagedFastEmbedProvider` 也在同一真实 cache 完成 install/descriptor/embed smoke：
  revision 与 384-d 校验通过，完整 contract fingerprint 为
  `3baadbcd6bd877c20e7d832a45bdba5255efb408c1756a1d3918d160dbf369e0`。

### B. Heterogeneous local HTTP path: Ollama + all-minilm

- Runtime：本机 Ollama HTTP `/api/embed`；模型 pull 约 45 MB；请求传数组并设置
  `truncate=false`。
- Output：384-d；Ollama 文档声明 `/api/embed` 返回 L2-normalized vectors。
- 同一组四句的首次请求 total 818.52 ms、load 554.09 ms；热请求 total 55.54 ms、load
  26.84 ms。cosine：large/enormous `0.907033`，large/coffee `0.087383`，large/weather
  `0.049546`。
- 关键发现：即便两边都叫 MiniLM、都是 384-d，tokenizer/制品/runtime 路径产生的数值空间也
  不能视为同一空间。model name + dimension 绝不足以判定兼容。

此外，production seam 实现了 OpenAI-compatible `/v1/embeddings` adapter contract，并用本地
HTTP fixture 实测乱序 response index 重排。它只表示 wire compatibility；remote 的 model version、
dimension、normalization 必须由显式 profile 提供，artifact 不可观测时 descriptor 诚实记录
`remote-artifact-unavailable`，v1 composition 不默认启用、不发送 corpus。

## Storage / Retrieval Decision

选择 SQLite `BLOB`（float32 little-endian）+ application cosine top-K：

- 当前是个人媒体/产出语料，baseline 无需向量 DB、SQLite extension 或另一个服务；source filter
  后线性 scan 的可解释性和部署成本优于尚无规模证据的 ANN。
- v42 表只存 source kind/id、language/channel、source text SHA-256、model fingerprint、dimension、
  vector 和时间；不复制 authoritative source text，不存 learner/evidence/proposal identity。
- 全量 rebuild 先完成 source derivation + embedding，再在单一 SQLite transaction 内 replace。
  provider/codec/SQL 任一步失败时旧索引保持可读。
- 查询只在 descriptor 的 exact fingerprint 下读取，并重新核对 current source identity/text hash；
  source 增删改或 model contract 变化立即呈 `stale`，不会把旧向量配到新文本。
- 以后只有实测线性 scan 超出交互预算时，才在同一个 repository port 后引入 ANN；HTTP/domain
  contract 不需要随 storage implementation 改变。

## Fingerprint / Rebuild / Migration Contract

`model_fingerprint = SHA-256(provider_id, model_id, model_version, runtime_version,
artifact_sha256, dimension, normalization, purpose_contract, index_schema_version)`。

- 任一字段变化：旧 index `stale`，禁止 cross-space compare、padding、truncation 或 in-place migration。
- 恢复路径只有从 media corpus / production corpus projection 全量重建。
- production document 继续只来自 completed immutable writing attempt 或 finalized/completed local-authoritative
  realtime learner turn；provider transcript 不进入 source adapter。
- production lexeme 是同一 production projection 的 distinct read source，只用于给既有 3.15.6 target
  找解释性 near-semantic clue；它不能制造 target 或写任何 learning fact。

## Lifecycle / Degradation Contract

实际 runtime 足以支持五个稳定状态：`not_installed / ready / stale / failed / disabled`。安装是单次显式
HTTP 操作；FastEmbed/HF 同步 retrieval 没有可复用的结构化 byte-progress/cancel hook，因此本阶段不伪造
百分比或“已取消”状态。UI 显示 indeterminate installing，失败回到 typed error；后续若换 downloader seam，
可 additive 增加真实 progress/cancellation。

- not installed / disabled / failed：semantic result 为空且附 capability/reason；exact FTS、播放、Studio、
  3.15.6 v1 gap 和 TTS 不受影响。
- stale：拒绝 semantic hit，要求原子 rebuild；不会混用旧/新空间。
- uninstall：删除模型 bytes 和 derived vectors；不触及 corpus source、attempt、observation、evidence、
  capability、proposal、review 或 TTS cache。
- unsupported language：v1 local model descriptor 是 English-first；UI/API 可按 language filter，模型质量不被
  宣称为多语能力。未来 provider descriptor/profile 可扩展语言 support，而不改变 source ownership。
- low memory/runtime failure：请求返回 typed provider failure；旧索引/authoritative data 保留，exact path
  可继续使用。
