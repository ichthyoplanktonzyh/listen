# Phase 3.4.4 Closeout: Learning Evidence Channelization

完成时间：2026-07-07 CST

## 交付内容

1. **ADR 0017**：通道化追加式 LearningObservation、任务→通道映射 v1、投影写入者互斥
   （升级确认声明为过渡直写）、legacy backfill 与便携资产策略。
2. **Domain**（`crates/domain/src/learning_observation.rs`）：`LearningObservation` 契约、
   四个枚举、追加式身份指纹（entry + task + **outcome** + source_ref + occurred_at）、
   映射单点定义（marking / practice / review / upgrade confirmation）。
3. **Persistence schema v23**：`learning_observations` 追加式表 + entry/capability 索引 +
   entry 级联删除；未清除 legacy LexicalObservation 幂等回填（origin=legacy_backfill）；
   repository 追加/分页查询方法。
4. **写入路径接线（四条全部）**：上下文标记双写、练习成功与失败均记录（修复失败偏置）、
   复习按 rating 映射（source/anchors 去重）、升级确认入证据流。
5. **便携资产**：bundle 追加 optional `learning_observations`（版本仍 6），导出全量、
   导入按 id 幂等、跳过本地缺失 entry。
