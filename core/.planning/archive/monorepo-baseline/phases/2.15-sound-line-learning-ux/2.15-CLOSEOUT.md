# Phase 2.15 Closeout: Sound Line Learning UX

状态：COMPLETED

## Summary

Phase 2.15 将 Phase 2.14 已有的声音线能力推进到用户可感知的学习闭环：

- 设置中继续保留文字线 phoneme ribbon 与声音线 sound pattern ribbon 的独立开关。
- 文字线默认表达“字幕单词对应的稳定教学音素”。
- 声音线获得独立视觉身份：音频图标、不同色彩组、圆角形态、音节/韵律短语分隔和独立 tooltip。
- 声音线只消费真实 `sound_analysis.learning_phones`，无 `sound_analysis` 时显示轻量不可用状态，不做词典或 raw CTC fallback。
- evidence marker 从内部 finding/status 文案改为学习者友好的表达：
  `supported by audio`、`possible linking`、`possible reduction`、`possible deletion`。
- raw CTC observed label 继续只作为 evidence/timing 来源，不作为默认教学标签泄漏到声音线。
