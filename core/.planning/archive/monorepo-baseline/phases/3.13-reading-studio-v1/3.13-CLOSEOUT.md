## Key Decisions

1. **段落分组 = 派生投影不落库**；身份 = 首 cue id，位置游标直接锚定 cue。
2. **位置是 cursor 不是 evidence**：v37 upsert，历史由 attempt/judgment 族承担。
3. **无 LLM 默认路径为一等公民**：manual rubric + 自评 judgment
   （`SemanticGeneratorKind::Manual`），自评永不冒充 gold。
4. **读听差异不比较跨 rubric judgment**：各侧独立归约（adjudication 最新生效、
   abstain=未评估），并置为 possibilities；先读后听是产品语义不是污染。
5. **rubric lookup 是读端 additive seam**（§3.6 标准）：不改身份铸造，不改
   append-only 语义。
6. **阅读证据只来自显式标记**：段落任务结果永不批量写词级 observation
   （负向测试钉住）；assistance 按翻译可见性记录，镜像 listening 不变量。
