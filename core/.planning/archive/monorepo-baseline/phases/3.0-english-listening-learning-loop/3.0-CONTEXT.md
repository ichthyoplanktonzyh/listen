# Phase 3.0 Context: English Listening Learning Loop

状态：PLANNED

## Why This Phase Exists

Phase 2 的主线把 LLPlayerNext 从普通字幕播放器推进到真实声音流学习底座：

```text
WordTimeline
  -> ChunkTimeline
  -> PhoneTimeline
  -> sound_analysis.learning_phones
  -> connected_speech explanations
  -> sound-line marker playback
```

Phase 2.18 又把代码架构和学习资产模型收敛到
`LexicalEntry + LexicalUnit + LearningStatus`，为后续学习体验扩张提供了清晰边界。

Phase 3.0 的存在不是为了继续堆功能菜单，而是为英语作为第一门学习语言建立完整学习闭环：

```text
真实输入
  -> 可理解度判断
  -> 听力障碍诊断
  -> 主动验证练习
  -> 复习巩固
  -> 进度反馈
  -> 回到真实输入
```

本阶段的产品判断是：

> 真正的语言能力来自听力突破；听力突破来自大量可理解输入，以及对真实声音流的可复现、
> 可解释、可验证训练。

因此 Phase 3.0 的核心不是“播放器 + 背单词 + 发音评分”，而是：

> 帮用户把真实英语听懂，并知道自己为什么没听懂、下一次该怎么练。

## Product Thesis

LLPlayerNext 的学习体验应围绕真实声音流，而不是围绕抽象知识点。

产品需要同时服务两种输入：

- **大量泛听输入**：降低打断，帮助用户积累可理解输入量。
- **高密度精听输入**：围绕句子、chunk、词汇、语流现象和 L1 transfer 进行诊断与练习。

常见语言学习软件能力可以吸收，但必须被重新解释为听力本位能力：

| 常见能力 | Phase 3.0 中的解释 |
|---|---|
| 背单词 | 在真实音频中识别词汇，而不只是回忆释义 |
| Anki / SRS | 复现真实片段中的听觉识别失败，而不只是卡片复习 |
| 听写 | 验证用户是否能从声音流主动恢复文本 |
| Cloze | 验证 `known_recognized` 是否真的能在语境中听出 |
| 发音练习 | 从听懂和模仿真实语流出发，先做 shadowing / A-B 对比 |
| 统计仪表盘 | 解释听力障碍变化，而不是泛泛记录打卡时长 |
| 课程路径 | 根据用户真实失败记录生成输入处方，而不是固定关卡 |

## Core Learning Beliefs

### 1. Listening-First

语言能力的核心突破点是对真实声音流的稳定理解。文字、词典、音标、语法、翻译和笔记都是解释层，
不是最终目标。

用户最终需要能做到：

- 在自然语速中切分 chunk。
- 在弱读、连读、省音、闪音、缩约中识别词汇。
- 在没有完整字幕提示时理解句子。
- 在不同说话人、不同材料和不同语速中迁移识别能力。

### 2. Comprehensible Input

学习系统必须帮助用户找到并持续消费合适难度的输入。

“合适”不是只看 CEFR 或总词汇量，而应综合：

- 未知词密度。
- `known_not_recognized` 密度。
- chunk 长度和复杂度。
- 语速。
- connected-speech 现象密度。
- 字幕、WordTimeline、PhoneTimeline 的资源质量。
- 用户过往在类似片段中的练习表现。

### 3. Diagnosis Before Drills

练习不应只问“做对了吗”，而应解释“为什么没听懂”。

Phase 3.0 的诊断层至少包含：

- 词义障碍：不知道这个词或短语。
- 声音识别障碍：知道含义，但在真实音频中听不出。
- Chunk 障碍：无法实时切分或处理语块。
- 真实语流障碍：weak form、deletion、linking、assimilation、contraction、flapping 等。
- L1 transfer 障碍：母语听觉系统对 L2 声音流产生错误预期。

### 4. Active Verification

诊断必须被主动验证。系统说“这个词你应该能听出”并不够，用户需要在真实音频中证明。

优先验证方式：

- Cloze：隐藏目标词，听音频填空。
- Dictation：听 chunk / sentence 写出文本。
- 字幕渐隐：逐步从看字幕过渡到听声音。
- Shadowing：跟读真实 chunk 并进行 A-B 对比。

练习失败应优先写入 `LexicalObservation` 或练习记录。全局 `LearningStatus` 仍以用户确认作为权威，
系统不应静默自动降级。

### 5. L1-Aware Learning

学习者听不懂 L2，不只是因为 L2 本身难，也因为大脑会自动用 L1 的音系、词边界、节奏和语义习惯
去解析 L2。

Phase 3.0 应把 L1 与 L2 明确建模为独立维度：

- UI language：界面语言。
- L1：学习者母语或主要语言背景。
- L2：当前学习语言。

首个真实闭环目标是：

```text
L1 = Mandarin Chinese
L2 = English
```

Mandarin -> English 的初版难点表应覆盖：

- 英语 stress-timed rhythm 与中文听觉预期差异。
- 弱读功能词，例如 `of`、`to`、`for`、`and`、`have`、`would`。
- schwa 和 reduced vowels。
- 词尾辅音、辅音连缀和爆破释放。
- t/d deletion、flapping、linking。
- `gonna`、`wanna`、`gotta`、`didja`、`woulda` 等压缩形式。

L1-aware 提示不应变成长篇语法课。最佳形态是：

```text
短解释
  -> 真实片段回放
  -> 立即练习
  -> observation / review item
```

## Relationship To Existing Architecture

Phase 3.0 应复用 Phase 2 已经建立的核心资产：

| Existing asset | Phase 3.0 use |
|---|---|
| `LexicalEntry + LexicalUnit + LearningStatus` | 听力驱动词汇状态、cloze、SRS、个人语料搜索 |
| `LexicalObservation` | 记录语境内识别成功/失败，不静默覆盖全局状态 |
| WordTimeline | 词级播放窗口、cloze 对齐、听写 diff、YouGlish-like 搜索 |
| ChunkTimeline | chunk replay、chunk dictation、逐步展开、shadowing |
| PhoneTimeline / `sound_analysis` | 声音线解释、connected-speech 回放、发音/跟读对比 |
| Language profile | L2 能力矩阵与语言差异化降级 |
| LANG-009 seam | L1-aware diagnosis 的未来入口 |
| Flutter typed controllers | 精听/泛听模式、练习状态、复习队列的 UI 状态基础 |

Phase 3.0 不应重新引入旧 `WordProfile` / `WordObservation` 路径。

## Scope Boundaries

### In Scope

- 英语听力学习闭环的产品路线图。
- 精听 / 泛听体验分离。
- 可理解输入与材料难度信号。
- 字幕渐隐、cloze、听写、chunk-first 训练。
- 本地 YouGlish-like 个人真实语料库。
- 听力驱动词汇复习与 native SRS。
- Mandarin -> English 的 L1-aware diagnosis 和专项练习。
- Shadowing 和录音 A-B 对比的轻量闭环。
- 诊断型学习统计。

### Non-Goals

- 不在 Phase 3.0 方向文档中拆分每个后续小 phase 的详细执行任务。
- 不把 Anki 作为核心数据模型；Anki export / AnkiConnect 可以作为后续互操作层。
- 不承诺 ELSA 式复杂发音评分作为第一版发音能力。
- 不过早扩张到多门 L2 的完整体验闭环。
- 不把 AI 聊天、作文批改、大而全语法课程或游戏化排行榜作为近期主线。
- 不绕过 Phase 2.17 的真实媒体声音线 QA。

## Product Completion Definition

英语作为第一门语言的 Phase 3.0 闭环可以被认为成立，当且仅当用户能够完成：

1. 导入真实英语视频或音频。
2. 系统给出词级、chunk、声音线学习视图。
3. 系统帮助判断材料难度与精听/泛听适配度。
4. 用户可以通过字幕渐隐、cloze、听写验证自己是否真的听懂。
5. 失败结果能回写为 observation、练习记录或复习项。
6. 词汇学习围绕真实音频片段和来源 chunk 展开。
7. 用户可以在个人语料库中搜索词、短语、chunk 和语流现象。
8. 系统能为 Mandarin L1 的英语学习者提供 L1-aware 诊断提示。
9. 用户可以进行 chunk-level shadowing 和录音 A-B 对比。
10. 仪表盘能显示听力障碍类型、复习表现和同一材料理解度提升。
