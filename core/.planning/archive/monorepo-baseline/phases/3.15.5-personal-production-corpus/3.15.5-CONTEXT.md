# Phase 3.15.5 Context: Personal Production Corpus

日期：2026-07-16

## 实施裁决

个人产出语料库是 `SemanticTaskAttempt` 之上的**可重建查询投影**，不是新的学习资产或
证据权威。Writing attempt 先成功落库；增量索引失败不回滚用户作答，全量原子重建是恢复
路径。投影可以整体删除，immutable attempts 仍足以恢复全部内容。

投影分两层：document 每个最终 learner response 只保存一份全文与来源；entry 只保存
lemma key、surface form、Unicode-scalar span 和 document 引用。这样词典可统计同一回答中
多次出现，又不会为每个 token 复制整段回答。单词查询复用 lexical normalization 路径，
短语查询使用 document FTS phrase match。

## Assistance 不是自治判决

本 phase 不保留原计划的 `scaffolding: bool`。这个布尔值会把“有上下文、有提示、有修订”
错误压成“自主/非自主”结论，也容易让未来复盘把合法 learner output 静默排除。

投影只记录可观察的 assistance provenance：内容锚定、来源重构、用户修订，以及为后续真实
consumer 预留的明确目标、模型建议、直接模仿、未知。3.15.6 可以透明地按复盘目的选择
权重或分组，但不得改写事实。当前 Writing writer 只产生 `written`，没有 spoken writer。

## 与 Phase 3.16 的资产边界

裁决如下：

- 产出语料 document/entry 是从 attempts 派生、可删除重建、没有独立用户意图的查询投影。
- 3.16 个人模板是用户显式收藏/编辑/命名后形成的 durable asset，拥有独立身份和生命周期。
- 3.16 可以从产出语料发现候选，并引用 `attempt_id` / document 作为 provenance；但不得把
  corpus document id 当成模板身份，也不得让重建/删除投影删除模板。
- 同一句文字可以同时出现在语料与模板中：前者回答“我在哪里用过”，后者回答“我决定以后
  复用什么”。这不是两套互相竞争的“用户语言”，而是事实投影与用户资产两个层次。

这一边界延续项目开放性原则：共享事实与生命周期 seam，不强迫未来的对话、复盘、词典和
模板 surface 共享同一种界面。
