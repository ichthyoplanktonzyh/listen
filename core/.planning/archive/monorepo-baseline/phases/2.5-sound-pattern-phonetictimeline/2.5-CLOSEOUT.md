# Phase 2.5 Closeout: Sound Pattern And PhoneTimeline

> 日期：2026-06-22
> 状态：完成

## 结果

Phase 2.5 已把真实声音模式的承载对象从一次性 `PhoneticAnalysis` 结果升级为可管理、
可激活、可导入导出、可播放消费的 `PhoneTimeline` 资源。

本阶段不选择 release-grade real-audio phone recognizer。当前 provider gate 结论是
**no release provider selected**：研究 fixture、TIMIT gold、ZIPA/MFA/Wav2IPA 等候选可以继续
输出统一 PhoneTimeline 契约，但没有通过 benchmark、许可证和真实语流保真度审查的 provider
不得进入默认 product path，也不得默认声称 `detected_in_audio`。

## 完成内容

### 后端资源契约

- `domain` 新增 `PhoneTimeline`、`PhoneTimelineSummary`、`PhoneTimelinePrecision` 和
  `PhoneTimelineId`。
- SQLite schema v14 新增 `phone_timeline_runs`。
- `SubtitleRepository` 增加 PhoneTimeline save / list / get / active / activate / archive /
  delete。
- completed `PhoneticAnalysis` 会桥接生成 PhoneTimeline candidate。
- `research-fixture` 桥接结果标记为 `approximate`，并保留 synthetic provenance。
- LLTimeline export/import 保留 PhoneTimeline candidates 和 `active_phone_timeline_id`。
- TIMIT benchmark dataset 生成器迁移到新 PhoneTimeline 契约。

### API 与契约

- 新增：
  - `GET /v1/subtitles/{track_id}/phone-timelines`
  - `GET /v1/subtitles/{track_id}/phone-timelines/summary`
  - `GET/DELETE /v1/phone-timelines/{timeline_id}`
  - `POST /v1/phone-timelines/{timeline_id}/activate`
  - `POST /v1/phone-timelines/{timeline_id}/archive`
  - `GET /v1/phone-timelines/{timeline_id}/export`
- OpenAPI v1 和 generated local API client 已同步 PhoneTimeline schema。

### Flutter 消费端

- `LocalApi`、timeline models、`SubtitleController` 已接入 PhoneTimeline。
- Timeline Resource Summary 显示 PhoneTimeline candidates，并支持激活、归档、删除。
- 播放器/诊断侧优先消费 active PhoneTimeline；无 active PhoneTimeline 时回退旧
  `phonetic-analyses`。
- 当前 phone lookup 继续在客户端本地完成，不引入播放位置高频 API 往返。
- Diagnosis Card 可显示 active PhoneTimeline 的 sound pattern phones、findings、provider /
  model / phone set provenance，并支持点击 phone loop。

### Provider Benchmark Gate

- 新增 `2.5-BENCHMARK.md`，记录候选 provider 状态、质量门槛和 no-release-provider 决策。
- 复用 Phase 2.0 research infrastructure：
  - `scripts/phonetic-eval.py`
  - `scripts/phonetic-research-adapter.py`
  - `scripts/verify-m20-phase0.sh`
  - `testdata/phonetic-analysis/*`
