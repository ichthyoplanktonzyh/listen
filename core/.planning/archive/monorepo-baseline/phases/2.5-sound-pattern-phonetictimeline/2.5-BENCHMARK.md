# Phase 2.5 Provider Benchmark And Quality Gate

更新时间：2026-06-22 09:04 CST

## Decision

Phase 2.5 不选择 release-grade real-audio phone recognizer。

本阶段收口策略是：

1. 先把 PhoneTimeline 作为一等资源打通。
2. app 可以管理、激活、导入导出和消费 PhoneTimeline。
3. `research-fixture` / TIMIT gold / 后续 ZIPA、Wav2IPA、MFA phone alignment 都必须输出同一
   PhoneTimeline 契约。
4. 没有通过 benchmark 和许可证审查的 provider 不进入默认 product path，也不得产生默认
   `detected_in_audio` 结论。

## Candidate Status

| Candidate | Current role | Release decision | Reason |
|---|---|---|---|
| MFA phone alignment | forced-aligned/canonical boundary candidate | not detected provider | MFA 可提供 phone-level alignment，但主要对齐 canonical phone，不证明真实弱读/省音/闪音 |
| ZIPA 64M / ZIPA CTC | research candidate | not selected | harness 已存在，但模型许可证元数据、真实音频校准和 timestamp projection 仍未过门槛 |
| Wav2IPA / Wav2Vec2Phoneme | research candidate | not selected | 需要锁定具体模型、训练数据 provenance、Apple Silicon 成本和实际 connected-speech 保真度 |
| Allosaurus | baseline only | not selected | 可做跨语言 baseline，但不作为默认英语学习 provider |
| deterministic research fixture | test fixture | synthetic only | 只能验证 lifecycle、UI 和 feedback，不是真实音频检测 |
| TIMIT phone gold | benchmark/gold import | aligned gold resource | 可作为 phone timeline gold fixture，不代表可发布 provider |

## Quality Gate

一个 provider 进入默认 product path 前必须同时满足：

- 输入数据：至少 10 条 development cases 通过 `validate-inputs`，最终 test split 50-100 条固定用例。
- 时间轴：phones 单调、位于音频范围内、可映射到 sentence/token 或明确说明不可映射。
- 真实语流：不能把实际弱读、省音、闪音、缩约规范化回字典发音后仍声称 detected。
- 指标：记录 PER、timeline validity、token association coverage、failure rate、RTF、peak RSS、
  model size。
- 诊断：高置信 weak form / deletion / flapping / assimilation / contraction / linking findings
  需要人工 precision review。
- 来源：provider/runtime/model revision、checksum、训练数据 provenance、许可证和分发边界明确。
- 产品诚实：低置信、canonical-only、fixture、license-pending 结果不得标成默认
  `detected_in_audio`。

## Phase 2.5 Benchmark Outcome

Phase 2.5 以 **no release provider selected** 收口。

这不是失败，而是符合阶段原则：

- PhoneTimeline contract、lifecycle、LLTimeline import/export 和 app consumption 已可继续承载
  后续 provider。
- Sound Pattern View 可以消费 active PhoneTimeline，但 UI 必须显示 provider / precision /
  confidence / synthetic provenance。
- 后续真正模型工程化应作为新 phase 或 research batch 继续推进，不阻塞 Phase 2.5 资源闭环。
