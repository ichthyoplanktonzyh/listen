# 词汇来源原句记录方案

> Phase 3.5.5 子项，来源于词汇学习面板 UX 走查讨论
> 日期：2026-07-09

---

## 问题

### 问题 1：修改状态后来源原句未记录

点击字幕词汇 → 打开 WordLearningPanel → 通过 4 通道能力画像改为 `not_acquired` → 来源原句区域为空。

**根因**：`setCapabilityOverride()` 路径不传 `source`，后端不写 `lexical_occurrence`。旧状态 ChoiceChips 路径 (`setSelectedWordStatus`) 正常记录，但 4 通道 UI 已取代旧状态 UI，用户只能走能力覆盖路径。

| 路径 | UI | 是否传 source | 是否记录 occurrence |
|------|-----|:------------:|:-----------------:|
| 旧状态 ChoiceChips | `onStatus` → `setSelectedWordStatus` | ✅ | ✅ |
| 4 通道能力覆盖 | `onCapabilityOverride` → `setCapabilityOverride` | ❌ | ❌ |

### 问题 2：已标记词汇再次遇到无法加来源

某词已标记为 `not_acquired`，用户在另一句话中再次遇到同一词，点击后面板已显示标记状态，没有途径将当前句添加为新的来源原句。

**根因**：`openWord()` 在词汇已缓存时跳过 upsert，全程不传 source，不写 occurrence。

---

## 设计原则

### 记录来源原句 = 记录"遇到"，不绑定状态变更

`lexical_occurrence` 的语义是 **"用户在这个句子中遇到了这个词"**，是一个独立事实。是否记录与状态变更解耦。

### 触发方式：两种

| 触发方式 | 行为 | 场景 |
|---------|------|------|
| **自动触发** | 用户将任一通道改为 `not_acquired` 时，自动记录当前语境句 | 用户首次标记"未掌握" |
| **手动按钮** | 面板来源原句区按钮"记录当前句"，点击后记录 | 已标记词汇再次遇到，用户主动添加 |

### 记录的是"点击词所在的句子"

手动按钮记录的是 `selectedCue`（用户点击词汇时的那句话），与播放器当前播放位置无关。用户点击词汇时焦点的句子就是来源句。

### 旧状态移除

后续独立 phase 移除旧状态 ChoiceChips（不认识/认识但听不出/已掌握），面板仅保留 4 通道 UI。

## 改动清单

### 1. `openWord()` 补 source

**文件**：`apps/desktop/lib/controllers/learning_workflow_controller.dart`

每次点击词汇时，无论词汇是否已存在，都通过 `upsertWordLexicalEntry` 传入 `source` 参数。

- 不修改 `status`（保持 `null`），仅记录 occurrence
- 后端 `ON CONFLICT` 逻辑自动处理同一位置去重（递增 `encounter_count`）
- 不同句子自动创建新 occurrence

### 2. `setCapabilityOverride()` 在 `not_acquired` 时补 source

**文件**：`apps/desktop/lib/controllers/learning_workflow_controller.dart`

当 `conclusion == "not_acquired"` 时，额外调用一次带 `source` 的 upsert，记录当前句。

- 传递 `status: null`，不干扰能力覆盖的写入
- 仅在 `not_acquired` 时触发，`acquired` 或 `null`（取消覆盖）不记录

### 3. WordLearningPanel 加"记录当前句"按钮

**文件**：`apps/desktop/lib/widgets/panels/word_learning_panel.dart`

来源原句标题栏右侧新增按钮：

```
来源原句                    [记录当前句]
```

- 按钮置灰条件：无有效 `selectedCue` / `selectedToken`
- 点击后调用新增回调 `onRecordSource`

### 4. SidePanel / main.dart 串联回调

**文件**：
- `apps/desktop/lib/widgets/layout/side_panel.dart`
- `apps/desktop/lib/main.dart`

- `SidePanel` 新增 `onRecordSource` 回调参数
- `main.dart` 实现 `_recordCurrentSource()` → 调用 `learningWorkflowController.recordCurrentSource()`

### 5. `learning_workflow_controller.dart` 新增 `recordCurrentSource()`

```dart
Future<void> recordCurrentSource({
  required LocalApi? api,
  required String language,
  required LearningController learning,
  required bool Function() isMounted,
  required Map<String, dynamic>? Function(SubtitleToken token, Cue cue) sourceFor,
}) async {
  final token = learning.selectedToken;
  final cue = learning.selectedCue;
  if (token?.normalized == null || cue == null || api == null) return;
  final details = LexicalEntryDetails.fromJson(
    await api.upsertWordLexicalEntry(
      token!.normalized!,
      token.text,
      null,
      language: language,
      source: sourceFor(token, cue),
    ),
  );
  if (!isMounted()) return;
  learning.selectWord(details);
}
```

## 不做的

- 旧状态 ChoiceChips 的保留/移除（单独 phase 处理）
- 新增后端 API（复用 `PUT /v1/lexical-entries` 的 source 路径即可）
- `vocabulary_screen.dart` 不记来源（无字幕语境，保持现状）
