# 底部工具栏功能键溢出菜单方案

## 问题描述

进入播放页面后，底部工具栏的泛听、Chunk 模式、字幕模式三个功能菜单按钮，会在窗口宽度低于 1080px 时**整体消失**，仅保留一个标记收件箱的图标按钮。

**影响：**
- 窗口缩窄后用户无法通过鼠标点击进入泛听、Chunk 或字幕设置
- 泛听的核心操作（开始/结束、标记收件箱、硬中断）只剩快捷键可用
- 用户对窗口大小的操作预期是"重新排列"，而不是"功能消失"

**根因位置：**
[playback_controls.dart](file:///Users/shadow/LLPlayerNext/apps/desktop/lib/widgets/player/playback_controls.dart#L128-L130)

```dart
LayoutBuilder(
  builder: (context, constraints) {
    final roomy = constraints.maxWidth >= 1080;  // 硬阈值
```

当前窄窗口 `else` 分支（第 374-385 行）只渲染了一个 `bookmark_add_outlined` 按钮，其余全部跳过。

## 解决方案

### 1. 溢出菜单替代直接隐藏

将 `roomy` 分支逻辑改为：

- **宽窗口（>= 阈值）**：保持现状，三个功能菜单按钮平铺在工具栏上。
- **窄窗口（< 阈值）**：将三个功能菜单按钮**折叠进一个溢出菜单按钮**（`···` 或 `more_vert` / `more_horiz`），点击弹出菜单，内部以子菜单或列表项的形式提供三个功能的入口。

溢出菜单结构示意：

```
┌─────────────────────┐
│ 👂 泛听模式          │  → 点击弹出原有泛听子菜单
│ ─────────────────── │
│ 🧩 Chunk 模式       │  → 点击弹出原有 Chunk 子菜单
│ ─────────────────── │
│ 📄 字幕模式          │  → 点击弹出原有字幕子菜单
└─────────────────────┘
```

这样在窄窗口下所有功能仍然可达，只是多一次点击。

### 2. 阈值调整

当前 1080px 阈值偏高。建议结合工具栏实际占用宽度重新评估：

| 元素 | 大致宽度 |
|---|---|
| 时间戳 ×2 | ~108px |
| 进度条 | 弹性 |
| 播放控制按钮 ×4 | ~144px |
| 循环按钮 | ~36px |
| 三个功能菜单按钮 ×3 | ~330px |
| 倍速下拉 | ~72px |
| 音量按钮 | ~36px |
| 设置按钮 | ~36px |

实际功能按钮区（从上一句到设置）大约需要 800px+ 即可舒适应放。新阈值可以考虑 **840px~900px** 之间，或直接以工具栏 Row 的实际宽度通过 `LayoutBuilder` 动态决定。

### 3. 实现要点

- 溢出菜单按钮在窄窗口时始终显示，替代原先的单一 `bookmark_add_outlined` 按钮
- `bookmark_add_outlined` 收件箱标记功能可放入泛听子菜单内（窄窗口时），或作为溢出菜单的第一级常驻项
- 阈值降低后，`restart_alt`（重新开始）按钮在窄窗口中可以保留或也收进溢出菜单
- 改动范围仅限 [playback_controls.dart](file:///Users/shadow/LLPlayerNext/apps/desktop/lib/widgets/player/playback_controls.dart)
