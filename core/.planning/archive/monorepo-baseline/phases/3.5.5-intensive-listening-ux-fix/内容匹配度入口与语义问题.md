# 内容匹配度（Content Fit）入口与语义问题

> Phase 3.5.5，来源于精听模块 UX 走查讨论
> 日期：2026-07-09

## 问题描述

"内容匹配度"（Content Fit）功能难以被用户发现，且语义不够明确，UI/UX 语义需要重新设计。

## 现状

### 功能位置

1. **右侧面板 → "字幕资源"（第二个 Tab）** → 顶部 `ContentFitCard`
   - 路径很深：用户需要先切换到"字幕资源" Tab 才能看到
   - "字幕资源" 本质是技术管理面板（导入/管理字幕、timeline 资源），用户不会想到这里查看内容难度
   - 文件：[side_panel.dart](file:///Users/shadow/LLPlayerNext/apps/desktop/lib/widgets/layout/side_panel.dart#L333-L366)
   - 文件：[subtitle_resource_manager_panel.dart](file:///Users/shadow/LLPlayerNext/apps/desktop/lib/widgets/panels/subtitle_resource_manager_panel.dart#L132-L139)

2. **首页媒体库列表** → 每行 `_MiniFitChip`（Meaning / By ear 两个小标签）
   - 有展示但缺乏上下文解释，用户容易忽略
   - 文件：[media_library_section.dart](file:///Users/shadow/LLPlayerNext/apps/desktop/lib/widgets/home/media_library_section.dart#L251-L260)

### 命名问题

| 当前英文 | 当前中文 | 问题 |
|---------|---------|------|
| `contentFit` | 内容匹配度 | "匹配"什么？跟谁匹配？语义模糊 |
| `contentFitMeaning` | 理解 | 不够直观，用户可能不清楚这个维度代表什么 |
| `contentFitSound` | 听辨 / By ear | 不够清晰 |

### 核心矛盾

- 功能价值：告诉用户"这段材料对你来说难不难、适合精听还是泛听"——这是**内容选择决策的核心信息**
- 实际入口：藏在技术管理面板深处，用户不容易自然发现
- 用户预期：用户打开媒体或浏览媒体库时，最想知道的之一是"这个对我合适吗"，但当前 UI 没有在关键路径上回答这个问题
