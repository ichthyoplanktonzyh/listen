# 循环播放管理方案

## 问题描述

当前 App 中存在多处循环播放能力，但所有"循环"的管理入口分散且不统一，缺少全局可视状态。

### 现有循环类型

| 循环类型 | 触发方式 | 状态存储 | 停止方式 |
|---|---|---|---|
| **当前句循环** (cue loop) | 底部工具栏 `repeat_one` 按钮 | `subtitleController.loopCue` (bool) | 再次点击 `repeat_one` 取消 |
| **Chunk 循环** | Chunk 菜单 → "循环当前语块" | `playerController.sourceLoopStart/End` | Chunk 菜单 → "停止来源循环" |
| **展开循环** (expanded chunk) | Chunk 菜单 → "展开循环" | 同上 `sourceLoopStart/End` | 同上 |
| **听感 C 视图 Hotspot 循环** | Hotspot 点击 | 同上 `sourceLoopStart/End` | 同上 |
| **泛听循环** | 泛听模式自身无独立循环，但打断/标记涉及位置跳转 | 无独立循环状态 | 无 |

### 核心问题

**所有非 cue-loop 的循环共用同一个 `sourceLoopStart/End` 状态和同一个"停止来源循环"入口。**

具体表现：

1. **状态不明** — 当 `sourceLoopStart != null` 时，Chunk 菜单底部才会出现"停止来源循环"选项。但用户无法区分当前循环是 chunk 循环还是 hotspot 循环，也不知道循环范围是什么。
2. **入口隐蔽** — "停止来源循环"藏在 Chunk 菜单的最底部，还受 `sourceLoopStart != null` 条件控制。如果不先打开 Chunk 菜单，用户根本不知道在哪里停止循环。
3. **入口分裂** — 不同循环类型（chunk、hotspot、expanded chunk）各自触发循环，但停止入口却只有一个，且由 Chunk 菜单独占。Hotspot 触发的循环也要跑到 Chunk 菜单去停止，心智模型不匹配。
4. **无视觉反馈** — 循环激活时，底部工具栏没有统一的视觉指示（如高亮、badge、标签）告诉用户"当前处于循环模式"。

**根因代码位置：**
- 循环状态：[`sourceLoopStart/End`](file:///Users/shadow/LLPlayerNext/apps/desktop/lib/controllers/player_controller.dart#L137-L138) 在 `PlayerController` 中
- 循环执行：[main.dart `_onPosition`](file:///Users/shadow/LLPlayerNext/apps/desktop/lib/main.dart#L579-L584) 中检测是否到达 `sourceLoopEnd` 并跳回 `sourceLoopStart`
- 循环停止入口：[playback_controls.dart](file:///Users/shadow/LLPlayerNext/apps/desktop/lib/widgets/player/playback_controls.dart#L310-L318) 仅在 Chunk 菜单中条件渲染

## 方案建议

### 方案 A：统一循环状态指示器 + 浮动停止按钮（推荐）

**思路**：将循环视为一个"活跃模式"，用一个统一的视觉组件来指示和管理，独立于具体触发来源。

**具体设计：**

1. **新增 `activeLoop` 状态** — 替代原始的 `sourceLoopStart/End` 布尔判断，用一个枚举或结构体描述当前循环：

```dart
enum LoopType { chunk, expandedChunk, hotspot, ... }

class ActiveLoop {
  final LoopType type;
  final Duration start;
  final Duration end;
  final String label; // 显示用，如"语块循环"、"Hotspot 循环"
}
```

2. **底部工具栏新增循环状态指示区** — 在播放进度条上方或紧邻 `repeat_one` 按钮的位置，当 `activeLoop != null` 时显示一个带标签的 chip：

```
[ ⟳ 语块循环 ]  [ ⊗ 停止 ]
```

或

```
[ 🔁 当前句 ]  [ ⟳ Hotspot 循环 ]  [ ⊗ 停止所有循环 ]
```

3. **点击停止按钮统一停止** — 不再需要在不同菜单间跳转

4. **好处**：
   - 循环状态一目了然
   - 任何类型的循环都用同一个入口管理
   - 不影响原有的触发方式（Chunk 菜单、Hotspot 点击等照常设置循环）

### 方案 B：保留现有入口，但增加全局停止按钮

**思路**：较为保守，在底部工具栏常驻一个"停止循环"按钮，同时在循环激活时添加视觉反馈。

**具体设计：**

1. 将当前仅出现在 Chunk 菜单中的 `stopSourceLoop` 选项提升到底部工具栏第二行（状态行），当 `sourceLoopStart != null` 时显示
2. `repeat_one` 按钮选中时给予更明显的颜色区分
3. 在播放进度条上标记当前循环范围

### 方案 C：循环范围可视化

**思路**：在进度条上叠加循环范围的视觉标记，让用户直观看到正在循环的区域。

**具体设计：**

在进度条 `Slider` 下方或轨道上绘制两个标记点（`sourceLoopStart` 和 `sourceLoopEnd`），并用浅色背景高亮之间的范围。这样用户：
- 一眼知道当前循环覆盖哪段
- 拖拽进度条时也能感知循环边界
- 配合方案 A 的停止按钮，构成完整的"可见 + 可控"闭环
