# Phase 2.9 Plan: Production Engine Multilingual Decoupling

更新时间：2026-06-24 CST
状态：✅ COMPLETED — 收口文档见 2.9-CLOSEOUT.md

> 前置：Phase 2.8 完成了消费侧最后一块拼图（token timing alignment + 韵律估算）。
> 消费侧已语言无关。本阶段解耦生产侧对英语的绑定，让非英语语言也能走通
> "音频 → 精确时间轴 → app 消费"的完整链路。

## Objective

将生产管线从"英语专用 + 其他语言降级"转变为"语言感知派发 + 干净降级"：
1. 管线每个步骤按语言选择对应 provider/model，或显式降级
2. 中文作为首个非英语语言走通完整生产链路
3. 英语行为为回归基线，不退步

## Problem Statement

生产管线 5 个英语强绑定点：

| # | 组件 | 绑定 | 影响 |
|---|------|------|------|
| P1 | 转写后处理 | 管线不传播语言到后续步骤 | 后续步骤无法选择语言模型 |
| P2 | 强制对齐 | MFA/MMS_FA 只有英语声学模型 | 非英语无精确词边界 |
| P3 | 发音分析 | CMUDict + 英语规则硬编码 | 非英语无发音/规则分析 |
| P4 | 文本 chunk | COCA/PHRASE 英语词表门控 | 非英语无语义 chunk |
| P5 | PhoneTimeline | 无 release provider | 所有语言 approximate/unsupported |

## Steps

### Step 1: 管线语言传播

在转写管线中传播检测/声明的语言到后续每个步骤：
- `refine_transcription_word_timelines` 接收 `language: Option<LanguageCode>`
- 语言来自 whisper 检测（`detected_language`）或用户声明
- 后续步骤（强制对齐、pause refinement、chunk 生成）都能读到语言

### Step 2: 强制对齐语言感知降级

强制对齐 sidecar 接口支持传入语言参数：
- MFA/MMS_FA 如果有该语言模型则使用，否则跳过（而非失败）
- 英语继续走 MFA → MMS_FA → WhisperX 降级链
- 非英语暂时跳过强制对齐，依赖 whisper DTW + Phase 2.8 字符级对齐
- 为将来接入 MFA 多语言模型 / 其他对齐器留 seam

### Step 3: 发音分析 provider 化

`speech_analysis` 中的 `analyze_sentence` / `analyze_rules` 包装为
`EnglishPronunciationAnalyzer`，不再作为通用入口：
- `PronunciationProvider` trait 已有 `analyze_sentence` 方法
- 确认 `ChinesePronunciationProvider` 的发音标注路径在生产侧可用
- 非英语语言的 `analyze_sentence` 由对应 provider 实现，或返回空

### Step 4: 文本 chunk 检测语言感知

`detect_text_chunks` 的英语门控扩展为语言派发：
- 英语：继续使用 COCA/PHRASE 词表
- 中文：基于标点和句法边界的 chunk 检测（中文天然以标点分 chunk）
- 其他：降级为纯声学 chunk（已语言无关）

### Step 5: 中文端到端验证

用真实中文音频走通完整管线：
- whisper.cpp 中文转写 → DTW timestamps
- token timing alignment（Phase 2.8）
- 跳过强制对齐（干净降级）
- chunk 生成（声学 + 中文文本 chunk）
- pronunciation（CC-CEDICT pinyin）
- app 消费验证

### Step 6: 验证

- `cargo test --workspace` 全通过
- 英语生产管线回归（全链路不退步）
- 中文生产管线端到端（转写 → 时间轴 → chunk → 发音 → app 消费）

## Verification Criteria

1. 英语管线行为不变（回归基线）
2. 中文可走通 whisper 转写 → word timeline → chunk timeline → app 消费
3. 非英语强制对齐干净降级（不 panic、不产出错误数据）
4. `cargo test --workspace` 全通过
5. `cargo clippy --workspace` 无新增错误

## Out of Scope

- MFA/MMS_FA 多语言声学模型的训练或集成（需单独研究）
- PhoneTimeline provider 选型（Phase 2.5 benchmark 结论：暂无 release provider）
- 日语生产管线（当前 word_timeline: Unsupported，需先有 tokenizer + 声学模型）
