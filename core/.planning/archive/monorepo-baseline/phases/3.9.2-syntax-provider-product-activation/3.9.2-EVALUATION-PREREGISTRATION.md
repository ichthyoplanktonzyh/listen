# Phase 3.9.2 Corrected Syntax Qualification Preregistration

状态：LOCKED BEFORE V2 VALIDATION RUN（2026-07-13）

本文件纠正 Phase 3.9.1 的评估层级错误，但不修改其冻结 fixture/report。v2 开发集可用于形成
provider-neutral query；一旦本文件登记 validation digest，validation 只运行一次，不按结果加
词表或例外。

## 1. 三种不同判断

1. **Artifact qualification**：runtime/model provenance、token mapping、tree validity、failure
   closure、资源和许可是否允许产生产品可消费的共享句法 artifact。
2. **Consumer query qualification**：某个 B/SenseGroup/matcher query 能否从 neutral fields 安全
   得出结果。每项独立授权，不能用 provider 名称整体放行。
3. **Product ambiguity policy**：证据不足时 abstain 并走现有 fallback。它不是 parser attachment
   gold，也不计入 attachment accuracy。

## 2. V2 evidence roles

- `attachment_gold`：语义角色由句内显式论元消歧，允许评价 raw query。
- `product_policy`：表面句仍有多重合理分析，只验证 raw query `abstain` 后产品结果为 `block`；
  不把 provider 的某个 parse 记作语言学错误。
- `manual_product_qa`：真实字幕形态与传播复核，不宣称完整 UD tree gold。
- `coverage`：只用于 mapping/tree/resource，不参与语义准确率。

Want-to 清晰对照：

- `Which candidate do you want to win the election?`：`win` 已有显式 object `the election`，
  candidate 是 embedded subject，raw expected `block`。
- `Which game do you want to win?`：game 是 `win` 的 object，raw expected `allow`。
- `Which team do you want to beat in the final?`：team 是 `beat` 的 object，raw expected `allow`。
- `Which team do you want to win?`：无上下文时标为 `product_policy`，raw expected `abstain`，产品
  expected `block`。

## 3. Artifact gates

- validation lexical alignment coverage `>= 0.995`，关键 case `= 1.0`。
- silent misalignment `= 0`；所有非 exact mapping 显式标注。
- valid artifact 必须单 root、HEAD 有界、无环、span/ownership 合法；任何 invalid sentence closed。
- crash `= 0`；missing/corrupt/unsupported/timeout/protocol/invalid output 不写 artifact。
- cold p95 `<= 20s`，warm single p95 `<= 250ms`，batch throughput `>= 8/s`，RSS `<= 2GiB`。
- runtime/model 不进入默认 consumer bundle；许可与 exact checksum 延用已审计 asset manifest，任何
  新 artifact/version 必须重新审计。

## 4. Per-query gates

每项仅在自身 `attachment_gold` cases 上评分：

- macro accuracy `= 1.0`（v2 样本小，不用 0.9 掩盖一个错误）。
- expected block 不得 raw allow；expected allow 不得 raw block。
- raw abstain 不算错误触发，但表示该 query 未达到产品激活所需 coverage；该项保持 fallback。
- `product_policy` case 必须 raw abstain，product decision 必须 block；否则 ambiguity policy gate 失败。
- surface `gonna/wanna` 不计生成成功。

资格输出是 matrix，例如：

```text
artifact: qualified | not_qualified
b.future_going_to: qualified | fallback_only
b.habitual_used_to: qualified | fallback_only
b.have_to: qualified | fallback_only
b.want_to: qualified | fallback_only
sense_group: qualified | fallback_only
dependency_matcher: qualified | fallback_only
```

## 5. Activation rule

只有 `artifact=qualified` 且对应 query=`qualified` 时才能激活 syntax behavior。artifact 合格但
query=`fallback_only` 时，消费者必须与无 syntax 基线逐项相同。SenseGroup/matcher 仍受 domain
validator、teaching granularity 和非 canonical guardrail 独立约束。
