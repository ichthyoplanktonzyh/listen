# Phase 3.9.2 Closeout: Syntax Provider Product Activation

状态：COMPLETED — QUALIFIED OPTIONAL PROVIDER

## Outcome

本阶段纠正了 Phase 3.9.1 把产品保守政策当作唯一 parser gold 的资格错误，并以独立 v2
development/locked validation 重新评估。spaCy 的 token-aligned artifact 通过结构、mapping、
许可、资源与 failure gate；B 的 `going_to`、`habitual_used_to`、`have_to` 分别通过，`want_to`
因 basic dependencies 无法稳定区分 wh embedded subject/object 而明确 abstain/fallback。

产品 composition 已接入一个可选 Provider：一次 track 请求只 probe 一次、analyze 一次，每句
独立 finalise 一份 artifact；Reference B、syntax-aware SenseGroup 与 dependency matcher 共享
同一 artifact identity。未配置/模型缺失/损坏/timeout/协议错误/坏树时不阻断基础产品，并精确
回到既有 B 与 rule SenseGroup。

## Delivered

- 14 development + 15 digest-locked validation v2 cases、独立 scorer/tests、预登记和冻结报告；
  争议句为 policy case，不再冒充 attachment gold。
- application `SyntacticConsumerOrchestrator`、中立 consumer DTO 与
  `POST /v1/subtitles/{track_id}/syntactic-consumers` OpenAPI/HTTP composition。
- capability-specific qualification：artifact / B verified subset / SenseGroup / matcher 分别授权，
  消费者不按 `provider_id` 分支。
- 一次 batch、逐句 validator 隔离；坏句不污染其他句，三个消费者引用同一 artifact ID。
- fully pinned opt-in spaCy 产品环境、model wheel hash、stable content checksum、安装 probe、刷新/
  disable/uninstall 规则与 runtime/model/training-data 分层许可 manifest。
- corrected real-media report：244 cues / 1773 words、100% lexical coverage、98.759% exact span、
  零 silent mismatch、刷新确定；一个双 root 口语残句由逐句 validator 闭合 fallback。

## Frozen decisions

1. artifact 资格不自动授权任一 consumer query；新增 query 必须独立预登记和验证。
2. `want_to` 固定走 text heuristic，直到新的 query 证据明确通过。
3. 产品只选择 spaCy；Stanza 保留研究对照，不同时承担第二套 runtime。
4. 句法 artifact 是 ephemeral/rebuildable evidence，不是 C、ChunkTimeline parent 或用户资产。
5. matcher candidate 不是 Construction canonical/occurrence/capability identity。
6. base app 不捆绑 Python/model；opt-in capability 失败不得阻断字幕、播放或基础学习。
