# Phase 3.9.2 Qualification: Corrected Syntax Product Decision

日期：2026-07-13

## Decision

spaCy 3.8.13 + `en_core_web_sm` 3.8.0 获得**可选本地共享句法 artifact Provider**资格。
资格不等于逐 query 全信任：产品只激活明确通过的消费者能力，其他 query 继续精确 fallback。

| Capability | Decision | Evidence / boundary |
|---|---|---|
| neutral token-aligned artifact | qualified | locked validation mapping/coverage 100%，exact span 100%，零 silent misalignment、零 tree issue |
| B `going_to` | qualified | development 3/3；locked 3/3 |
| B `habitual_used_to` | qualified | development 2/2；locked 2/2 |
| B `have_to` | qualified | development 2/2；locked 2/2 |
| B `want_to` | **fallback_only** | development 2/4；locked 1/3，basic dependencies 不能可靠区分 wh embedded subject/object |
| syntax-aware SenseGroup | qualified | 只消费 validated artifact；phrase/标点/2–8 token 教学粒度 guardrail 仍最终裁决 |
| dependency matcher | qualified candidate source | 只输出可重建 matcher-local candidate；无 Construction canonical/occurrence/capability authority |

锁定歧义政策例中 raw spaCy 对 `Which player do you want to score?` 给出 allow，故 raw
`ambiguity_policy_passed=false`。这不是忽略失败：它直接导致整个 `want_to` query
`fallback_only`；产品不读取该 raw allow，而继续使用已有文本保守 block。修正后的方法把
artifact 结构资格、query correctness 与产品歧义 policy 分开，避免再次把某句政策标签伪装成
唯一 parser gold，也避免用一个不合格 query 否决其他已通过能力。

## Identity correction

旧研究 descriptor 的 model tree checksum 包含 Python import 生成的 `__pycache__/*.pyc`，会随
解释器缓存变化，不适合作为模型身份。产品 sidecar 排除 bytecode cache；同一模型在旧研究 venv
与 fresh product venv 均得到稳定 content SHA-256
`adda6df4860f555a57e6e31635f233359ab471dafa177d58d96a8d4198450a7c`。不重跑或改写 locked
validation；parser 输出和资格统计未变，产品 descriptor 从此使用稳定 identity。

## Authority guardrails

learner capability。B 仍是 `PossibleByRule`，syntax provenance 只说明门控证据来源；SenseGroup
保留独立 candidate lifecycle；matcher 返回值仅为诊断候选。
