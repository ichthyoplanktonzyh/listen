> 本 phase 由 3.12 v1 拆出：judge 资格评估（fixture 制作 + 人工 gold 标注 + 留出集
> 评估）本身是 phase 体量的工作，与 provider 基础设施混在一起会导致两边都无法诚实收口。

## Objective

用开发集/留出集分离的人工校验，测定跨语言 LLM judge（L1/L2 复述信息点覆盖、段落理解、
写作反馈）的真实能力边界，并按预登记门槛裁决其资格等级：不可用 / 仅可显示为可纠正
heuristic feedback / 可作 supporting evidence。

## User Value

本 phase 不交付新学习功能；它决定用户在 Studio 中看到的自动语义反馈是"经过校验的诚实
辅助"还是根本不该出现。没有它，3.13–3.15 的 LLM 反馈只是接通了 API 的猜测。

## Scope

### In

- Judge fixture 制作：真实两层复述录音（L1 普通话 / L2 英语，好/中/差刻意覆盖）、
  段落理解回答、dictogloss/摘要文本；narrative/dialogue/explanation 题材各有覆盖。
- 干扰因子覆盖：同义改写、ASR 噪声与不确定区段、部分覆盖、abstain 应当发生的场景。
- 开发集与留出集严格分离：prompt/schema 只在开发集上调；查看留出集结果前**预先登记**
  指标、通过门槛与三级资格语义（不可用 / 仅可显示 / 可作 supporting evidence）。
- 人工逐信息点 gold 标注：precision、recall、误判、漏判、引用真实性（span 是否真实
  存在于 transcript）、重复稳定性。
- 至少两个协议族/模型族交叉运行，记录 provider 间一致性差异。
- 资格裁决文档 + 复现实验记录；资格结论写入 provider capability descriptor 语义
  （按用途分别授予：跨语言复述判定、段落理解判定、写作反馈可各自不同级）。

### Out

- 新协议 adapter、设置 UI、密钥/隐私机制（3.12 已定）。
- capability projection 写入资格（即使评估优秀，projection 仍属 3.17 的 confirmation
  gate 决策）。
- 自动扩充评估集、合成数据代替真实用户产出。
- 为讨好指标调整 rubric/judgment 领域契约（契约问题回 3.11 修，不在评估里打补丁）。

## Dependencies

- 3.11 rubric/judgment contract；3.12 至少两个异构 adapter 可用。
- 真实录音素材：可复用 3.8 RecordingAsset 采集链路 + owner 自录复述样本；
  `/Users/shadow/Desktop/视频` 真实媒体做片段来源。

## Key Work

1. 评估任务定义与预登记：指标、门槛、资格语义先于任何留出集运行写死。
2. Fixture 采集与人工 gold 标注（最耗时项，允许分批：先跨语言复述，后写作反馈）。
3. 评估 harness：批量运行、结构化输出校验、重复稳定性、跨 provider 对照。
4. 留出集评估与资格裁决报告；失败用途明确记录能力边界与降级决定。
5. 资格结论接入：judge 输出在未获资格用途上保持隐藏（3.12 的默认态），获资格用途
   点亮"可纠正 heuristic feedback"显示。

## Exit Signal

- 每类用途（跨语言复述判定 / 段落理解判定 / 写作反馈）有独立、可复现的留出集报告
  与明确资格等级；没有任何资格是用开发集成绩授予的。
- 引用真实性达标：judge 引用的 supporting span 可在 transcript 中精确定位。
- 至少一个用途获得"仅可显示"级资格，或诚实记录全部失败并确认 3.13–3.15 以
  客观事实 + 用户自评交付。
- 资格结论以文档 + descriptor 双形式存在，3.13–3.15 可直接消费。

## Guardrails

- 样本量诚实：十余条只够管线验证；资格结论必须基于留出集规模与覆盖面如实陈述边界。
- 评估失败不阻塞 Studio 排期；Studio 的降级路径（客观事实 + 自评）本来就是一等公民。
- 人工标注是 gold，LLM 自评/互评不能替代。
- 未获资格的用途不得以"仅供参考"名义出现在学习 surface。
