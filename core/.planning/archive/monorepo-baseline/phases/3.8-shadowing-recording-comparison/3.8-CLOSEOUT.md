## Outcome

Phase 3.8 把“听懂真实语流”向“模仿真实语流”推进了一步：用户可从当前媒体 chunk、复习卡
或词典内联片段进入同一个 shadowing 面板，按 chunk → 1+2 → 整句逐步展开，以三档倍速
听原音、录制本地 PCM16 WAV，并通过原音/录音/A-B-A 与双波形、时长和停顿事实进行比较。

本阶段没有把录音完成伪装成 speaking 能力成功。shadowing attempt 使用非评价
`completed / score = null`，不生成 capability observation、review 或 content-fit 校准数据。

## Delivered

### 录音资产与诚实 completion

- schema v33 `recording_assets`、SQLite `RecordingRepository` 与 create/get/delete API。
- `RecordingAsset` 保存语言、容器/codec、采样率、声道、sample format、时长、byte length、
  SHA-256、recorder version、目标和来源片段 snapshot，为 Phase 3.14 转录用例保留输入 seam。
- `PracticeKind::Shadowing` 与 `PracticeResult::Completed`；同一录音 completion 幂等。
- completion 只写 activity/attempt 事实，不生成 speaking/listening observation、review item，
  不修改 capability，也不参与 content-fit。

### macOS 录音与权限

- `AVAudioRecorder + Flutter MethodChannel`，输出 16 kHz mono PCM16 WAV 到 App Support。
- Info.plist 麦克风用途说明与 Debug/Release audio-input entitlement；权限未授予时解释并可打开
  系统设置，录音取消和空文件均有明确清理/错误路径。
- 正式打包脚本保留 Release entitlements，最终 arm64 QA 包内含 Rust sidecar、ffmpeg/ffprobe
  与 runtime。

### Shadowing 交互与音频焦点

- 精听练习浮窗第四题型“跟一下”；韵律 ChunkTimeline 是目标层，无 chunk 时诚实降级整句。
- 0.75x / 0.9x / 1.0x，当前 chunk → 1+2 → 整句；当前媒体继续使用主播放器 loopRange。
- 复习卡和词典内联入口复用第二切片播放器，固定为单一来源片段，不替换主播放器状态。
- D6 独占音频焦点：原音、麦克风录制、录音回放任一时刻只有一个发声源。
- 原音、录音及 A-B-A 播放；关闭练习时恢复主播放器速率并清理录制/切片状态。

### 客观比较

- ffmpeg 提取同范围 16 kHz mono PCM16 参考 WAV。
- Rust `shadowing_comparison` 计算双波形 peak/RMS 摘要、录音相对时长差、参考/录音停顿区间
  与最近停顿平均绝对偏移。
- UI 只展示客观事实和“无评分”边界；比较失败保留录音并显示降级说明，不输出未经校准的
  发音、重音或节奏评价。

## Key Decisions

1. **模仿完成不等于会说**：`completed` 是活动事实，不投影 speaking success。
2. **韵律 chunk 是 shadowing 单位**：SenseGroup grouping mode 不改变练习目标层。
3. **不新增第三种播放器语义**：当前媒体走主播放器，跨媒体走既有第二切片核心。
4. **录音是耐久用户资产**：默认本地、可删除，媒体删除不级联删除录音；snapshot 保留。
5. **比较只呈现事实**：在没有校准证据前不做发音评分或“好/坏”诊断。
6. **跨媒体片段不可句间导航**：复习/词典 shadowing 固定当前来源片段，播放按钮及空格键
   控制切片播放器，上一句/下一句和主字幕进度不进入该 surface。
