## Objective

点亮精听三姿态的"跟一下"（内化型）：chunk-level 可调速跟读、录音、A/B 对比与
轻量节奏比较。从"听懂真实语流"自然过渡到"模仿真实语流"，不承诺复杂发音评分。

## User Value

> "这个 chunk 我已经能听出来了——0.9x 跟三遍，录一条和原音 A/B 对比，
> 听得出我的停顿位置不对。"

## Scope

### In

- **Shadowing 播放**：
  - 单位是**韵律层 ChunkTimeline 的 chunk**（无 chunk 回退句级）。SenseGroup 是
    语义标注，不是跟读单位；`groupingMode` 任何取值都不改变 shadowing 目标层
    （ADR 0016 双层分离，3.5.5"只收表达不合并数据"裁决）。
  - 0.75x / 0.9x / 1.0x；循环与逐步展开（1 -> 1+2 -> 整句）复用现有 chunk 控制。
  - 原音播放两条路径（对齐 3.5.7 裁决，不再引入第三种播放语义）：
    - 从当前媒体 chunk 控制进入 → 主播放器 `loopRange`（B 组语义，未迁移）；
    - 从复习项/词典切片等跨媒体入口进入 → 3.5.7 第二解码切片核心 + 跨媒体 resolver。
  - 录音时原音静音/暂停策略沿用 D6 焦点策略：任一发声源独占音频。
- **录音**：麦克风采集 -> `RecordingAsset` 落库（兑现 3.0.1 deferred 的
  `RecordingRepository`；新增 SQLite 迁移，版本号接续当前 HEAD——注意 3.6.1 审计
  修复后已到 v31）；macOS 权限缺失时解释并引导系统设置。
- **A/B/A 对比播放**：原音 -> 用户录音 -> 原音，一键循环对比。录音回放是本地文件
  播放，不占用主播放器；与切片核心并存时同样遵守 D6 独占。
- **轻量比较（`ShadowingComparison`）**：时长差、停顿位置粗对比（复用 2.21 已落地的
  Rust RMS/F0 baseline 与 pause 检测）；波形并排展示。不做打分。
- **入口点亮**："跟一下"从 3.5.6 精听练习浮窗姿态栏的禁用占位变为可用。UI 形态
  决策：作为练习浮窗内的第四种题型面板（默认），不另开第二个浮窗；复习项 /
  词典切片入口跳转到同一面板。
- 记录：`PracticeAttempt`（shadowing 类型）+ 可选保存最好一次录音；媒体丢失时
  保留录音与 prompt snapshot。**shadowing attempt 无客观正确率，明确排除在
  content-fit-v2 增量折算之外**（3.5/3.6 的折算口径只收 cloze/dictation 正确率），
  避免污染难度校准。
- **证据裁决**：shadowing 完成是 activity/attempt 事实，不自动等于 target-level
  speaking success。不得为了适配现有 `PracticeResult` 写成 `Correct` 后触发 ADR 0017
  speaking observation；本 phase 应为非评价完成建立诚实表达，或显式抑制 observation。
  只有未来经校验的目标表达产出任务才可写较强 speaking evidence。
- **未来转录 seam**：`RecordingAsset` 保存语言、格式、采样信息、时长、来源片段、录制
  版本与文件完整性元数据，供 3.14 新增 recording-transcription use case；不把现有整媒体
  transcription job 假装成已可转录麦克风录音。

### Out（Non-goals）

- 发音评分、音素级对齐打分、GOP 类算法（长期研究线，不进 3.x）。
- 节奏/重音自动诊断（"重音位置偏"这类结论需要证据校准，先只呈现客观对比）。
- 复习队列中的 shadowing 评分卡（评价口径成熟后再进 3.4 卡型）。
- 不为 shadowing 新建第三种播放器实例语义（两条既有路径覆盖所有入口）。
- 片段复述、角色接话、L1/L2 两层复述、录音 ASR、SemanticJudgment 与 LLM feedback
  （统一进入 3.14 Speaking Studio v1）。

## Key Work

1. 录音采集（macOS 权限、格式、存储路径策略）+ `RecordingRepository` 落地
   （domain 资产类型 + SQLite 迁移 + application trait，遵循 v31 之后的版本序）。
2. shadowing 面板 UI（练习浮窗内）：调速、循环、逐步展开、录制控制；文案走 localization。
3. A/B/A 播放控制与波形并排视图（原音路径按入口二选一，见 Scope）。
4. 时长/停顿粗对比计算（Rust 侧复用 DSP，输出 `ShadowingComparison`）。
5. attempt/资产落库与"保存最好一次"；确认 content-fit 折算排除。
6. 非评价 completion contract：验证不会因 `Correct` 占位值生成虚假的 speaking observation；
   RecordingAsset 元数据满足 3.14 转录输入需要，但不在本 phase 启动转录。

## Exit Signal

- 选一个真实 chunk 完成：听 -> 跟 -> 录 -> A/B 对比 -> 重录 -> 保存。
- 时长与停顿对比在真实录音上给出可理解的客观展示（manual_product_qa 记录）。
- 麦克风缺权限、无 chunk、媒体丢失三条降级路径可走通。
- **独立可用**：shadowing 可直接从 chunk 控制进入，不依赖练习/复习闭环。

## Guardrails

- 只呈现客观对比，不输出未经校准的主观评价。
- 录音是用户资产：默认本地存储、可删除、媒体删除不级联删录音
  （沿用"学习资产 outlive 媒体"不变量）。
- 音频焦点遵守 D6：任一时刻只有一个发声源。
- “录过/跟过”与“会说”分离；非评价 activity 不进入 speaking projection。
