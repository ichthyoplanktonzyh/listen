## 设计决策总结

1. **两个 tier 而非一个大 trait**：发音/规则走 trait dispatch，timing/chunk 确认为语言无关算法无需 per-language provider
2. **`rule_catalog()` 返回 `serde_json::Value`**：避免迁移 `RuleDefinition` 到 domain
3. **chunk 门控仅保留 text_chunk**：声学 chunk 和 partition 对所有有词时间的语言有效
4. **`analyze_pronunciation_track` 容错**：`filter_map(.ok())` 跳过失败句子（标点句/无 provider 匹配），不中断整个 track
5. **中文 profile 能力升级**：实测证明估算和声学 chunk 对中文有效，不应声明 Unsupported

## 遗留 Gap → Phase 2.8

1. **Whisper BPE → app token 时间对齐**：whisper 词级时间戳绑定 BPE 边界，与 jieba/lindera 不对齐，中文词跳动精度受限
2. **韵律感知估算**：当前统一字符权重，中文应等权（syllable-timed），日语应 mora 权重
3. **命名统一**：`WordTiming` 语义上是 `TokenTiming`，可选重构
