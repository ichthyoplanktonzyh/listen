# Phase 2.12 Plan: UI State Management Refactoring

更新时间：2026-06-25 CST

状态：✅ 已完成。

## Objective

重构 LLPlayerNext Flutter 前端的状态管理层，引入细粒度响应式状态容器 Store\<T\>，为后续 UI/UX 重构提供基础设施。

## Scope

### 核心变更

| 变更 | 描述 |
|------|------|
| Store\<T\> | 通用响应式状态容器，支持 select() 细粒度订阅 |
| StoreBuilder / StoreBuilder2 | 声明式 Widget，只监听特定状态切片 |
| typed domain models | WordProfile / WordDetail / Diagnosis / PhraseCandidate 等 7 个 typed 类 |
| PlayerController 重构 | 内部迁移到 Store\<PlayerState\> |
| SubtitleController 重构 | 内部迁移到 Store\<SubtitleState\> |
| LearningController 重构 | 内部迁移到 Store\<LearningState\> |
| SubtitleOverlay 提取 | 从 _playerSurface() 提取为独立 Widget |
| SidePanel 提取 | 从 _sidePanel() 提取为独立 Widget |

### 不包含（后续阶段）

- 完整 UI/UX 视觉重构
- 导航状态管理
- Service 层提取（MediaService / SubtitleService / LearningService）

## Design Principle

```text
旧: Controller → ChangeNotifier → notifyListeners() → ALL widgets rebuild
新: Controller → Store<T> → select(field) → ValueNotifier → only interested widgets rebuild
```

1. **向后兼容**：保留 ChangeNotifier 接口，现有代码不修改。
2. **增量迁移**：Controller 内部使用 Store，外部接口不变。
3. **按需提取**：布局提取从最大块开始，不一次性拆完。
4. **类型优先**：核心数据类型用 typed class 替换 `Map<String, dynamic>`。
