## Delivered

### Store\<T\> — 通用响应式状态容器

**文件**: `apps/desktop/lib/state/store.dart`

- 使用 `select<R>(R Function(T))` 创建 ValueNotifier，Widget 只监听需要的数据。
- `update(T Function(T))` 内部比较新旧值，只通知变更的 selector。
- `replace(T)` 支持整体重置。
- 无缝集成：Store extends ChangeNotifier，保留现有 listener 兼容性。

### StoreBuilder — 声明式选择器 Widget

**文件**: `apps/desktop/lib/state/builder.dart`

- `StoreBuilder<T, R>` — 一个 selector，用于单字段监听。
- `StoreBuilder2<T, R1, R2>` — 两个 selector，用于需要两个状态的场景。
- 用法示例：
```dart
StoreBuilder<PlayerState, bool>(
  store: playerCtrl.store,
  select: (s) => s.playing,
  builder: (_, playing) => Icon(playing ? Icons.pause : Icons.play),
)
```

### Controller 重构

三个 Controller 内部迁移到 Store：

- **PlayerController**: `store.update((s) => s.copyWith(...))` 替代 `_state = _state.copyWith(...)`。新增 `select()` 公开方法。
- **SubtitleController**: 同上，所有 `_update(fn)` 改为 `_store.update(fn)`。
- **LearningController**: 同上。

所有 public getter/setter、ChangeNotifier 接口、ListenableBuilder 兼容性保持不变。
