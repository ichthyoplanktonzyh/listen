# Phase 2.20 Algorithm And Metrics Research

状态：DRAFT

调研日期：2026-06-30

## Principle

Phase 2.20 的目标不是把当前项目里已经存在的 heuristic 调到某个小样本分数最高，
而是建立一个有研究依据的、可逐步校准的真实可听结构分析系统。

Therefore:

- Current project metrics are diagnostic signals, not truth.
- Helsinki/LibriTTS labels are automatic silver labels, not human gold.
- Small local smoke runs prove the pipeline works and expose failure modes; they do not define
  final thresholds.
- Algorithm changes should be justified by published prosody/phonetics work, corpus annotation
  conventions, or measured product QA.
- Numeric gates should only be promoted after comparing with published baselines or annotation
  agreement ranges where available.

## Route Correction: Actual Delivery

2026-06-30 route review clarified the most important product constraint:

```text
actual audible structure != default predicted reading
```

Text can predict likely stress and syntax, but actual prominence and phrasing
must be supported by audio measurements. Therefore:

- Current deterministic `stress_anchors` are mostly `text_predicted` priors.
- CTC phone evidence is valuable for segmental phenomena such as flapping,
  deletion, weak forms and phone mismatch, but it should not be the primary
  rhythm skeleton.
- The main generator route should migrate to forced-aligned WordTimeline timing,
  duration/rate evidence, RMS energy/loudness, and optional F0/pitch evidence.
- The corrected architecture is a layered hybrid: text prior plus acoustic
  confirmation or override, with explicit provenance.

See `2.20-ROUTE-CORRECTION.md`.

## What We Are Estimating

The product question is:

```text
What audible structure should the learner hear in this sentence?
```

That maps to several different sub-problems:

| Product Field | Research Object | Main Evidence |
|---|---|---|
| `stress_anchors` | prosodic prominence / pitch accent / information-bearing stress | lexical stress, syntax/POS, F0 movement, intensity, duration, spectral emphasis |
| `phrase_boundaries` | prosodic boundary / intonation-unit break / thought-group break | silent pause, final lengthening, pitch reset, speech-rate discontinuity, syntax |
| `weak_groups` | weak forms and backgrounded function-word groups | function-word class, duration reduction, phone evidence, connected-speech context |
| `compression_spans` | locally high speech-rate / packed expected units | phone/syllable/word duration normalized by local rate and expected units |
| `listening_hotspots` | learner-facing explanation quality | manual product QA; public corpora do not directly answer this |

## Provenance Labels Needed

Future RhythmFrame output should preserve evidence provenance. Candidate labels:

| Label | Meaning |
|---|---|
| `text_predicted` | predicted from transcript, lexical stress, syntax or function-word class |
| `forced_alignment_timing` | timing is supported by forced-aligned WordTimeline/phone alignment |
| `duration_supported` | locally normalized duration supports the cue |
| `rate_supported` | local speech-rate or expected-unit density supports compression/boundary |
| `energy_supported` | RMS/loudness supports observed prominence |
| `pitch_supported` | F0/pitch reset/contour supports prominence or boundary |
| `ctc_segmental_evidence` | CTC phone evidence supports a segmental phenomenon, not the whole rhythm skeleton |
| `manual_product_qa` | human QA has judged the displayed item useful/correct |

## Research-Backed Feature Families

### 1. Prominence / Stress Anchors

Research direction:

- Prosodic prominence is not identical to dictionary lexical stress.
- Prominent words are often cued by some combination of F0/pitch, duration, intensity/loudness,
  and spectral emphasis.
- Text-only predictors can be strong for prominence placement, but they are predicting likely
  prosodic prominence rather than measuring the actual audio performance.

Implementation implication:

- `stress_anchors` should not be "all dictionary-stressed content words".
- A reasonable v1 should combine:
  - lexical stress and content/function-word category;
  - sentence position and punctuation/syntax;
  - observed duration relative to local context;
  - RMS energy/loudness as the first production-side acoustic support;
  - F0/pitch once voicing, octave-error, speaker range and calibration guardrails are defined.
- Current deterministic v0 can remain a baseline, but confidence must distinguish:
  `text_predicted`, `duration_supported`, `energy_supported`, and later `pitch_supported`.

Metric implication:

- Helsinki prominence labels can score anchor placement as silver-label regression.
- Report precision/recall/F1, but do not set a gate from a tiny smoke sample.
- Compare against Helsinki reported text-model baselines before deciding whether a score is
  good, bad, or simply a different task.

Known baseline context:

- Helsinki Prosody reports BERT at about 83.2% 2-way accuracy and 68.6% 3-way accuracy on
  the text prominence prediction task. That is not directly comparable to our end-to-end
  audio pipeline, but it is a useful calibration reference.

### 2. Prosodic / Phrase Boundaries

Research direction:

- Prosodic boundary perception is typically tied to multiple cues, not pause alone.
- Commonly cited cues include pause duration, pitch reset, and final lengthening.
- Recent boundary-detection work also uses speech-rate discontinuities and syntactic validity.

Implementation implication:

- `phrase_boundaries` should not be a raw "gap >= N ms" rule by itself.
- A better v1 boundary score should combine:
  - silent pause duration;
  - pre-boundary lengthening;
  - phrase-initial acceleration or rate reset;
  - punctuation/syntactic break where transcript permits it;
  - pitch reset when F0 is available.
- Internal boundaries and sentence-final boundary/cadence should be reported separately.

Metric implication:

- Boundary F1 should support a tolerance window and should distinguish internal vs final
  boundaries.
- Helsinki word-boundary labels can be silver-label regression, but ToBI/break-index corpora
  would be better human gold if available.
- Do not tune a single pause threshold on three samples.

### 3. Rhythm / Compression

Research direction:

- Speech rhythm metrics in the literature include %V, ΔC/ΔV, VarcoV, rPVI and nPVI.
- These metrics are useful for corpus-level rhythm description and speaker/language variation,
  but they are not direct learner-facing hotspot labels.
- Rate normalization matters; raw duration thresholds are brittle across speakers and speaking
  rates.

Implementation implication:

- `compression_spans` should use local rate-normalized evidence, not only global constants.
- Candidate signals:
  - expected phones/syllables per second;
  - local z-score against neighboring words/chunks;
  - duration per expected unit;
  - function-word density;
  - optional rhythm metrics as aggregate diagnostics, not direct UI labels.

Metric implication:

- Use span overlap/IoU and manual labels for product QA.
- Use rhythm metrics to characterize selected material and detect regression, not to claim a
  sentence-level explanation is correct.

### 4. Weak Groups / Connected Speech

Research direction:

- Weak forms and connected speech are heavily dependent on function-word status, local rate,
  phonetic context, and actual realization.
- Public prosody corpora generally do not provide direct labels for our learner-facing weak
  groups or hotspot explanations.

Implementation implication:

- `weak_groups` can start from function-word grouping, but confidence should increase only with
  timing/phone/acoustic support.
- Raw phone-model mismatch should remain evidence, not default teaching explanation, unless
  connected-speech context supports it.

Metric implication:

- Buckeye can provide natural speech windows and phone/word evidence.
- Final usefulness/misleading/unsupported rates require manual product QA.

## Metric Classes

Every Phase 2.20 score should declare its evidence class:

| Class | Meaning | Example |
|---|---|---|
| `gold` | human annotated target labels from an accepted corpus | ToBI/break-index labels if licensed/local |
| `silver_label` | automatic labels from a research corpus/tool | Helsinki prominence/boundary labels |
| `heuristic_proxy` | derived local proxy, useful for debugging only | duration-per-expected-unit threshold |
| `manual_product_qa` | human judgement of learner-facing usefulness | rhythm-frame QA rubric |
| `coverage` | pipeline availability or evidence completeness | `rhythm_frame_coverage`, phone evidence coverage |

## Implementation Direction

Immediate safe moves:

1. Keep the Helsinki/LibriTTS adapter as a silver-label regression harness.
2. Keep the 3-sentence smoke result as a pipeline diagnostic only.
3. Add published-baseline fields to benchmark reports before introducing gates.
   **Landed** in `scripts/evaluate-helsinki-prosody.py` as `benchmark_context`.
4. Add acoustic feature extraction research before changing default phrase-boundary logic.
   **Revised** in `2.20-ROUTE-CORRECTION.md`: `pre_boundary_lengthening` is a fallback
   `heuristic_proxy`, while the main route is forced-aligned WordTimeline + duration/rate +
   RMS energy.
5. Implement algorithm changes boldly once they are tied to a documented feature family:
   prominence, boundary cues, rhythm/rate normalization, or manual product QA.
6. Do not continue optimizing CTC-derived rhythm as the product skeleton. Use CTC as
   segmental evidence and move rhythm generation to the production-side D -> F path.

Avoid:

- Setting gates from the current three-sentence smoke run.
- Calling Helsinki automatic labels "truth".
- Treating every dictionary-stressed content word as audible prominence.
- Treating every 100ms alignment gap as a phrase boundary.
