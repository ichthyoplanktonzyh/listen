# Phase 3.1 Closeout: Intensive Listening Practice Slice

完成日期：2026-07-04

## 结论

Phase 3.1 已完成首个用户可用的精听练习竖切片：用户可以从当前句进入 Test posture，
发起 cloze、chunk dictation 或 sentence dictation，听真实音频窗口后作答，提交后看到
token diff、诊断入口、重练/重放/存复习等下一步动作。该切片独立可用，不依赖后续 3.x
phase。

## 已落地

- 三姿态入口：Understand 打开诊断，Test 提供 cloze / chunk / sentence 三种练习，
  Shadowing 作为 planned/disabled 入口保留到 Phase 3.8。
- Flutter practice slice：新增 `PracticeController`、practice DTO、LocalApi practice/review
  typed wrapper、practice 面板与主播放器集成。
- Cloze 选择策略：优先使用当前句内 `known_recognized`，其次 `known_not_recognized`、
  `unknown_meaning`，最后回退到首个词。
- Capability gating：无当前句时禁用；无 word sync 时禁用精确 cloze；无 chunk 时 chunk
  dictation 回退句级；estimated timing 明示 degraded。
- 练习结果：提交 `PracticeAttempt`，展示 token-level diff；失败项可一键创建 `ReviewItem`；
  不静默修改全局 `LearningStatus`。
- C-1 phrase-aware diagnosis：当前句命中的 Phrase lexical entries 参与 meaning /
  recognition barrier 判断。
- C-2 rhythm hotspot loop：诊断卡可显示 document-level rhythm hotspot，并点击复听证据范围。
- 新增手写 Dart DTO + fixture 契约测试，沿用 ADR 0014。
