# Phase 3.19.2 Context: Backend Runtime Hardening & Interface Deepening

状态：ACTIVE

日期：2026-07-26

父阶段：Phase 3.19 Product Validation & Release Closeout

## Why This Phase Exists

Phase 2.24 已经把依赖方向、runtime ownership、repository 拆分和跨端 typed contract
治理到正确形态。Phase 3.x 随后继续加入 realtime、embedding、TTS、四通道学习、
Personal Expression、FSRS 与 Anki，使本地后端增长到 15 个 Rust crates、217 条 `/v1`
路径和 schema v48。

2026-07-26 后端只读审计确认：领域事实与测试基础仍然可靠，但运行模型和 composition
interface 已出现新的扩展压力：

- Axum async handler 直接执行同步 application / rusqlite 调用；
- 全部 SQLite 操作共享一个 `Mutex<Connection>`，数据库访问既串行又可能阻塞 Tokio worker；
- SSE receiver 把 `Lagged` 与 `Closed` 都折叠为 stream 结束；
- `AppServices`、`ApiState` 和单一 `router()` 再次成为宽 composition 热点；
- repository 原始错误文本进入 HTTP 500 body；
- structured error 之外缺少统一 request/job/slow-operation tracing；
- CI 尚无 Rust advisory/license/source supply-chain gate；
- 当前分支 `cargo fmt --check` 有 4 个文件、6 个未格式化 diff。

这不是新产品 feature，也不改变任何学习权威、HTTP wire shape 或 Flutter 呈现。它是 Phase
3.19 发布前的后端可靠性与可维护性修正。

## Parallel Frontend Constraint

Owner 正在使用 Claude 独立推进前端设计优化。本 phase：

- 不编辑 `apps/desktop/**`；
- 不改变 Flutter 可见语义、导航或视觉；
- 不主动改变 OpenAPI request/response shape；
- 如后端 contract 必须变化，先停在兼容设计 checkpoint，不与前端并行分支制造隐式破坏。

## Design Lens

本 phase 使用 deep-module 语言：

- module 以小 interface 隐藏并发、恢复、错误与观测复杂度；
- seam 只放在真实变化点；
- adapter 通过相同 interface 接受 production 与 deterministic test；
- replace-don't-layer：迁移调用者后删除旧 pass-through；
- deletion test：若删除新 module 只会让复杂度散回所有 route/caller，它才在提供 depth。

## Fixed Decisions

1. SQLite 继续作为本地权威存储；不以“异步化”为理由更换数据库。
2. 先测量并发/尾延迟，再裁决 dedicated blocking executor、actor 或 connection strategy。
3. 不在 217 个 handler 上长期散落手写 `spawn_blocking`；执行策略必须形成一个可测试 module。
4. SSE event 是通知，不是权威状态；lag 后客户端必须能通过已有 GET/read model resync。
5. 对外错误只保留稳定 code、可行动消息、correlation ID 与 retryable；内部细节只进脱敏日志。
6. `AppServices` 的用例 modules 保留；本 phase 优化 composition interface，不重新制造 fat trait。
7. 路由按资源域组合，根 router 只拥有 merge、auth、health 与 state installation。
8. supply-chain gate 先进入 CI/文档，不增加运行时依赖。

## Non-goals

- 云端部署、多用户、远程数据库；
- 修改学习 evidence/projection/override authority；
- 新 Provider、新学习功能或新 UI；
- 为每个 repository 创建一对一 shallow wrapper；
- 一次性追求所有 Rust 文件低于任意行数；
- 把 SSE 改造成 durable event log。
