## Summary

新增 SenseGroup 意群语义标注层，与 ChunkTimeline 韵律层独立共存。SenseGroup 是
token-span 句子级文本标注，播放范围通过 WordTimeline 投影。规则回退 provider 提供
基础分组能力（标点+长度+短语保护），无需外部模型依赖。

## Alignment Deferral (ADR 0016 Decision 6)

两层已独立落地，但尚无消费场景证据需要对齐：
- ChunkTimeline 提供音频时间和韵律证据（声学边界、停顿、pre-boundary lengthening）
- SenseGroupAnalysis 提供语义分组标注（标点/长度规则）
- 两者使用不同 token index 空间（chunk 用 word 序数，sense group 用原始 token index）

对齐数据结构（哪个 SenseGroup 对应哪些 ChunkTimelineChunk）留待有消费需求的 phase
再定义。3.4.2 保证两层独立存储、独立激活、互不干扰即可。

## ChunkTimeline Rename Evaluation (ADR 0016 Decision 7)

评估结论：**继续推迟改名。**

证据：
- SenseGroup 尚未被产品消费验证（showSenseGrouping 默认 off）
- ChunkTimeline 在 codebase 中有 ~50 处引用（domain/application/api/flutter/tests）
- 改名为 ProsodicGroup 或 ProsodyTimeline 仅有命名清晰度收益，无功能收益
- 改名的正确时机是 SenseGroup 产品验证后，两层消费模式稳定时
