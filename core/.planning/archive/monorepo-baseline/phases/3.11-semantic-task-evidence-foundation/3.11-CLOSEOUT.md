## Key Decisions

1. **独立任务族而非扩 `PracticeKind`**：结构性保证语义任务不能批量写 lexical observation；
   `PracticeResult` 承载不了逐点判定。
2. **rubric 身份含任务用途**：同段复述用与摘要用 rubric 不可比较；修订追加版本、改快照即拒绝。
3. **abstain 一等、与 failure 分离**：未评估不进任何失败分母。
4. **adjudication ≠ capability override**：append-only，原 judgment 逐字节不变。
5. **3.11 零 observation writer / 零 projection writer**：唯一天然锚定目标的句型产出推迟
   3.16（ADR 0020-7）。
6. **快照自足、无 media 外键**：删除媒体后全链路仍可读。
7. **不进 vocabulary bundle**：语义事实是 clip 锚定任务事实，需要迁移另立专用 bundle。
8. **不交 Dart DTO**：按 seam 标准，无真实 consumer 的 DTO 是死代码，推迟 3.13。
