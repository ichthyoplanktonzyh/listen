# Phase 3.19.1 Closeout: Realtime Conversation Product Correction

状态：COMPLETE — owner 真实 Qwen provider/device QA 通过（2026-07-22）

## Outcome

Realtime Conversation 已成为自由对话与显式内容锚定对话的唯一多轮交互容器。会话以本地
session identity 和 sequence 排序双方 turns；provider item ID 只用于在途关联。每个合格 learner
turn 独立保存音频并走本地 Whisper authority，只有 finalized learner output 投影进 Production
Corpus；assistant、失败和 interrupted turns 只保留诚实 history，不进入个人产出。

Speaking 收敛为结构化 L2 retelling、content-anchored retelling、shadowing 与 Pattern Production。
内容通道直接把 explicit Content Selection 适配成 Realtime anchor，固定答案练习没有被重新包装成
“对话”。Role Reply 的历史移除不在本 closeout 重开讨论。

## Delivered

- ADR 0027 与 typed `RealtimeTurnAssembler` 固定 ordered turn、caption/final、duplicate、barge-in 和
  local-authority 语义；
- free/topic 两个明确入口，共用 ordered timeline、voice activity、retry、finish drain、
  post-processing、cancel 和 route-close 生命周期；
- learner-only Production Corpus 可从 writing attempts + finalized realtime learner turns 原子重建，
  Gap Review 保持只读；
- Speaking/Realtime launch contract 解耦，内容通道以 sibling chooser 呈现 retelling、shadowing 和
  topic conversation；
- OpenAI Realtime Agents、LiveKit Agents、Pipecat 与 LiveKit Flutter Starter 仅用于事件分层、
  ordered context、关闭 flush 与 timeline 测试模式，不引入其 runtime 依赖；映射见
  `3.19.1-SCHEME-B.md`；
- owner QA 后修复三个 release regression：#34 宽矮窗口侧栏可滚动、#35 进入 Speaking 先抢占音频
  焦点、#36 macOS `Data` 头部裁剪后以相对偏移切 pre-roll 导致 SIGTRAP。

## Authority And Migration Boundary

- Conversation History：持久化双方 turns，领域身份是 session + local sequence；
- Provider events：临时关联和 live caption，不成为 durable identity 或 learner transcript authority；
- Production Corpus：可重建的 learner-only projection，不拥有会话事实；
- review/evidence：只读消费 corpus；3.19.1 不增加 observation、proposal、capability 或 review writer；
- schema v45 对已删除产品数据执行破坏性清理，不保留兼容层。
