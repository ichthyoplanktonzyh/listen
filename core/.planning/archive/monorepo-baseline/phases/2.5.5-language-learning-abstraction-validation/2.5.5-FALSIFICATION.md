# Phase 2.5.5 — Abstraction Falsification & Extensibility Seams

更新时间：2026-06-22 CST
覆盖：Step 4（扩展 seam 规格）、Step 5（ja/ar 类型学证伪）、Step 6（top-15 envelope）

本文回答：**抽象能否扩展到主流学习语言而不打特例分支？** 方法是用类型学上最远的两种
主流学习语言（Japanese、Arabic）逐字段跑一遍 capability matrix + 三单位模型，对每个字段标
`clean pass / forces special case / needs seam`，并据此把抽象修订到通过。

## Step 4: 扩展性 seam 规格（命名，不实现）

### Seam 4.1 — 开放 `kind` taxonomy

**问题**：`tokenization` / `lexical_units` / `listening_units` / `rhythm_prosody` /
`morphology` 若是闭合 `enum` + 穷举 `match`，每加一种语言都要回改枚举与所有 match 臂——
这与 capability matrix"不支持的能力**干净降级**"的哲学自相矛盾（穷举 enum 无法降级，只能崩）。

**决策**：

```text
kind = namespaced string
  core.*   跨语言共享：core.syllable / core.word / core.phrase / core.chunk / core.sound_pattern
  <lang>.* 语言扩展：en.stress_group / zh.tone / ja.mora / ja.pitch_accent / ar.root / fr.liaison_group
```

- 维护一个 **known-kind 注册表**约束拼写，但解析端遇到未知 kind **干净降级**（渲染为通用单位，
  不 panic、不阻断播放与状态）。
- capability 查询返回某语言**声明支持**的 kind 集合；UI 据此显示 available / degraded。

### Seam 4.2 — Token ↔ LexicalUnit ↔ ListeningUnit 的 N:M alignment

**问题**：三个单位各自独立切分同一句话，真正难的是**它们之间的对齐**——liaison / 变调 /
弱读 / reduced form 全活在这一层，而原抽象只把三者列为平行概念，没有给对齐一个归宿。

**决策**：定义一个"单位间多对多对齐"概念（概念层，2.6 不新建持久表）：

```text
UnitAlignment
- token_span      : [token...]      文本锚定，保留原始范围
- lexical_span    : [lexical...]    学习对象
- listening_span  : [listening...]  时间锚定，来自 Word/Chunk/Phone timeline
- relation        : exact | reduced | fused | liaison | sandhi | epenthetic | elided
- evidence        : timeline ref / rule id
```

- **声音侧已有真相源**：ListeningUnit 不是新存储，而是现有 Word/Chunk/Phone timeline +
  profile 的**视图**；alignment 是"时间锚定听觉单位"与"文本锚定 token/lexical"之间的关系。
- 1:1 的部分（WordTimeline 词对齐）今天已存在；**新增的是非 1:1**（liaison group 跨 token、
  一个 reduced chunk 对多 token）。

### Seam 4.3 — LexicalUnit 拆"粒度 × 归一"两轴

**问题**：`kind: word|lemma|char|phrase` 把粒度与归一混轴，表达不了"词粒度 + lemma 归一"。

**决策**：

```text
granularity   : char | word | phrase | morpheme        (units 大小)
normalization : surface | lemma | citation | root       (归一形态)
normalized_key: 不透明，profile normalizer 的输出       (禁止任何 substring/去缀假设)
```

| 语言 | (granularity, normalization) | normalized_key 来源 |
|---|---|---|
| en | (word, lemma) | 词形还原 |
| zh | (word, surface) + (char, surface) fallback | 分词后表层 |
| ru | (word, lemma) | 屈折还原 |
| ja | (word, citation) | 动词/形容词 → 辞書形 |
| ar | (word, root) | 形态分析（**非线性**，见 Step 5） |

> **关键**：`normalized_key` 必须是 normalizer 的不透明输出，**不能假设它是表层的子串或去缀
> 结果**——否则阿拉伯语词根（非连续语素）直接破坏它。

## Step 5: 类型学证伪

标注图例：✅ clean pass ｜ ⚠️ needs seam（指明哪条）｜ ❌ forces special case（须修订抽象）

### Japanese（mora / pitch accent / 三文字 / 无空格）

| 字段 / 单位 | 结果 | 说明 |
|---|---|---|
| tokenization | ✅ | 无空格 + 词切分，与 zh 同机制；送り仮名（食べる=漢字+かな）= 单词跨脚本，复用 zh 混排 token 的"保留原始范围" |
| LexicalUnit granularity | ✅ | word（含 char fallback） |
| LexicalUnit normalization | ⚠️ 4.3 | 动词 taberu/tabeta/tabete → citation（辞書形）。闭合 `word\|lemma\|char` 表达不了"词粒度+citation 归一"，需粒度/归一拆轴 |
| ListeningUnit: mora | ⚠️ 4.1 | にっぽん = 4 mora / 2 syllable。mora 不在原 kind 集 → `ja.mora`，开放 taxonomy 接住 |
| **ListeningUnit: pitch accent** | ❌→修订 | はし(箸 HL / 橋 LH) 的"听不出"是**音高最小对立**，**不锚定任何单一词的"词义未知"状态**——当前 observation 只能挂 LexicalUnit，此失败无处安放 |
| rhythm_prosody | ⚠️ 4.1 | mora-timed 不在原枚举（仅 stress/syllable/tone/pitch_accent/mixed）→ `mora_timed` 开放接住；pitch_accent 已在枚举 |
| morphology | ✅ | agglutinative 已在枚举 |
| diagnosis + L1 | ⚠️ Step 3 | English-L1：pitch 全新；Mandarin-L1：mora 较新、pitch 较熟 → L1 seam 被实际触发 |

**ja 净结论**：通过，触发 4.1（mora/mora_timed）、4.3（citation 归一）、L1 seam，并逼出一条
**真实修订**：⬇️

> **修订 R1（来自 ja，zh 同样需要）**：**听力 observation 必须能锚定到 ListeningUnit，而不只
> LexicalUnit。** 声调 / 音高最小对立的"听不出"是听觉单位层的对比失败，不是某个词的属性。
> 这正面回答了 2.5.5 / 2.6 的 Open Question："非词锚定听力观察挂哪里"——挂 ListeningUnit
> 视图 + 一个 contrast 类型的观察。

### Arabic（非线性词根-词型 / abjad / RTL）

| 字段 / 单位 | 结果 | 说明 |
|---|---|---|
| tokenization | ⚠️ 4.1 | 正字法词内有附着语素（clitic）：وبيتهم = wa-(和)+bayt(房)+hum(他们的)。需 clitic 切分，原枚举 `whitespace\|cjk\|char\|mixed` 无此项 → 开放 taxonomy 接住 |
| script underspecification | ✅（强化 listening-first） | abjad 通常不写短元音——**文本严重欠定发音**。对听力 App 是正面验证：text 远不足以表达 audio，必须以听觉为本位 |
| LexicalUnit granularity | ✅ | word |
| **LexicalUnit normalization** | ❌→修订 | 词根 k-t-b：kataba/kitaab/kutub/maktab 共享**非连续**词根。`normalized_key` 若假设为表层子串/去缀 → 失败。词根不是表层的子串 |
| ListeningUnit | ✅ | core.syllable + ar.stress_group（规则重音）；vowel_length 音位性、强调辅音 emphatics |
| sound_features | ✅ | vowel_length **已在原枚举**（stress/tone/pitch_accent/vowel_length）——原设计预留对了 |
| rhythm_prosody | ⚠️ 4.1 | stress（按重音处理） |
| morphology | ⚠️ 4.1 | 非连续/模板形态（templatic）不在原枚举（analytic/fusional/agglutinative/compound_heavy）→ `templatic` 开放接住 |
| diagnosis + L1 | ⚠️ Step 3 | English-L1：vowel length、emphatics、ʕ/ħ/q 难；L1 seam 触发 |

**ar 净结论**：通过，触发 4.1（clitic/templatic）、4.3、L1 seam，并逼出一条**真实修订**：⬇️

> **修订 R2（来自 ar）**：`normalized_key` **必须 provider-opaque，禁止任何结构/子串假设**。
> 阿拉伯语词根非线性，归一是形态分析器的不透明输出。词汇身份建议存 **lemma（citation）为单位
> + root 作二级索引**（word family 在阿拉伯语本就是 root-based，呼应 Nation）。

### 证伪净产出（三条对抽象的真实修订）

| # | 修订 | 来源 | 落点 |
|---|---|---|---|
| R0 | **开放 taxonomy 非可选、是必需** | ja(mora/mora_timed) + ar(clitic/templatic) 全部落在原闭合枚举之外 | Seam 4.1 升级为硬约束 |
| R1 | **听力 observation 可锚定 ListeningUnit（非仅 LexicalUnit）** | ja pitch / zh tone 最小对立 | 2.6 诊断模型 + Open Question 定论 |
| R2 | **`normalized_key` provider-opaque，无子串假设** | ar 非线性词根 | Seam 4.3 强化 |

> 这三条不是橡皮图章，是 ja/ar 真刀真枪跑出来的。**它们便宜地在文档里被发现，而不是在 2.6
> 写到一半被发现。** 这正是本 phase 存在的理由。

## Step 6: Language Envelope（top-15 学习语言 + 类型学聚类）

默认按**学习人数**（产品是听力学习器，ja/ko 因文化驱动学习量大而进前列），非纯母语人数。

近似 top-15 学习语言：English, Spanish, French, German, Japanese, Mandarin Chinese,
Italian, Korean, Portuguese, Russian, Arabic, Hindi, Dutch, Turkish, Vietnamese。

| 簇 | 类型学特征 | 语言 | 代表/状态 |
|---|---|---|---|
| A 欧洲屈折+空格+字母 | 屈折、空格分词、Latin/Cyrillic | es fr de it pt ru nl | en 基线 + es/fr/de/ru 设计验证集（liaison/compound/mobile stress） |
| B 无空格表意/混排+声调或音高 | 词切分、logographic/混排、tone/pitch | zh ja | **zh 已实现 + ja 已证伪**（mora/pitch/三文字） |
| C 非线性形态+abjad+RTL | templatic 词根、abjad 欠定元音、RTL | ar (he) | **ar 已证伪** |
| D 黏着+空格 | 黏着、词≠词素 | ko tr | ko 进 envelope，概念探针（粒度轴 morpheme），本轮不证伪 |
| E 印度系 abugida | abugida（含元音附标）、屈折 | hi | **残留**：abugida 书写轴本轮未压（见下） |
| F 东南亚声调分析语 | 声调、Latin+附标、按音节空格 | vi | tone 机制（zh）+ 空格（en）部分覆盖 |

**覆盖声明**：

- **已实现**：en, zh。**已证伪探针**：ja, ar。**同簇可延展**：es/fr/de/ru/it/pt（簇 A）。
- en + zh + ja + ar 覆盖了**最硬的三条轴**：无空格切分（zh/ja）、mora/pitch 音系（ja）、
  非线性形态（ar），加上欧洲屈折基线（en + 设计集）。
- **已知残留**：**hi 的 abugida 书写系统**是本轮唯一未被压的*书写轴*新形状（元音附标、辅音
  默认带固有元音）。判断：Token 模型"保留原始字符范围 + 字/词粒度"大概率可吸收，但**列为下一个
  书写轴探针**，在 hi 真正进入实现前补一次纸面证伪。
- **小语种**：明确**不进承诺**，可加可不加。架构只对 top-15 envelope 的类型学轴封顶有效。
