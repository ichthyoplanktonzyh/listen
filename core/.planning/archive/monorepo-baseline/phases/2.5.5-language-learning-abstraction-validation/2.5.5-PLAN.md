# Phase 2.5.5 Plan: Language Learning Abstraction Validation

更新时间：2026-06-22 CST

## Objective

在 Phase 2.6 写任何多语言代码之前，证明语言学习抽象：

1. 立得住真实二语习得（SLA），不是工程美学的自我想象；
2. 能扩展到主流学习语言 top-15，不被迫打特例分支；

并锁定 invariant / variant 边界、L1 -> L2 诊断 seam，以及两个扩展性 seam。本阶段交付物是
**设计文档**，不是生产代码。

## Position In Milestone 2

```text
2.3 Manual WordTimeline Review
  -> 2.3.5 Rust Module Decomposition
  -> 2.4 ChunkTimeline
  -> 2.5 Sound Pattern / PhoneTimeline
  -> 2.5.5 Language Learning Abstraction Validation   (本阶段，前置)
  -> 2.6 Multilingual Learning Foundation
```

## Design Principle

```text
validate before implement
  -> ground every abstraction element in real SLA
  -> lock the single invariant (comprehension axis)
  -> minimize, do not expand, the abstraction
  -> falsify on paper with typologically distant languages
  -> name extensibility seams, do not build them
```

关键原则：

- **SLA as ground truth**：抽象正确性的裁判是真实听力/词汇研究，不是内部优雅度。
- **One invariant**：唯一语言不变量是理解轴（词义是否已知 × 声音是否听出，对应 Field 的
  decoding vs meaning-building）；其余结构全是 variant。
- **Minimize, not expand**：本阶段缩小抽象到 en+zh 真正会用到的范围，只为远语言留 seam，
  不做 grand design、不大包大揽。
- **Paper falsification over implementation**：用 Japanese / Arabic 在纸面上证伪，比实现
  四种欧洲语言更能暴露英/中偏置，且成本是一页文档。
- **Seam, not subsystem**：L1 / 开放 taxonomy / 单位 alignment 都以"命名 seam"形式定型，
  实现留到真正需要的语言进入时。
- **Top-15 envelope**：架构只对主流学习语言封顶有效；小语种可加可不加，不进承诺。

## Work Breakdown

### Step 1: SLA Foundation Mapping

把多语言抽象的每个核心元素映射到真实 SLA / 心理语言学依据，产出
`2.5.5-SLA-FOUNDATION.md`。

至少覆盖：

- 诊断轴（词义 vs 声音识别）<- Field 听力解码 vs 建义；Vandergrift & Goh。
- 听觉单位语言特定性（English=stress、French=syllable、Japanese=mora、Mandarin=
  syllable/tone）<- Cutler 及同事的跨语言切分策略；Otake et al.；Mehler et al.
- chunk / phrase 听觉单位 <- Wray 公式化语块。
- LexicalUnit 取代 lemma <- Nation word family 及其对形态复杂语言的局限。
- `meaning candidates` 节点 <- Marslen-Wilson cohort / 口语词识别候选竞争。
- L1 过滤 L2 <- Best PAM；Flege SLM。

Exit criteria:

- 每个核心抽象元素都有"依据 / 务实取舍 / 应删除"三选一的明确标注。
- 没有任何被陈述为合理但无依据的悬空概念遗留进 2.6。

### Step 2: Invariant / Variant Boundary Lock

明确并写死哪一层跨语言不变、哪一层按语言变。

- **Invariant**：理解轴的全局词汇状态枚举（`Unclassified / UnknownMeaning /
  KnownNotRecognized / KnownRecognized`）声明为语言无关、跨语言复用、持久资产稳定。
  理由：它定义在 meaning × sound 的理解轴上，不依赖任何书写/形态/音系特征，对任何语言
  的听力都成立。
- **Variant**：tokenization、lexical unit、listening unit、pronunciation、
  rhythm/prosody、morphology、diagnosis reason taxonomy 全部经由 profile / provider。
- **关键区分**：持久"状态"（invariant）与派生"诊断理由 reason"（variant、可按 profile
  扩展）必须分层，状态稳定、理由按语言可扩展。

Exit criteria:

- invariant / variant 边界在文档中以一条清晰的线表达，可被 2.6 直接引用。
- 全局状态枚举被显式声明为语言不变量；诊断 reason taxonomy 被显式声明为 per-profile。

### Step 3: L1 -> L2 Diagnosis Seam

把 L1 作为诊断模型的一等（可空）维度定型。

- 诊断概念上从 `diagnose(L2_unit, status)` 变为 `diagnose(L1, L2_unit, status)`。
- 本阶段只定 seam：一个可空 `learner_l1` 维度，v1 不参与任何规则计算。
- 说明未来 L1-aware 用途（如中文母语者听英语弱读、英语母语者听中文声调的不对称难点），
  但不实现规则、不改 schema。

Exit criteria:

- 诊断模型设计含一个可空 L1 维度，且明确 v1 不读取它。
- 文档说明该 seam 如何在不改持久 schema 的前提下后续启用。

### Step 4: Extensibility Seams Specification

为两个会在远语言处漏的关节定型概念，命名但不实现。

1. **Open `kind` taxonomy**
   - 决策：`lexical_units` / `listening_units` / `rhythm_prosody` / `morphology` 等
     taxonomy 采用 namespaced string + "未知即干净降级"，而不是穷举 `enum` + 穷举
     `match`。
   - 理由：capability matrix 的"干净降级"哲学要求开放枚举；穷举 enum 与之自相矛盾，且每
     加一种语言都要回改枚举与所有 match 臂。
2. **Token <-> LexicalUnit <-> ListeningUnit N:M alignment**
   - 定型一个"单位间多对多对齐"概念，作为 liaison / 变调 / 弱读 / reduced form 的归宿。
   - 同时修正 `LexicalUnit.kind` 把"粒度"与"归一形态"混轴的问题：拆为两条正交轴——
     粒度（char / word / phrase / morpheme）× 归一形态（surface / lemma / citation /
     root）。

Exit criteria:

- 两个 seam 各有"形状 + 为什么"的规格说明。
- `LexicalUnit` 的粒度/归一两轴分离方案被记录，可表达"词粒度 + lemma 归一"（俄/德）与
  "词粒度 + surface"（中文）。
- 明确这些 seam 在 2.6 只落到接口/概念层，不落实现。

### Step 5: Typological Falsification (ja + ar [+ ko])

用类型学上远的主流学习语言逐字段证伪抽象，产出 `2.5.5-FALSIFICATION.md`。

- **Japanese**：mora ≠ 音节、pitch accent、三文字混排、无空格。
  - 关键证伪点：はし(箸/橋) 的高低音"听不出"锚在 ListeningUnit，挂不到任何"词"上——
    检验 Step 3 的 L1 seam 与"非词锚定听力观察"的归宿。
- **Arabic**：非线性（词根-词型）形态、RTL abjad、无短元音。
  - 关键证伪点：kataba / kitaab / kutub 共享词根 k-t-b，`normalized_key` 无法用线性子串
    表示——检验 Step 4 的粒度/归一两轴拆分是否成立。
- **Korean（可选）**：黏着、形态爆炸、有空格但词 ≠ 词素——检验粒度轴对 morpheme 的容纳。

方法：把每种语言逐字段填进 capability matrix，逐单位走一遍 Token / LexicalUnit /
ListeningUnit 三分模型，对每个字段标注 `clean pass / forces special case / needs seam`。

Exit criteria:

- Japanese 与 Arabic 在纸面上通过且零特例分支；不通过处被反馈为对 Step 1–4 抽象的具体
  修订，并记录修订点。
- 证伪结果明确指出哪些字段必须是开放 taxonomy（否则远语言加不进来）。

### Step 6: Language Envelope Scoping

明确架构的目标语言封顶范围与类型学聚类。

- 列出主流学习语言 top-15（按学习人数而非纯母语人数，纳入 ja/ko 等文化驱动语言）。
- 按类型学聚类标注（欧洲屈折+空格 / 无空格表意+声调 / 非线性形态 / 黏着 等），并标注每簇
  由哪个已实现或已证伪语言代表。
- 声明：架构对 top-15 封顶有效；小语种可加可不加，不进本阶段及 2.6 承诺。

Exit criteria:

- top-15 集合与聚类映射成文，每个类型学簇都有代表语言。
- 明确哪些语言是"已实现"（en/zh）、"已证伪探针"（ja/ar/ko）、"同簇可延展"（es/fr/de/ru/
  it/pt 等）。

### Step 7: Feed Back Into 2.6 And Closeout

把校验结论回灌 Phase 2.6，并收口本阶段。

- 更新 `2.6-CONTEXT.md` / `2.6-PLAN.md`：消费已校验抽象，引用 2.5.5 为前置；把 Step 1.5
  Listening Model 的 ListeningUnit 明确为"概念 + 诊断词汇表 + 现有 timeline 资源的视图"，
  不新建持久表；诊断 reason 与全局状态分层；加入 L1 seam。
- 把 2.6 Open Questions 中已被本阶段回答的项标注为已决；新增 alignment / 开放 taxonomy
  作为 2.6 的实现约束。
- 写 `2.5.5-CLOSEOUT.md`，更新 `STATE.md`，把 2.6 标为"待 2.5.5 收口后进入"。

Exit criteria:

- 2.6 文档反映已校验抽象，不再有悬空概念。
- STATE.md 反映 2.5 -> 2.5.5 -> 2.6 的新顺序与 2.5.5 收口状态。

## Validation

本阶段不跑 cargo / flutter，而是以下面四条作为"测试"：

```text
1. SLA 映射完整：每个核心抽象元素都有依据/务实取舍/删除三选一标注。
2. invariant/variant 边界、L1 seam、两个扩展 seam 均成文且各有理由。
3. Japanese + Arabic 纸面证伪通过且零特例分支（或抽象被修订到通过）。
4. 2.6 文档与 STATE.md 已回灌，无悬空概念遗留。
```
