## SLA 裁决（主干是否凭空想象）

主干 **evidence-grounded**，不是想象：

- 诊断轴（词义 vs 声音）= Field 的 decoding vs meaning-building。
- 听觉单位语言特定性 = Cutler 跨语言切分（en=stress / fr=syllable / ja=mora / zh=syllable·tone）。
- Token/LexicalUnit/ListeningUnit 三分 = 正字法/音系词区分 + 韵律音系层级（Nespor & Vogel）。
- LexicalUnit = Nation word family；chunk = Wray 公式化语块；候选竞争 = Marslen-Wilson cohort。
- L1 过滤 L2 = Best PAM + Flege SLM + Cutler 切分迁移。

唯一被判 `revise` 的是 capability **字段过度分解**（rhythm/sound_features/listening_units 共变）
与 `LexicalUnit.kind` 混轴——均已在 R 修订中收敛。

## 证伪逼出的三条修订（真实、非橡皮图章）

- **R0 开放 taxonomy 是必需**：ja(mora/mora_timed) + ar(clitic/templatic) 全落在原闭合枚举外。
  → kind 用 namespaced string + 未知即降级，禁止穷举 enum。
- **R1 听力 observation 可锚定 ListeningUnit**（不止 LexicalUnit）：ja pitch / zh tone 的最小
  对立"听不出"不是某个词的属性。→ 回答了"非词锚定听力观察挂哪里"。
- **R2 `normalized_key` 必须 provider-opaque**：ar 非线性词根 k-t-b 不是表层子串。→ 词汇身份
  存 lemma/citation + root 二级索引。

## 锁定的 invariant / variant 边界

- **Invariant（跨语言、持久、稳定资产）**：理解轴的全局词汇状态枚举。
- **Variant（per-profile/provider）**：tokenization、lexical unit、listening unit、
  pronunciation、prosody、morphology、**诊断 reason taxonomy**、L1 维度。
