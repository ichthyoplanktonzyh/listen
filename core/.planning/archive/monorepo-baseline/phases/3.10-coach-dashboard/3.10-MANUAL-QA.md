# Phase 3.10 Manual QA: Coach Dashboard

状态：READY FOR OWNER QA（2026-07-12）

## 目标

确认 Dashboard 在真实学习历史上确实回答“哪里有证据、是否在改善、下一步做什么”，并保持
建议式、无惩罚感。自动化已覆盖聚合口径、通道缺席、来源分页、材料轨迹、确认式毕业和
10,000 事件性能；本清单只保留产品体验与真实数据裁决。

## 前置

- 使用包含真实媒体和既有练习/复习/泛听历史的日常数据库。
- 至少准备一份可完成两次泛听的材料；两次结束时分别选择“听懂大意”和“全部听懂”。
- 如当前没有到期复习或猎词候选，对应建议缺席属于正确降级，不必造假数据。

## QA-A：入口与总体语义

1. 从首页“学习工具”打开“学习教练”，再从左侧“我的学习”打开一次。
2. 确认页面能在正常窗口和窄窗口阅读，无横向溢出或卡片遮挡。
3. 确认页面没有 streak、打卡、红点、失败惩罚或“必须完成”语气。
4. reading / speaking / writing 显示“尚未评估”，不显示 0 分或负面能力结论。

通过标准：入口自然；页面是诊断和邀请，不是任务中心。

## QA-B：数字与来源事实

1. 对照最近 7 天实际行为，检查泛听次数/时长、练习、复习等数字是否方向正确。
2. 逐个点击有数据的指标卡。
3. 确认弹窗列出实际 session / attempt / event / capability-history ID、结果和本地时间。
4. L1 规则命中文案和来源不得暗示为音频确证或个人能力定论。

通过标准：每个数字能下钻到 durable facts；无来源的 0 不伪造明细。

## QA-C：建议与跳转

1. 若有到期复习，点击建议并确认进入声音复习队列。
2. 若有猎词候选，点击建议并确认进入包含猎词单的词汇界面。
3. 点击“继续真实内容输入”并确认返回工作台，而不是创建任务或修改状态。
4. 返回 Dashboard，确认跳转没有清除或重复生成学习事实。

通过标准：建议可执行、可返回、无副作用；缺席上游数据不阻塞其他建议。

## QA-D：材料轨迹、分档与毕业

1. 对同一真实材料完成两次泛听，依次自报“听懂大意”与“全部听懂”。
2. 打开 Dashboard，确认“材料进展”显示该材料及“大意 → 全部听懂”的轨迹。
3. 若材料达到候选门槛，点击“标记已毕业”；先取消，确认内容库没有变化。
4. 再次确认毕业，回到首页确认该材料进入“已毕业”分组。
5. 对连续自报“不清楚”的材料，确认只给出“转入精听”建议；取消不改变队列，确认后才改变。
6. 对稳定“听懂大意”的材料，确认可建议保留泛听；建议不得自动执行。

通过标准：轨迹与真实自报一致；任何队列/毕业变化均需确认；毕业不改变词汇或四通道能力。

## QA-E：历史不足与降级

在无学习历史的新数据库或测试 profile 中打开 Dashboard：

- 显示三项 starter checklist；
- 不显示伪造建议或伪造改善；
- future channels 仍为“尚未评估”；
- 页面不是空白页，也不报错。
