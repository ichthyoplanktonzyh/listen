# Phase 2.24 Interface Inventory

> 初始盘点：2026-07-14
> 基线提交：`66ba51a0`
> 目的：记录 caller、变化原因和 dependency category，防止以机械 trait/拆文件冒充解耦。

## 1. Cargo 与 crate seam

当前依赖方向成立：

```text
domain <- subtitle-core / diagnosis-core / speech-analysis <- application
application <- persistence-sqlite / dictionary-provider / llm-provider / syntactic-provider / api-http
api-events <- api-http
```

- `api-http` 直接引用 `speech_analysis::`：0。
- Cargo 循环依赖：0。
- `application -> speech-analysis`：合法的 in-process core-engine dependency；不为纯算法创建 port。
- 外部 runtime（HTTP download、OS process、filesystem）：local-substitutable / true-external，
  适合 production + fake adapter。

## 6. `api-http` runtime ownership

| Module | Runtime responsibilities | Dependency category | 目标 |
|---|---|---|---|
| `transcription.rs` | download、checksum、filesystem、process、queue、job state、events | true-external + local-substitutable | runtime transcription module |

拟新增真实 seams：

- `ProcessRunner`：Tokio production adapter + deterministic fake adapter。
- `ArtifactDownloader`：HTTP/file production adapter + in-memory fake adapter。
- job event sink：runtime-neutral facts + api-http SSE adapter + test recorder adapter。

文件系统优先使用真实 temporary directory stand-in；只有测试无法通过 module interface 覆盖时
才新增 filesystem port。

## 8. Rust/Python locality

- production/test Rust 共 63 处 `use domain::*` / `use crate::*`；Step 5 先清 production，
  test-only `super::*` 不属于同一问题。
- `persistence-sqlite/src/subtitles.rs` 1337 行，实现 subtitle、pronunciation、timeline、
  LLTimeline 四个 interfaces；属于机械文件 locality，不需要新 seam。
- `production_pipeline.py` 1433 行，函数自然聚为：
  - acoustic cue calculation；
  - timeline JSON conversion/alignment merge；
  - production quality report；
  - audio preparation/tool resolution；
  - post-aligner orchestration；
  - CLI parser/dispatch。
- 现有 `aligners.AlignerPlugin` 已是有效 variation seam，继续复用，不创建第二套 adapter。
