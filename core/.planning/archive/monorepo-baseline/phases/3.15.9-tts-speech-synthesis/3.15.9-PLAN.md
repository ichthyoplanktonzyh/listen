## Objective

交付一个高频、provider-neutral 的语音合成深模块：默认在 macOS 使用系统本地语音，
让词典词语/无真人音频例句与 Writing learner text 可一键听回；统一合成、缓存、取消、
来源标识和音频焦点，但允许各场景使用自己的 surface。

本地优先不等于把 Piper 写死为领域事实。当前 macOS 底盘已具 `/usr/bin/say`，零下载、
离线、可枚举多语言 voice 并可输出 AIFF；因此 v1 先以系统语音 adapter 提供立即可用的
本地路径。Piper 是未来跨平台/质量 adapter 候选，只有经真实质量、许可、体积与生命周期
审计后才进入，不为复用 3.9.3 七态而制造下载成本。在线 provider 可在用户明确配置并同意
发送文本后接入同一 seam，本 phase 不交付。

## 高频用户场景与优先级

1. 词典词语：优先播放 dictionary provider 的真人/词典标准音频；缺失时显示并使用本地
   TTS fallback。TTS 不替代 PRON-001 的规范音素事实。
2. 无真人音频例句：词典来源快照/个人产出中的文本可本地朗读；有真实媒体切片时仍以真实
   切片为学习首选，TTS 是补充，不伪装成原声。
3. Writing 读回：朗读当前 learner-owned draft、submitted response 或 revision；不朗读
   provider suggestion 作为用户产出，也不改写 attempt。
4. L1 提示、最小对立对素材、conversation/review 批量生成延后；这些是合法后续 consumer，
   但需各自验证 voice 质量、任务语义与干扰预算。

## Deep Module 与 provider-neutral seam

外部 interface 不是浅的“文本 → bytes”，而是：

```text
SpeechSynthesis
  capability / provider + voice descriptors
  synthesize(SynthesisRequest) -> SynthesisAsset
  clearRebuildableCache()
```

`SynthesisRequest` 包含 text、BCP-47 language、可选 voice、语速和场景 purpose；
`SynthesisAsset` 包含本地可播放 path、provider/voice/version、语言、合成标记、format、
cache hit 与稳定 content hash。调用者无需知道进程、输出格式、临时文件、原子发布、
并发去重或 provider 命令行。

- application 定义 `SpeechSynthesisProvider` port 与中立 DTO；provider 只产生带 provenance 的
  draft/artifact，不接触任何学习 repository。
- local-runtime 的 `SpeechSynthesisManager` 选择 adapter、校验请求、按
  provider/version/voice/language/rate/text 建 cache key、single-flight 合成并原子发布文件。
- 首个生产 adapter 是 macOS system speech；deterministic fake adapter 跑同一 manager contract。
- 新增 provider 只扩展 descriptor/adapter；不得修改 dictionary、Writing attempt、production
  corpus 或 capability 语义。

## 音频焦点与资源生命周期

- Flutter 建单一 auxiliary speech playback controller，统一 dictionary remote audio 与 TTS
  asset；新请求取消/释放旧实例，页面关闭与 app dispose 释放资源。
- 播放 auxiliary speech 前暂停主媒体、slice player、review/recording playback；不自动恢复，
  保留用户位置与 loop 状态。开始录音或其他 foreground audio 时反向停止 auxiliary speech。
- 后端合成进程 `kill_on_drop`，同 cache key 并发请求只生产一次；失败不留下半文件。
- cache 是可重建本地资源，不进 SQLite、不进 vocabulary bundle、不进 LLTimeline；提供体积状态
  与显式清理。provider/voice/version 或请求变化自然产生新 key，旧文件可清理而不影响事实资产。
- 系统 voice 缺失/语言不支持/进程失败时 capability 或请求诚实失败；所有原有播放、词典、
  Writing 与生产语料功能保持可用。

## 与相邻领域的边界

- pronunciation：PRON-001/字典音频是规范发音或 provider 资源；TTS 是可听 rendering。
  词典标准音频优先，TTS fallback 必须标“合成语音”。
- slice playback：真人媒体 occurrence 仍是语境证据并优先；TTS 不生成 occurrence、
  ListeningUnit、RhythmFrame 或 PhoneTimeline。
- conversation/review：未来可消费同一 synthesis interface，但 session/turn/review facts 与播放
  surface 归各自领域；本 phase 不提前建 conversation/review writer。
- Writing / personal production corpus：只读 controller 当前 learner text；不修改 immutable
  attempt，不刷新/新增 production corpus document，不把音频或播放次数写成 assistance/evidence。
- capability：TTS playback 永不写 learning observation、semantic judgment 或 projection。

## Exit Signals

- 无额外模型安装即可在支持的 macOS 上本地合成；系统能力不可用时零回退损害。
- 词典标准音频优先且 TTS fallback 明示；无真人音频例句与 Writing learner text 可朗读。
- 主媒体、slice、remote pronunciation、TTS 与录音之间不存在双声源；快速切换无泄漏。
- 相同请求命中可重建 cache；并发不重复生产；可查看/清理资源；失败无半文件。
- provider/voice/language/version provenance 由 typed asset 暴露；在线 provider 未配置时不发送任何文本。
- 负向测试钉住零 attempt mutation、零 production-corpus writer、零 observation/judgment/projection。
