# Phase 2.3.5 Closeout: Rust Module Decomposition

> 日期：2026-06-21
> 状态：完成

## 结果

Phase 2.3.5 已完成 `persistence-sqlite`、`application`、`api-http` 三个核心 Rust crate 的 mechanical decomposition。

本阶段没有引入产品能力、没有修改 HTTP API contract、没有修改 SQLite schema。目标是为 Phase 2.4 ChunkTimeline 和 Phase 2.5 PhoneTimeline 留出清晰的代码落点。

## 拆分结果

### `persistence-sqlite`

- `connection.rs`：`SqliteRepository`、连接打开、schema version、迁移备份路径。
- `migrations.rs`：schema version 和迁移 SQL。
- `support.rs`：错误、JSON helper、repository lock helper。
- repository / 表域模块：`media.rs`、`progress.rs`、`transcription.rs`、`dictionary.rs`、`phonetic_analysis.rs`、`vocabulary.rs`、`subtitles.rs`、`lexical.rs`。
- `tests.rs`：原 crate-level 单元测试。

### `application`

- shared contract：`dto.rs`、`repositories.rs`、`providers.rs`、`error.rs`、`util.rs`。
- use case 模块：`media.rs`、`vocabulary.rs`、`subtitles.rs`、`pronunciation.rs`、`word_timelines.rs`、`chunks.rs`、`transcription_pipeline.rs`、`phonetic_fixture.rs`、`dictionary.rs`、`learning.rs`、`diagnosis.rs`、`lexical.rs`。
- root `lib.rs`：保留 `AppServices`、public re-export、shared timeline helper。

### `api-http`

- `routes/`：`media.rs`、`pronunciation.rs`、`speech.rs`、`timelines.rs`、`transcription.rs`、`phonetic_analysis.rs`、`vocabulary.rs`、`dictionary.rs`。
- root `lib.rs`：保留 `ApiState`、router registration、auth middleware、SSE events、error response。
- `api-http` 的 `speech-analysis` Cargo 直接依赖已移除；HTTP 层通过 `application` 编排访问语音分析能力。

## 验证

- `cargo test --workspace --quiet` 通过。
- `git diff --check` 通过。

## 后续约束

- 新增 persistence 逻辑进入 `crates/persistence-sqlite/src/<domain>.rs`，迁移进入 `migrations.rs`。
- 新增 application 编排进入 `crates/application/src/<use_case>.rs`。
- 新增 HTTP handler 进入 `crates/api-http/src/routes/<route_group>.rs`，只在 root `lib.rs` 注册 route。
- `domain/src/lib.rs` 仍较大，但不阻塞 Phase 2.4；如后续领域类型继续增长，可单独开架构阶段处理。
