## Summary

The evaluation stage is now real enough to expose failures.

Phase 2.17 proved the pipeline can run and no longer emits obvious false `linking` markers. Phase 2.19's first scorer shows that phone-level benchmark quality is mixed:

- TED-LIUM transcript/timing import is exact against `.stm`.
- Buckeye s0201a and s0301a score in the same rough range as the historical fb-espeak TIMIT baseline.
- Buckeye s0101a and the Phase 2.17 TIMIT artifact are poor and require investigation before we trust their score as model quality.

## Findings

1. **TED-LIUM is currently a transcript/timing check, not phone-quality evidence.**
   The exact result is expected because the artifact is generated from STM-like reference segmentation.

2. **Buckeye can already produce useful signal.**
   s0201a at `0.304348` PER and s0301a at `0.352423` PER suggest the current phone recognizer is in the expected range on some natural speech windows.

3. **s0101a first window is not trustworthy as model-quality evidence.**
   It scores `1.004525` PER and contains unknown prediction symbols `a`, `aː`, and `ɪɹ`. The first scored segment includes `{B_TRANS}` and a long lead-in window, so this likely mixes windowing/noise and symbol-mapping failures.

4. **The Phase 2.17 TIMIT artifact is abnormally bad.**
   Its `0.874286` PER is much worse than the historical `0.304636` fb-espeak TIMIT dev baseline. Treat this as an artifact/pipeline investigation item, not as final model quality.

5. **Current benchmark result: pipeline quality is not yet release-grade.**
   The runner and scorer are working; the phone identity layer needs mapping, windowing, and boundary diagnostics before it can support a release gate.

## Next Questions

- Are TIMIT sentence windows correct after LLTimeline import/export and API job creation?
- Should `phone_recognition` map additional espeak outputs (`a`, `aː`, `ɪɹ`, `x`, `ei5`, `s.`) instead of passing them through?
- Should Buckeye scoring skip non-lexical lead-in windows by default?
- How much of PER is sequence identity vs boundary/window drift?
- What precision do Brooklyn / Venezuela sound-line markers achieve under manual listening?
