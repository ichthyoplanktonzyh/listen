# Phase 3.9.1 Closeout: Shared Syntactic Analysis Provider

状态：COMPLETED — NEGATIVE PROVIDER QUALIFICATION

完成时间：2026-07-13 16:53 CST

产品裁决：没有 qualified parser；保留现有 B / rule SenseGroup fallback

上游：Phase 3.9 Reference B、Phase 3.4.2 SenseGroup、Phase 3.4.3 Construction Spike、
ADR 0010 / 0011 / 0016 / 0020，以及 `3.9.1-PLAN.md`。

## Outcome

Phase 3.9.1 建立了一份共享、provider-neutral、可重建的英文句法分析契约，并证明 Reference B、
SenseGroup 与 dependency matcher 可以消费同一 artifact，而无需把 Stanza/spaCy 私有类型带入
消费者。token alignment、tree validation、provider/model provenance、closed failures、资格 gate
和无模型降级均已落地。

本阶段也得到明确的负向研究结论：Stanza 1.13.0/en_ewt 与 spaCy 3.8.13/en_core_web_sm 3.8.0
都在锁定验证集的 multi-token wh-extraction 上产生一个高风险假阳性，因此均为
`not_qualified`。依 PLAN Slice 3 的预设分支，本阶段以研究结论收口，不伪造产品 parser 能力。

## Delivered

### Neutral artifact and provider boundary

- ADR 0023 固定 rebuildable identity、Unicode scalar half-open span、1:N/N:1 mapping、缓存隔离、
  validation/qualification 双 gate 与模型生命周期边界。
- domain `SyntacticAnalysis` 包含 lemma/POS/morphology/dependency、完整 runtime/model/checksum/
  profile provenance、source fingerprint 与显式 unaligned 状态。
- application provider 只返回 draft；server-side finalizer 铸造 artifact identity 并对精确字幕
  snapshot 运行 span、coverage、HEAD、root、cycle、ownership validator。

### Research adapters and qualification

- 独立 `syntactic-provider` crate + JSONL Python sidecar；Stanza/spaCy 均映射到同一中立契约，
  stdout 只传协议，stderr 只传诊断。
- runtime/model missing、corrupt、unsupported language、timeout、malformed protocol、invalid output
  都闭合失败，不产生 draft；runtime/model 不进入应用 bundle。
- 12 development + 12 digest-locked validation cases、mapping contracts、预登记 gate、raw report、
  性能/RSS/体积与分层许可审计齐全。验证集每个候选只运行一次，失败后未加特例调参。

### Consumers and Construction seam

- Reference B 仅对验证过的 future/motion `going to`、habitual/state `used to`、`have to do with`
  query 建 syntax seam；`want to` 因失败保持 text heuristic。syntax evidence 仍为
  `PossibleByRule`，绝不升级成 C。
- `syntax-aware-sense-group/v1` 与 rule provider 是独立 analysis run。dependency subtree 只提出
  boundary/head/NP-PP-clause 候选，强标点、短语完整性、min/max 和 3–5 教学粒度最终裁决；低
  coverage/错误 snapshot 精确 fallback，ChunkTimeline 不参与。
- dependency matcher 只产出 source artifact + subtitle span + bindings 的 rebuildable candidate；
  类型与序列化守卫证明没有 Construction/canonical/occurrence/capability identity。

## Frozen Decisions

1. 结构 validation 与 provider qualification 是两个独立 gate；结构合法不能自动获得产品资格。
2. 当前 Stanza/spaCy 只保留为隔离研究候选，产品 composition 不启用。
3. `want to` 不使用句法 gate；未来必须通过新的预登记/锁定 fixture 版本重新资格评估。
4. 句法 artifact 不是用户资产、学习证据、C/audio evidence 或 ChunkTimeline parent。
5. matcher candidate 不是 Construction canonical identity；后续 curated layer 必须独立铸造/链接。

## Next
