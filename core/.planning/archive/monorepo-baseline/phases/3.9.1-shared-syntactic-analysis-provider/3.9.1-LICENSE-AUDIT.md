# Phase 3.9.1 Runtime / Model / Treebank License Audit

状态：Slice 0 initial audit，2026-07-13。不是法律意见；未核实项一律 research-only。

## 审计规则

代码/runtime、模型权重、训练 treebank、预训练向量/embedding 是四个不同资产。只有 runtime
许可证清楚不能推导模型可再分发。每次实际下载后必须补齐 exact artifact URL、version、SHA-256、
compressed/unpacked size 和随包 license/model card snapshot；缺一项不得进入可分发产品路径。
