## 2. Token alignment gate（强制）

分母为所有 `kind=word` 的 SubtitleToken；标点另报，不用标点抬高词覆盖率。

```text
lexical_alignment_coverage = 有至少一个合法 syntactic-token 映射的 word token 数 / word token 总数
exact_span_rate = 映射联合 span 与 SubtitleToken span 完全相等的 word token 数 / word token 总数
silent_misalignment_count = validator 接受、但映射到不相交 source span 的关系数
```

通过条件：

- 验证集 lexical alignment coverage 总体 `>= 0.995`；每个关键歧义 case `= 1.0`。
- `silent_misalignment_count = 0`。
- mapping-contract-v1 的 split/merge/normalized-overlap/Unicode 示例全部通过。
- 非 exact mapping 必须带显式 status；未映射 token 必须出现在 diagnostics。
- parser offset 不是 Unicode scalar 时，adapter 必须转换并由非 ASCII fixture 验证；不得透传冒充。

任一失败都禁止下游 syntax activation，即使 dependency accuracy 看起来更高。

## 3. 关键歧义 gate（强制）

按 fixture 的 `decision_targets` 评分。一个 case 只有在所需 lemma/UPOS/dependency query 都足以
支持预期 allow/block 时才算正确；parser 恰好给出最终字符串但证据链不成立不算正确。

通过条件：

- 所有目标 macro accuracy `>= 0.90`。
- future/motion `going to`、habitual/state `used to` 各自 balanced accuracy `>= 0.90`。
- 高风险 false positive 为零：motion/location 不得触发 future `gonna`；`be/get used to + NP/GERUND`
  不得触发 habitual；`has to do with` 不得触发 obligation reduction。
- validation 中已有 surface `gonna/wanna` 只用于解析/映射，不得当作预测成功。
- 无足够句法证据时结果是 abstain，并走现有 B fallback；不得猜 allow。

开发集错误可驱动通用 adapter/contract 修复，但不能增加只命中验证文本的特例。

## 4. Tree validity and failure gate（强制）

- 每个标记为 valid 的 sentence：span 有界、HEAD 有效、恰好一个 root、无环、全部 HEAD 同句。
- crash rate `= 0`；malformed response 被 closed taxonomy 捕获且不写 artifact。
- timeout rate `<= 0.01`，单句 hard timeout 为 5 秒、100 句 batch hard timeout 为 60 秒。
- runtime/model missing、unsupported language、corrupt model、timeout、invalid output 都必须让字幕导入、
  播放、A、现有 B 和 rule SenseGroup 继续工作。

验证集 v1 样本较小，因此任何一次 crash 或 timeout 都视为失败；`<= 0.01` 是后续扩大 real-media
run 的资格线，不用小样本零失败宣称稳定性。

## 5. Resource gate（研究资格与产品候选分开）

参考机器必须记录：芯片、RAM、macOS、Python、候选 runtime/model 精确版本、线程数。测量包括
sidecar spawn、模型加载和第一批请求。

产品候选通过条件：

- 三次冷启动 p95 `<= 20 s`。
- 预热后单句 latency p95 `<= 250 ms`，100 句 batch throughput `>= 8 sentences/s`。
- 峰值 RSS `<= 2 GiB`。
- 隔离 venv + 所需模型总磁盘 `<= 2 GiB`。
- 默认 consumer bundle 增量必须为 `0 B`；模型只可按需安装。

超过资源线的候选仍可作为 research quality baseline，但不得被称为产品 qualified provider。

## 6. License/provenance gate（强制，且独立于质量）

runtime、model weights、每个 training treebank/dataset、word vectors/embeddings 分别登记：精确版本、
下载 URL、SHA-256、体积、license 原文/URL、redistribution、commercial use、notice/share-alike 要求。
任一项 unknown 即 `research_only`；质量与资源全过也不能进入可分发路径。

## 7. Provider qualification decision

报告只能给出以下结论之一：

- `qualified_product_candidate`：全部 correctness/alignment/failure/resource/license gate 通过；
- `qualified_research_baseline`：correctness/alignment/failure 通过，但资源或分发许可未通过；
- `not_qualified`：任何 correctness/alignment/failure gate 失败。

Stanza 与 spaCy 是首轮候选，不是预定赢家。若二者都失败，本阶段保留 fallback 并以负结果收口。
