Both small models attach the wh phrase in a form that the development-frozen
neutral query cannot distinguish safely from an extractable object. Allowing

when both models collapsed subject/object evidence. The validation failure
shows that a multi-token wh phrase introduces a second ambiguity shape. This is
recorded for a future candidate/fixture v2, not tuned into v1 after inspection.

## Propagation decision

- `going to`, `used to`, and `have to` neutral dependency queries are suitable
  for consumer seam tests because both candidates passed their locked pairs.
- `want to` is not syntax-enabled. Existing conservative Reference B behavior
  remains authoritative.
- A provider result cannot activate product behavior merely because it validates
  structurally. Product composition requires a separately qualified provider
  decision, which is absent in this phase.
- Missing/failed/unqualified syntax leaves current Reference B and rule-based
  SenseGroup unchanged. It never populates Reference C or ChunkTimeline.

Raw reports are preserved under `evaluation/` for case-level review.
