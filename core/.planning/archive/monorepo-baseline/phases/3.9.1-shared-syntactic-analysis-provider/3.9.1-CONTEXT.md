# Phase 3.9.1 Context: Shared Syntactic Analysis Provider

日期：2026-07-13

## 为什么插入这个阶段

Phase 3.9 的 Reference B 已从无条件字符串替换进化为带保守上下文阻断的语流预测，但继续
扩展 `going to`、`want to`、`used to`、功能词弱读等规则时，仅凭相邻词和词表无法稳定区分
动词补语、地点名词、疑问抽取和惯常/状态构式。

与此同时，Phase 3.4.2 的 SenseGroup 当前仍使用 `punctuation_length_rule_v1`：标点、长度
限制和 PhraseCandidate 保护只能建立保底分组，不能可靠保持 NP / VP / PP / 从句结构。Phase
3.4.3 也已证明 Construction 需要稳定 occurrence/slot 身份，但没有生产级句法来源。

因此，本阶段建立一个共享、可重建、Provider-neutral 的句法分析层；B、SenseGroup 和
Construction 只消费统一分析结果，不分别堆叠互不一致的上下文猜测。

## 已有架构裁决

- ADR 0016 已规定 `SenseGroupAnalysis` 不依赖特定 parser；UD dependency parse 是未来
  Provider，而当前规则 Provider 必须保留为无模型降级路径。
- SenseGroup 是文本 token span；ChunkTimeline 是声音/韵律 time span。句法结果不得冒充
  声学边界。
- Reference B 是文本条件下的可听结构预测；即使使用句法模型，也不得填充需要真实声音证据
  的 C。
- Construction canonical identity 不由 parser/LLM 直接铸造；parser 只提供可重建的 occurrence
  证据和候选结构。
- Python forced-alignment sidecar 已证明 JSON 请求/响应、逐项校验、失败降级的可行性；ADR
  0011 同时证明 token index 映射必须显式，不能假设 Python 分词与 SubtitleToken 一一对应。

## 业界参考结论

共同可复用的标准是 Universal Dependencies / CoNLL-U，而不是某个解析器的私有对象。稳定
契约至少需要：FORM、LEMMA、UPOS、XPOS、FEATS、HEAD、DEPREL，以及原文 char span 和项目
token 映射。

首轮候选：

| 候选 | 本阶段用途 | 主要风险 |
|---|---|---|
| Stanza | UD-first 质量基准与首个 Python research Provider | Python/PyTorch、模型体积和启动成本 |
| spaCy | 英语工业基线、dependency pattern 参考 | 跨语言一致性与模型分发需单独审计 |
| UDPipe 1 | C++/FFI 与轻量离线生产候选 | 官方预训练模型通常带非商业限制；代码与模型许可分离 |
| Trankit | Transformer 质量对照，仅在前两者不足时运行 | 资源成本高，不作为首个生产候选 |

Festival 的 post-lexical rules 和 eSpeak NG 的多词/上下文发音规则证明 A→B 应采用“词典发音
+ 句法/词性条件 + post-lexical transformation”的分层；Semgrex / DependencyMatcher 证明
Construction 应在依存图上匹配，而不是退化为字符串搜索。MFA 等 forced aligner 只作为 C
的音频证据参考，不进入句法权威层。

## 关键产品例子

```text
I'm going to leave after lunch.
```

- syntax：`going to` 后接动词补语；
- B：允许生成未来构式的压缩候选；
- SenseGroup：可形成 `I'm going to leave / after lunch`；
- Construction：命中 `BE GOING TO + VERB` occurrence。

```text
I'm going to London after lunch.
```

- syntax：`to London` 是方向/地点结构；
- B：不得生成 `gonna`；
- SenseGroup：保持 `I'm going to London / after lunch`；
- Construction：不得命中未来构式。
