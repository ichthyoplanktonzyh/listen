model removal partial → restore → cancel → uninstall。取消测试揭示 `venv/ensurepip` 孙进程竞态后，
installer 改为独立 process group；最终 release 实测 Cancel 返回 disabled、staging 清空、旧安装可重新启用。

App 内普通用户闭环，并以 HTTPS pinned wheel hash、组合 delivery checksum、安装后 probe 闭合当前风险。
