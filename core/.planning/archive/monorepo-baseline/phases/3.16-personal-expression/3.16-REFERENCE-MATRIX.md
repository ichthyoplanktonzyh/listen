## Reference decision

最强产品参考是 Language Islands 的“用户生活内容为一级资产”，但其掌握/调度语义不可核，故只
采用交互启发。生产身份以 3.4.3 gold fixture 和当前 semantic fact contract 为权威。所有候选来源
都停在显式创建表单之前；创建之后的 `UserSentencePatternId`、版本和删除生命周期完全独立。
