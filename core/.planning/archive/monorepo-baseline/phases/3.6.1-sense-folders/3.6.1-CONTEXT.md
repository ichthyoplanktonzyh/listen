# Phase 3.6.1 — Sense Folders Context

## Why this phase exists

Phase 3.6 made the listening dictionary useful at the lexical-entry level:
personal media slices, corpus search, source collection, review entry points and
four-channel summaries are all available. It deliberately excluded formal
senses. The Phase 3.6 review then established that senses must be optional
folders, not a mandatory classification of every occurrence.

SceneLex independently models and produces resources at the sense level. Its
role does not redefine LLPlayerNext: SceneLex may later supply a published,
versioned external semantic reference and teaching resource, while LLPlayerNext
continues to own a learner's local folders, media occurrences and evidence.

## Locked decisions

1. Local folder ID is the only identity authority. External sense IDs are
   optional alignment metadata.
2. Entry-level capability remains the only active capability authority. This
   phase does not introduce a second sense-level assessment model.
3. Learning observations stay append-only and entry-level. Folder assignment is
   an organizational edge, not evidence re-attribution.
4. Folders are optional. The zero-folder state is complete and unassigned slices
   remain visible directly below the entry.
5. Manual assignment is the only classification mechanism. No heuristic or LLM
   WSD is hidden behind UI convenience.
6. The first external reference seam must be opaque and provider-neutral; it is
   intentionally not named or coupled to SceneLex in durable LLPlayerNext API
   fields.
