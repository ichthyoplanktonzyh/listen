# Phase 3.6.1 — Sense Folders Manual QA

Run this with a real imported English media item that has at least two saved
source clips for the same lexical entry.

1. Open the listening dictionary and select the entry. Confirm its existing
   clips appear under **Unassigned clips** and the entry-level four-channel
   summary is unchanged.
2. Create a meaning folder with a label, definition/gloss, and optionally an
   external reference. Confirm it appears without moving any clip implicitly.
3. Assign one clip to the folder. Confirm it appears only inside that folder;
   the other clip remains under **Unassigned clips**; both remain playable and
   retain all existing mark/review actions.
4. Change the assigned clip's folder, then remove it from the folder. Confirm
   no duplicate or lost clip appears.
5. Delete the folder. Confirm assigned clips return to the unassigned entry
   list, and the entry's capability summary, review queue and playback state
   do not change.
6. Quit and reopen the app. Confirm the folder/assignment state survives when
   retained, or the unassigned state survives after deletion.

Pass condition: no action requires assigning every clip; no SceneLex/network
call is made; external reference remains informational only.
