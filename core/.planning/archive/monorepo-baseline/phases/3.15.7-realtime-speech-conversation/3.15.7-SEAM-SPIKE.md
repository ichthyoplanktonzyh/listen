# Phase 3.15.7 Realtime Protocol / Seam Spike

状态：COMPLETE（协议与本地真实 WebSocket transport seam）；provider credential smoke pending

日期：2026-07-16

## 问题

在写 session/turn persistence、原生音频和 UI 前，先验证 OpenAI Realtime 与 Qwen Omni Realtime
能否在不抹平真实差异的前提下，共用 LLPlayerNext 内部的 request/event/error 契约。

## 查证来源

- OpenAI Realtime API reference：<https://developers.openai.com/api/reference/resources/realtime>
- OpenAI `gpt-realtime` model：<https://developers.openai.com/api/docs/models/gpt-realtime>
- Alibaba Cloud Model Studio realtime API：<https://help.aliyun.com/en/model-studio/realtime>

2026-07-16 查证到的共同工程底线是 mono PCM16/24 kHz、WebSocket session、append audio buffer、
VAD/manual turn、增量 assistant transcript/audio。协议专属字段和事件名称留在 adapter crate，不能泄漏到
application/domain。

## 异构点与裁决

| 问题 | OpenAI | Qwen | LLPlayerNext 裁决 |
|---|---|---|---|
| session shape | GA `session.type=realtime`，audio input/output 子对象 | modalities/voice/input-output format 为不同字段 | codec 各自编码；application 只提交 neutral request |
| learner transcript preview | `delta` 是增量 | `text + stash` 是完整预览 | 统一为 `ProviderTranscriptPreview { text }`，由 codec 负责语义转换 |
| learner transcript authority | provider input transcription 是独立 ASR/rough guidance | provider ASR 同属远端即时结果 | 两者都只服务即时 UI；没有任何 local/attempt/corpus writer |
| identity | session/item/response id | session/item/response id | 仅 opaque correlation；本地 session/turn identity 另建 |
| errors | handshake/event error | handshake/event error | 映射为 Auth/RateLimit/Timeout/Offline/Disconnected/Protocol |

## 已实现的 Spike

- `application`：provider-neutral request、descriptor、session trait 与 event contract。
- `domain`：稳定、可序列化的 realtime provider error taxonomy。
- `realtime-provider`：OpenAI/Qwen 两个 codec，以及真实 `tokio-tungstenite` WebSocket transport。
- 安全边界：credential 只进入 Authorization handshake，不进入 descriptor/event；空 credential 在联网前
  明确失败。model query 使用 URL parser 编码；非 `ws/wss` endpoint 明确拒绝。
- contract suite 通过真实 loopback TCP/WebSocket handshake 与 frame 往返，不把 codec 单测冒充 transport。

## 验证结果

`cargo test -p realtime-provider`：8 tests passed，包括：

- 两协议相同 neutral PCM append contract；
- OpenAI delta 与 Qwen `text + stash` 映射为相同 preview 语义；
- provider final transcript 仍是 provider event，绝不成为 local authority；
- assistant PCM、认证、限流、协议错误与错误配置的 stable degradation；
- 两 adapter 均跨越真实本地 WebSocket transport 完成 session update 与 audio frame。

`cargo clippy -p realtime-provider --all-targets -- -D warnings`：通过。

## 仍待真实 Provider Smoke

当前工作环境没有用户授权的 OpenAI/Qwen credential，因此没有向外部 provider 发送 learner audio，亦没有
伪造“真实 provider 已验收”。后续 owner QA 使用安全 profile/keychain 后至少执行一家：建连、双向音频、
VAD/manual turn、barge-in、限流/断流 cleanup。此项 pending 不阻塞继续实现本地 facts/lifecycle，但在完成前
Phase 3.15.7 只能标记 code complete / owner QA pending。

## 对后续实现的约束

1. local session/turn id 不得由 provider id 派生。
2. provider transcript 可更新易失 live state；只有本地 whisper.cpp completed transcript 可 finalize learner fact。
3. 中断、local ASR 失败或空 transcript 的 turn 不得进入 spoken corpus。
4. content anchor 只能是可空 surface context；不得进入 shared session/turn 必填 identity。
5. adapter 新增不得修改 attempt、corpus、3.15.6 gap review 或 capability projection 语义。
