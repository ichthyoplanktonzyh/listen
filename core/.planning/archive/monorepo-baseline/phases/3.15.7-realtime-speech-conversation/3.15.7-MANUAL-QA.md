# Phase 3.15.7 Manual QA: Realtime Speech Conversation

状态：OWNER REAL-PROVIDER QA PENDING

日期：2026-07-16

## 环境与凭据

- macOS 真机、可用麦克风与扬声器；系统已授予 listen 麦克风权限。
- bundled whisper.cpp model 已安装并能完成现有 Speaking 本地转写。
- OpenAI Realtime 或 Qwen Omni Realtime 至少一家有效 API key。密钥只在 App 的 provider
  对话框输入，由 sidecar 写入 macOS Keychain；不要贴进聊天、终端、截图或阶段文档。
- 有字幕的真实媒体；进入 Speaking 前记下播放位置与播放/暂停状态。

## 主路径

1. 在 Speaking 打开 `Realtime conversation`，添加 OpenAI 或 Qwen profile。保存后的列表与重新
   打开界面均不得显示 key、auth header 或 keychain reference。
2. 点 Start，确认 App 明示会把麦克风音频和当前内容 context 发往所选在线 provider；实时输入
   字幕明确标为 provider caption，而不是 learner-output 事实。
3. 围绕当前字幕自然说至少三轮；确认 learner audio 连续上行、assistant transcript/audio 连续
   返回，没有必须等整段结束才能听到回复的假 realtime 行为。
4. assistant 播放中直接开口：播放应立即停止并开始新一轮，不能双声源、卡死或继续播旧 response。
5. 点 Finish：输入采集停止，最后一条 provider response 可完成；随后 UI 进入 local Whisper
   转写。成功后单独显示 local learner transcript，不得用 provider caption 回填。
6. 在「我的产出」查询 spoken：只出现 local Whisper 成功的 finalized learner turn；打开条目能
   看到 realtime activity/source context。3.15.6 gap review 可只读看到 spoken projection，但查询
   不新增学习事实。
7. 退出 surface：恢复进入前的媒体位置且不自动播放；麦克风、socket 与 assistant player 均释放。

## Honest degradation

8. 无 profile、删除 credential、错误 key、错误 endpoint/model、断网、限流分别检查：显示稳定且
   可理解的失败状态，其他播放/词典/Studio 仍可使用，密钥不进入日志。
9. live 中途关闭面板或切换通道：session 记为 interrupted，半截 turn 不进 corpus，无残留录音、
   socket 或声音。
10. provider 正常但 local Whisper model 缺失或转写失败：provider caption 仍只服务即时体验；
    session 诚实 failed，零 finalized learner turn、零 spoken corpus document。
11. provider 断流或 response 超时：已落本地音频按终态策略清理；App 可再次 Start，不需要重启。

## 数据与边界核对

- 抽查 SQLite：provider profile 无 secret；terminal turn 不可改写；content anchor 可空。
- 成功、失败和中断前后 `learning_observations`、capability projection/proposal、ReviewCard/evidence
  writer 均无新增；3.17 confirmation gate 未前移。
- 本清单不包含 3.15.9 system voice 听感/cache QA，也不授权修复 hunting 毫秒 event-id flaky。
