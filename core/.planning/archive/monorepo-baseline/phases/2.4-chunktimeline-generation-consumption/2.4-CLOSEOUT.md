# Phase 2.4 Closeout: ChunkTimeline Generation And Consumption

> 日期：2026-06-21
> 状态：完成

## 结果

Phase 2.4 已把 chunk 从临时算法结果升级为可生成、可持久化、可激活、可导出、可播放消费的一等资源。

第一版 provider 使用 existing `speech-analysis::chunk_partition`，以 active WordTimeline 为 timing source，生成 `acoustic_semantic_v1` ChunkTimeline。estimated timing 会降级为 approximate，不声称 precise acoustic boundary。

## 完成内容

### 后端资源契约

- `domain` 新增 `ChunkTimeline`、`ChunkTimelineChunk`、`ChunkTimelineSummary`、`ChunkTimelinePrecision`、`ChunkBoundarySource`。
- SQLite schema v13 新增 `chunk_timeline_runs`。
- `SubtitleRepository` 增加 ChunkTimeline save / list / get / active / activate / archive / delete。
- `application` 增加从 active WordTimeline 生成 ChunkTimeline candidate/active 的服务。
- LLTimeline export/import 保留 ChunkTimeline candidates 和 `active_chunk_timeline_id`。

### API 与契约

- 新增：
  - `GET/POST /v1/subtitles/{track_id}/chunk-timelines`
  - `GET /v1/subtitles/{track_id}/chunk-timelines/summary`
  - `GET/DELETE /v1/chunk-timelines/{timeline_id}`
  - `POST /v1/chunk-timelines/{timeline_id}/activate`
  - `POST /v1/chunk-timelines/{timeline_id}/archive`
  - `GET /v1/chunk-timelines/{timeline_id}/export`
- OpenAPI v1 已同步 ChunkTimeline schema。

### Flutter 消费端

- `LocalApi`、timeline models、`SubtitleController` 已接入 ChunkTimeline。
- Timeline Resource Summary 显示 ChunkTimeline candidates，并支持生成、激活、归档、删除。
- 播放器优先消费 active ChunkTimeline；无 active resource 时回退旧 `chunk-partitions`。
- 字幕 chunk capsule 可点击跳转。
- 播放控制栏新增 Prev/Next chunk、Loop chunk、Expand chunk；配合已有 Loop sentence 构成渐进听力路径。
