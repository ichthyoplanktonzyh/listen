## 表面行为约束（v2：从白名单改为行为规则，原型第 7 屏同步呈现）

任何表面按行为归类，不逐个报批：

1. **整面 Studio**：仅当用户显式"进入一个场景"时出现；独占主区与焦点；
   必须自带返回并恢复来处现场。同屏最多一个，切换=会话交接不叠加。
2. **右侧栏 Panel**：仅承载当前场景上下文；不抢焦点、不含多阶段流程；
   可折叠且折叠不丢状态；与场景无关时必须消失。
3. **浮窗 Float**：仅承载跨场景借用的独立能力；非模态可拖动；关闭不影响
   宿主状态；全局至多一个（既有豁免：精听练习窗）。
4. **文内 Inline**：仅作用于正文对象；hover/选中/键盘聚焦出现，焦点移开
   即走；不新增持久层；与词级手势分工（词命中词、空白命中句）。

行为级禁则：凡有 stepper 生命周期的流程一律整面任务容器，不进 bottom
sheet/dialog/Panel；dialog 仅剩破坏性确认；任何表面不得未经请求抢键盘焦点。

现状迁移：阅读姿态→工作台读通道；段落任务 bottom sheet→任务容器（阶段
自适应）；听测整面替换→任务容器住户；读听差异 dialog→反馈区卡片；切片
回听浮窗与狩猎悬浮卡→保持。
