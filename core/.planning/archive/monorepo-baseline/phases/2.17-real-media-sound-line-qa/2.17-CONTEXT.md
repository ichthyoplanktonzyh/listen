## Product Rule

真实媒体 QA 不是为了证明模型“看起来聪明”，而是为了回答：

- 哪些 evidence marker 学习者听得出来？
- 哪些 connected-speech explanation 有帮助？
- 哪些 raw CTC mismatch 应保留为高级诊断？
- 哪些 mismatch 应默认过滤，避免污染学习体验？
- 回放时间窗是否足够短、足够稳定、足够贴近 marker？

## Repository Rule

不要把无明确再分发许可的媒体文件直接提交到 repo。

Phase 2.17 的 repo 交付物优先是：

- manifest
- checksum
- resource shape validation
- QA notes
- expected screenshot / observation references
- lightweight verifier

媒体本体可以留在本地路径或外部受控位置；manifest 必须记录 source locator、hash 和复现步骤。

## Non-Goals

- 不新增完整 Prosodic Hierarchy。
- 不扩展多语言 sound-line 模型。
- 不重写 CTC provider。
- 不追求一次性解决所有真实语流误报。
- 不把人工听感 QA 伪装成全自动客观指标。
