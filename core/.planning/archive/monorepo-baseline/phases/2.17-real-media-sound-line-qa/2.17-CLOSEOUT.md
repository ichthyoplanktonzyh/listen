## Fixes Landed

- Added a headless real-media QA runner that uses the existing Rust API instead of requiring manual UI clicking.
- Made the phoneme sidecar environment robust by injecting Homebrew `PATH` and `PHONEMIZER_ESPEAK_LIBRARY` when available.
- Stopped promoting raw CTC insertion to learner-facing `linking` without cross-token boundary context.
- Fixed `phonetic_alignment::backtrace` detected-index-zero deletion underflow, which previously panicked background jobs and left them stuck at `analyzing`.
- Added verifier support for local-only `lltimeline.local_path` plus quality warnings for phone-only artifacts and marker-family domination.
