# Phase 2.6 后续：真日语 —— 经验验证派遣修复 + surface 身份 seam

> 日期：2026-06-23
> 承接：`2.6-DISPATCH-FALSIFICATION-AND-FIX.md`（今天先证伪并修好了派遣层）。
> 动机：那次修复用的是**桩 ja**（`core.char` + 无词典，只作守卫）。桩证明不了修复真成立——
> **只有加一门真语言才能验证**。于是把 ja 从桩升级为真语言。

## 1. 做了什么

把日语从守卫 fixture 升级为真语言（surface 身份先行，用户选定的范围）：

- **分词**：`JapaneseTokenizer`，**lindera 4.0 + 内嵌 IPADIC** 形态分词，放 `lindera` feature 后；
  feature 关（默认/离线）时退**字级** fallback。镜像 jieba 模式，但**默认关**（lindera 未离线缓存，
  默认开会破离线构建）。token 字节偏移重建连续片段，保证 round-trip（lindera 默认丢空白，靠补 gap 还原）。
- **词典**：`JapaneseDictionaryProvider` 走 **JMdict/EDICT2 行格式**（EDRDG 社区词典）+ 15 词 seed
  兜底，镜像 `ChineseDictionaryProvider`/CC-CEDICT；读安装的 `.data`，按 kanji 与 kana 双查，剥 `(pos)`/`EntL`。
- **profile**：`tokenization` `core.char`→`ja.morphological`；`dictionary_providers` `[]`→`[jmdict]`；
  `pronunciation` `core.none`→`ja.kana`；`lexical_normalization` 保持 `core.surface`。
- **注册**：`tokenizer_for` 加 `ja.morphological` 一臂；api-http 词典栈加 `JapaneseDictionaryProvider` 一行。

## 2. 验证结果（本练习的真正收获）

**加一门真·共享 Han 脚本的形态语言，只动了 profile + provider + 注册点，没动任何派遣核心。** 经验证实，
非口头断言：

| 改动点 | 性质 |
|---|---|
| `profile_for("ja")` 分支（spike 已加）+ `japanese()` 字段 | profile（sanctioned 注册） |
| `JapaneseTokenizer` + `tokenizer_for` 的 `ja.morphological` 一臂 | provider + 注册 |
| `JapaneseDictionaryProvider` + api-http 栈一行 | provider + 注册 |

**没碰**：`tokenize()` 核心、`detect_language`（kana 已在 spike 处理 ja）、逐字门控（ja≠zh 自然不触发）、
`diagnose_sentence`（读 `profile.diagnosis_reasons`，开放）。

→ ROADMAP §14.11 退出条件「**新增主流语言主要是 provider + profile 工作，不需改动既有语言代码**」
**现在对一门真语言经验成立**。今天上午这条还是被证伪的；修复 + 真日语让它成真。注意这本可以出更差的
结果（若日语逼出某个派遣编辑），所以它是真验证不是走过场。

## 3. 浮出的 seam（承诺的 mini-证伪）—— surface 身份不归并日语活用

日语**活用**：食べる / 食べた / 食べます 是同一词的屈折。在 `core.surface` 身份下，**每个活用形是独立
`LexicalUnit`，不归并到辞書形（base form）**。

关键发现，且它**精确命中今天的 Fix 4**：
- lindera **能**给出 base form，但 `tokenize()` 出口的 Fix 4 归一是
  `baseline_normalized_key(profile.lexical_normalization, token.text)`——**从 surface 文本重算，丢弃
  tokenizer 可能给出的 lemma**。
- Fix 4 当时正确地**停掉了写死英语 lemma**，但它写死成了「从 surface 推」——对 zh（无 lemma）对，
  却**挡住了 ja 的 base-form 归并**。
- 一般化修法（下一个 seam）：归一 key = **provider 若能供则用 provider 供的不透明 key，否则**
  `baseline_normalized_key(profile.norm, surface)`。`LexicalUnit::new` 早已支持 provider 供的不透明
  key（ADR 0012 R2），缺的是让 tokenizer 把它传出来、`tokenize()` 尊重它而非用 surface 覆盖。

surface-first（用户选定）**接受 v1 活用形不归并**；归并是后续 seam，已定位、未做。

## 4. lindera feature 工程事实

- **默认关**（`default = ["jieba"]` 不含 lindera）。lindera 内嵌 IPADIC，未离线缓存，默认开会破
  `cargo build --offline`。验证：默认离线 workspace 286 通过、ja 走字级 fallback。
- **`--features lindera`**：真形态分词。验证：`japanese_lindera_segments_morphologically` 断言「学生」
  为单一词素（字级会切成 学/生），且 round-trip 精确。
- Cargo.lock 增约 787 行（lindera 依赖树 + 内嵌词典）——真形态分析器的代价，按 feature 隔离。

## 5. 刻意延后（surface-first 范围外，非缺陷）

- **base-form 归并**（§3 seam）：让 provider 供归一 key 流过 `tokenize()`。
- **EDICT2 可下载资源注册**（钉死 commit + sha256，像 CC-CEDICT）：seed + 安装路径已就位，目录注册是
  安装步；当前 seed 兜底，装了 `.data` 即全量。
- **纯 kanji 无 kana 行仍判 zh**（detect_language 残留，需真 language-id provider）。
- **声学侧**（日语 ASR/对齐/pitch accent 检测）：独立 production-engine program（ADR Future Path）。
