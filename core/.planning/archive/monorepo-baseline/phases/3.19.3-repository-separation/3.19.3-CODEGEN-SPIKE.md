# Phase 3.19.3 Dart Wire Client Codegen Spike

Date: 2026-07-28

Status: REJECTED FOR EXPANSION

Tool: OpenAPI Generator 7.24.0, generator `dart-dio`,
`serializationLibrary=json_serializable`

## Purpose

Test the ADR 0031 checkpoint without committing generated code or coupling
repository separation to a client rewrite.

## First result: canonical contract validation failed

The first standard generation attempt rejected `contracts/openapi/v1.yaml`:

- 47 templated routes did not declare their path parameters;
- three flow-style response descriptions used unquoted commas and were parsed
  as unexpected mapping fields;
- `LexicalSource.media_fingerprint` was declared twice;
- the method-level parity improvement independently found one implemented
  phonetic-job DELETE operation missing from OpenAPI.

These were contract defects even without code generation. They were repaired,
and OpenAPI Generator validation then passed with only five unused-model
recommendations.

## Second result: generated client failed the acceptance gate

After contract repair, full generation completed:

- 370 Dart source files were generated;
- 291 generated files contained `dynamic` or `JsonObject`;
- `build_runner` failed after writing 861 outputs;
- failures included generated syntax errors in
  `VocabularyAssetBundle` and `SpeechSynthesisAsset`;
- generated serialization also required a Dart language feature not enabled by
  the generated package;
- no generated file was copied into the product source tree.

The previous forced `--skip-validate-spec` experiment produced 881 analyzer
issues before generated-part completion, confirming that bypassing validation
is not a viable workaround.

## Decision

Do not adopt OpenAPI Generator `dart-dio` for the current full contract.

Repository separation proceeds with:

- the existing typed handwritten transport client;
- explicit version negotiation;
- immutable contract/runtime artifacts;
- locked consumer fixtures;
- method-level route parity and standard OpenAPI validation;
- existing handwritten compatibility models for timeline and SSE.

A future generator experiment must use a deliberately smaller, normalized
contract slice or a different generator and must independently pass ADR 0031's
static-type, deterministic-build and mapper gates. It is not part of Phase
3.19.3 cutover.
