# Phase 2.16 Plan: Real Connected Speech Model v1

状态：COMPLETED

## Objective

建立真实语流核心现象 v1，让声音线不仅显示“怎么组织”，还能够解释“为什么听起来变了”。

## Candidate Phenomena

### 1. Weak Form / Reduction

- function words reduction
- vowel reduction to schwa-like targets
- expected-vs-observed duration / confidence evidence

### 2. Elision / Deletion

- /t/ /d/ deletion
- consonant cluster simplification
- phrase-internal deletion candidates

### 3. Linking

- consonant-vowel linking
- intrusive /r/ or linking /r/ if English profile supports it
- observed insertion evidence remains marker-only unless explanation is stable

### 4. Assimilation

- place assimilation
- common phrase-level assimilation patterns
- evidence must not depend on raw CTC label alone

### 5. Contraction

- orthographic contraction and spoken contraction alignment
- expected pronunciation variants

### 6. Flapping

- American English /t,d/ flapping candidates
- vowel-context and stress-context conditions

## Architecture Direction

- Add a connected-speech explanation layer above `LearningPhone`.
- Keep `LearningPhone.symbol` stable.
- Attach phenomenon evidence as explanation/marker metadata.
- Separate:
  - expected canonical phone
  - learning phone label
  - observed acoustic evidence
  - connected-speech explanation

## Verification

- Fixture-level unit tests for each phenomenon family.
- Real media smoke tests from Phase 2.15.
- Regression test: CTC substitution alone cannot create a high-confidence teaching explanation.

## Closeout Criteria

- At least 3 high-frequency phenomenon families are implemented end to end.
- UI can present explanations without exposing raw model jargon.
- Raw CTC labels remain diagnostic evidence, not teaching labels.
