# Phase 2.16 Context: Real Connected Speech Model v1

状态：PLANNED

## Why This Phase Exists

Phase 2.14 建立声音线数据架构，Phase 2.15 让声音线成为可用的学习界面。

Phase 2.16 才开始系统化建模真实语流中最常见、最影响听力理解的现象。

核心问题：

```text
Why can I understand the text, but fail to hear the sentence in real speech?
```

## Scope

本阶段目标是 core connected-speech phenomena v1，不是完整语音学系统。

优先覆盖：

- weak form / reduction
- elision / deletion
- linking
- assimilation
- contraction
- flapping

## Product Rule

继续遵守 Phase 2.14 原则：

```text
CTC provides audio evidence and timing.
Expected pronunciation provides teaching labels.
Connected-speech rules provide explanations and training hints.
```

真实语流解释可以改变“为什么这样听”，但不能随意改写用户可见的基础教学标签。

## Non-Goals

- 不承诺完整 Prosodic Hierarchy。
- 不优先做 Foot / Prosodic Word / Phonological Phrase。
- 不优先做 F0 / Intonation Phrase。
- 不做多语言 profile。

这些属于 Phase 2.16 之后的研究增强。
