# Phase 2.16 Closeout: Real Connected Speech Model v1

状态：COMPLETED

## Summary

Phase 2.16 在 Phase 2.14/2.15 的声音线基础上补齐真实语流解释层：

- `LearningPhone.symbol` 继续保持稳定教学标签。
- CTC / observed phone 继续只提供 timing、confidence、observed evidence 和诊断信息。
- connected-speech 现象通过 `sound_analysis.connected_speech` 作为 explanation metadata
  附着到声音线，不直接改写基础教学音素。
- UI marker 可以展示学习者友好的 explanation label/hint，而不是 raw model jargon。

本 phase 的 v1 覆盖 6 类高频英语语流现象：

- weak form / reduction
- deletion / elision
- linking
- assimilation
- contraction
- flapping

## Implementation

- `crates/domain/src/sound_analysis.rs`
  - 新增 `ConnectedSpeechFamily`、`ConnectedSpeechExplanationStatus` 和
    `ConnectedSpeechExplanation`。
  - `SoundAnalysis` 新增向后兼容的 `connected_speech` 字段，旧 JSON 缺字段时默认空数组。
- `crates/speech-analysis/src/sound_analysis.rs`
  - 新增 `explain_connected_speech()`，从 phone alignment pattern 生成 explanation metadata。
  - weak form、deletion、linking、assimilation、contraction、flapping 均有 fixture-level
    单元测试覆盖。
  - generic high-confidence substitution 不生成 connected-speech teaching explanation，避免
    raw CTC mismatch 被误升格为教学标签。
- `apps/desktop/lib/models/timeline.dart`
  - Flutter 解析/导出 `connected_speech`。
  - `PhonemeRibbonFinding` 支持 explanation label/hint override。
  - `buildPhonemeRibbonFindings()` 会把 `connected_speech` 合并为声音线 marker；没有旧
    `findings` 时也能显示解释。
- `contracts/openapi/v1.yaml`
  - 同步 `ConnectedSpeechExplanation` schema。
