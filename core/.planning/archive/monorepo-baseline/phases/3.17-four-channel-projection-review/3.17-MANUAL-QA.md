## Preconditions

- 不要求执行 3.15.7 realtime provider、3.15.8 embedding、3.15.9 TTS 或 3.16 的独立 QA。

## Checklist

1. 在词典打开词条详情 → “能力建议”，确认四通道独立显示；证据不足时明确保持未评估。
2. 展开 pending proposal，核对 channel、算法版本、结论、理由和来源 snapshot；来源媒体缺失时
   snapshot 仍可解释，不能显示成学习失败。
3. 拒绝一条 proposal：projection/effective state 不变，刷新后显示 rejected，原 evidence 仍可查。
4. 确认一条 proposal：projection/history 更新；若该通道已有 user override，effective state 仍按
   override，清除 override 后才看到 projection。
5. 在词典总览打开“跨通道复习”，只应出现明确 `not_acquired` 的已评估 gap；unassessed 不得作为
   失败候选。打开目标后返回路径正常。
6. 重启应用并再次查看 proposal/decision/history；执行同语言 rebuild 后旧 proposal/decision 和
   override 不被改写，算法/证据未变化时不重复制造 proposal。
7. 验证 speaking 与 writing 不互推 acquired；3.16 pattern 的 speaking/writing attempt 仍分通道且
   原始 response/self-assessment 不变。
