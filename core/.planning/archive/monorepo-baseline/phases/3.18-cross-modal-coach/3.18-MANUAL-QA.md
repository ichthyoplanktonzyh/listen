## 核心体验

1. 从资产层打开 Coach，确认 reading/listening/speaking/writing 四区同时存在；没有合格事实的
   通道显示“尚未评估”，不显示失败、综合语言分、排名、streak 或伪造进度。
2. 核对每个非零数字的层级标签与 drill-down：attempt、supporting judgment、adjudication、
   observation、proposal、confirmed projection/history、personal-expression attempt 不得混成
   同一种能力结论。
3. 打开一个来源事实。若原媒体存在，核对 snapshot 与原内容；在数据库副本中删除/失联来源后
   重开 Coach，确认 immutable snapshot 仍显示并明确标注来源不可用，不制造学习失败。
4. 使用已有的明确 `not_acquired` gap 打开 Cross-modal Review；确认 `unassessed` 条目不会进入
   failure gap。关闭词条详情后回到 gap 队列，再返回 Coach。
5. 分别验证可用的 Review、Hunting List、Cross-modal Review、Personal Expression typed
   destination。中退或完成后返回 Coach，时间窗与滚动位置保持，数据显式刷新；内容会话未销毁，
   返回时不自动播放。
6. 无任何合格建议的数据允许显示 0 条建议；有建议时逐条核对真实依据与可忽略性。拥有
   `UserSentencePattern` 只产生资产邀请，不显示为 speaking/writing acquired。

## 降级与 authority

1. 未配置 LLM provider 时四通道事实、gap 与建议仍可用，状态只说明“未配置”；配置 provider

2. 使用**已经存在**的 proposal/confirmed projection/override/history 数据刷新 Coach，确认
   override 的 effective assessment 优先且各层仍可区分。不要为本清单执行 3.17 owner QA。
3. 结束前检查数据库：浏览 Coach、drill-down、建议跳转本身不得新增或修改 observation、judgment、
   projection proposal/decision、projection、override 或 capability history。
