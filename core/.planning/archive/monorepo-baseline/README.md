# Monorepo Planning Baseline

This directory is a frozen historical snapshot of the planning system that
existed before `listen-core` and `listen-app` became independent repositories.

It is retained for decision history, completed phase records, and migration
context. It is not an active source of truth. Current backend work must use the
documents directly under `/Users/shadow/listen-core/.planning/`.

The archived files were moved without rewriting their content. Relative links
and repository paths inside them therefore describe the former monorepo layout
and may no longer resolve from this directory. Use Git history when the original
path context is required.

Frontend planning after the split belongs to the live `.planning/` tree in the
`listen-app` repository.
