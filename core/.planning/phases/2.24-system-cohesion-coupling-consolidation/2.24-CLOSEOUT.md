三个主要深模块按变化原因聚合：

- `MediaAnalysisUseCases`：media/subtitle、timeline resources、corpus projection、content-fit、
  diagnosis 与 coach material，共享派生资源 invalidation/provenance；lexical 是显式 collaborator。
- `LexicalLearningUseCases`：normalization、lexical assets、capability/evidence、sense folders、
  vocabulary transfer 与 recognition upgrade。
- `PracticeUseCases`：practice sessions、review scheduling、hunting 与 listening inbox；lexical
  evidence 通过 lexical module 写入。

既有 `PronunciationUseCases`、`RecordingUseCases`、`DictionaryUseCases`、
`LearnerProfileUseCases`、`LlmProviderUseCases` 与 `SemanticUseCases` 保持窄依赖模块。

## Runtime Ownership

```text
api-http (Axum/auth/routes/events)
  ├── local-runtime
  │     ├── ProcessRunner (production + fake)
  │     ├── ArtifactDownloader (production + fake)
  │     └── transcription / phonetic / speech-batch / sound-line / resource jobs
  └── application
        ├── MediaAnalysisUseCases
        ├── LexicalLearningUseCases
        ├── PracticeUseCases
        └── six narrow specialist modules
              └── split repository/provider ports
```

HTTP route 修改不再要求理解 downloader、subprocess 或 job-state implementation；算法 crate
修改也不改变 application public result shape。

## Flutter Boundary

LocalApi 在 `services/api/*` 内完成 request construction、JSON decode 与 typed model construction。
本 phase 新增/复用 media、timeline、subtitle、lexical、learner、LLM、transcription、phonetic、
resource/job 等模型；UI/controller 不再读取这些 endpoint 的匿名字段。

唯一 allowlist：

- `lexical.dart:exportVocabulary`：这是可加字段、带版本的 transfer document。客户端职责是无损
  写盘而不是解释后重建；`api_service_transport_test.dart` 验证未知 extension field 被保留。

## Persistence and Pipeline Locality

- SQLite subtitle persistence 已按 subtitle track、pronunciation、word/chunk/sense/phone timeline、
  LLTimeline resource 七个 repository responsibilities 拆分。
- `production_pipeline.py` 只保留 CLI/dispatch；I/O、acoustics、report、conversion、audio、
  alignment 与 orchestration 位于按功能命名的 modules。
- 里程碑编号式 `m18.rs` / `m18_ui.dart` 已删除并改为功能命名。

- 测试 module 可继续使用局部 `super::*` prelude；production wildcard 为 0。
