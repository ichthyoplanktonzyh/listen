# Phase 3.1 Plan: Intensive Listening Practice Slice

状态：PLANNED

上游输入：`3.0-PHASE-BREAKDOWN.md`、`.planning/discuss/listen-learning-activity-path.zh.md`、
`.planning/phases/3.0.1-learning-loop-architecture-foundation/3.0.1-CLOSEOUT.md`

## Objective

兑现 Phase 3.0.1 已就绪的后端 vertical slice（PracticeItem -> PracticeAttempt ->
LexicalObservation / ReviewItem / LearningEvent），把精听的"验证型姿态"做成用户可用
的 Flutter UI，并以三姿态入口组织当前句的学习动作。同步把 C-1（词组进诊断）、
C-2（声音证据流入诊断）落进诊断层——它们是"先诊断再练习"的核心兑现点。

## User Value

> "刚才这句我以为听懂了——测一下，证明我真的听出来了，而不是看懂了字幕。"

用户第一次能对真实句子完成：先听 -> 主动恢复 -> 对照 -> 记录失败 -> 再练。

## Scope

### In

- **三姿态入口框架**（当前句 / 当前 chunk 上下文入口）：
  - `听懂了吗？` -> 打开诊断（已有能力，入口重组）。
  - `测一下？` -> cloze / chunk dictation / sentence dictation（本 phase 实现）。
  - `跟一下？` -> shadowing 占位入口，显示 planned/disabled，Phase 3.8 点亮。
- **Flutter PracticeController + practice UI**：
  - cloze：优先挖空 `known_recognized` 词；用户听音频填空。
  - chunk dictation / sentence dictation：听写 + token diff 结果展示。
  - 播放真实音频窗口（word/chunk/sentence anchor）。
  - 提交 -> `PracticeAttempt`；失败 lexical anchor -> `LexicalObservation`；
    可选一键创建 `ReviewItem`；写入 `LearningEvent`。
  - 结果视图：错在哪里、可能为什么（连接诊断）、下一步动作（重练 / 存复习 / 继续听）。
- **诊断升级**：
  - C-1：已确认 phrase 作为诊断对象参与"词义未知 / known_not_recognized"归因。
  - C-2：Listening structure / hotspot 证据引入诊断卡（"这里有弱读压缩区"），
    并可点击复听对应声音区域。
- **capability gating**：无 Word sync 时禁用精确 word cloze、保留句级听写；无 chunk
  时回退句级；estimated timing 显示 degraded。
- 新增 Dart DTO 按 ADR 0014：手写 + fixture 契约测试。

### Out（Non-goals）

- shadowing / 录音（3.8）。
- session summary 与卡点状态（3.2）。
- 复习队列 UI 与 SRS 调度（3.4）。
- 字幕渐隐训练模式完整版（随 3.1/3.2 迭代增量，不作为本 phase 退出条件）。
- 练习结果自动修改全局 `LearningStatus`（永久 guardrail）。

## Dependencies

- 3.0.1 后端（已完成）。
- 现有诊断管道、能力矩阵、chunk/word timeline 消费路径。
- 无对其他 3.x phase 的依赖。

## Key Work

1. PracticeController / Store（遵循 controller + Store 唯一 UI 状态模式）。
2. 三姿态入口 UI（当前句工具区重组，替换单一 Practice 按钮心智）。
3. cloze / dictation 交互与 token diff 视图。
4. practice API 客户端接入（generated client + 手写 DTO 契约测试）。
5. 诊断 C-1 / C-2 落地（diagnosis-core + 诊断卡 UI）。
6. capability gating 与降级文案。

## Exit Signal

- 用户从当前句/chunk 一步进入 cloze 或听写，完成后看到 diff、归因和下一步行动。
- 失败词写入 observation，可一键存复习；全局 `LearningStatus` 未被静默修改。
- 诊断卡能解释 phrase 障碍并引用声音证据复听。
- **独立可用**：不依赖任何其他 3.x 功能；普通播放/查词路径无回归。
- `flutter analyze` / `flutter test` / 相关 cargo tests / contract validation 通过。

## Guardrails

- 继承 3.0-PHASE-BREAKDOWN 全局规则 1-9。
- 练习失败是 evidence，UI 语气不制造挫败感。
- 无资源时诚实降级，不出现"点进去才发现做不了"的入口。
