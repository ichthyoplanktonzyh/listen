## Objective

诊断型 dashboard：从 durable 事实聚合，回答"哪里听不懂、是否变好了、下一步练什么"。
教练只建议，不指派；不做打卡装饰。

**Durable 事实清单（现行 schema）**：`LearningEvent`、`PracticeAttempt`、
`ReviewAttempt`（v19 `review_schedules`）、`LearningObservation`（ADR 0017
channelized 观察）、`LexicalCapabilityHistory`（v22 四通道状态历史）、
`recognition_evidence` / 升级建议（v21）、`hunting_candidates`（v20）、
`content_fit_calibrations`（v27）、`media_triage_intents`（v26）、泛听
session + `ListeningCompleted` 理解度自报。不读 legacy `LearningStatus`。

## User Value

> "本周 listening 通道 not_acquired -> acquired +9；最顽固的是弱读 for/have。
> 建议：复习到期 12 项、做弱读专项、或试试靶单里难度高一档的下一集。"

## Scope

### In

- **聚合层**：读侧聚合服务（不新增权威存储），按周期与维度汇总：
  - 输入量：泛听时长与会话数（3.3 extensive session 记账）。**精听没有 session
    事实（3.5.6 裁决：一题一结果），精听侧只统计练习/复习事实，不虚构时长**。
  - 主动验证：cloze/dictation 正确率与练习数（`PracticeAttempt`）、复习正确率与
    到期完成率（`ReviewAttempt`）。
  - 词汇变化（四通道口径）：listening 通道 capability 转化数
    （`LexicalCapabilityHistory`）、升级建议产生/确认/拒绝数、反复失败词
    （`hunting_candidates` 聚合）、仅在特定 chunk 失败的词。
  - 语流障碍：最常失败 connected-speech family / 难点类别分布（3.9 存在时，
    读其 `LearningEvent` 难点命中记录）。
  - 材料回访：同一媒体多次泛听的理解度自报变化（`ListeningCompleted` 序列）、
    content-fit 校准轨迹（v27，含 attempt 增量折算与自报折算两类证据）。
- **建议引擎 v1**：规则型下一步建议，每条建议一键直达对应功能：
  - 到期复习（v19 到期查询）；
  - 专项训练入口（3.9 存在时）；
  - 材料爬坡/降档（3.5 双维难度 + 靶单/泛听队列/暂缓区路由）；
  - 熟料回听（依据 = 理解度自报轨迹 + triage intent，**不再依赖已删除的
    熟料标记事件**）；
  - shadowing 候选（3.8 存在时）；
  - 猎词单候选确认（3.7 存在时：`hunting_candidates` 里未确认的高频失败词）。
- **材料毕业**：建议性标记，口径 = 理解度自报轨迹 + 练习/复习正确率 +
  content-fit 校准趋势（**"卡点解决率"已随 3.2 机制撤除，不再是输入**）。
- **历史不足降级**：starter checklist（不是空页）；缺哪类数据就诚实说明 insight 受限。
- **通道可扩展 envelope**：聚合结果按 channel/capability 命名分区；3.10 有数据的
  listening 区块正常展示，reading/speaking/writing 若无主动验证只返回 unavailable /
  unassessed reason，不创建零值指标或空洞建议。3.13–3.17 后由 3.18 扩充消费者。
- 泛听 completion 页与复习结束页复用同一聚合口径的小结组件（精听无结束页，
  不为 dashboard 复活 session summary）。

### Out（Non-goals）

- 打卡、streak、徽章、学习时长排行（P5 红线）。
- 预测式建模/ML 推荐（规则先行，证据成熟再议）。
- 跨设备聚合实现（数据模型 sync-ready 即可）。
- 复活任何 3.5.6 撤除的机制（卡点状态机、悬案区、精听 session summary）。
- 义项（sense folder）维度统计——词条级画像是唯一读端口径（3.6.1 边界）。
- Reading/Speaking/Writing Studio 指标、SemanticJudgment 聚合、跨通道 gap 与四通道
  capability projection（分别属于 3.13–3.18）。

## Dependencies

- 数据来源随 3.1~3.9 逐步变厚；本 phase 排最后以获得最大数据基础。
  最小成立条件：3.1 + 3.4 存在（有验证与复习事实可聚合）——已满足。
- 3.7/3.8/3.9 各自缺席时对应区块与建议干净降级（见 Exit Signal）。

## Key Work

1. 聚合服务与查询 API（周期、维度、分页；大事件量性能验证；只读，不反写）。
2. dashboard UI（诊断型区块 + 建议列表 + 直达跳转；文案走 localization；
   入口进 3.35 工作台首页，与现有"继续学习/复习"卡并列）。
3. 建议规则集 v1（参数记 heuristic_proxy；每条建议可追溯到依据数据）。
4. 材料毕业标记与靶单联动（3.5 triage intent 读写口径，毕业标记走建议确认，
   不静默改 intent）。
5. starter/降级状态。
6. channel-ready 响应 envelope 与缺席区块契约测试：未评估不是 0，未知未来区块向后兼容。

## Exit Signal

- 用户从 dashboard 得到 ≥3 条可一键执行的下一步建议，每条可追溯到依据数据。
- 所有数字点开可见来源事实（durable attempt/event/observation），无凭空统计。
- 历史不足时显示 starter checklist 而非空页或伪数据。
- **独立可用**：dashboard 缺席任何上游 phase 时对应区块干净降级，不阻塞其余区块。

## Guardrails

- 每个展示数字必须回答诊断问题；纯虚荣指标一律不上。
- 建议是邀请不是任务：无红点轰炸、无未完成惩罚感。
- 聚合只读 durable 事实，不反写权威记录；不读 legacy status。
