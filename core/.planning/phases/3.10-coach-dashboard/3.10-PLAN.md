# Phase 3.10 Plan: Coach Dashboard

状态：PLANNED

上游输入：`3.0-PHASE-BREAKDOWN.md`、`3.0-PLAN.md` Track G、
`.planning/discuss/listen-learning-activity-path.zh.md` 第 6 幕

## Objective

诊断型 dashboard：从 durable 事实（`LearningEvent` / `PracticeAttempt` /
`ReviewAttempt` / `LexicalObservation` / status history）聚合，回答
"哪里听不懂、是否变好了、下一步练什么"。教练只建议，不指派；不做打卡装饰。

## User Value

> "本周 known_not_recognized -> known_recognized +9；最顽固的是弱读 for/have。
> 建议：复习到期 12 项、做弱读专项、或试试靶单里难度高一档的下一集。"

## Scope

### In

- **聚合层**：读侧聚合服务（不新增权威存储），按周期与维度汇总：
  - 输入量：泛听时长、精听句子数、复听次数（3.3/3.2 会话记账）。
  - 主动验证：cloze/dictation/复习正确率、练习数（3.1/3.4）。
  - 词汇变化：状态转化数、反复失败词、仅在特定 chunk 失败的词。
  - 语流障碍：最常失败 connected-speech family / 难点类别分布（3.9 存在时）。
  - 材料回访：熟料回听后的理解度变化、二刷提升（3.5/3.3 存在时）。
- **建议引擎 v1**：规则型下一步建议（到期复习、专项训练入口、材料爬坡/降档、
  熟料回听、shadowing 候选、悬案区回访），每条建议一键直达对应功能。
- **材料毕业**：结合理解度自报与卡点解决率给出"这段已达标"的建议性标记。
- **历史不足降级**：starter checklist（不是空页）；缺哪类数据就诚实说明 insight 受限。
- 会话结束页与复习结束页复用同一聚合口径的小结组件。

### Out（Non-goals）

- 打卡、streak、徽章、学习时长排行（P5 红线）。
- 预测式建模/ML 推荐（规则先行，证据成熟再议）。
- 跨设备聚合实现（数据模型 sync-ready 即可）。

## Dependencies

- 数据来源随 3.1~3.9 逐步变厚；本 phase 排最后以获得最大数据基础。
  最小成立条件：3.1 + 3.4 存在（有验证与复习事实可聚合）。

## Key Work

1. 聚合服务与查询 API（周期、维度、分页；大事件量性能验证）。
2. dashboard UI（诊断型区块 + 建议列表 + 直达跳转）。
3. 建议规则集 v1（参数记 heuristic_proxy）。
4. 材料毕业标记与靶单联动（3.5 存在时）。
5. starter/降级状态。

## Exit Signal

- 用户从 dashboard 得到 ≥3 条可一键执行的下一步建议，每条可追溯到依据数据。
- 所有数字点开可见来源事实（durable attempt/event），无凭空统计。
- 历史不足时显示 starter checklist 而非空页或伪数据。
- **独立可用**：dashboard 缺席任何上游 phase 时对应区块干净降级，不阻塞其余区块。

## Guardrails

- 每个展示数字必须回答诊断问题；纯虚荣指标一律不上。
- 建议是邀请不是任务：无红点轰炸、无未完成惩罚感。
- 聚合只读 durable 事实，不反写权威记录。
