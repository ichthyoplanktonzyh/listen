## Outcome

Phase 3.10 将 3.1–3.9 已存在的学习事实聚合为诊断型 dashboard，回答"哪里有证据、是否在改善、
下一步做什么"。聚合层只读 durable 事实，不新增权威存储；建议是邀请不是任务，无红点轰炸或
打卡装饰。reading/speaking/writing 缺少主动验证时明确显示"尚未评估"，不创建零值指标或空洞
建议。channel-ready envelope 为 Phase 3.13–3.18 的四通道教练预留 additive 形状。

## Delivered

### 聚合服务与查询 API

- 专用只读 `CoachDashboardRepository`，SQLite 周期聚合（`coach_dashboard_facts`）：泛听
  session/时长、练习（cloze/dictation）总数与正确数、复习总数与成功数、到期复习项数、
  猎词候选数、L1 难点规则命中数、listening capability 转化数。
- `GET /v1/coach/dashboard?days=N` channel-ready JSON envelope，含`period_start_ms` /
  `period_end_ms` / `generated_at_ms` / `channels[]`（每 channel 含 status、metrics 列表、
  可选 unavailable_reason）及 `material_insights[]`（材料理解度轨迹与 triage intent）、
  `suggestions[]`（规则建议，含 title_key、reason_key、action、evidence_source 与 count）。
- 数字可分页下钻：`GET /v1/coach/evidence` 返回实际 attempt / session / event / history 明细。

### Flutter Dashboard UI

- Typed DTO（`CoachDashboard`、`CoachChannelSummary`、`CoachMetric`、`CoachSuggestion`、
  `CoachMaterialInsight`）与 `CoachDashboardController`（Store 驱动）。
- 双语（中/英）Dashboard 页面 `CoachDashboardScreen`：按 channel 分区指标卡、材料轨迹表、
  建议列表；loading/error 状态处理完整。
- 入口进入 3.35 工作台首页"学习工具"菜单，与"继续学习/复习"卡并列；可从左侧"我的学习"打开。
- 建议可一键直达：到期复习→复习队列、猎词候选→词汇界面、真实内容输入→工作台。
- 无历史时显示三项 starter checklist（首次泛听、首次练习、首次复习），不显示空白页或伪数据。

### application 层规则与降级

- 建议引擎 v1（`SuggestionKind` 枚举）：到期复习、猎词候选确认、专项训练（3.9 数据存在时）、
  材料爬坡/降档、熟料回听、shadowing 候选（3.8 存在时）、继续内容输入；所有建议参数标为
  `heuristic_proxy`，每条可追溯到依据数据。
- 材料毕业候选：基于重复理解度自报轨迹 + 练习正确率 + content-fit 校准趋势的规则建议，确认后
  写入 `graduated` triage intent，不静默修改能力。
- "不清楚→转精听 / 听懂大意→保留泛听"的确认式 content-fit 建议。
- 上游缺席降级：3.7/3.8/3.9 各自缺席时对应区块与建议干净降级，不阻塞其余区块。
- future channels（reading/speaking/writing）返回 `unavailable_reason` 而非 0 值。

### 契约与自动化

- OpenAPI 规范（`/v1/coach/dashboard`、`/v1/coach/evidence` 端点）。
- HTTP 路由注册与 application 接缝测试：`coach_dashboard_is_channel_ready_and_uses_starter_state`。
- Flutter transport seam 回归：`coach_dashboard_controller_test.dart` 验证 typed DTO 反序列化

- 10,000 事件有界性能测试与材料轨迹/毕业回归。

## Key Decisions

1. **聚合只读不反写**：不新增权威存储，不写回 dashboard 侧聚合结果；建议确认不走静默修改。
2. **通道可扩展 envelope**：不以 0 填充未来通道；reading/speaking/writing 返回"尚未评估"原因，
   符合 seam 裁决标准（additive 响应形状、不绑定资产身份）。
3. **精听不虚构 session 时长**：3.5.6 撤除 3.2 的 session summary 机制后，精听侧只统计
   练习/复习事实，不虚构时长指标。
4. **建议是邀请不是任务**：无红点轰炸、无未完成惩罚感；不创造新诊断类型、不复活已撤除机制。
5. **数字可追溯到 durable facts**：每个指标数字点开可见实际 attempt / session / event / history
   ID、结果与时间，无凭空统计。
6. **历史不足诚实降级**：无数据时显示 starter checklist 而非空页、报错或伪数据。
