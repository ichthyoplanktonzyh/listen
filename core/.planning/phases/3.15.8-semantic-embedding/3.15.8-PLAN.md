## Objective

建立独立的本地优先 **semantic embedding 能力类别（类别 7）**，把模型推理、向量身份、
可重建索引与相似检索封装成一个小 interface。首批用户价值是个人媒体/产出语料的按意思检索，
并以可解释的 near-semantic relationship 增补 3.15.6 gap review；embedding 结果始终是派生索引/
read model，不成为 learner-output、attempt、observation、evidence、capability、proposal 或模板事实。

## Slice 0 Spike 裁决问题（必须先完成）

在持久化/API/UI 前，用真实模型与真实 transport 验证并记录：

1. **本地实现**：至少一个可在 macOS Apple Silicon 本地推理、模型权重不进入 base bundle 的真实
   embedding runtime/model；记录许可证、语言覆盖、模型/运行时版本、维度、文件 fingerprint、
   下载体积、冷/热延迟、RSS/CPU 与离线复用。
2. **兼容实现**：再验证一个异构实现，或实现一个诚实的 OpenAI-compatible `/v1/embeddings`
   adapter seam；兼容只表示 wire shape，descriptor 必须报告实际 model/dimension/normalization，
   不能假设与本地向量空间可混用。
3. **检索实现**：以 SQLite BLOB + application 内 cosine top-K 为 v1 baseline，与引入向量扩展/
   独立向量库比较。当前个人数据规模下，除非实测证明必要，不增加新的数据库运行时依赖。
4. **模型契约**：dimension、model id/version、runtime version、artifact SHA-256、normalization、
   purpose prefix、index schema version 共同形成 `model_fingerprint`。任何一项变化都使旧向量 stale；
   不做跨空间 migration，只从 authoritative source/projection 全量重建。
5. **降级契约**：spike 锁定 stable `not_installed / ready / stale / failed / disabled`；安装请求期间
   UI 使用 indeterminate busy，不把 transient request state 伪造成持久状态。未安装与离线时 exact
   lemma/FTS、3.15.6 v1 排序和其他 Studio 保持可用，零静默联网。

Spike 结果写入本 phase `3.15.8-SEAM-SPIKE.md`，并据结果锁定实现；未完成不得进入 Slice 1。

## Target Interface And Ownership

- application 定义 `EmbeddingProvider` port：descriptor + 批量 `embed(purpose, texts)`；返回向量与
  完整 provenance，拒绝空文本、非有限值、数量/维度不一致。调用方不接触 tokenizer、ONNX、
  HTTP wire、模型文件或下载实现。
- concrete adapter 位于独立 provider/runtime ownership，不进入 domain identity。至少 production
  local adapter + deterministic test adapter；若落 OpenAI-compatible adapter，它只在显式 profile/
  privacy/cost 配置后可用，v1 不静默发送 corpus 文本。
- persistence 只存可重建 `EmbeddingIndexRecord`：source kind/id、language、text fingerprint、model
  fingerprint、dimension、float32 vector 与 timestamps。source 删除可 cascade 清投影；索引本身没有
  portable asset、learning evidence 或独立删除权威。
- `SemanticEmbeddingUseCases` 是外部深模块：capability、rebuild、semantic search 与 near-semantic
  gap enrichment 都通过它；HTTP/Flutter 不拼 cosine、不判断 stale、不写底层向量行。

## Scope

### In

- **provider + lifecycle**：真实本地模型 adapter、明确 opt-in install/enable/disable/delete/rebuild；
  +0B model base，下载/模型损坏/内存不足/runtime failure 诚实降级。第二实现或兼容 seam 过同一
  descriptor/embed contract suite。
- **可重建向量索引**：索引媒体 corpus 的 sentence/chunk 文本与 personal production document；
  写作 attempt 与 realtime local-authoritative turn 的既有 source/projection 规则不变。增量刷新可
  best-effort，全量原子 rebuild 是恢复路径。
- **语义语料检索**：一个 typed API 同时检索 media / production，可按 language/source/channel
  filter，返回 top-K similarity、source snapshot/provenance 与 model fingerprint；无模型、stale、
  空索引和无命中分开表达。exact FTS 仍保留，不被 embedding 替换。
- **near-semantic gap 增补**：只在现有 3.15.6 候选/产出词或文档之间生成可解释 relationship，
  返回“与哪些真实产出相近、相似度、模型版本、为何仍是练习候选”。它是 additive read signal，
  不能单独制造候选、不能把阈值写成词义真值、不能绕过 BNC/evidence/recency 排序与 top-K。
- **当前 surface 最小接线**：在现有 corpus/gap 资产旅程提供按意思查询与 near-semantic explanation；
  surface 可后续迁移，媒体锚点、词典页或现有布局不进入 domain/provider identity。

### Out

- 自动写 attempt、LearningObservation、recognition evidence、capability projection/proposal、ReviewItem
  或 UserSentencePattern；3.17 confirmation gate 保留。
- 义项聚类、canonical synonym graph、语料去重、主题覆盖、通用 FocusTarget 或自动模板铸造。
- 用 provider transcript、TTS 文本/音频、LLM suggestion 或未 finalized learner turn 建索引事实。
- 3.15.7 真实 provider/device QA、3.15.9 owner 听感 QA、已知 hunting 毫秒 event-id flaky 修复。
- 把当前内容锚定 conversation surface、词典入口或 desktop-only 布局固化为永久产品前提。

## Exit Signals

- 真实本地模型在 macOS Apple Silicon 完成 query/document embedding 与语义近邻 smoke；第二异构
  实现或 OpenAI-compatible seam 通过同一 contract suite，且维度/模型差异不会混入同一索引。
- 模型、runtime、purpose 或 dimension 改变后旧索引明确 stale；全量 rebuild 幂等/原子，失败保留
  旧投影；模型删除后 exact FTS 与所有权威学习数据完整。
- 个人媒体与 written/spoken production 都能按意思返回 top-K，并带 similarity/source/model
  provenance；provider/local transcript authority 边界不变。
- gap review 仍为透明 top-K 只读模型；near-semantic signal 只提供可解释增补，查询前后
  attempt/evidence/observation/capability/proposal/review writer 计数不变。
- 未安装、离线、模型损坏、不支持语言、资源不足与 stale index 均有 stable typed degradation，
  不阻断 exact search、播放、Studio、3.15.6 v1 或 TTS。

## Guardrails

- 体验与功能优先；只有模型体积/许可证、CPU/RAM/延迟、网络、隐私、成本、数据正确性和兼容性
  是硬约束。当前 surface/容器不是永久禁令。
- Embedding 相似度不是 synonym/义项/能力真值；阈值和模型版本必须可见，文案使用“语义相近
  候选”，禁用“你不会用/这是同义词”等结论。
- 向量只在相同 model fingerprint/dimension/normalization/purpose 空间内比较；不拼接、不补零、
  不跨模型迁移。
- 索引永远可删重建；learner attempt、local-authoritative realtime turn、3.15.5 corpus source 与
  3.15.6 receptive facts 的所有权不变。
