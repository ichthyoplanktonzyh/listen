# Phase 3.14 Slice 0: Short-recording ASR Spike

日期：2026-07-15 CST
状态：CODE COMPLETE；真人普通话麦克风 QA 待 owner

## 裁决

whisper.cpp 可继续作为 Speaking Studio v1 的短录音 ASR provider，不启动 FunASR spike。
必须使用独立 recording-transcription use case，不能复用“整媒体 → 抽音轨 → 导入字幕”job。
ASR 只产生可核对的 raw transcript 和 provenance；它不评分、不写 observation，识别错误或
失败不等于 speaking failure。

## 已落地契约

- 输入：既有 `RecordingAsset` + installed/custom model + requested language。
- 预检：本地文件存在，最长 120 秒，16 kHz / mono / PCM s16 WAV，byte length 与 SHA-256
  匹配；English-only model 拒绝非英语请求。
- 状态：`queued → transcribing → completed | cancelled | failed`；取消沿用子进程 cancellation
  probe，失败只保留 error code/message，不生成用户失败事实。
- 输出：raw transcript、segment offsets、detected language、latency、provider/runtime/model
  revision/checksum 与录音 content hash。corrected transcript 属 Slice 1 durable attempt，不覆盖 raw。
- 生命周期：当前短 job 是 runtime 内临时状态；任务 attempt 和 raw/corrected transcript 的重启恢复
  由 Slice 1 持久层承接，避免为 spike 提前复制整媒体 job schema。

## 实测

| 样本 | 格式 / 模型 | 结果 | 延迟 | 证据等级 |
|---|---|---|---:|---|
| 真实新闻英文 14.0s（owner 本地 QA media 抽取） | 16k mono PCM16 / base.en | 内容整体可读；`Coy Wire` → `koi wire` | 348ms API job | `manual_product_qa` |
| 普通话 7.424s（macOS Tingting TTS） | 16k mono PCM16 / base multilingual | 内容完整；简体输入返回繁体字形 | 560ms API job | `coverage`，不冒充真人 QA |
| 真实新闻英文 60s，运行中取消 | 16k mono PCM16 / base multilingual | 122ms 后 `cancelled`，无 transcript/error evidence | 122ms 至取消响应 | `manual_product_qa` |

首次中文实测用 `-ojf` 失败：whisper.cpp full JSON 的 token 字段含拆开的中文 UTF-8 bytes，
严格 JSON parser 报 invalid unicode code point。短录音切换到标准 `-oj` 后，segment text/offsets
与 detected language 均正常。这个失败说明整媒体 pipeline 不能直接当成短录音已可用。

## 3.8 底盘预检

- 录音资产已保存 ASR 所需语言、格式、采样、时长、录制版本、byte length 与 content SHA-256。
- `notDetermined` 才请求权限；denied/restricted/unavailable 在音频焦点交接前返回。
- 开始录音前暂停 primary player、recording player、slice player；播放参考/用户录音前先暂停
  另一声音源。Reading/Speaking 返回内容会话只保留位置，不自动播放。
- 本 Slice 未新增播放器、bottom sheet/dialog、Speaking 首页或任务 mega-controller。

## Reference Matrix 复核

- Sentence Paths：仍只有营销页观察，维持 `heuristic_proxy`；没有把其未知评分语义写入产品。
- H5P Speak the Words：开源 README 明确是固定问题经 speech recognition 作答；只保留显式
  录音/处理/error/retry 状态参考，固定答案匹配与评分明确排除。
- iSpraak：项目页和源码仓库可核 TTS/上传 MP3/现场录制三种 prompt 来源及即时反馈定位；
  retry/history 细节未独立核验，不据此固化 schema；逐词/总分/progress graph 明确排除。

## Owner 最小真人普通话验证（不需要截图）

1. 在现有跟读录音入口录一段 8–15 秒普通话自然口语，包含一个人名或数字；停止后不要删除。
2. 在后续 Speaking 转写核对界面选择多语 base/small，语言设为中文，等待完成。
3. 只记录三项：是否能取消、raw transcript 是否大意可读、专名/数字/简繁是否需修改。

该步骤只把中文从 `coverage` 升为 `manual_product_qa`；不以单条录音调阈值，也不产生口语分。
