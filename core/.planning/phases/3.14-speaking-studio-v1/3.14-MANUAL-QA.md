# Phase 3.14 Manual QA: Speaking Studio v1

状态：OWNER QA PENDING（按 owner 要求在 phase code complete 后统一体验）
日期：2026-07-15

本清单只覆盖自动化无法证明的真实麦克风、声音切换和产品可理解性。不要为完成清单录制或
上传私人内容；任意 10–60 秒本地新闻片段与一段双人对话即可。

## 最小准备

1. 在 `main` 可体验版本中确认 whisper.cpp 至少安装 `base.en`；真人普通话验证需另装 multilingual
   `base`。Learner Profile 设定 L1（例如 `zh`）。
2. 打开一份含英文字幕的真实媒体，停在 10–60 秒新闻段；另准备至少两句连续对话。
3. 开始前记住主播放器位置，并保持主播放器正在播放一次，用于验证进入任务会暂停。

## A. 英文新闻复述

1. 从当前内容切到 Speaking。确认没有独立 Studio 首页，来源播放会暂停其他声音。
2. 回听来源后开始录音；确认权限提示出现在焦点交接前，录音期只突出麦克风，不出现 transcript、
   rubric 或反馈。
3. 说 10–20 秒英文并停止。确认先出现 raw transcript 核对页，可独立编辑 corrected transcript，
   并选择 reliable/suspect/unreliable。
4. 保存后确认只显示客观事实：录音时长、停顿、ASR latency/reliability；主动点击“请求反馈”后
   才出现逐信息点自评。全程不得出现综合口语分、逐词相似度或固定答案分。
5. 保存自评，修正一个已保存 verdict；确认原 verdict 不被覆写。立即重说只允许一次。

## B. Role Reply

1. 在双人对话的应答句处切换 Role Reply。依次查看 full sentence、keywords、no text；确认音频播放
   的是前置对话，文字 assistance 是当前应答句的三档快照。
2. 用不同措辞表达同一交际信息。确认流程不要求逐字匹配；自评 rubric 聚焦是否完成接话意图。
3. 若 corrected transcript 中确实出现一个已保存词/短语，显式确认它；确认只显示字面命中表达，
   `unreliable` ASR 时不提供该证据入口。

## C. L1 与无 judge 降级

1. 在 attempt 保存后选择 L1 意义核对，用 L1 typed 复述并保存；返回 Speaking 后原状态仍在。
2. 关闭/不配置 LLM provider 重做一次 A；确认录音、转写、客观事实、自评、回放和完成均可用。
3. 确认 L1 事实不会出现在 speaking target evidence 中，也没有自动 capability projection。

## D. 延迟复述与恢复

1. 完成立即复述后加入延迟复述；从复习资产入口打开卡片。确认卡片不先揭示原句，而是进入同一
   Speaking 状态机。
2. 中途分别在录音、转写核对、自评阶段退出：录音/转写会安全停止；核对/自评草稿在同一 app
   session 重开后恢复；未来阶段不能通过 stepper 跳过。
3. 完成延迟复述后显式选择 again/hard/good；返回复习入口。任何退出路径只恢复主媒体位置，
   不自动播放。

## E. 真人普通话短录音

1. 使用 multilingual `base` 对 5–15 秒真人普通话录音转写；记录 latency、detected language、
   是否可读和简繁体表现。
2. 修正至少一个 ASR 错误，确认 raw transcript 保持原样、corrected transcript 单独保存。
3. 在 transcribing 时取消一次，确认状态回到可重录，取消不显示为 speaking failure。

## 通过口径

- A–E 无阻塞缺陷；允许 ASR 有识别错误，但必须可核对、可修正、provenance/uncertainty 诚实。
- 同时只能有一个声音源；返回内容或资产入口均不自动播放。
- 未配置/未获资格的 judge 不影响主链路；不出现综合口语分。
