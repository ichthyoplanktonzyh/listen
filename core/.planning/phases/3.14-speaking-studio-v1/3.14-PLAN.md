## Phase 3.13.5 基线与模块接口裁决

- Speaking 是**当前内容的通道**，不是独立 Studio 首页；有可复述片段且本机录音能力
  可用时点亮。延迟复述从资产层进入，同样打开任务容器并携带来源快照。
- 生命周期共享候选必须等 Reading + Speaking 两个真实住户后再审计。审计结果若只是同名方法、
  但恢复/退出副作用不同，则不抽 interface；录音状态机、转写核对和反馈布局始终属于 Speaking。
- Slice 2 实证结论：Reading 恢复 typed/rubric 草稿；Speaking 退出必须取消 recorder/短 ASR、
  保存 RecordingAsset 关联状态并交还三类音频焦点。真实重复不足，抽取只会形成 pass-through，
  因此 v1 保留两个窄 controller，不建立 generic interface 或 mega-controller。
- 容器不承诺三栏。录音阶段以麦克风与波形/计时为视觉中心；转写完成后才展开核对，用户
  请求反馈后才出现反馈。stepper 只报告状态，不允许点击未来阶段。

## Objective

在 3.8 shadowing 模仿层之上建立构造性口语：隐藏完整原句后的片段复述、角色接话、
立即重说一次与延迟复述；按需使用 L1 复述拆分“没听懂”和“说不出”。

## User Value

> “我能用中文说清这段在讲什么，却用英语组织不出来；系统指出我漏掉的两个信息点和
> 可复用表达。我重说一次，几天后再说，看到的是具体变化而不是一个神秘口语分。”

## Scope

### In

- RecordingAsset → transcription use case：复用已安装 whisper.cpp runtime/provider 概念，
  但为短录音新增独立输入、语言、取消、临时文件和 transcript provenance；实测普通话/
  英语录音，不假设整媒体 job 可直接复用。
- L2 片段复述：10–60 秒真实片段，隐藏完整原句，保存录音、transcript、attempt。
- 角色接话：完整原句/关键词/无文本三档 assistance；判断交际信息而非逐字匹配。
- 两层复述：默认 L2；失败/不确定时可选 L1 意义复述。L1 是 clip-level listening
  comprehension fact，不是 speaking evidence。
- SemanticJudgment：固定 rubric、逐信息点覆盖、精确 transcript spans、ASR uncertainty、
  user adjudication；无 LLM 时显示客观录音事实和自评。
- 立即重说最多一次 + 可加入延迟复述；避免机械高密度重复。
- 只有显式锚定的目标表达且构造性产出成立时写 speaking observation；不自动 projection。
- 两条入口：内容旅程从 Speaking 通道进入当前片段；资产旅程从延迟复述/复习进入，完成或
  中途退出后返回原入口并恢复主媒体位置，绝不自动恢复播放。
- 阶段固定为“听来源 → 复述录音 → 核对转写 → 自评/合格反馈 → 完成·可重说”；feedback
  在录音和转写核对阶段不占位，防止提示泄露。

### Out

- 发音总分、音素/GOP 打分、母语者相似度、口音消除目标。
- 强制先 L1 后 L2、自动翻译用户 L1 后冒充其 L2 产出。
- 开放式无语境 AI 陪聊、实时语音 agent。
- speaking capability projection（3.17）。

## Slice 0 结论（2026-07-15）

- 新增独立 `RecordingAsset -> RecordingTranscriptionJob` 异步路径；只读取 16 kHz mono
  PCM s16 WAV，不经过 `MediaId`、ffmpeg 抽取或 SubtitleTrack 导入。job 返回 raw transcript、
  segment offsets、requested/detected language、latency 与 runtime/model/录音 hash provenance；
  当前为 runtime 内短生命周期 job，Slice 1 再把 raw/corrected transcript 随 attempt 持久化。
- 真实新闻英文 14.0 秒：base.en，348 ms，内容可读；人名 `Coy Wire` 误作 `koi wire`，证明
  raw transcript 必须可核对修正。普通话 7.4 秒管线样本：multilingual base，560 ms，语义完整
  但简体输入输出为繁体；该样本是 macOS TTS，不能升级为真人 `manual_product_qa`。
- whisper.cpp `-ojf` 的中文 token 明细会包含拆开的 UTF-8 bytes，严格 JSON parser 失败；短录音
  改用 `-oj` segment JSON 后中英文均可解析。60 秒真实英文输入在 122 ms 发出取消，最终保持
  `cancelled`、无 transcript/失败证据。格式、文件长度和 SHA-256 不匹配会诚实拒绝/失败。
- 3.8 预检通过：权限拒绝发生在焦点接管前；录音前暂停 primary/recording/slice 三个声音源；
  A/B/A 回放切源前暂停另一声音源；返回内容只保留位置，不自动播放。未新增播放器语义。
- 参考复核：H5P 源码/README 只支持“固定问题经语音识别回答”，因此仅保留显式状态与 retry
  参考，固定答案判断完全排除；iSpraak 可核的是 TTS/上传/现场录制三种 prompt 来源及即时反馈，
  其逐词/总分/history 不进入本 phase；Sentence Paths 仍只有营销页观察，保持
  `heuristic_proxy`，未升级证据等级。详见 `3.14-SLICE-0-ASR-SPIKE.md`。

  assistance 不得进入其他 task kind。Flutter typed client 已有独立 spoken-attempt request。
- persistence 继续复用 v35 append-only semantic attempt JSON，无新 migration；零 judgment、零
  observation/projection writer。
- Speaking 已有自己的真实状态机：`listen -> record -> transcribe -> review ->
  ready_feedback -> assess -> done`。权限拒绝发生在焦点交接前；停止录音后先持久化
  RecordingAsset，再启动独立短录音 job；失败/取消回到可重录状态，录音事实不被改写成

- 核对阶段同时保留 raw 与 corrected transcript，ASR reliability 由用户显式标记；保存 attempt

## Slice 2–5 完成结论（2026-07-15）

- **生命周期审计**：Speaking 的 in-memory draft 以 source/kind/assistance/recall 身份恢复；退出
  录音会取消 recorder，退出转写会取消短 ASR，review/feedback/assessment 可恢复，未来阶段 intent
  不可跳。与 Reading 只有表面方法名相同、资源副作用不同，未抽通用 interface。
- **Role Reply**：内容场景可在 retelling / role reply 间切换；取当前 cue 的前置对话作音频 prompt，
  当前 cue 只作为 full sentence/keywords/no text assistance snapshot。判断模板只问交际信息，
  不做固定答案或逐词评分；目标表达 observation 锚定应答句而非 prompt 句。
- **延迟复述**：完成后可创建 `speaking_attempt` review asset；到期卡不显示固定答案，直接进入同一
  Speaking 状态机，完成后由用户显式选择复习难度。退出回到复习资产入口；主媒体只恢复位置，
  不自动播放。
- **证据与降级**：L1 意义核对复用 typed listening task，独立写 listening fact，绝不生成 speaking
  evidence。3.12.1 judge 未获资格，因此产品只显示录音时长、≥120ms 停顿、ASR latency/reliability、
  raw/corrected transcript、目标表达字面命中与用户自评；自评修正走 append-only adjudication。
- **anchored writer**：只有 completed L2Retelling/RoleReply、非 unreliable ASR、corrected transcript
  真实字面包含、且用户显式点击已保存表达时，写 `SpeakingProduction` observation；assistance
  进入事实，零 speaking projection。L1、shadowing、缺失字面目标、unreliable ASR 均不能写入。

## Exit Signal

- 用户完成“听片段 → L2 复述 → 核对 transcript → 看逐点反馈 → 重说 → 保存”。
- L2 困难时可选 L1 归因；跳过 L1 完全不受阻。
- 切换/关闭 LLM provider 后录音、转写、自评和 A/B 回放仍成立。
- Attempt、judgment、adjudication、target observation 各自可追溯且不跨粒度污染。
- 内容通道与资产入口打开的是同一任务生命周期；退出回到正确来源，草稿/录音阶段可恢复。
- 录音时不存在常驻反馈栏；转写核对前不显示完整原句或 rubric 要点。

## Guardrails

- 不输出综合口语分；只显示信息覆盖、目标表达与客观时长/停顿事实。
- ASR transcript 可由用户修正；原始与修正版分开保留。
- LLM uncertain/失败不是用户 speaking failure。
- L1 是 X 光，不是固定翻译步骤。
- 不复制 `ReadingTaskController`/`ReadingTaskStudio` 成 speaking 变体；只有真实重复成立才抽生命周期
  interface。v1 审计未达到抽取门槛，两个住户保留各自窄 implementation 和布局。
- 任何声音源切换必须先交接音频焦点；返回内容会话只恢复位置，不未经用户请求播放。
