## Phase 3.13.5 基线与模块接口裁决

- Speaking 是**当前内容的通道**，不是独立 Studio 首页；有可复述片段且本机录音能力
  可用时点亮。延迟复述从资产层进入，同样打开任务容器并携带来源快照。
- 共享的是一个深的**任务生命周期模块**，其 interface 只暴露 launch/resume、当前阶段
  snapshot、用户 intent、保存/退出；来源快照、草稿恢复、append-only attempt 和未来阶段
  不可跳由模块保证。录音状态机、转写核对和反馈布局属于 Speaking 住户的 implementation。
- 3.13 目前是第一个住户；3.14 成为第二个真实住户后，才从两者重复行为中提取上述 seam。
  不建立包含 reading/speaking 全部字段的通用 mega-controller，也不让测试越过 interface。
- 容器不承诺三栏。录音阶段以麦克风与波形/计时为视觉中心；转写完成后才展开核对，用户
  请求反馈后才出现反馈。stepper 只报告状态，不允许点击未来阶段。

## Objective

在 3.8 shadowing 模仿层之上建立构造性口语：隐藏完整原句后的片段复述、角色接话、
立即重说一次与延迟复述；按需使用 L1 复述拆分“没听懂”和“说不出”。

## User Value

> “我能用中文说清这段在讲什么，却用英语组织不出来；系统指出我漏掉的两个信息点和
> 可复用表达。我重说一次，几天后再说，看到的是具体变化而不是一个神秘口语分。”

## Scope

### In

- RecordingAsset → transcription use case：复用已安装 whisper.cpp runtime/provider 概念，
  但为短录音新增独立输入、语言、取消、临时文件和 transcript provenance；实测普通话/
  英语录音，不假设整媒体 job 可直接复用。
- L2 片段复述：10–60 秒真实片段，隐藏完整原句，保存录音、transcript、attempt。
- 角色接话：完整原句/关键词/无文本三档 assistance；判断交际信息而非逐字匹配。
- 两层复述：默认 L2；失败/不确定时可选 L1 意义复述。L1 是 clip-level listening
  comprehension fact，不是 speaking evidence。
- SemanticJudgment：固定 rubric、逐信息点覆盖、精确 transcript spans、ASR uncertainty、
  user adjudication；无 LLM 时显示客观录音事实和自评。
- 立即重说最多一次 + 可加入延迟复述；避免机械高密度重复。
- 只有显式锚定的目标表达且构造性产出成立时写 speaking observation；不自动 projection。
- 两条入口：内容旅程从 Speaking 通道进入当前片段；资产旅程从延迟复述/复习进入，完成或
  中途退出后返回原入口并恢复主媒体位置，绝不自动恢复播放。
- 阶段固定为“听来源 → 复述录音 → 核对转写 → 自评/合格反馈 → 完成·可重说”；feedback
  在录音和转写核对阶段不占位，防止提示泄露。

### Out

- 发音总分、音素/GOP 打分、母语者相似度、口音消除目标。
- 强制先 L1 后 L2、自动翻译用户 L1 后冒充其 L2 产出。
- 开放式无语境 AI 陪聊、实时语音 agent。
- speaking capability projection（3.17）。

## Key Work

1. **Slice 0 — ASR 与底盘预检**：普通话/英语短录音真实 spike；验证格式/采样、延迟、
   人工可读性、取消和失败降级；核对 3.8 RecordingAsset、麦克风权限与音频焦点接缝。
2. **Slice 1 — 事实与用例**：Retelling/RoleReply task types、prompt/source snapshot、固定
   rubric、RecordingAsset→transcription、raw/corrected transcript 与 append-only attempt。
3. **Slice 2 — 第二住户与生命周期 seam**：先实现 Speaking 状态机，再用 Reading +
   Speaking 两个真实 adapter 提取最小任务生命周期 interface；通过该 interface 测试恢复、
   退出、重做和不可跳未来阶段，删除由抽取产生的重复测试，不增加透传层。
4. **Slice 3 — 场景原生 Speaking UI**：从内容通道或资产入口打开整面容器；录音中心布局、
   转写核对、按需反馈、自评、立即重说一次与延迟入口；禁止 float/bottom sheet 承载流程。
5. **Slice 4 — 证据与降级**：L1 fallback 诊断矩阵；合格 judge 才显示可纠正 feedback；
   anchored speaking observation writer 及 L1/shadowing/模型改写不生成证据的负向测试。
6. **Slice 5 — 真实媒体 QA 与 closeout**：新闻复述 + 对话接话；覆盖好/部分/错误、ASR
   不确定、权限拒绝、离线/无 LLM、中途退出恢复和主媒体不自动播放。

## Exit Signal

- 用户完成“听片段 → L2 复述 → 核对 transcript → 看逐点反馈 → 重说 → 保存”。
- L2 困难时可选 L1 归因；跳过 L1 完全不受阻。
- 切换/关闭 LLM provider 后录音、转写、自评和 A/B 回放仍成立。
- Attempt、judgment、adjudication、target observation 各自可追溯且不跨粒度污染。
- 内容通道与资产入口打开的是同一任务生命周期；退出回到正确来源，草稿/录音阶段可恢复。
- 录音时不存在常驻反馈栏；转写核对前不显示完整原句或 rubric 要点。

## Guardrails

- 不输出综合口语分；只显示信息覆盖、目标表达与客观时长/停顿事实。
- ASR transcript 可由用户修正；原始与修正版分开保留。
- LLM uncertain/失败不是用户 speaking failure。
- L1 是 X 光，不是固定翻译步骤。
- 不复制 `ReadingTaskController`/`ReadingTaskStudio` 成 speaking 变体；复用生命周期 interface，
  住户保留自己的 implementation 和布局。
- 任何声音源切换必须先交接音频焦点；返回内容会话只恢复位置，不未经用户请求播放。
