# Phase 3.18 Plan: Cross-modal Coach & Four-channel Closeout

状态：PLANNED

日期：2026-07-11

上游输入：Phase 3.10、3.13–3.17、
`.planning/phases/3.0-english-listening-learning-loop/3.11-3.18-FOUR-CHANNEL-SHARED-CONTEXT.md`、
LOOP-018。

## Objective

把 3.10 listening-era Coach 扩展为真正的四通道诊断工作台：从 durable facts 回答用户在
哪里“能听/能读但说写不出”、哪些变化有证据、下一步可选什么；完成四通道产品方向收口。

## User Value

> “我本周不是简单学了 20 个词：有 6 个从读懂变成听出，3 个已经能在复述里主动说出；
> 两个表达写作仍需提示。每条建议都能点回原片、原稿或录音，我可以选择做或不做。”

## Scope

### In

- 扩展 3.10 channel-ready aggregation：reading/listening/speaking/writing 分区与 cross-modal
  gap；每个数字点回 attempt/event/observation/judgment/history。
- 指标只来自已存在事实：输入/阅读、主动验证、构造性产出、修订、延迟重用、projection
  proposal/confirmation、复习完成。
- Cross-modal insight：read yes/listen no、listen yes/speak no、recognition yes/production
  unassessed 等；unassessed 与 not_acquired 分离。
- 建议引擎 v2：Reader、retelling/role reply、dictogloss、personal pattern、cross-modal
  review deep links；邀请式、可追溯、可关闭。
- LLM/provider health 只作为功能可用性说明，不把模型分数聚合成学习者分数。
- Starter state 按通道说明“尚未主动验证”，提供可选入口，不制造零值图表。
- 最终端到端 QA：同一真实内容完成听→读→说→写，并在 Coach 中追溯完整事实链。

### Out

- CEFR 认证、标准化考试预测、语言总分、排名、streak、徽章。
- Coach 自动分配强制课程或因未完成而惩罚。
- 在聚合层发明新 evidence 或反写 capability。
- 跨设备云同步实现。

## Dependencies

- 3.10 channel-ready envelope 与 listening suggestions。
- 3.13–3.16 Studio facts；3.17 projection/review 可按通道缺席降级。

## Key Work

1. 聚合 contract v2：channel blocks、cross-modal gaps、evidence links、availability reasons。
2. Dashboard UI：通道诊断、趋势、来源事实 drill-down 与下一步建议。
3. 建议规则 v2 与可解释参数；无上游数据/无 provider/无媒体的降级矩阵。
4. 性能：大 attempt/judgment/history 数据量下分页、索引与增量聚合验证。
5. 产品 closeout QA：真实内容四通道链路、provider 切换/离线、媒体删除、用户 adjudication、
   override 与重投影场景。
6. 更新 PROJECT/REQUIREMENTS/ROADMAP/STATE 与 milestone closeout，记录仍未成立的能力。

## Exit Signal

- 用户从同一真实内容完成听、读、说、写至少各一条独立任务，Coach 可追溯显示而不混写。
- 至少三条下一步建议直达真实功能且每条可解释依据；用户可忽略而无惩罚。
- 缺任何通道或 LLM provider 时其他区块正常工作，未评估不显示为失败。
- 没有综合语言分；所有 capability 变化来自 3.17 或用户 override，不来自 Dashboard。

## Guardrails

- Coach 只读事实并建议，不成为新的权威写入者。
- 纯虚荣指标不上线；数字必须回答诊断或下一步行动问题。
- 四通道完整不等于每个格子有值，诚实缺席是完成条件的一部分。
