## Phase 3.13.5 基线

- Cross-modal Review 是**资产驱动旅程**，由首页到期资产/复习入口进入，不是内容通道，
  也不占用内容工作台常驻面板。
- ReviewCard 只负责呈现可追溯目标与选择合适练习；执行时 deep link 到既有 Reader、
  Speaking、Writing 或 Personal Expression 任务住户，携带 target、source snapshot、返回位置。
- 完成/中退回到资产队列并保留任务阶段；若原媒体存在可恢复内容现场，若媒体缺失则使用
  snapshot 降级，不把来源缺失误判为学习失败。
- projection 是独立深模块：interface 输入版本化 evidence window，返回可解释 proposal；
  writer、阈值、replay 和 override 保护藏在 implementation，不把算法细节泄漏给 UI/Coach。

## Objective

在 reading/speaking/writing 已积累真实 attempt 和 observation 后，分别建立可解释、版本化、
确认门禁的 projection/suggestion，并让复习能针对“能认不能产出”等跨通道 gap 选择任务。

## User Value

> “这个表达我读听都认识，但两次复述都没说出来。系统没有静默判我‘不会’，而是建议
> 做一次情境接话；我确认后，它进入合适的复习卡，而不是继续给我听音识词。”

## Scope

### In

- Reading / Speaking / Writing 各自独立 evidence audit：任务强度、assistance、不同语境、
  延迟保持、用户 adjudication、LLM validation class。
- 每通道独立 projection proposal：版本化纯函数、writer exclusivity、窗口/阈值依据、
  confirmation gate；证据不足允许长期保持 unassessed。
- LLM judgment 只有在 3.12.1 获得相应用途资格且未被用户纠正为无效时才作为 supporting
  evidence；不单独产生 acquired。
- Cross-modal gap read model：read/listen/speak/write 的已评估组合，不把 unassessed 当失败。
- ReviewCard 扩展：reading comprehension、constructed speaking、writing reconstruction、
  personal pattern reuse；卡型仍尽量读侧派生。
- 目标建议与用户确认：升级、降级、加入专项复习均不静默覆盖 override。
- Review queue 与内容工作台通过 typed launch/return context 连接，不直接操作各 Studio 内部状态。
- 历史重投影和 algorithm version 迁移策略；旧 evidence 不重写。

### Out

- 一个跨四通道的综合等级或 CEFR 分数。
- 用 speaking/writing 成功隐式推出其他通道 acquired。
- 未经研究/QA 的统一阈值。
- Dashboard 大改（3.18）。

## Dependencies

- 3.13–3.16 已产生足量真实、多情境、含失败与延迟的 evidence；不足则本 phase 可只收口
  某些通道，其他保持无 projection，不为排期制造算法。
- 3.12.1 judge qualification report；3.11 target granularity contract。

## Key Work

1. 导出匿名/本地 evidence audit 报告，检查每通道样本量、任务偏差和 assistance 分布。
2. 逐通道研究与算法设计；每个算法独立 ADR、版本、测试和 manual_product_qa。
3. Repository/application projection writer 与 writer ladder；禁止多 writer 争同一 slot。
4. Cross-modal gap query 与建议依据解释。
5. 新 ReviewCard/read model 与任务住户 deep links；验证 content/asset 返回语义、原会话不自动
   播放及来源媒体丢失时 snapshot 降级。
6. 历史 replay/重投影测试、override 不变测试、unassessed 保真测试。

## Exit Signal

- Reading、speaking、writing 每个通道都有独立资格报告：证据充分者建立经人工 QA 的
  proposal → user confirmation → projection 路径；证据不足者记录不建算法的结论并保持
  unassessed。完成不要求三个通道都被强行投影，但要求三个通道都被诚实裁决。
- 用户能从一个 cross-modal gap 进入正确类型复习并回到来源事实。
- 所有结论可展开看到 attempt/observation/rubric/judgment/adjudication。
- 换 projection version 不改写历史 evidence 或 user override。
- 从资产队列进入任一通道任务并完成/中退后能回到原卡，且不复制该任务的生命周期实现。

## Guardrails

- Phase 不是“把四个状态填满”；诚实 unassessed 优于虚假完整。
- LLM source 与 validation class 正交，provider 品牌不进入投影规则。
- 不建立综合分；通道之间无强制蕴含。
- Review 负责编排，不成为新的 attempt/judgment/observation writer。
