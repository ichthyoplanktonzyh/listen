# Phase 3.5.6 Plan: Intensive Practice Floating Window

状态：ACTIVE（2026-07-10 立项）

上游输入：`3.5.6-CONTEXT.md`、冻结的
`../3.5.5-intensive-listening-ux-fix/精听模块UX问题与方案.md`、
`../3.2-stuck-points-session-summary/3.2-CLOSEOUT.md`。

## Objective

把精听的 cloze / chunk dictation / sentence dictation 从右侧面板独立为可拖动的浮动练习
小窗。小窗提供当前题、答案/结果/diff、加入复习队列、与主播放器同步的最小播放控制和句子
导航；关闭即退出练习并清除练习循环。

这同时撤回 Phase 3.2 在**精听**路径引入、现已被产品判断为过度设计的卡点、跳过、悬案区、
session summary 与“精听完毕”机制。`PracticeItem` / `PracticeAttempt` / 失败入复习队列仍是
耐久学习事实，完全保留。

## User Value

> “我在当前句直接测一下、听一下、改一下；做完随时关掉，不需要理解 session、卡点或悬案。”

## Scope

### In

- 姿态栏“测一下”三种题型作为唯一精听练习入口；打开对应浮窗，不再切换右侧 Practice tab。
- 可拖动浮窗：标题栏/关闭、左侧练习结果区、右侧迷你播放器、底部“第 N / 总句”导航。
- 上一/下一句与键盘方向键切换句子；空格播放/暂停；切句自动创建同题型的新 `PracticeItem`。
- 关闭浮窗清除 range loop；“返回标签页”收起迷你播放器但保留练习题。
- 从精听 UI、Flutter controller、HTTP API、OpenAPI 与 generated client 移除卡点/跳过/悬案/
  diagnosis-viewed / intensive-summary surface。
- 保留 `PracticeSession`、`PracticeItem`、`PracticeAttempt`、提交评估、失败自动或手动加入复习。

### Out

- Shadowing 录音/比较（Phase 3.8）；本阶段只保留禁用入口。
- 新的学习数据模型、迁移或既有 `PracticeAttempt` 历史的删除。
- 更改泛听的理解度自报、Listening Inbox 或 session 生命周期。
- 移除历史 `learning_events` 中已存在的 stuck-point 事实；它们保留为历史分析数据。

## Critical Boundary

`completePracticeSession` 目前也被 Phase 3.3 的泛听结束流用于写 `ListeningCompleted` 与理解度
自报，不能因精听不再有“完成”按钮而直接删除。

本阶段采用以下收敛方式：

1. 精听 `PracticeController` 不再加载 summary、创建卡点事件或调用 complete。
2. 泛听完成语义保持可用；若 API 名称/契约需要清晰化，迁移为仅泛听可调用的 completion use case
   并同步 `ExtensiveListeningController`，不能让通用 practice completion 继续泄漏回精听 UI。
3. 与精听卡点专属的 routes / DTO / OpenAPI / generated client / application methods 则彻底删除。

## Exit Signals

1. 用户只从“测一下”菜单进入练习，练习不再占据右侧 panel。
2. 做完或不做都可用 × 清晰退出，且没有残留 practice loop。
3. ◀ ▶ 取代跳过，当前题型在相邻句上连续可用；答案与复习队列结果仍可追溯。
4. 精听路径不存在卡点/悬案/summary/finish/session-complete 概念或 API 调用。
5. 泛听结束及其 comprehension report 不回归。
6. `flutter analyze`、`flutter test`、相关 Rust tests、`validate-contracts.sh` 与
   `git diff --check` 全部通过。

## Guardrails

- 浮窗只编排 UI 和本地播放；高频播放位置不经 HTTP。
- 不把 3.2 的旧状态机换名后塞回小窗；一题一结果是唯一用户可见进度。
- 不删耐久 attempt/review 数据、不改既有数据迁移；移除的是新增写入入口和读侧产品 surface。
- 不修改冻结的 3.2 / 3.5.5 phase 文档。
- 每个独立提交同步 `CHANGELOG.md`，契约删改必须同步 OpenAPI 与 generated client。
