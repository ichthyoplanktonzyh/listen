# Phase 3.35 UX Review Checklist

Created: 2026-07-05 11:54 CST

Source: code-only UX/UI walkthrough from the owner. This checklist is part of
Phase 3.35 follow-up work, not a new product phase.

## P0: Must Fix In This UI Pass

- [x] Home does not explain the user's current or recent learning state.
  - Add a Continue Learning area.
  - Add recent/current media information when available.
  - Add resource readiness summary instead of only entry cards.
- [x] Top toolbar treats every action as equal priority.
  - Group actions into content entry, current-media/subtitle operations,
    learning tools, and system/tools.
  - Keep original actions reachable without keeping all icons visible.
- [x] Playback workbench wastes space in intensive listening mode.
  - Reduce fixed media padding.
  - Persist media/transcript split ratio.
  - Add reset/compact layout controls.
  - Keep narrow-window behavior overflow-free.
- [x] Playback bar mixes primary transport with learning and style actions.
  - Keep previous sentence, play/pause, next sentence, sentence loop, and
    progress as primary controls.
  - Move extensive listening, Inbox, chunk loop, subtitles, and style controls
    into mode menus or secondary controls.
- [x] Right panel navigation is weakly discoverable.
  - Show labels when width allows.
  - Give empty states a concrete title, reason, and next action.

## P1: Product-Language Cleanup

- [x] Subtitle and timeline resource panels expose technical fields too early.
  - First layer should answer: subtitles available, word sync available,
    chunk replay available, listening structure available, action needed.
  - Provider/id/generator/precision details should be secondary.
- [x] Diagnosis card is too short for sound evidence.
  - Split into summary and evidence/detail regions.
  - Avoid forcing all pronunciation/rhythm detail into one small scroll area.
- [x] Word learning detail reads like a database record.
  - Restructure into word head, learning state, meaning/pronunciation,
    source sentence, and collapsed history.
  - Hide raw millisecond timestamps from the first layer.
- [x] Settings dialog needs category grouping.
  - Use tabs or side categories: playback, subtitles, learning,
    resources/transcription, external tools, experimental.

## P2: Future Source And Token Hygiene

- [x] URL import is not yet a productized "Add source" flow.
  - Future YouTube/provider work should use: paste link, identify source,
    choose play/download, show copyright/download state.
- [x] Colors are not fully tokenized.
  - Continue replacing hard-coded overlay/status/ribbon colors with semantic
    ListenTheme tokens where doing so does not weaken signal colors.

## Current Pass Boundary

- P0 and P1 UI changes are implemented.
- Keep backend/domain contracts unchanged.
- Do not add a YouTube provider or fake online library.
- Phase 3.35 UX review items P0-P2 are implemented.
