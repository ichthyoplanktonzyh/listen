# Phase 3.35 Closeout: Listening Workbench UI Redesign

状态：AWAITING_OWNER_QA

## Summary

Phase 3.35 已完成代码与自动化层面的 UI 重构：listen 从功能堆叠式播放器整理为来源中立的
听力学习工作台，并保留 Phase 3.1 至 3.3 的学习语义和本地优先原则。最终关闭仍需 owner
完成截图审查与真实媒体手工 QA。

## Completed Scope

- 来源中立首页、继续学习、最近媒体和资源 readiness 摘要。
- 分组 app bar、独立播放条与主次动作分层。
- 可拖动并持久化的媒体/文稿布局，支持压缩、复位和窄窗口重排。
- 右侧字幕、资源、词汇、诊断、练习和 Inbox 导航与空态。
- 字幕资源与 timeline 的用户能力首层、折叠技术详情和上下可拖动区域。
- 诊断摘要/证据结构与词汇学习页层级重排。
- 六类设置导航和来源产品化 URL 流程。
- 集中式 ListenTheme，以及媒体 overlay、节奏、音素和学习状态语义 token。
- 当前字幕句按真实行位置跟随，适配可变高度文稿。
- 收尾复审（P3）：首页“继续学习”接通最近媒体持久化与继续播放恢复；readiness 预取全局
  收件箱/词汇量；倍速下拉即时刷新；分栏拖动写盘防抖；文稿跟随在手动滚动时暂停并可一键
  回到当前句；窄窗口媒体区可拖动并支持压缩/复位；姿态栏按上下文显示；Test 姿态控件描边化；
  文稿空态与无媒体播放条精简。详见 `3.35-UX-REVIEW-CHECKLIST.md` P3 节。

## Product Decisions

- local-first 不等于 local-only；本地文件和 URL 进入同一工作台。
- 不实现虚假的 YouTube feed/provider；当前 URL 能力沿用 yt-dlp 解析与下载。
- 参考每日英语听力的信息层级，不复制品牌、订阅模型或像素布局。
- 技术资源字段保持可访问，但不占据用户首层。
