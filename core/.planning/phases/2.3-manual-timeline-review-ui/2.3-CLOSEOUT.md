# Phase 2.3 Closeout: Manual Timeline Review UI

更新时间：2026-06-21 11:02:30 CST

## Status

实现第一版已完成，自动化验证已通过；仍需用真实 `.lltimeline.json` 资源跑一次手动媒体
QA 后，才能把 Phase 2.3 标记为完全收口。

本次实现交付的是句子级 Word Timing Inspector，不包含 waveform editor 或拖拽编辑。

## Shipped

- Manual Review 入口从占位状态升级为可打开句子级 inspector。
- App 可读取完整 active WordTimeline：
  `GET /v1/word-timelines/{timeline_id}`。
- App 可创建 user-adjusted WordTimeline：
  `POST /v1/subtitles/{track_id}/word-timelines`。
- Flutter `WordTiming` 模型补齐 `text`、`confidence`、`provider_version`，并支持
  `toJson()`。
- 新增 Flutter `WordTimeline` 模型，用于加载完整 source timeline。
- 新增 `ManualReviewDraft`，负责：
  - 克隆完整 source words。
  - 当前句过滤。
  - dirty word tracking。
  - 毫秒级 `start_ms` / `end_ms` 边界更新。
  - 句内 overlap / sentence boundary / inverted boundary 校验。
  - 生成 user-adjusted timeline create payload。
- 新增 `ManualTimelineReviewDialog`：
  - 显示当前句文本和 word timing rows。
  - 支持 Prev/Next sentence。
  - 支持 start/end `±10ms` / `±50ms` 微调。
  - 支持整数毫秒输入。
  - 支持播放当前句和当前词。
  - 支持 Reset sentence / Save revision。
- 保存后创建 `created_by=user`、`status=active` 的新 WordTimeline revision。
- 保存成功后重新加载 timeline summary 和 `trackWordTimings()`，让播放器高亮消费新的
  active timeline。
- Manual Review 入口从 icon-only action 调整为 Timeline Resource Summary 中的带文字
  按钮，提升可发现性。
- 修正点击字幕单词后的右侧面板导航：选词现在打开 Word Learning 面板，而不是 Subtitle
  Resources 面板。
- 修正 Play sentence / Play word 试听后退出 Manual Review 仍然保留 source loop 的问题；
  inspector 退出时会恢复进入前的 source loop 状态。
- 字幕资源导出复用原有 Export 入口，新增格式选择：SRT 或 LLTimeline JSON。选择
  LLTimeline JSON 会导出完整 `.lltimeline.json` 文档，而不是 SRT。
- Timeline Resource Summary 也提供直接的 Export LLTimeline JSON 入口，避免用户在看到
  manual WordTimeline 版本时还要回到上方字幕资源 tile 查找导出。

## Data Contract

保存 payload 采用以下语义：

```text
parent_timeline_id = sourceTimeline.id
created_by = user
status = active
algorithm_id = manual-review
algorithm_version = llplayernext-phase-2.3
metrics_json.lifecycle.human_reviewed = true
metrics_json.review.edited_word_count = dirty word count
metrics_json.review.reviewed_sentence_ids = edited sentence ids
words = full draft words
```

Word-level 约定：

- 被编辑词：
  - `timing_source = user_adjusted`
  - `provider_id = user`
  - `provider_version = llplayernext-manual-review-v1`
  - `start_ms` / `end_ms` 为媒体时间轴上的绝对整数毫秒值
- 未编辑词：
  - 保留 parent timeline 的 source/provider/confidence
  - 保留 parent timeline 的 `start_ms` / `end_ms`

## Known Limitations

- Inspector 第一版是对话框，不是完整专用页面。
- 当前只提供表格式毫秒编辑和步进微调。
- 毫秒输入框第一版通过提交文本字段生效；`±10ms` / `±50ms` 按钮是主要微调路径。
- 试听使用已有 source loop 机制，保存前主播放器高亮不会显示 draft 边界。
- 没有 waveform visualization。
- 没有拖拽边界。
- 没有自动再对齐或文本编辑 workflow。

## Deferred

- Waveform rendering and word boundary overlay。
- Drag-to-adjust boundaries on waveform。
- Zero-crossing snap。
- Suspicious gap/duration warning UI 的更细分展示。
- PhoneTimeline / phoneme-level inspector。
- Text edit -> automatic realignment -> manual review workflow。

## Handoff To Phase 2.4

Phase 2.4 可以基于 active WordTimeline 生成 ChunkTimeline。若存在 active
`created_by=user` 或 `user_adjusted` timeline，应优先作为 chunk generation 输入；没有
人工版本时仍可回落 production candidate 或 legacy timings。
