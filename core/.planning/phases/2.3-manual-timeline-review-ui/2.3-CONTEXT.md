# Phase 2.3 Context: Manual Timeline Review UI

更新时间：2026-06-20 00:34:23 CST

## Background

Phase 2.2 已经让 app 成为 `.lltimeline.json` 资源消费端：

- app 可导入 LLTimeline JSON v1。
- Transcript 面板可展示 Timeline Resource Summary。
- 用户可查看 active/candidate WordTimeline。
- 用户可激活 candidate timeline。
- 播放器词级高亮通过 `trackWordTimings()` 消费 active WordTimeline，且无资源时回落
  legacy word timings。

现在缺少的是人工校正闭环：生产端输出的 WhisperX/MFA/MMS_FA timeline 即使整体质量好，
仍会有个别词边界需要用户修正。Phase 2.3 要把“发现问题 -> 微调 -> 保存为人工版本 ->
立即用于播放高亮 -> 可导出资源 revision”跑通。

## Problem

当前用户只能在多个候选 WordTimeline 之间切换，不能直接修正：

- 某个词 start/end 偏早或偏晚。
- 某句局部对齐失败，但整条 timeline 仍可用。
- post-alignment fallback 后需要人工确认和微调。
- 准备发布学习视频前，需要把最终 WordTimeline 标记为人工复核版本。

如果没有人工校正 UI，Phase 2.4 的 ChunkTimeline 生成和后续发布流程会缺少可信的最终
word-level timing source。

## Product Shape

Phase 2.3 先做 **句子级 Word Timing Inspector**，不是完整波形/拖拽编辑器。

```text
Timeline Resource Summary
  -> Manual review
  -> Current sentence Word Timing Inspector
  -> Adjust start/end for selected words
  -> Save as user_adjusted WordTimeline
  -> Activate adjusted timeline
  -> Playback highlight refreshes
```

## Scope

1. 从 Timeline Resource Summary 的 Manual Review 入口进入。
2. 展示当前句子的 word timings。
3. 支持选中词并微调 start/end。
4. 支持播放当前句或词片段，用于校验边界。
5. 保存为新的 `created_by=user` / `timing_source=user_adjusted` WordTimeline。
6. 保存后自动激活 user-adjusted timeline。
7. 支持导出包含人工版本的 `.lltimeline.json`。

## Non-Goals

- 不在本阶段做完整 waveform editor。
- 不做跨句拖拽、多轨批量编辑或自动重分配算法。
- 不做 ChunkTimeline 编辑器；那是 Phase 2.4。
- 不把 WhisperX/MFA/MMS_FA runtime 集成进播放器 app。
- 不覆盖生产候选 timeline；人工修正必须形成新的 resource revision 或 candidate。

## Success Criteria

- 用户能针对当前句查看和微调词级时间边界。
- 保存后产生新的 user-adjusted WordTimeline，不破坏原 production candidate。
- user-adjusted timeline 自动激活，播放器高亮立即使用它。
- 用户仍可切回 WhisperX/MFA/MMS_FA 候选。
- `.lltimeline.json` export 能包含人工校正后的 timeline。
