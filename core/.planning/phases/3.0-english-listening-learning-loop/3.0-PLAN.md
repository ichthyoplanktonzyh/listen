# Phase 3.0 Plan: English Listening Learning Loop

状态：PLANNED

## Objective

在 Phase 2 的真实声音流资源和 Phase 2.18 的新学习资产架构之上，把英语作为第一门语言做成完整学习闭环：

```text
真实输入
  -> 可理解度判断
  -> 诊断
  -> 主动练习
  -> 复习巩固
  -> 进度反馈
  -> 回到真实输入
```

本文件是后续 Phase 3.0 相关工作的对齐依据，不把每个后续执行 phase 细拆到任务级。

## Sequencing Principle

Phase 3.0 的排序原则：

1. **先稳定证据**：Phase 2.17 真实媒体声音线 QA 仍是进入学习功能扩张前的关键前置项。
2. **先立学习行为架构**：Practice / Review / LearningEvent 等地基优先于具体功能扩张。
3. **先做语境内验证**：cloze、听写、chunk replay 优先于完整 Anki-like 系统。
4. **先做本地真实语料**：YouGlish-like 体验优先基于用户本地媒体库，不急于在线聚合。
5. **先做轻量发音对比**：shadowing 和 A-B 对比优先于复杂发音评分。
6. **统计服务诊断**：dashboard 先回答“哪里听不懂、是否变好了”，而不是做打卡装饰。

## Track 0: Learning Loop Architecture Foundation

目标：让 Phase 3.0 的学习行为共享同一套事实模型，避免 cloze、听写、SRS、语料搜索、
shadowing 和 dashboard 各自发明局部数据结构。

High-level work:

- 建立 Practice / Review / LearningEvent / Corpus / Difficulty / LearnerProfile / Recording 的边界。
- 定义这些对象与 `LexicalEntry`、`LexicalObservation`、WordTimeline、ChunkTimeline、PhoneTimeline 的关系。
- 以 cloze + chunk dictation 作为第一条 vertical slice。
- 固定规则：练习失败优先写 observation / review evidence，不静默修改全局 `LearningStatus`。

## Track A: Real Media Evidence Foundation

目标：确保后续练习基于可信声音证据，而不是 demo 级 marker。

High-level work:

- 完成 Phase 2.17 真实媒体声音线 QA。
- 建立 2-3 条真实英语媒体回归包。
- 记录 connected-speech marker 的 keep / filter / downgrade / investigate 决策。
- 固定 raw CTC mismatch 默认隐藏、降级或升格为教学解释的边界。
- 为后续 cloze、听写、shadowing 复用可回放片段窗口。

Exit signal:

- 至少一组真实媒体 case 能完整覆盖 media/subtitle -> WordTimeline -> ChunkTimeline ->
  PhoneTimeline -> `sound_analysis.connected_speech` -> UI marker playback。

## Track B: Comprehensible Input And Mode Split

目标：让用户知道哪些材料适合泛听，哪些片段值得精听。

High-level work:

- 为媒体、句子或片段计算学习难度信号：
  - 未知词密度。
  - `known_not_recognized` 密度。
  - 语速。
  - chunk 长度。
  - connected-speech 密度。
  - timeline/resource quality。
- 建立精听 / 泛听模式分离：
  - 泛听：连续播放、少打断、记录完成度和整体理解度。
  - 精听：句循环、chunk 循环、字幕渐隐、cloze、听写、声音线解释。
- 支持用户快速标记材料感受：
  - too easy
  - comprehensible
  - challenging
  - too hard

Exit signal:

- 同一段媒体可以被用户明确作为泛听材料或精听材料使用。

## Track C: Subtitle Fading And Active Verification

目标：把“看懂字幕”逐步转化为“听懂声音”。

High-level work:

- 字幕训练模式：
  - 全字幕。
  - 延迟字幕。
  - 点击显示字幕。
  - 隐藏已掌握词。
  - 只显示关键词或困难词。
- Cloze 主动验证：
  - 优先挖空 `known_recognized` 词。
  - 用户听音频填空。
  - 填错写入 `LexicalObservation` 或练习记录。
  - 全局 `LearningStatus` 调整需要用户确认。
- 听写练习：
  - chunk dictation。
  - sentence dictation。
  - token diff。
  - 漏词、错词和功能词失败标记。
- Chunk-first 训练：
  - 单 chunk replay。
  - chunk 逐步展开：1 -> 1+2 -> full sentence。
  - chunk cloze / dictation / shadowing 入口。

Exit signal:

- 用户可以对一个真实句子完成“先听 -> 主动恢复 -> 对照 -> 记录失败 -> 再练”的闭环。

## Track D: Listening-Driven Vocabulary And Review

目标：让词汇学习围绕真实音频识别，而不是只围绕释义记忆。

High-level work:

- 词汇详情页升级：
  - 当前 `LearningStatus`。
  - 来源原句和来源 chunk。
  - 真实音频片段播放。
  - 最近 cloze / dictation / observation 结果。
  - 常见 connected-speech 现象。
  - 不同媒体中的出现次数。
- 本地 YouGlish-like 搜索：
  - 搜索词。
  - 搜索短语。
  - 搜索 chunk。
  - 搜索 connected-speech family。
  - 返回真实媒体片段并支持词窗口、chunk、整句播放。
- Native SRS 复习队列：
  - 词汇卡。
  - 真实例句卡。
  - 音频识别卡。
  - cloze 卡。
  - chunk 卡。
- Anki 互操作作为后续增强：
  - export `.apkg`。
  - AnkiConnect。
  - 不把 Anki 作为权威学习资产存储。

Exit signal:

- 用户能从一个失败词进入真实例句集合，并在多个真实音频片段中复习它。

## Track E: L1-Aware Diagnosis

目标：解释一个 Mandarin L1 用户为什么特别容易在某类真实英语声音中失败。

High-level work:

- 设置中区分：
  - UI language。
  - L1。
  - L2。
- 建立 Mandarin -> English 难点 profile v1：
  - weak function words。
  - schwa / reduced vowels。
  - final consonants。
  - consonant clusters。
  - t/d deletion。
  - flapping。
  - linking。
  - stress-timed rhythm。
  - compressed forms such as `gonna`, `wanna`, `didja`, `woulda`。
- L1-aware 诊断提示：
  - 普通语流解释 + Mandarin L1 听觉迁移解释。
  - 短提示优先，不做长篇课程。
  - 必须能回到真实片段复听和练习。
- L1-aware 专项库：
  - 从用户材料中聚合同类失败片段。
  - 支持专项 replay / cloze / dictation。

Exit signal:

- 用户不只知道“这里发生了 weak form”，还知道“为什么中文母语背景下容易漏掉它”，并能马上复听练习。

## Track F: Shadowing And Pronunciation Comparison

目标：从听懂真实语流自然过渡到模仿真实语流。

High-level work:

- 可调速 shadowing：
  - 以 chunk 为默认单位。
  - 0.75x / 0.9x / 1.0x 等速度。
  - 支持循环和逐步展开。
- 录音 A-B 对比：
  - 原音播放。
  - 用户录音播放。
  - 波形对比。
  - 时长差异。
  - 停顿位置差异。
- 后续可增加轻量诊断：
  - 是否漏词。
  - 节奏是否过慢。
  - 重音位置是否偏。
  - 明显 phone 缺失。
  - L1 transfer 提示。

Exit signal:

- 用户可以选择一个真实 chunk，完成听、跟读、录音、对比、重练。

## Track G: Diagnostic Dashboard

目标：统计服务诊断和复习，不做泛泛学习时长展示。

High-level work:

- 输入量：
  - 泛听时长。
  - 精听句子数。
  - 复听次数。
- 主动验证：
  - cloze 正确率。
  - dictation 正确率。
  - chunk 练习数。
- 词汇变化：
  - `known_not_recognized -> known_recognized` 转化。
  - 反复失败词。
  - 只在特定 chunk 中失败的词。
- 语流障碍：
  - 最常失败 connected-speech family。
  - weak forms / deletion / linking / flapping 等专项表现。
- L1-aware 难点：
  - Mandarin -> English 难点分布。
  - 最近改善和仍需专项训练的项目。
- 材料回访：
  - 同一材料二刷/三刷理解度提升。
  - 旧材料复听提醒。

Exit signal:

- 用户能从 dashboard 得到下一步练习建议，而不是只看到“学了多久”。

## Suggested Near-Term Order

建议 Phase 3.0 相关工作从以下顺序启动：

1. Phase 2.17 真实声音线 QA。
2. Phase 3.0.1 学习行为架构地基。
3. 输入难度信号与精听/泛听模式。
4. 字幕渐隐、cloze、chunk dictation。
5. 本地 YouGlish-like 个人语料搜索。
6. 听力驱动词汇详情与 native SRS。
7. Mandarin -> English L1-aware diagnosis v1。
8. Chunk-level shadowing 和录音 A-B 对比。
9. 诊断型 dashboard。

## Guardrails

- 不静默修改用户全局 `LearningStatus`；系统练习结果优先写入 observation / review evidence。
- 不把 raw CTC label 直接展示为教学目标。
- 不用 Anki 数据模型限制 LLPlayerNext 自己的真实语境复习模型。
- 不把 L1-aware explanation 写成泛泛翻译或语法课；它必须回到真实音频。
- 不把 dashboard 做成打卡中心；它必须解释听力障碍和下一步行动。
- 不在真实声音线 QA 未稳定前扩大依赖 marker 的高风险学习功能。
