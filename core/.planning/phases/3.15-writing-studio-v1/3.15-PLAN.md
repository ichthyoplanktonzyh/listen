## Phase 3.13.5 基线

- Writing 是当前内容的通道，不建独立 Studio 首页；只有来源文本/片段满足任务 capability
  时点亮。个人模板等资产驱动写作由资产层进入同一任务生命周期。
- 复用 3.14 经第二住户验证后的任务生命周期 interface，不复制 Reading/Speaking controller。
  Writing implementation 自己拥有 editor、版本、finding disposition 与 revision diff。
- 写作阶段编辑器占主导（宽屏目标 ≥60%）；来源为可折叠侧条，feedback 只在用户提交初稿并
  请求后出现。固定三栏、常驻反馈栏、bottom sheet 和多阶段 dialog 均不允许。
- 阶段为“读/听来源 → 初稿 → 请求分层反馈 → 修订 → 保存版本·可延迟复写”；未来阶段不可点。

## Objective

让 writing 从逐字听写进入意义生产：用 dictogloss 重构、片段摘要与观点回应形成初稿、
分层反馈、用户修订和跨时间复写的完整事实链。

## User Value

> “我不是把字幕抄对，而是听完后用自己的英语重构。系统先告诉我漏了哪层意思，再提示
> 两个可改进点；第二稿仍是我自己写的，几天后还能看到哪些问题反复出现。”

## Scope

### In

- Dictogloss：听完整片段、可记关键词、停止音频后重构；保存听取次数/assistance。
- 一句话摘要、50–100 词摘要、观点回应三类最小 writing task。
- 固定 SemanticRubric：内容完成优先于语言表面错误；多个版本共享同一 rubric。
- 分层 feedback：任务完成/信息遗漏 → 组织衔接 → 语境用词 → 语法拼写；每次建议数量有上限。
- Revision history：原稿、模型原始 feedback、用户采纳/拒绝、修订稿、diff 与再次出现事实。
- 用户文本永远是产出权威；模型可建议，不能自动替换后保存为用户稿。
- 显式目标词/phrase/construction 的新语境主动使用可写 writing observation；不自动 projection。
- 无 LLM 时支持原文/rubric 对照、自评和版本保存。
- 内容旅程和资产旅程共享草稿/退出恢复；返回内容会话时保持媒体/阅读位置且不自动播放。

### Out

- 通用富文本编辑器、协同写作、云文档、长篇作文课程。
- 模型整篇代写、自动接受修改、单一 grammar score。
- 将逐字 dictation 成功映射为完整 writing acquired。
- writing capability projection（3.17）。

## Key Work

1. **Slice 0 — 计划保鲜与 Harper 裁决**：吸收 3.14 closeout；完成 Harper 本地 finding
   spike，明确其只处理语法/拼写底层，不越权判断内容与组织；建立 Reference Matrix。
2. **Slice 1 — 事实与用例**：Dictogloss/Summary/Response contract、assistance snapshot、
   固定 rubric、版本身份与 revision history。
3. **Slice 2 — 编辑器优先任务住户**：接入任务生命周期 interface；实现来源折叠、编辑器
   ≥60%、自动保存、退出恢复和不可跳未来阶段；feedback 未请求时完全不占位。
4. **Slice 3 — 分层反馈与用户决定**：finding category、severity（非总分）、source span、
   suggestion、provider provenance、user disposition、采纳/拒绝与 diff；内容层先于表面层。
5. **Slice 4 — 证据与 handoff**：writing observation 只消费用户提交文本与明确 target；
   模型 suggestion 不算成功；用户确认的反复问题/目标表达仅 handoff 给 3.17。
6. **Slice 5 — 真实材料 QA 与 closeout**：dictogloss + 观点回应；覆盖无模型、拒绝、schema
   invalid、恢复草稿、来源媒体缺失和窄窗口编辑可用性。

## Exit Signal

- 用户完成“听/读片段 → 初稿 → 分层反馈 → 自主修订 → 保存版本”。
- 原稿永远可见；拒绝建议不会制造负面能力证据。
- 模型直接生成的文字无法进入 writing observation writer。
- 同一 rubric 的延迟复写可与首稿比较；换 rubric 时明确不可直接比较。
- 编辑、反馈和修订阶段视觉重心随阶段变化；写作时没有常驻反馈栏挤压编辑器。

## Guardrails

- 意义与任务完成优先，不以错误计数替代写作能力。
- 自动 feedback 是可纠正 finding，不是教师真理。
- 不把所有语法问题上升为 durable 学习资产；先记录 attempt，反复且用户确认后再进入复习。
- 用户文本与版本历史是 Writing 模块的权威；共享生命周期 interface 不暴露或接管编辑器内部状态。
