# Phase 2.17 Plan: Real Media Sound-Line QA

状态：PLANNED

## Objective

建立 2-3 条真实英语媒体声音线回归包，验证 `sound_analysis.connected_speech`、声音线 marker、
evidence 回放和 raw CTC mismatch 过滤边界是否能支撑真实学习体验。

本 phase 的目标不是继续扩大模型覆盖面，而是把 Phase 2.14-2.16 已经打通的链路固定成可复现
回归资产：

```text
media/subtitle
  -> WordTimeline
  -> ChunkTimeline
  -> PhoneTimeline
  -> sound_analysis.learning_phones
  -> sound_analysis.connected_speech
  -> sound-line marker
  -> listen-to-this-moment playback
  -> QA decision
```

## Deliverables

### 1. Real Media QA Pack Manifest

新增一组 repo 内 manifest，记录每个 QA case：

- case id
- source locator
- media fingerprint / checksum
- subtitle resource locator
- LLTimeline / PhoneTimeline locator
- target phenomena
- expected connected-speech families
- known false positives
- known false negatives
- manual listening notes
- screenshot or UI observation references

建议位置：

```text
testdata/sound-line-real-media/
  README.md
  manifest.jsonl
  cases/
```

若媒体无再分发许可，只提交 manifest、checksum 和 QA notes，不提交媒体本体。

### 2. Lightweight Verifier

新增轻量脚本，至少验证：

- manifest JSONL 可解析。
- 每个 case 的 referenced `.lltimeline.json` 存在或被标记为 local-only。
- LLTimeline JSON schema 基础有效。
- 至少一个 active/candidate PhoneTimeline 含 `sound_analysis.learning_phones`。
- 至少一个 case 含 `sound_analysis.connected_speech`。
- connected-speech marker 的 `phone_start` / `phone_end` 不越界。
- playback window duration 在可听范围内，例如 40ms-1500ms。

建议命令：

```sh
python scripts/verify-sound-line-real-media.py \
  --manifest testdata/sound-line-real-media/manifest.jsonl
```

### 3. Manual QA Record

每个 case 记录最少 3 个观察点：

- 一个“有帮助”的 marker。
- 一个“可疑/误导”的 marker。
- 一个“应该有但没有”的听感现象，若存在。

每条观察应包含：

- timestamp / phone range
- connected-speech family
- UI label
- playback result
- QA decision: keep / filter / downgrade / needs provider investigation

### 4. Filtering Decision Input

输出一个短文档，供后续 phase 决定 raw CTC mismatch 策略：

```text
.planning/phases/2.17-real-media-sound-line-qa/2.17-CTC-MISMATCH-FINDINGS.md
```

重点回答：

- 哪些 mismatch 可以支持 connected-speech explanation？
- 哪些 mismatch 只能作为高级诊断？
- 哪些 mismatch 应默认隐藏？
- 哪些问题来自 timing，哪些来自 phone identity？

## Candidate Cases

优先选择真实英语新闻/访谈/教学类材料，避免音乐歌词作为主验收样本。

初始候选：

- Brooklyn middle school cell phone ban news sample。
- 旧 timeline production verify 新闻样本。
- TIMIT/Buckeye 仅作为辅助研究样本，不作为产品 UI 主验收样本。

## Acceptance Criteria

- 至少 2 条真实英语媒体 case 形成可复现 manifest。
- 至少 1 条 case 含完整 `sound_analysis.connected_speech`。
- verifier 能在本机跑通，并对缺少 local-only 媒体给出清晰诊断。
- 每条 case 至少有 3 条 manual listening observation。
- 至少形成 5 条 raw CTC mismatch / connected-speech filtering 决策记录。
- 不把未授权媒体文件提交到 repo。
