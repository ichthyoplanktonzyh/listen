# Phase 3.9 Plan: L1-aware Diagnosis v1（Mandarin -> English）

状态：PLANNED

上游输入：`3.0-PHASE-BREAKDOWN.md`、`3.0-PLAN.md` Track E、
`.planning/discuss/listen-user-journeys-current-and-planned.zh.md` §20

## Objective

解释"为什么中文母语的听觉习惯让我漏掉这个英语声音"：LearnerProfile 持久化、
Mandarin -> English 难点 profile v1 进入诊断层短提示，并支持从用户自己的语料
聚合同类失败片段做专项练习。L1-aware 走 profile/provider seam（LANG-009 兑现），
不硬编码语言对。

## User Value

> "又漏了句尾的 t——诊断多了一行：中文听觉习惯对词尾辅音不敏感，这是你第 7 次
> 栽在这类声音上。点开有你自己材料里的 15 个同类片段。"

## Scope

### In

- **LearnerProfile 持久化**（兑现 3.0.1 deferred）：UI language / L1 / L2 三者分离
  设置；未设置 L1 时只显示基础诊断。
- **Mandarin -> English 难点 profile v1**（`L1L2DifficultyProfile`）：
  - weak function words、schwa/reduced vowels、final consonants、consonant clusters、
    t/d deletion、flapping、linking、stress-timed rhythm、compressed forms
    （gonna/wanna/didja/woulda）。
  - 每类难点：识别规则（基于现有诊断证据与 rhythm/connected-speech 标记）、
    一句话 L1 迁移解释、必须附带真实音频复听动作。
  - profile 内容需引用研究依据（对比音系学/二语听辨文献），按 AGENT.md 算法证据
    规则记录来源；不写成泛泛语法课或刻板印象。
- **诊断集成**：失败命中难点类别时，诊断卡追加 L1 短提示（短句优先）；
  不支持的 L1/L2 组合显示语言中立提示，干净降级。
- **专项聚合库**：按难点类别聚合用户语料中的同类片段（复用 3.6 corpus index，
  connected-speech family 搜索接口在此接通），支持专项 replay / cloze / dictation
  （复用 3.1 管道）。
- 难点命中记录进 `LearningEvent`（供 3.10 难点分布统计）。

### Out（Non-goals）

- 其他 L1/L2 组合的 profile 内容（架构支持，内容不承诺）。
- 长篇课程化解释、发音矫正教学。
- 自动判定用户 L1。

## Dependencies

- 3.1（诊断管道升级后的接入点）——硬依赖。
- 3.6（专项聚合复用 corpus index）——软依赖：缺席时专项库退化为当前媒体内聚合。

## Key Work

1. LearnerProfile 持久化 + 设置 UI（UI 语言 / L1 / L2 分离）。
2. L1L2 难点 profile provider（规则 + 解释文案 + 研究依据记录）。
3. 诊断卡 L1 短提示注入与降级路径。
4. 难点 -> 语料聚合查询与专项练习入口。
5. 内容评审：难点解释逐条对照文献，避免未经证据的断言（validate-abstractions 纪律）。

## Exit Signal

- Mandarin L1 用户的失败命中难点类别时，诊断出现简短 L1 提示且可一键复听真实片段。
- 未设置 L1 / 不支持组合时基础诊断无回归、无空泛刻板文案。
- 至少一类难点（如 weak function words）可从用户语料聚合出专项片段并进入练习。
- **独立可用**：不设置 L1 的用户完全无感；设置后也可只看提示不进专项。

## Guardrails

- 提示必须回到真实音频；没有可复听证据的类别不出提示。
- 解释是 possibilities 不是检测结论（沿用语言感知诊断口径）。
- profile 内容的每条规则记录研究/证据来源。
