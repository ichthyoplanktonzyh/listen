## Objective

解释"为什么中文母语的听觉习惯让我漏掉这个英语声音"：LearnerProfile 补 L1 持久化、
Mandarin -> English 难点 profile v1 进入诊断层短提示，并支持从用户自己的语料
聚合同类失败片段做专项练习。L1-aware 走 profile/provider seam（LANG-009 兑现），
不硬编码语言对。

## User Value

> "又漏了句尾的 t——诊断多了一行：中文听觉习惯对词尾辅音不敏感，这是你第 7 次
> 栽在这类声音上。点开有你自己材料里的 15 个同类片段。"

## Scope

### In

- **LearnerProfile 持久化**（兑现 3.0.1 deferred，范围按现状收窄）：
  - 已存在：学习语言来源（2.11）、UI 语言设置。仅新增 **L1 设置**与三者分离的
    统一读取面（One profile read model，供诊断层与 3.10 消费）。
  - 未设置 L1 时只显示基础诊断；设置入口进 3.35 的六类设置导航。
- **Mandarin -> English 难点 profile v1**（`L1L2DifficultyProfile`）：
  - weak function words、schwa/reduced vowels、final consonants、consonant clusters、
    t/d deletion、flapping、linking、stress-timed rhythm、compressed forms
    （gonna/wanna/didja/woulda）。
  - 每类难点：识别规则（输入 = 现有诊断证据 + audible-structure v1 的
    document-level `rhythm_frames` / 2.16 connected-speech 标记）、一句话 L1 迁移
    解释、必须附带真实音频复听动作。
  - profile 内容需引用研究依据（对比音系学/二语听辨文献），按 AGENT.md 算法证据
    规则记录来源；不写成泛泛语法课或刻板印象。
- **诊断集成**：失败命中难点类别时，诊断卡追加 L1 短提示（短句优先）。诊断入口
  沿 3.4.1 后的单一 capability profile 路径接入（diagnosis-core 规则 + provider
  seam），不引入平行诊断状态；不支持的 L1/L2 组合显示语言中立提示，干净降级。
- **专项聚合库**：按难点类别聚合用户语料中的同类片段。
  - 现状：corpus 投影（v28）只索引词 token / 句子 / chunk 三类，v29 加了 FTS5 与
    lemma 归一；**没有 connected-speech family 维度**。
  - 本 phase 需新增可重建的 family 标注投影（列或伴生表，沿用"投影可重建、
    reindex 触发点齐全"的 v28 口径），标注来源 = active timeline 的
    rhythm_frames / connected-speech 标记；这是明确的后端工程量，不是接线。
  - 聚合结果进专项 replay / cloze / dictation（复用 3.1 管道与 3.5.6 练习浮窗）；
    试听走 3.5.7 切片核心。
  - corpus 缺席/未索引媒体：专项库退化为当前媒体内聚合。
- 难点命中记录进 `LearningEvent`（供 3.10 难点分布统计）。

### Out（Non-goals）

- 其他 L1/L2 组合的 profile 内容（架构支持，内容不承诺）。
- 长篇课程化解释、发音矫正教学。
- 自动判定用户 L1。
- 义项级（sense folder 级）诊断归属——诊断证据仍是词条级（3.6.1 边界不动）。
- L1/L2 两层复述、LLM 跨语言语义 judge、speaking/writing 迁移诊断；本 phase 的
  `L1L2DifficultyProfile` 是有研究依据的 listening 规则 provider，不是通用 LLM provider。

## Dependencies

- 3.1 诊断管道 + 3.4.1 单一 capability profile 路径——硬依赖，均已存在。
- 3.6 corpus 投影与 reindex 机制——family 投影在其上扩展；缺席时按降级路径。
- 2.16 / 2.21 connected-speech 与 rhythm_frames 契约（算法线搁置中，**只消费
  现有 shape，不等待也不触发算法质量提升**）。

## Key Work

1. LearnerProfile L1 持久化 + 设置 UI + 统一读取面（分离 UI 语言 / 学习语言 / L1）。
2. L1L2 难点 profile provider（规则 + 解释文案 + 研究依据记录）。
3. 诊断卡 L1 短提示注入与降级路径。
4. corpus family 标注投影（可重建 + reindex 触发点）+ 难点 -> 语料聚合查询 +
   专项练习入口。
5. 内容评审：难点解释逐条对照文献，避免未经证据的断言（validate-abstractions 纪律）；
   每条规则记 evidence class。

## Exit Signal

- Mandarin L1 用户的失败命中难点类别时，诊断出现简短 L1 提示且可一键复听真实片段。
- 未设置 L1 / 不支持组合时基础诊断无回归、无空泛刻板文案。
- 至少一类难点（如 weak function words）可从用户语料聚合出专项片段并进入练习。
- **独立可用**：不设置 L1 的用户完全无感；设置后也可只看提示不进专项。

## Guardrails

- 提示必须回到真实音频；没有可复听证据的类别不出提示。
- 解释是 possibilities 不是检测结论（沿用语言感知诊断口径）。
- profile 内容的每条规则记录研究/证据来源。
- family 投影是读侧可重建数据，不是权威学习资产；重建丢失可接受。
