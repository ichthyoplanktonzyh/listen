# 3.9 L1 难点 Profile 研究依据（Mandarin → English v1）

状态：随 Phase 3.9 实现落地（2026-07-12）
代码位置：`crates/diagnosis-core/src/l1l2.rs`

## 证据分层原则

按 AGENT.md 算法证据规则，本 profile 显式区分两层：

1. **Profile 内容**（类别清单 + 一句话迁移解释）：来源为已发表的对比音系学与
   二语听辨研究（下表）。解释统一为 possibilities 语气，不作个体检测断言。
2. **识别规则**（类别 → audible-structure v1 证据 family 的映射）：evidence class
   一律 `heuristic_proxy`——上游 rhythm frame 与 2.16 connected-speech 标记本身
   即为 `heuristic_proxy`，映射不提升其证据等级。

Guardrail 落实：识别规则只消费带可复听时间跨度的证据（weak group /
compression span 直接携带 ms；connected-speech ref 须与同 token 区间的
ConnectedSpeech hotspot 对齐取得 ms），无 span 的类别不出提示。
`final_consonants` 与 `consonant_clusters` 当前无对应检测器，声明为空
family（内容已备、证据 provider 待算法线补齐），永不虚假触发。

## 已知边界

- 所有识别规则均为**规则先验**（TextPrior）或音素证据的 heuristic_proxy，
  不是对该用户音频的检测结论；诊断文案沿用 possibilities 口径。
- 节奏类差异（syllable-timed vs stress-timed）在现代文献中是连续统
  （Grabe & Low 2002 本身即是对二分法的量化修正）；解释文案不使用
  "汉语是 syllable-timed 语言"的断言式表述。
- 其他 L1/L2 组合仅有架构支持（provider seam 返回 None），无内容承诺。
