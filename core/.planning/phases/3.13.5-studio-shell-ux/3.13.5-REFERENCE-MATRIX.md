## 表面语法规则（草案，原型 G 屏同步呈现）

四类表面：

1. **整面 Studio**：进入一个场景，占据主区，自带退出返回；同屏最多一个。
   承载：阅读器、任务容器（读任务/复述/写作）、听力工作台。
2. **右侧栏 Panel**：依附当前场景的上下文，不抢焦点，可折叠；内容必须与
   当前场景相关。承载：词汇学习面板、诊断摘要、材料词汇概览详情。
3. **浮窗 Float**：跨场景借用的独立能力，可拖动、非模态；全局同时至多
   一个。承载：切片回听窗。豁免：精听练习窗（3.5.6 已验收，不迁移）。
4. **文内 Inline**：作用于正文对象的轻量操作，悬停/选中出现，移开即走。
   承载：句子工具栏、词点击、SenseGroup 胶囊、翻译渐隐。

现状迁移映射：阅读姿态→整面 Studio；段落任务 bottom sheet→任务容器；
听测整面替换→任务容器住户（来源区=纯音频）；读听差异 dialog→反馈区卡片；
切片回听浮窗→保持；狩猎悬浮卡→保持（泛听场景，非本 phase 范围）。

禁则：桌面端不再用 modal bottom sheet 承载多阶段流程；dialog 只留给必须
打断的破坏性确认。
