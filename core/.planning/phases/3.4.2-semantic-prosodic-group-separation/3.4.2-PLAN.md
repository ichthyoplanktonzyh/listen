## Objective

新增句子 token-span 型 SenseGroup 语义加工层，同时保留现有 ChunkTimeline 的音频时间和
声学/韵律证据。SenseGroup 是句子级文本标注，不是全局学习资产；播放范围通过 WordTimeline
投影获得。

## User Value

> "我可以按语义单位理解一句话，而不只是按说话者的停顿来切分；练习和回听都能以意义单位
> 为目标，即使没有高级语法分析器也能工作。"

## Exit Signals

1. 同一句可以同时拥有语义分组和实际韵律分组，且两者互不覆盖。
2. text-only SenseGroup 可通过词时间轴获得安全播放范围。
3. SenseGroup 默认是 annotation/practice target，不自动进入全局词汇资产。
4. 没有 parser/model 时现有 Chunk replay 不回退。
5. 规则回退 provider 对英语和中文 fixture 产出合理分组。
6. `cargo test --workspace` 和 `flutter test` 通过。

## Guardrails

- 用户意群修正是独立 overlay 层（ADR 0016 决策 9），不得以改写 provider analysis
  行内数据的方式实现；3.4.2 只保证 schema 不排除，不建机制。
- 不把所有自由组合意群建立长期 known/unknown 状态。
- 不用句法边界冒充真实音频边界。
- 不在 spike 前锁定 UDPipe 为正式依赖。
- 不在算法未验证前全局重命名 chunk 引用。
- 不混入 Construction、SentencePattern 或其他 3.4.3 工作。
