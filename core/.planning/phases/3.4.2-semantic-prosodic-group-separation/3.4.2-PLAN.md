# Phase 3.4.2 Plan: Semantic / Prosodic Group Separation

状态：PLANNED — blocked by Phase 3.4.1

共享上下文：
`../3.0-english-listening-learning-loop/3.4.X-LEARNING-DOMAIN-V2-SHARED-CONTEXT.md`

## Objective

新增句子 token-span 型 SenseGroup 语义加工层，同时保留现有 ChunkTimeline 的音频时间和
声学/韵律证据，建立两层之间允许非一一关系的对齐模型。

## Planned Slices

1. 领域词汇、身份、层次性与 alignment ADR。
2. provider-neutral SenseGroup analysis contract 和固定多语言 fixture。
3. parser/provider spike；比较 UD、浅层句法、规则与 LLM fallback 的实际失败模式。
4. consumer-side semantic analysis persistence/resource lifecycle。
5. SenseGroup -> WordTimeline -> playback range 投影。
6. semantic/prosodic alignment 与 UI 渐进消费。
7. 证据充分后再决定 ChunkTimeline 是否迁名；禁止先做全局机械 rename。

## Exit Signals

- 同一句可以同时拥有语义分组和实际韵律分组，且两者互不覆盖。
- text-only SenseGroup 可通过词时间轴获得安全播放范围。
- 一对多、多对一对齐有 contract fixture 和 UI 降级。
- SenseGroup 默认是 annotation/practice target，不自动进入全局词汇资产。
- 没有 parser/model 时现有 Chunk replay 不回退。

## Non-goals

- 不把所有自由组合意群建立长期 known/unknown 状态。
- 不用句法边界冒充真实音频边界。
- 不在 spike 前锁定 UDPipe 为正式依赖。
