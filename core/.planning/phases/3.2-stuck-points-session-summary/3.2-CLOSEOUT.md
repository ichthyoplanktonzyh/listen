# Phase 3.2 Closeout: Stuck Points & Session Summary

完成日期：2026-07-04

## 结论

Phase 3.2 已完成精听卡点闭环的首个可用切片：当前句/当前 chunk 可显式标记卡点或跳过，
诊断查看与 practice/review evidence 会进入读侧聚合，session summary 可显示卡住、当场解决、
主动验证、加入复习、仍未解释等数字；未解释/未处理项可回听、可手动关闭；用户可宣告
精听完毕并持久化熟料标记。

## 已落地

- 后端事件语义：新增 `stuck_point_marked`、`stuck_point_skipped`、`diagnosis_viewed`、
  `stuck_point_closed`、`familiar_material_marked` learning event kind，以及
  `practice_session` subject kind。
- 读侧聚合器：从 `LearningEvent`、`PracticeAttempt`、`ReviewItem` 派生
  `PracticeSessionSummary` 与 `StuckPointSummary`，不新增卡点状态机权威表。
- 状态派生：支持 marked、resolved_with_hint、actively_verified、added_to_review、skipped、
  unexplained、closed；手动保存 review 时按 `ReviewItem.source.practice_attempt_id` 关联，
  不反向修改 attempt JSON。
- API / contract：新增 session summary、complete session、mark/skip/close stuck point、
  diagnosis viewed routes；同步 OpenAPI 与手写 generated client。
- Flutter：Practice panel 新增标记卡点、跳过、session summary、悬案区 v0 回听/关闭、
  精听完毕确认与熟料标记；现有练习流程保持独立可用。
- 契约测试：新增 Dart summary fixture 解析测试、PracticeController 卡点标记测试、
  API route 测试、SQLite/AppServices summary 聚合测试。
