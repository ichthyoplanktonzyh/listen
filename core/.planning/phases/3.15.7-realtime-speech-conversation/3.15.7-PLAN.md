# Phase 3.15.7 Plan: Realtime Speech Conversation（realtime 语音对话）

状态：PLANNED（方向承诺，开工前按 3.15.5/3.15.6 落地现状修订；对应裁决代号 P4）

日期：2026-07-16

上游输入：`.planning/discuss/conversation-output-corpus-and-model-categories.zh.md`
§4/§5/§9/§11（v2 裁决：首批异构厂商 OpenAI Realtime + 千问 Qwen Omni）；ADR 0022
厂商中立精神（类别内 ≥2 异构 adapter 过同一契约套件）；3.12 keychain/auth_ref 密钥模式；
3.14 录音采集、audio focus 与本地 whisper.cpp 转写基建；3.15.5 产出语料摄入口。

## Objective

引入 **realtime 全双工语音对话**作为独立中立模型类别（类别 8）：新 seam 家族抽象
session 生命周期、双向音频流、turn 边界、transcript 事件、（可选）function call。
产品形态是**当前段落锚定的口语对话练习**；用户发言的权威文稿走本地 whisper.cpp，
产出喂 3.15.5 语料库（此处实现 scaffolding 排除逻辑），复盘归 3.15.6。

## User Value

在自己正在学的内容语境里跟 AI 用嘴对话——3.14 结构化复述之后的开放口语出口。对话产出
自动进入产出语料与 gap 复盘,realtime 一落地就有学习闭环归宿,不是孤立陪聊玩具。

## Scope

### In

- **realtime 中立 seam**：application trait 抽象 session/音频双向流/turn 边界/transcript
  事件；≥2 个异构厂商 adapter 过同一契约套件。realtime 协议比文本更不标准——这是新 seam
  家族，工程量如实预期，不是「加个 adapter」。
- 首批厂商：OpenAI Realtime + 千问 Qwen Omni（v2 裁决）。
- **证据文稿解耦**：麦克风音频统一喂本地 whisper.cpp 得权威 user transcript；厂商 ASR
  只用于对话体验，不进证据、不进语料。换厂商不改变产出语料口径。
- 当前段落对话：以当前媒体段落/内容为对话锚点与开场语境；退出只恢复位置不自动播放
  （沿 Studio 生命周期纪律）。
- 产出摄入：user transcript → 3.15.5 语料（channel=`spoken`）；**scaffolding 排除逻辑
  在此实现**（AI 先说过、用户复读的词打 scaffolding 标记，不计自主产出）。
- 密钥走 3.12 keychain + auth_ref；audio focus 复用 3.14 单一焦点纪律。
- 诚实降级：无 provider / 断流 / 认证失败时对话入口隐藏或如实报错，不影响其余功能。

### Out

- 发音评测 GOP（类别 10，后置）；说话人分离（类别 4，后置）。
- 开放世界自由闲聊首页：v1 锚定当前内容，不建独立「聊天室」心智。
- 对话内容作为 observation/projection（transcript 是事实与语料，能力结论仍走 3.15.6
  确认 + 3.17 门）。
- TTS（类别 9，3.15.9 正交）。

## Slices（开工时细化）

- Slice 0 — seam spike：单厂商端到端（音频进出 + turn + transcript 事件），验证抽象形状。
- Slice 1 — 中立化：第二异构 adapter + 共同契约套件。
- Slice 2 — 产品接线：当前段落对话 UI + audio focus + 退出/恢复。
- Slice 3 — 证据链：whisper.cpp 权威文稿 + scaffolding 标记 + 语料摄入。

## Exit Signals

- 两个异构 adapter 过同一契约套件；**owner 至少对其中一家完成真实端到端对话 QA**。
- 对话后 user transcript 以本地转写入产出语料，scaffolding 词被正确排除；3.15.6 复盘
  可见口语产出。
- 断网/认证失败/中途断流均诚实降级，不留半截证据。

## Guardrails

- **中立性必须可实测，不做纸面中立**：若 owner 网络环境实测不了 OpenAI Realtime，换成
  实际可达的异构厂商（豆包等）再宣称类别中立；契约套件全绿但两家都测不通不算达标。
- 厂商 transcript 与本地权威文稿字段分开存放，永不混淆来源。
- 对话音频/文稿留本地；发往厂商的内容限于对话所需，密钥不落普通存储。
