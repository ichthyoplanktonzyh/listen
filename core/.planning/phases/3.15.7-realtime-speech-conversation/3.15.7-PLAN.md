## 真实协议 Spike 裁决

首批 adapter 为 OpenAI Realtime 与 Qwen Omni Realtime，均走服务端 WebSocket，应用内部共同
audio contract 为 mono PCM16/24 kHz。共同事件只覆盖：session ready、speech start/stop、turn
commit、provider transcript preview/final、assistant transcript/audio delta、response done、rate limit
与 stable error。

必须保留的异构差异：

- OpenAI session/audio format 使用当前 GA Realtime shape；provider 输入 transcript 是独立 ASR，
  官方也只将其定义为 rough guidance。
- Qwen session 字段、voice/model、地域/workspace endpoint 不同；输入 transcript delta 的完整
  preview 是 `text + stash`，不能按 OpenAI delta 累加规则解析。
- provider item/event/response id 仅作 opaque provenance/correlation，不成为 session/turn identity。
- function call 是 capability-gated 增量，不阻塞首个 conversation surface。

两个 adapter 必须过同一 neutral contract suite（成功、VAD turn、assistant audio/transcript、
provider transcript 差异、认证、限流、协议错误、断流、取消）。有凭据时至少一家做真实 socket
smoke；没有凭据时明确记录 owner QA pending，不以 fake server 冒充真实可达。

## Scope

### In

- **共同 conversation 事实**：provider-neutral profile、session、ordered turn、local audio asset、
  provider transcript（即时体验）、local transcript（learner-output authority）、finalized/failed/
  interrupted lifecycle 与 provenance。media/content anchor 是可空 surface context。
- **两异构 adapter**：OpenAI Realtime + Qwen Omni Realtime；共同 seam/contract suite，协议专属
  encoder/decoder 保持在 adapter crate。
- **本地 loopback streaming bridge**：Flutter 不接触 provider secret；通过本地受 bearer 保护的
  full-duplex channel 发送 PCM chunk、接收 neutral events/audio delta。
- **内容锚定首个 surface**：当前段落只进入可选 context/instructions；对话 UI 不固化未来开放
  chat/role-play 的导航或布局。退出恢复原位置但不自动播放。
- **音频与权威 transcript**：原生 capture 同时流式输出与本地 WAV 落盘；每个 learner turn
  finalize 后走 bundled whisper.cpp。provider transcript 只显示为“即时字幕”，永不替代 local。
- **spoken corpus projection**：仅 finalized + local transcription completed 的 learner turn 作为
  immutable attempt source；best-effort 增量刷新、可全量重建。assistance 保存事实 provenance，
  不写 autonomous/scaffolding verdict。
- **honest degradation**：无 profile/credential、unsupported model/format、认证失败、断网、限流、
  中途断流、local ASR 不可用/失败均有稳定状态；半截 turn 不进 corpus，不影响其余功能。
- **安全**：secret 只在 keychain；发往 provider 的 audio/context 有明确提示；本地 audio/transcript
  生命周期可见且不进入普通日志。
