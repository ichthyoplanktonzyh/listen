# Phase 2.6 Closeout: Multilingual Learning Foundation

> 日期：2026-06-22
> 状态：完成（首批真实验收语言 English + Chinese）

## 结果

Phase 2.6 把 LLPlayerNext 从"英语优先学习播放器"扩展为"语言能力可插拔的学习播放器底座"，
首批真实验收语言为 English + Chinese。语言行为通过 `LanguageLearningProfile` + provider 注入：
唯一语言不变量是**理解轴**（全局 `WordStatus`），其余结构（分词、词汇单位、词典、发音、诊断
理由）按 profile / provider 变化，未知语言 / 未知 kind 干净降级。英语行为作为回归基线全程保持。

抽象在写代码前已由 Phase 2.5.5 用真实 SLA 校验、并经 Japanese / Arabic 类型学证伪锁定
（ADR 0012）。本阶段是该契约的实现。

## 完成内容

### Step 1-2：语言 Profile + 语言感知分词

- `domain::LanguageLearningProfile` + `profile_for`（en / zh / degraded），kind 为开放
  namespaced string，未知语言干净降级。
- `subtitle-core::tokenize(language, text)` + `Tokenizer` trait；汉语默认 jieba 词分词，
  `--no-default-features` 走字级 fallback；英语回归基线不变。

### Step 3：LexicalUnit

- `domain::LexicalUnit`（粒度 × 归一两轴 + 不透明 `normalized_key`）；英语 word 身份向后兼容
  旧 `WordProfileId`；汉语字 / 词 namespaced 不污染英语词汇。

### Step 4：去 `language=en` 硬编码

- `subtitle-core::import` 未声明语言时按脚本检测（含汉字 → zh，否则 en），用于分词与存储
  `track.language`；声明的语言优先。
- Flutter `SubtitleTrack` 读取 language；`_learningLanguage` 解析器（active 字幕轨语言 → en
  fallback）串到所有词汇 / 词典 / 词配置 / 来源快照 / 短语调用与 `_sourceFor`。
- 后端补强：`diagnose_sentence` / `phrase_candidates` 原写死 en，改为经 `sentence_language`
  （新增 `sentence_track_language` 仓储方法，JOIN `subtitle_tracks.language`）按句子所属轨语言
  查 profile。删除死代码 `normalizeLexical`。

### Step 5：汉语词典与拼音 Provider（CC-CEDICT）

- `ChineseDictionaryProvider` 接入 **CC-CEDICT**（约 12 万词条，读安装的 `.u8`、数字拼音转调号、
  简繁双查），25 词内置种子作离线兜底。
- CC-CEDICT 以钉死镜像 commit + 真实 SHA-256 注册进学习资源目录（CC-BY-SA 4.0），运行时下载，
  像 ECDICT 一样可安装。
- 既有 `lookup_dictionary` 按 `supported_languages` 派发，无特例分支；拼音走
  `DictionaryLookup.phonetics`；面板隐藏空 IPA 区（中文无 IPA provider）。

### Step 6：汉语学习面板与语言感知诊断

- 诊断在 application 层给 recognition barrier 叠加该语言 profile 的听辨因素（zh: 声调 / 词边界 /
  同音 / 轻声 / 变调；en: 弱读 / 连读…），namespaced、按 profile、**明确标注为"可考虑因素非检测"**
  （中文无音频分析，ADR 延后）。`DiagnosisHint` 新增 `reasons`，`diagnosis-core` 保持语言无关。
- 词面板新增汉字逐字拼音分解（字 → 拼音 / 声调），从词典拼音对齐、零额外查询、按脚本门控。

### Step 7：双语回归与收口

双语回归测试集（散落各 crate / flutter，已收敛为显式回归）：

- tokenizer contract / 中英混排 / 字符范围（subtitle-core）
- import 语言检测（subtitle-core）
- 词典 provider 语言路由（persistence）
- 诊断按轨语言查 profile（persistence）
- recognition barrier 听辨因素（persistence）
- **英汉词汇 + 来源快照语言隔离 capstone**（persistence）
- CC-CEDICT 解析 + 拼音调号规则（dictionary-provider）
- 诊断卡 reason 渲染 + 面板逐字拼音（flutter widget）

## 不变量遵守（ADR 0012 / 2.5.5）

- **理解轴唯一不变量**：全局 `WordStatus` 语言无关、未改动。
- **状态 ≠ 诊断理由**：理由 taxonomy per-profile、可扩展、非持久。
- **开放 kind taxonomy**：namespaced string，未知干净降级，无穷举 enum + 穷举 match。
- **英语回归基线**：全程保持，所有英语测试通过。

## 需求映射（§18.4 LANG-001..010）

  LANG-005（去硬编码）、LANG-006（CC-CEDICT 词典 / 拼音）、LANG-007（汉语面板 + 诊断）、

## 后续（刻意延后，非本阶段缺陷）

- **非英语音频 → 听觉单位生产**（汉语 ASR / 强制对齐 / 声调检测）：独立的 production-engine 后续
  program（ADR Future Path）；本阶段只让消费端 listening-ready、语言可插拔。
- **LANG-004 听觉锚定观察 / LANG-009 L1 seam**：按设计仅为预留 seam，待真实声音侧与 L1×L2
  对比难度表落地后再实现。
- **学习语言来源优先级**：当前实现 active 字幕轨语言 → en fallback；用户手动选择 / 媒体 metadata
  两个来源留 seam（见 `_learningLanguage` 注释）。
- **CC-CEDICT 多音词**：取第一条读音；逐字"义"未做（当前只做逐字"音"）。CC-CEDICT 装载依赖
  第三方镜像仓库存续（钉死 commit → 文件不可变；仓库若被删则安装 404、provider 回落种子）。
- **能力矩阵 API 暴露给 client**：未做；面板用脚本门控暂够（Open Question 待定）。
- 未跑活体 UI 点选闭环（后端 SQLite 集成测 + client widget 测 + 契约校验已分别覆盖各环节）。
