# Phase 2.13 Plan: Text-Centered Phoneme Ribbon

更新时间：2026-06-26 CST
状态：IN_PROGRESS

> **定位**：完成"以文字为中心"这条线的音素学习体验。用户导入视频、Whisper 转录后，
> 词级跳动、chunk 高亮、音素跳动三大学习体验应全部就绪——音素数据来自词典，时间
> 对齐从词级时间戳均分合成。用户无需下载额外模型。
>
> 以真实语流为中心的第二条线（音节化、韵律短语、声音结构）进入独立的 Phase 2.14。

## Objective

1. Whisper 转录完成后，音素带即可跳动——数据来自词典发音 + 词级时间戳合成
2. CTC 真实音素数据存在时，自动升级为真实数据驱动（精度更高，无需代码切换）
3. PhonemeRibbon 有明确的脉冲动画，跳动感清晰
4. 设置精简：音素相关设置收敛为 1 个开关（音素带可见性）

## 降级策略

```
优先级：CTC 真实音素（phoneticAnalysisBySentence）
          ↓ 无数据时
        词典音素 + 词级时间戳合成（pronunciationBySentence + timingsBySentence）
          ↓ 无数据时
        隐藏音素层（SizedBox.shrink）
```

消费端不区分数据来源，PhonemeRibbon 接收 `List<DetectedPhone>` 统一渲染。

## Steps

### Step 1: 词典音素时间合成 ✅ 函数已写，待集成

在 `timeline.dart` 新增 `synthesizePhonesFromDictionary(pronunciation, wordTimings)`：
- 从 `pronunciationBySentence` 取每个词的音素列表（带 `token_index`）
- 从 `timingsBySentence` 取对应词的 `start`/`end`
- 均分词时长给其音素，生成合成 `DetectedPhone`（`provider: 'dictionary'`）
- 函数已写入 timeline.dart，需集成到 main.dart 的 ribbon 渲染分支

### Step 2: 集成合成音素到 Ribbon 渲染

修改 main.dart 中的 PhonemeRibbon Builder：
```
CTC phones 非空 → PhonemeRibbon(phones: ctcPhones)
CTC phones 为空 → 合成 phones = synthesizePhonesFromDictionary(...)
                   phones 非空 → PhonemeRibbon(phones: synthesized)
                   phones 为空 → SizedBox.shrink
```
移除旧的 IPA 文字 fallback——所有音素信息统一走 ribbon。

### Step 3: PhonemeRibbon 脉冲动画

当前 `_PhoneCell` 是 StatelessWidget + AnimatedContainer，缺少真正的脉冲感。改为：
- `_PhoneCell` 改为 StatefulWidget，当 `isCurrent` 变为 true 时触发一次性脉冲
- 脉冲效果：scale 1.0 → 1.15 → 1.05（弹性衰减），持续 ~200ms
- 使用 `AnimationController` + `CurvedAnimation`（`Curves.elasticOut`）
- 非当前音素保持静止，不消耗动画资源

### Step 4: 端到端验证

- 导入视频 → Whisper 转录 → 开启音素带 → 确认词典音素以 ribbon 形式跳动
- 下载 CTC 模型 → 分析音频 → 确认自动切换为真实音素（无需用户操作）
- 关闭音素带 → 确认所有音素信息隐藏
- 性能：一句话 10-40 个合成音素，ribbon 动画无卡顿

## Success Criteria

1. Whisper 转录后即可看到跳动的音素带（无需 CTC 模型）
2. CTC 数据存在时自动升级，用户无感
3. 脉冲动画清晰可见，有"声音在跳动"的直觉
4. 一个开关控制全部音素显示
