## Outcome

个人听力词典 MVP 按 v2 修订的"资产优先"顺序完整落地：词典的组织形式是
**学习对象 → 切片** 的视图层级（义项刻意缺席，留给 3.6.x），第一刀零新后端消费既有
词汇资产，第二刀补上可重建的本地语料索引与搜索。词典可作为纯查询工具独立使用，
也接入了证据（逐例标记）、复习（每切片出口）与画像（override 就地编辑）三条既有管道。

## Delivered

### 词典页（Slice 1，词汇本演进）

- 词汇本演进为词典页：master-detail 页内详情取代弹窗；学习对象列表（word/phrase 统一、
  四通道摘要 + `CapabilityFilter` 过滤）→ 对象详情（切片列表、覆盖度诚实展示、空态引导）。
- 词典页自持第二解码切片窗（`SlicePlayerController` + `SlicePlaybackWindow` +
  `OccurrenceMediaResolver` 复用）：播放例句不离开词典、不触碰主播放器；进入词典路由时
  经回调暂停主播放器（D6 焦点策略）。深链 `initialEntryId` 按 id 直取详情。
- 切片按估算语速排序（≈wpm 装饰性标注，退化输入不显示）；切片 UI 状态按 occurrence
  身份键控，排序不串已揭示/已标记状态。

### 逐例识别标记（Slice 2）

- 每切片"这次听出了/没听出"经 `create_lexical_observation` 走 ADR 0017 单写入口，
  自动触发 ADR 0019 listening 重投影与升级建议聚合；无稳定 sentence 关联的旧切片
  明确禁用并给出诚实文案，不伪造证据。

### 本地语料索引与搜索（Slice 3）

- schema v28 `corpus_occurrences`：可重建、非权威的搜索投影，与耐久 `lexical_occurrences`
  刻意分离；索引 lemma 键词 token、句级 phrase 行与 active chunk timeline 的精确 chunk 行。
- 重建触发：字幕导入、轨道语言修改、chunk timeline activate/archive/delete 与激活式生成；
  `POST /v1/corpus/reindex` 为存量库/漂移恢复的手动全量重建入口（词典页工具栏按钮）。
- `GET /v1/corpus/search`：单词查询走 lemma 键精确匹配，多词查询走 FTS 短语匹配
  （见下"债务清偿"）；大词条按 media 轮转采样（窗口函数交错），截断页跨来源多样化并在
  UI 显示"已跨媒体采样"提示。
- 词条详情"在我的媒体库中搜索"：corpus 命中经切片窗试听、一键收为该词条来源切片
  （复用 `upsert_lexical_entry` source 口径，normalized form 保证身份不分叉，去重已保存
  句子）；词汇本零结果时词典降级为 corpus 纯查询（试听 only——收藏需要词条归属）。
- Dart `CorpusOccurrence` 手写 DTO + committed fixture 契约测试（ADR 0014）。

### 动作出口与编辑回补（Slice 4）

- 每切片"加入复习"：ReviewItem 带 sentence anchor（句子快照 + 时间窗 + 媒体），复习队列
  按 3.4 既有卡型派生原句回听/cloze 类卡；词条级"加入复习"保留在详情工具栏。
- 回补词典化时移除的编辑面：四通道 override 就地编辑（镜像侧面板 chip 模式，重选清除、
  override 角标）、释义/笔记折叠编辑区、升级建议确认/拒绝 banner。
- 外链兜底（版权 guardrail 内）：零切片态与媒体库零结果态提供 YouGlish 外链（仅 en，
  系统浏览器打开）与词典发音（复用 `PronunciationButton`），文案明示"仅供参考，
  不作为练习素材"；外部结果不下载、不进本地练习管道。

### 债务清偿（本次收口前完成）

- **FTS5 取代 LIKE 全扫**：schema v29 `corpus_occurrences_fts`（rowid 镜像、触发器维护；
  `delete_track` 在 FK cascade 前显式清理，连贯性不依赖 cascade 是否触发触发器）。
  多词查询语义从裸子串升级为分词短语匹配（词边界、大小写折叠）。
- **lemma 归一双向打通**：重建时词 token 键经 `normalize_lexical_form`（用户纠正 →
  provider lemma → 基线）归一，与词条身份同路径；自由文本单词查询走同一路径。
  "run" 能找到 "running" 的语境，"Running" 查询命中 lemma 键。**注意：v29 之前建立的
  索引行仍是表面形键，需手动执行一次"重建媒体库语料索引"以获得 lemma 匹配。**

### 附带修复（3.5/3.5.6 接缝回归）

- 精听 session 在 extensive-only completion（3.5.6）后永不"完成"，3.5 content-fit-v2 的
  练习准确率校准失去触发点。已改为 attempt 提交时增量折算
  （`record_practice_accuracy_feedback`，best-effort、不双计），completion 只折算理解度自报。

## Key Decisions

1. **义项与图谱缺席是刻意的**：切片直接挂词条下；义项是 3.6.x 的可选文件夹（spike 把门，
   三个必答问题见讨论文档 §9）；图谱视图推迟到数据密度足够。
2. **练习出口收敛到复习队列**：不在词典内嵌 3.1 practice 会话 UI——练习浮窗绑定工作台与
   当前媒体循环（3.5.6），词典例句的动作出口是带 anchor 的 ReviewItem。"词典直接起练习"
   如有需要另立决策。
3. **corpus 投影永不权威**：可整表重建、媒体删除降级（`media_id` SET NULL）、
   证据/资产零依赖。
4. **`LexicalEntry` 不改名**："学习对象"是 UI/读端概念；construction 保持 ADR 0020
   独立身份，未并入。
