# Phase 3.6 Plan: Listening Dictionary MVP

状态：PLANNED

上游输入：`3.0-PHASE-BREAKDOWN.md`、`.planning/discuss/listen-learning-activity-path.zh.md`

## Objective

本地个人语料优先的听力词典：把一个词 / phrase / chunk 放进用户自己媒体库的多个
真实声音语境中反复听，训练泛化识别（`known_not_recognized -> known_recognized`
的真实过程），并诚实处理语料贫瘠的冷启动。

这不是发音词典，是 real-speech recognition and generalization tool。

## User Value

> "'gonna' 在我自己的材料里出现过 11 次——不同来源、不同语速，一条条听，
> 标记这次听出来了没有。"

## Scope

### In

- **Corpus index 持久化与搜索**（兑现 3.0.1 deferred 的 `CorpusIndexRepository`）：
  - 索引来源：已导入媒体的字幕/timeline 资源（word / phrase / chunk 级出现点，
    `CorpusOccurrence` + `PlayableSegment`）。
  - 搜索：word、已确认 phrase、chunk 文本；connected-speech family 搜索留接口
    （3.9 难点 profile 落地后接入）。
- **词典页**：
  - 例句列表：来源标题、字幕上下文、目标高亮、可用性状态。
  - 逐例播放：词窗口 / chunk / 整句；先听后显（默认遮字幕，点击显示）。
  - 按语速分组/排序（可计算）；用户"曾听出/没听出"历史标注。
  - **覆盖度诚实展示**：出现次数少时明说"你的语料里只有 2 例"，不装满页。
- **逐例识别标记**：每条例句单键标"这次听出了 / 没听出"，证据流入 3.4 升级建议
  （3.4 缺席时仅落库）。
- **动作出口**：保存好例句 -> `ReviewItem`（3.4 存在时）；从例句生成 cloze/听写
  （复用 3.1 practice 管道，缺席时只保留播放）。
- **外链兜底**：本地无/少结果时提供 YouGlish 外链与词典发音作为临时参考；
  外部结果不作为本地可练习音频。
- 入口：字幕 token 点击、词汇学习面板、词汇本、诊断结果、搜索框。

### Out（Non-goals）

- speaker 维度分组（无 diarization 数据）、前后音环境维度（数据不足）——
  明确砍掉，等语料与元数据成熟再议。
- 外部语料聚合、系统性下载外部音视频（版权红线）。
- caption 低置信来源生成听写（标低置信、只读）。

## Dependencies

- 无硬依赖，可独立开工（索引是独立后端工程量）。3.1/3.4 存在时练习/复习出口点亮。

## Key Work

1. corpus index 构建：导入/资源激活时增量索引（后台任务，注意大库性能）。
2. 搜索 API + OpenAPI/contract 同步。
3. 词典页 UI（列表、播放窗口、先听后显、覆盖度状态）。
4. 逐例识别标记落库（观察证据，语境去重口径与 3.4 一致）。
5. 外链兜底与降级文案。
6. 大词条（如 "the"）的结果截断/采样策略。

## Exit Signal

- 从词汇面板点入词典，看到本地真实例句并完成逐例播放 + 识别标记。
- 一个 known_not_recognized 词经词典标记产生的证据出现在升级建议聚合里
  （3.4 存在时）。
- 本地零结果时给出体面外链降级，不出现空页死路。
- **独立可用**：词典可作为纯查询工具使用，与闭环其他环节无耦合。

## Guardrails

- 版权/API 限制内只缓存 metadata/snapshot，不默认下载外部音视频。
- 不可信 caption 不生成 dictation。
- 覆盖度诚实：宁可少而真，不填充凑数。
