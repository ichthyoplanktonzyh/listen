# Phase 3.6 Plan: Listening Dictionary MVP

状态：PLANNED（2026-07-10 v2 修订；v1 以 corpus index 为第一刀，修订依据见下）

上游输入：`3.0-PHASE-BREAKDOWN.md`、`.planning/discuss/listen-learning-activity-path.zh.md`、
`.planning/discuss/personal-listening-dictionary-and-slice-player.zh.md`（含 §9 评审结论）。

前置依赖：Phase 3.5.7 Slice Playback Window（统一切片回听组件）。

## v2 修订要点

1. 词典的组织形式确立为"学习对象 →（可选义项）→ 切片"的**视图层级**：第一刀基本显示
   粒度是学习对象（`LexicalEntry`），切片（`LexicalOccurrence`）直接挂在对象下，**不做义项**。
   义项是可选整理文件夹，不是数据的强制结构。
2. 数据来源重排：第一刀只消费已有词汇资产（entry + occurrences + capability profile），
   **零新后端**；corpus 全库索引与搜索（v1 核心）降为第二刀增补。
3. 义项文件夹为独立后续 phase（3.6.x），由 sense spike 把门；2026-07-07"sense 身份 spike
   排在 3.6 前"的裁决据此修订为"排在义项切片前"。
4. 个人语料图谱视图明确推迟：将来纯读端推导、不落库；待词典真实使用数据密度足够后再评估
   可视化形态（力导向图未必优于时间×媒体活动视图）。
5. 词典页是词汇本的演进形态，不另开平行页面（兑现 3.5.5 遗留的"学习对象统一抽象"）。

## Objective

本地个人语料优先的听力词典：把一个词 / phrase 放进用户自己媒体库的多个真实声音语境
（切片）中反复听，训练泛化识别（listening 通道 not_acquired → acquired 的真实过程），
并诚实处理语料贫瘠的冷启动。

这不是发音词典，是 real-speech recognition and generalization tool。

## User Value

> "'gonna' 在我自己的材料里出现过 11 次——不同来源、不同语速，一条条听，
> 标记这次听出来了没有。"

## Scope

### In — Slice 1：资产词典页（第一刀，零新后端）

- 词汇本演进为词典页：学习对象列表（word / phrase 统一呈现，四通道能力摘要 +
  `CapabilityFilter` 过滤，复用 3.5.5 已落地的能力过滤面）。
- 对象详情：切片列表（来源标题快照、句子快照、目标词高亮、可用性状态），逐条经 3.5.7
  切片窗回听；先听后显（默认遮句子文本，点击显示）。
- 覆盖度诚实展示："你的语料里只有 2 例"不装满页；零切片对象有明确空态与引导。
- 入口：字幕 token 点击、词汇学习面板、词汇本导航、诊断结果。

### In — Slice 2：逐例识别标记

- 每切片单键标"这次听出了 / 没听出"，写入 3.4.4 通道化 `LearningObservation`
  （listening 通道；语境去重与身份指纹口径沿用 ADR 0017）。
- 只产证据：进入既有 projection / suggestion 管道，不直写 capability、不静默覆盖
  user override（ADR 0015）。
- 大词条（如 "the"）的切片截断/采样策略。

### In — Slice 3：corpus 搜索增补（第二刀，v1 核心内容）

- Corpus index 持久化与搜索（兑现 3.0.1 deferred 的 `CorpusIndexRepository`）：
  - 索引来源：已导入媒体的字幕/timeline 资源（word / phrase / chunk 级出现点，
    `CorpusOccurrence` + `PlayableSegment`）。
  - 导入/资源激活时增量索引（后台任务，注意大库性能）。
  - 搜索：word、已确认 phrase、chunk 文本；connected-speech family 搜索留接口
    （3.9 难点 profile 落地后接入）。
- 搜索 API + OpenAPI/contract 同步；词典页搜索框入口。
- 对象详情"在我的媒体库找更多例句"：corpus 命中经切片窗试听后可一键收为该对象的切片
  （创建 `LexicalOccurrence`，复用 3.5.5 来源原句的创建口径）。
- 外链兜底：本地零/少结果时提供 YouGlish 外链与词典发音作为临时参考；
  外部结果不作为本地可练习音频。

### In — Slice 4：动作出口与收口

- 保存好例句 → `ReviewItem`；从例句生成 cloze/听写（复用 3.1 practice 管道）。
- 按语速分组/排序（可计算时）。
- 验证、真实媒体手工 QA、CLOSEOUT。

### Out（Non-goals）

- **义项（LexicalSense）建模与 UI** —— 3.6.x 独立 phase，由 spike 把门。spike 必答三问
  （见讨论文档 §9）：
  (a) 词条级/义项级画像共存 precedence 与读端聚合；
  (b) 证据的义项归属与追加式 re-attribution（兼容 3.4.4 append-only 语义）；
  (c) 义项身份权威 = 用户文件夹，词典 API 义项仅为建议/对齐注释（同构于
  projection/override 分层）。
- **图谱视图**（推迟，见修订要点 4）。
- `LexicalEntry` 改名 `LearningObject`（不改："学习对象"是 UI/读端概念，粒度扩展走
  `LexicalUnit` granularity 轴；construction 保持 ADR 0020 独立身份，词典页将来以
  独立卡片类型接入，不并入词条模型）。
- speaker 维度分组（无 diarization 数据）、前后音环境维度（数据不足）——等语料与元数据
  成熟再议。
- 外部语料聚合、系统性下载外部音视频（版权红线）。
- caption 低置信来源生成听写（标低置信、只读）。

## Dependencies

- Slice 1 前置：3.5.7 切片窗。Slice 1/2 零后端新表，纯消费现有资产与证据管道。
- Slice 3 是独立后端工程量，可在 Slice 1/2 落地后独立立项推进；3.1/3.4 存在时
  练习/复习出口点亮。

## Exit Signals

1. 从字幕/词汇面板点入词典，看到该学习对象的全部切片并逐条回听，主播放器不被劫持。
2. 逐例标记产生 listening 通道 observation，并出现在既有 projection/suggestion 聚合里。
3. 覆盖度少时诚实展示；本地零结果给出体面外链降级，不出现空页死路。
4. corpus 搜索命中可试听并收为切片，收藏后出现在对象详情中（Slice 3 后）。
5. **独立可用**：词典可作为纯查询工具使用，与闭环其他环节无耦合。

## Guardrails

- 版权/API 限制内只缓存 metadata/snapshot，不默认下载外部音视频。
- 不可信 caption 不生成 dictation。
- 覆盖度诚实：宁可少而真，不填充凑数。
- 逐例标记只产证据，不静默改 capability override（ADR 0015 / 0017）。
- Slice 1/2 不建新表、不加字段；发现的模型缺口记录到义项 spike 议题，不顺手扩 schema。
- 词典页与词汇本不并存两套入口；迁移完成前旧入口保持可用，完成后移除。
