# Phase 3.8 Plan: Shadowing & Recording Comparison

状态：PLANNED

上游输入：`3.0-PHASE-BREAKDOWN.md`、`.planning/discuss/listen-learning-activity-path.zh.md`、
`3.0-PLAN.md` Track F

## Objective

点亮精听三姿态的"跟一下"（内化型）：chunk-level 可调速跟读、录音、A/B 对比与
轻量节奏比较。从"听懂真实语流"自然过渡到"模仿真实语流"，不承诺复杂发音评分。

## User Value

> "这个 chunk 我已经能听出来了——0.9x 跟三遍，录一条和原音 A/B 对比，
> 听得出我的停顿位置不对。"

## Scope

### In

- **Shadowing 播放**：以 chunk 为默认单位（无 chunk 回退句级）；0.75x / 0.9x / 1.0x；
  循环与逐步展开（1 -> 1+2 -> 整句）复用现有 chunk 控制。
- **录音**：麦克风采集 -> `RecordingAsset` 落库（兑现 3.0.1 deferred 的
  `RecordingRepository`）；权限缺失时解释并引导系统设置。
- **A/B/A 对比播放**：原音 -> 用户录音 -> 原音，一键循环对比。
- **轻量比较（`ShadowingComparison`）**：时长差、停顿位置粗对比（基于现有 Rust
  DSP 能力：pause/RMS）；波形并排展示。不做打分。
- **入口点亮**："跟一下"从 3.1 的占位变为可用；Listening structure cue / 复习项 /
  chunk 控制均可进入。
- 记录：`PracticeAttempt`（shadowing 类型）+ 可选保存最好一次录音；媒体丢失时
  保留录音与 prompt snapshot。

### Out（Non-goals）

- 发音评分、音素级对齐打分、GOP 类算法（长期研究线，不进 3.x）。
- 节奏/重音自动诊断（"重音位置偏"这类结论需要证据校准，先只呈现客观对比）。
- 复习队列中的 shadowing 评分卡（评价口径成熟后再进 3.4 卡型）。

## Dependencies

- 3.1（三姿态入口框架）——硬依赖。
- 现有 chunk replay 与 Rust DSP（pause/RMS）能力。

## Key Work

1. 录音采集（macOS 权限、格式、存储路径策略）+ `RecordingRepository` 落地。
2. shadowing 会话 UI：调速、循环、逐步展开、录制控制。
3. A/B/A 播放器与波形并排视图。
4. 时长/停顿粗对比计算（Rust 侧复用 DSP，输出 `ShadowingComparison`）。
5. attempt/资产落库与"保存最好一次"。

## Exit Signal

- 选一个真实 chunk 完成：听 -> 跟 -> 录 -> A/B 对比 -> 重录 -> 保存。
- 时长与停顿对比在真实录音上给出可理解的客观展示（manual_product_qa 记录）。
- 麦克风缺权限、无 chunk、媒体丢失三条降级路径可走通。
- **独立可用**：shadowing 可直接从 chunk 控制进入，不依赖练习/复习闭环。

## Guardrails

- 只呈现客观对比，不输出未经校准的主观评价。
- 录音是用户资产：默认本地存储、可删除、媒体删除不级联删录音。
