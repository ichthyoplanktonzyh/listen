# Phase 2.14 Prosodic Hierarchy Alignment

更新时间：2026-06-26 CST
状态：REFERENCE

## Question

声音线是否按照真实语音研究来组织？

短答：

> 是，Phase 2.14 的方向与真实语音/韵律研究一致；但当前实现只是 Prosodic Hierarchy 的最小可靠子集，
> 不是完整韵律层级实现。

## Research Frame

语音学和音系学研究中，真实语流的组织方式不同于文字。经典韵律层级理论通常将声音组织为：

```text
Phone
  -> Syllable
  -> Foot
  -> Prosodic Word
  -> Phonological Phrase
  -> Intonation Phrase
```

参考框架：

- Nespor & Vogel 1986: Prosodic Phonology
- Selkirk 1984: Phonology and Syntax
- MacNeilage 1998: speech production and syllable organization
- Levelt et al. 1999: speech production model

关键产品启发：

- 真实语音不是按 written word 一个个产出的。
- 音节是语音产出和感知中的基础单位之一。
- 词边界在连续语流里经常被弱读、连读、省音、同化和节奏重组削弱。
- 学习者“看得懂但听不懂”往往不是不知道词，而是没有把真实声音流切回正确语言单位。

## Why Word Is Not The Sound-Line Unit

文字线可以按 word / token / chunk 工作，因为它回答：

```text
What was said?
```

声音线不能以 written word 作为核心单位，因为它回答：

```text
How was it actually organized in the audio?
```

真实语流里的边界证据来自：

- vowel nucleus / syllable structure
- stress and prominence
- duration
- gap / pause
- final lengthening
- pitch reset
- phrase-final strengthening
- reduction and assimilation

其中很多证据不等同于文字词边界。

## Phase 2.14 Implemented Subset

Phase 2.14 实现的是一个可运行、可验证、不过度声称的子集：

```text
Phone / ObservedPhone
  -> LearningPhone
  -> Syllable
  -> pause-based ProsodicPhrase
```

### Phone / ObservedPhone

来源：CTC / PhoneTimeline。

职责：

- 提供音频 observation。
- 提供 timing、duration、confidence。
- 提供 mismatch evidence。

限制：

- raw CTC phone label 不等于教学真值。
- raw observed mismatch 不直接显示给学习者。

### LearningPhone

来源：expected pronunciation aligned to observed CTC timing。

职责：

- 用户默认看到的稳定训练标签。
- label 来自文本/词典/规则。
- timing 尽量来自真实音频 observation。

这是 Phase 2.14 的关键产品修正。它防止 `/s/` 被 CTC 误识别为 `/k/` 后直接污染用户训练 UI。

### Syllable

来源：LearningPhone 序列。

当前算法：

- vowel nucleus。
- onset / coda 划分。
- onset maximization。
- pause-aware boundary：明显停顿会阻止 onset maximization 跨停顿抢辅音。

边界：

- 当前是英语 ARPAbet-oriented baseline。
- 还没有 profile 化到不同语言的音节结构。
- 还没有 syllabic consonant、复杂合法 onset 列表、语言特异例外表。

### ProsodicPhrase

来源：LearningPhone / Syllable timing。

当前算法：

- pause/gap based。
- gap >= threshold 形成高置信 phrase boundary。

边界：

- 当前不是完整 Phonological Phrase。
- 当前不是完整 Intonation Phrase。
- 不使用 F0/pitch reset。
- final lengthening / local duration peak 暂未作为高置信边界。

## What Is Not Implemented Yet

当前未实现完整韵律层级：

| Layer | Status | Why Deferred |
|---|---|---|
| Foot | Not implemented | 需要 stress prominence / rhythm evidence |
| Prosodic Word | Not implemented | 需要弱读 cliticization、function word attachment、stress group model |
| Phonological Phrase | Partially approximated | 当前只有 pause-based phrase，不含完整 lengthening/prominence evidence |
| Intonation Phrase | Not implemented | 需要 F0 / pitch reset / intonation contour |

## Product Honesty

Phase 2.14 不应声称：

- 已完整实现 Prosodic Hierarchy。
- 已准确检测 intonation phrase。
- 已准确检测所有 phonological phrase。
- CTC phone label 是真实发音真值。

Phase 2.14 可以声称：

- 声音线已经不再按 written word 组织。
- 用户可见 phone label 已稳定化。
- CTC timing/evidence 已进入声音组织层。
- PhoneTimeline 已能携带 `sound_analysis`。
- Ribbon 已能按音节和 pause-based phrase 进行声音线分组展示。

## Suggested Next Phase

后续声音线增强可以按以下顺序推进：

1. Foot / stress group baseline。
2. Prosodic Word baseline：content word + weak function word attachment。
3. Phonological Phrase v2：pause + final lengthening + phrase-final strengthening。
4. Intonation Phrase spike：引入 F0/pitch extraction，验证 pitch reset 是否值得进入主线。
5. 多语言 profile：为英语、汉语、日语分别定义 syllable / mora / tone / stress 的组织规则。

## Architecture Rule

后续实现必须继续遵守：

> Sound organization may use text as reference, but sound boundaries must be justified by audio evidence.

中文：

> 声音组织可以把文字作为参照，但声音边界必须由音频证据支撑。
