# Phase 2.14 Stable Learning Phone Architecture

更新时间：2026-06-26 CST

## Decision

LLPlayerNext 的声音线以真实音频 observation 组织 timing、节奏、音节和韵律短语，但默认
教学标签不由 raw CTC phone label 决定。

架构准则：

> CTC provides audio evidence and timing; expected pronunciation provides teaching labels.

中文准则：

> CTC 负责真实声音证据与节奏组织，教学标签由稳定的文本/词典/规则发音提供。

## Why

Whisper/字幕文本线在“说了什么”上通常比 phone CTC 更稳定；文本 + 词典/规则生成的
expected pronunciation 适合作为学习者训练时看到的标准标签。

CTC phone recognition 更贴近真实音频，但 phone identity 会抖动。例如真实应听回 /s/ 的片段
可能被误识别成 /k/。如果 raw CTC label 直接进入 phoneme ribbon，用户会看到错误教材答案，
破坏训练目标。

因此 CTC 是 observation/evidence，不是默认教学真值。

## Phone Layers

| Layer | Source | Responsibility | User Default |
|---|---|---|---|
| ExpectedPhone | transcript + pronunciation provider + rules | Stable teaching label | visible |
| ObservedPhone | CTC / PhoneTimeline | Audio timing, duration, confidence, mismatch evidence | hidden by default |
| LearningPhone | ExpectedPhone aligned with ObservedPhone timing | Training display: stable label, audio-informed rhythm | visible |

## Behavioral Rules

- Phoneme ribbon displays `LearningPhone`, not raw `ObservedPhone`.
- `LearningPhone.symbol` / `display_ipa` default to `ExpectedPhone`.
- `LearningPhone.start/end` may come from aligned `ObservedPhone` when alignment is credible.
- raw observed label and confidence remain available as evidence for diagnostics and advanced views.
- In the first implementation, observed label never rewrites the visible teaching label.
- Future implementations may surface observed allophones/reductions only when confidence is high and the change
  matches a known connected-speech rule.

## Example

Expected pronunciation says:

```text
S
```

CTC observes a low-confidence:

```text
K
```

Default training display:

```text
S
```

Internal evidence:

```text
observed=K
confidence=low
alignment=mismatch
```

The user trains toward the stable language target, while the system keeps the audio observation for later
diagnosis.

## Relationship To SoundAnalysis

`SoundAnalysis` is audio-derived and sentence-scoped, not text-derived or sentence-owned.

The sentence is a shared observation window. Within the same sentence:

- the text line can view `WordTimeline` / `ChunkTimeline` / expected phones;
- the sound line can view audio-informed syllables / prosodic phrases / phone evidence.

The sound line is still organized by real sound because timing, pause, duration and phrase boundaries come from
audio evidence. The label stability rule only prevents unstable CTC identity from becoming the user's default
teaching label.
