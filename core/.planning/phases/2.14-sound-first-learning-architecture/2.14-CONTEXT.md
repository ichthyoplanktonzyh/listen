# Phase 2.14 Context: Sound-First Learning Architecture

更新时间：2026-06-26 CST
状态：COMPLETED

## Why This Phase Exists

Phase 2.13 已经让文字线具备 phoneme ribbon：没有 CTC 时，从文本/词典/规则生成 expected
phonemes 并按 WordTiming 合成跳动；有 CTC 时，原先可以直接显示 raw detected phones。

用户随后确认一个关键产品原则：

> CTC provides audio evidence and timing; expected pronunciation provides teaching labels.

也就是说，学习训练 UI 不能把 CTC phone label 当成默认教材答案。CTC 会误识别，例如应为
/s/ 的声音片段可能被识别成 /k/。用户的目标是听懂语言，而不是学习 CTC 的猜测。因此：

- CTC 负责真实音频 observation、timing、duration、gap、confidence。
- expected pronunciation 负责稳定、可靠的用户可见教学标签。
- raw CTC mismatch 进入诊断/高级 evidence，不直接成为训练答案。

Phase 2.14 的任务因此从“把 CTC phones 画出来”修正为：

```text
expected pronunciation + CTC observation
  -> stable LearningPhone
  -> audio-informed syllable / prosodic phrase organization
  -> PhoneTimeline.sound_analysis
  -> grouped phoneme ribbon
```

## Product Goal

建立第二条学习主线：声音线。

文字线回答：

```text
What was said?
```

声音线回答：

```text
How was it actually organized in the audio?
```

两者差异用于后续诊断：

```text
Why did I understand the text but fail to hear it?
```

## Design Boundary

SoundAnalysis 是 audio-derived and sentence-scoped，不是 text-derived or sentence-owned。

sentence 是共享观察窗口。它让文字线和声音线可以在同一段学习上下文里对照，但声音线的边界和
组织单位不由 written word / text chunk 决定。

当前落地结构：

```text
LLTimeline / PhoneTimeline
  phones[]                raw observed phones
  sound_analysis
    learning_phones[]     stable teaching labels with observed timing evidence
    syllables[]           first real sound organization unit
    prosodic_phrases[]    pause-based phrase grouping
```

## Research Alignment Boundary

Phase 2.14 不是完整 Prosodic Hierarchy 实现。它是面向产品训练闭环的最小可靠子集：

```text
Phone -> LearningPhone -> Syllable -> pause-based ProsodicPhrase
```

暂未实现：

- Foot
- Prosodic Word
- Phonological Phrase
- Intonation Phrase
- F0 / pitch reset
- stress prominence detection
- final lengthening confidence model

这些留给后续声音线增强阶段。
