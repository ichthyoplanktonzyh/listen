# Phase 3.13 Plan: Reading Studio v1

状态：PLANNED

日期：2026-07-11

上游输入：Phase 3.11/3.12、
`.planning/phases/3.0-english-listening-learning-loop/3.11-3.18-FOUR-CHANNEL-SHARED-CONTEXT.md`、
LOOP-010/012/015。

## Objective

把现有 transcript 从播放附属视图升级为独立阅读姿态，并用同一真实片段的只读/只听结果
建立读听差异诊断。首版只消费现有媒体 transcript，不建设通用电子书平台。

## User Value

> “这段我看文字完全懂，但关掉字幕就听不出来——系统能把它归到声音识别，而不是继续
> 给我讲词义；另一段则是听和读都不懂，我知道应该先补内容。”

## Scope

### In

- 媒体伴生阅读姿态：阅读位置独立于播放位置；按段落/场景组织；点击句子播放对应切片；
  查词/phrase、个人释义和来源收藏复用 3.6。
- 阅读辅助：翻译/生词提示可渐隐；无 word timing 仍可纯文本阅读。
- 段落任务 v1：主旨、标题、信息定位、简单推断；固定 SemanticRubric，LLM 缺席时可用
  committed/manual rubric 或用户自评。
- 读听差异：同一 source snapshot 的 reading attempt 与 listening fact 配对，输出
  possibilities，不把相关性写成因果检测。
- reading observation：只为明确 target 与任务结果写证据；片段理解不批量升级全部词。
- 独立阅读历史：位置、attempt、assistance、rubric/judgment/adjudication。

### Out

- EPUB/PDF/网页正文抽取、排版引擎、书架生态。
- 泛读时长排行、streak、每词强制状态操作。
- reading 自动 capability projection（3.17）。
- 用 LLM 自动生成的题目在未经 rubric 校验时写长期能力。

## Dependencies

- 3.11 attempt/rubric/judgment contract。
- 3.12 可选语义 provider；缺席不阻塞基础阅读。LLM 反馈显示资格随 3.12.1 裁决点亮，
  本 phase 不硬依赖 3.12.1（可并行），无资格时以 committed/manual rubric + 自评交付。
- 3.6 corpus/词典/切片核心与 3.5 meaning/sound fit。

## Key Work

1. Transcript → paragraph/scene read model spike；保持 SubtitleSentence identity 与播放映射。
2. ReadingController/Store 与独立阅读位置持久化；工作台入口和返回原播放上下文。
3. 段落任务、rubric 与 adjudication UI；assistance 逐次记录。
4. 读听差异聚合与解释卡：read yes/listen no、read no/listen yes、both no、both yes、unknown。
5. reading target observation writer + 错误通道负向测试；不写 projection。
6. 真实 transcript manual QA：新闻、对话各一段，验证阅读不中断、回听正确、归因诚实。

## Exit Signal

- 用户可不启动播放完成一段 transcript 阅读、查词、理解任务并保存位置。
- 从任意段落回听对应原音后仍能回到原阅读上下文。
- 至少一组真实材料形成可追溯的读听差异结论；缺一侧事实时显示未评估。
- 无 LLM 时手工 rubric/用户自评路径完整可用。

## Guardrails

- 阅读不是字幕自动滚动的改名；必须有独立节奏与任务。
- 阅读完成度、查词次数和停留时间不自动等于 reading acquired。
- 泛读默认低打扰；目标词不强制高亮。
