## v2 切片与执行序（可执行粒度）

  验证分段可读性（阈值可调）。产出分段质量结论后再动 UI。**通过标准**：两类真实

- **Slice 2 — 阅读位置持久化（后端）**：schema v37 `reading_positions`（track 键控

  OpenAPI；Flutter 防抖写入（沿用 3.35 `saveSoon` 模式）、进入阅读姿态时恢复。
- **Slice 3 — semantic Dart DTO + 段落任务 UI（manual rubric + 自评）**：手写

## Objective

把现有 transcript 从播放附属视图升级为独立阅读姿态，并用同一真实片段的只读/只听结果
建立读听差异诊断。首版只消费现有媒体 transcript，不建设通用电子书平台。

## User Value

> "这段我看文字完全懂，但关掉字幕就听不出来——系统能把它归到声音识别，而不是继续
> 给我讲词义；另一段则是听和读都不懂，我知道应该先补内容。"

## Scope

### In

- 媒体伴生阅读姿态：阅读位置独立于播放位置；按段落组织（派生分组，不落库）；点击
  句子经 3.5.7 切片窗播放对应切片；查词/phrase、个人释义和来源收藏复用 3.6。
- 阅读辅助：翻译（secondary track）逐段显示/渐隐；无 word timing 仍可纯文本阅读。
- 段落任务 v1：主旨、标题、信息定位、简单推断；manual `SemanticRubric`
  （`SemanticGeneratorKind::Manual`），用户自评产生 manual judgment；adjudication
  保留为对既有判定的纠正。
- 读听差异：同一 rubric（id, version, source hash）下不同 conditions 的 attempt 配对，
  读端派生聚合输出 possibilities，不把相关性写成因果检测。
- reading observation：只为用户显式标记的明确 target 写证据（capability=Reading）；
  片段理解不批量升级全部词。
- 独立阅读历史：位置 cursor（v37 upsert）+ attempt/judgment/adjudication（v35 既有
  append-only 表族）。

### Out

- EPUB/PDF/网页正文抽取、排版引擎、书架生态。
- 泛读时长排行、streak、每词强制状态操作。
- reading 自动 capability projection（3.17）。
- 用 LLM 自动生成的题目在未经 rubric 校验时写长期能力；LLM judgment 在 3.12.1
  资格裁决前进入任何学习 surface。
- 新协议 adapter、provider 基础设施改动（3.12 已定形）。

## Key Work

1. 段落派生纯函数 + 真实 transcript 分段质量 spike（把门）。
2. ReadingController/Store 与独立阅读位置持久化；工作台入口和返回原播放上下文。
3. semantic Dart DTO（首个真实 consumer）+ 段落任务、manual rubric 与自评/adjudication UI。
4. 读听差异派生聚合与解释卡：read yes/listen no、read no/listen yes、both no、
   both yes、unknown。
5. reading observation writer（显式标记）+ 错误通道负向测试；不写 projection。
6. 真实 transcript manual QA：新闻、对话各一段，验证阅读不中断、回听正确、归因诚实。

## Exit Signal

- 用户可不启动播放完成一段 transcript 阅读、查词、理解任务并保存位置。
- 从任意段落回听对应原音后仍能回到原阅读上下文。
- 至少一组真实材料形成可追溯的读听差异结论；缺一侧事实时显示未评估。
- 无 LLM 时 manual rubric + 用户自评路径完整可用。

## Guardrails

- 阅读不是字幕自动滚动的改名；必须有独立节奏与任务。
- 阅读完成度、查词次数和停留时间不自动等于 reading acquired。
- 泛读默认低打扰；目标词不强制高亮。
- 段落任务结果永不批量写词级 observation；observation 只来自用户显式标记。
- LLM 判定在 3.12.1 资格前不进任何学习 surface（3.12 默认态不动）。
- 派生段落分组不成为新的持久化权威；rubric source 快照是唯一需要长期解释的形状。
