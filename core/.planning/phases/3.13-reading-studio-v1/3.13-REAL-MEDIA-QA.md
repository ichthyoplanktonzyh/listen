## 3. Owner GUI 走查清单（收口前人工门）

按 exit signal 逐项：

- [ ] 不启动播放：打开媒体 → 侧栏"读一下？" → 完整读一段、查词、做段落任务、
      保存自评；关闭后重进阅读，位置恢复到锚定段落。
- [ ] 从任意段落点"听整段/回听这句" → 切片窗播放正确范围 → 关闭切片窗后阅读
      上下文（滚动位置、锚定）不变。
- [ ] 退出阅读姿态回到播放：主播放位置与进入前一致；进入前在播放则自动恢复播放。
- [ ] 读听对照：先做阅读任务，再从对照卡进"只听复述"（确认原文被面板遮住、
      至少听一遍才能提交），完成后重开对照卡看四象限解释；缺一侧时显示"未评估"。
- [ ] 阅读中词点击 → 词汇面板出现"读懂了/读不懂"按钮（仅阅读姿态显示），点击后
      状态条提示已记录。
- [ ] 翻译开关：有副字幕轨时逐段显示/隐藏；听测过程中翻译可见性如实进入标记。
- [ ] 歌词/无标点内容（如 MV 字幕）进阅读姿态不撕裂、不整篇一段。
