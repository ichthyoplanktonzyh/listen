# Phase 3.16 Plan: Personal Expression & Sentence Patterns

状态：PLANNED

日期：2026-07-11

上游输入：Phase 3.4.3、3.13–3.15、
`.planning/phases/3.0-english-listening-learning-loop/3.11-3.18-FOUR-CHANNEL-SHARED-CONTEXT.md`、
LOOP-016。

## Objective

兑现 Phase 3.4.3 的用户价值验证：从任意真实句子提炼个人表达模板，用槽位填充、口头表达
和书面表达把媒体中的语言迁移到用户自己的生活；同时用真实需求裁决是否需要通用
`FocusTarget`，而不是提前泛化 3.7 Hunting List。

## User Value

> “我把 `I ended up ...` 从剧里收藏成自己的模板，换成周末调试项目的经历，先写一遍、
> 再脱稿说一遍；以后在另一段材料里遇到它，还能继续积累和复用。”

## Scope

### In

- `UserSentencePattern` 生产 persistence/API/UI：来源 SentenceExemplar snapshot、pattern text、
  slots、用户说明、可选 opaque system construction ref、版本历史。
- 从 transcript/词典切片/Reading/Speaking/Writing Studio 收藏为模板。
- 槽位任务：看模板填自己的内容、隐藏模板写新句、隐藏模板口头说新句。
- 同一用户句可产生独立 speaking 与 writing attempt；不能互相推断 acquired。
- 使用记录：不同情境、assistance、延迟重用、用户自评与 target observation。
- `FocusTarget` field razor：只有当同一目标确需跨 reading/speaking/writing 调度时才建通用
  资产；否则保留各 Studio 的轻量入口，Hunting List 不迁移。
- 从个人模板进入 3.17 cross-modal review 的 handoff。

### Out

- canonical Construction 自动识别/下载/合并库。
- 用系统 construction link 覆盖用户模板身份或文本。
- 自动扩充模板、自动把所有收藏句转成练习。
- AI 自动生成“用户个人经历”并计为用户产出。

## Dependencies

- 3.4.3 identity/validator 结论。
- 3.14/3.15 speaking/writing attempt 与 target evidence writer。
- 3.6 来源句/切片与 3.13 阅读入口。

## Key Work

1. 用 3.4.3 gold fixture 复核生产 schema；保证用户身份权威与可选 system ref 分离。
2. 模板创建/编辑/删除/版本化与来源快照；媒体删除不级联删用户模板。
3. Slot editor + speaking/writing reuse tasks；明确 assistance 和主动产出条件。
4. 跨语境 occurrence/use history 与延迟重用入口。
5. FocusTarget 决策 spike：列出三类真实 consumer，满足才建；否则写拒绝结论。
6. 真实用户价值 QA：从一个媒体句建立模板，写自己的句子、说出来、数日后再次使用。

## Exit Signal

- 个人模板可脱离原媒体长期存在、编辑、导出和删除。
- 同一模板完成一次 writing 与一次 speaking 新语境使用，两条证据不混写。
- system construction 缺席不影响完整体验；存在时也不能覆盖用户资产。
- FocusTarget 建/不建都有基于真实 consumer 的明确结论。

## Guardrails

- 用户模板不是 canonical 语言学真理。
- 收藏、查看、模型建议不等于产出成功。
- 不因追求统一而重写 3.7 listening Hunting List 的已验证语义。
