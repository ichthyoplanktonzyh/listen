## Phase 3.13.5 基线

- Personal Expression 是**资产层**一级入口（“我的表达”），不是内容工作台的第五通道，
  也不建立独立四通道 rail。
- 用户可从阅读正文、查词上下文、Speaking/Writing 完成态把来源句保存为模板；保存后留在
  当前内容会话。主动练模板从资产层进入阶段自适应任务容器，退出返回“我的表达”。
- 模板任务复用任务生命周期 interface 与 speaking/writing 住户能力，但模板资产身份、槽位、
  版本和使用历史属于 Personal Expression implementation，不进入共享 interface。
- 全局迷你播放条仅表示原内容会话可恢复；模板练习取得音频焦点时暂停主媒体，返回不自动播放。

## Objective

兑现 Phase 3.4.3 的用户价值验证：从任意真实句子提炼个人表达模板，用槽位填充、口头表达
和书面表达把媒体中的语言迁移到用户自己的生活；同时用真实需求裁决是否需要通用
`FocusTarget`，而不是提前泛化 3.7 Hunting List。

## User Value

> “我把 `I ended up ...` 从剧里收藏成自己的模板，换成周末调试项目的经历，先写一遍、
> 再脱稿说一遍；以后在另一段材料里遇到它，还能继续积累和复用。”

## Scope

### In

- `UserSentencePattern` 生产 persistence/API/UI：来源 SentenceExemplar snapshot、pattern text、
  slots、用户说明、可选 opaque system construction ref、版本历史。
- 从 transcript/词典切片/Reading/Speaking/Writing Studio 收藏为模板。
- 槽位任务：看模板填自己的内容、隐藏模板写新句、隐藏模板口头说新句。
- 同一用户句可产生独立 speaking 与 writing attempt；不能互相推断 acquired。
- 使用记录：不同情境、assistance、延迟重用、用户自评与 target observation。
- `FocusTarget` field razor：只有当同一目标确需跨 reading/speaking/writing 调度时才建通用
  资产；否则保留各 Studio 的轻量入口，Hunting List 不迁移。
- 从个人模板进入 3.17 cross-modal review 的 handoff。
- 来源媒体删除后模板仍可依靠不可变 source snapshot 完整存在；只有回听等来源能力诚实降级。

### Out

- canonical Construction 自动识别/下载/合并库。
- 用系统 construction link 覆盖用户模板身份或文本。
- 自动扩充模板、自动把所有收藏句转成练习。
- AI 自动生成“用户个人经历”并计为用户产出。

## Dependencies

- 3.4.3 identity/validator 结论。
- 3.14/3.15 speaking/writing attempt 与 target evidence writer。
- 3.6 来源句/切片与 3.13 阅读入口。

## Key Work

1. **Slice 0 — 计划保鲜与 FocusTarget razor**：吸收 3.14/3.15 closeout；建立 Reference
   Matrix；列出至少三类真实 consumer，达标才引入通用 target 身份，否则记录拒绝。
2. **Slice 1 — 资产身份**：用 3.4.3 gold fixture 复核生产 schema；实现模板创建/编辑/
   删除/版本、来源快照与媒体删除不级联，保持用户身份权威和可选 system ref 分离。
3. **Slice 2 — 两条旅程接缝**：内容场景“保存为我的表达”不离场；资产首页浏览/筛选/
   继续练；deep link 带来源与返回语义，不复制 Studio 首页。
4. **Slice 3 — 场景原生练习住户**：Slot editor、隐藏模板写新句、隐藏模板口头表达；复用
   lifecycle 与对应 speaking/writing 住户，明确 assistance 和主动产出条件。
5. **Slice 4 — 历史与 review handoff**：跨语境 occurrence/use history、延迟重用、用户
   自评、target observation 与 3.17 handoff；通道证据互不推断。
6. **Slice 5 — 真实用户价值 QA 与 closeout**：媒体句→模板→自己的书面句→脱稿说→延迟
   再用；覆盖媒体删除、system construction 缺席、中途退出恢复与无模型路径。

## Exit Signal

- 个人模板可脱离原媒体长期存在、编辑、导出和删除。
- 同一模板完成一次 writing 与一次 speaking 新语境使用，两条证据不混写。
- system construction 缺席不影响完整体验；存在时也不能覆盖用户资产。
- FocusTarget 建/不建都有基于真实 consumer 的明确结论。
- 内容内收藏不会强制跳走；资产练习结束后返回资产入口，原内容会话仍可恢复。

## Guardrails

- 用户模板不是 canonical 语言学真理。
- 收藏、查看、模型建议不等于产出成功。
- 不因追求统一而重写 3.7 listening Hunting List 的已验证语义。
- 共享任务生命周期只协调阶段与恢复，不拥有模板资产或 speaking/writing 产出语义。
