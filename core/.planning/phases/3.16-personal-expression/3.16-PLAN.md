## FocusTarget Razor Decision

**拒绝建立通用 `FocusTarget`。** 实际 consumer 审计如下：

1. Hunting List 的 `HuntingTarget` 是显式 listening 狩猎资产，已有通过 owner QA 的预算、三态
   作答与 completion 语义；
2. `UserSentencePattern` 是用户命名、编辑和版本化的 durable expression asset；
3. speaking/writing 是同一 pattern 的两种使用记录，不是第三、第四种 target identity；reading
   目前只提供来源收藏入口，不调度 target；
4. 3.17 是未来 consumer，不能反向证明今天的泛化。

因此不存在三个共享同一身份、删除生命周期和调度语义的真实 consumer。3.16 使用
`UserSentencePatternId` 作为自身 attempt target；不迁移 Hunting List，不扩展其 modality。

## Objective

让用户从真实内容或自己的产出显式创建个人表达模板，保留不可变来源快照和版本历史，并在
writing/speaking 两个场景原生住户中用自己的内容复用。来源删除、system construction 缺席、
embedding 不可用都不破坏资产或核心练习。

## Exit Signals

- 模板脱离来源媒体长期存在，可编辑、查看版本、导出/删除；source snapshot 不变。
- 同一模板的 writing 与 speaking attempt 独立存在，任何一路都不写另一通道事实或 acquired。
- system construction ref 可空且不能覆盖用户 pattern/version text。
- embedding 只打开显式候选创建流程，零自动收藏/扩写/writer。
- 内容内收藏不离场；资产练习结束返回“我的表达”；Personal Expression 不成为第五 Studio。
- 自动化完成后停在 owner 手工体验 QA 边界。
