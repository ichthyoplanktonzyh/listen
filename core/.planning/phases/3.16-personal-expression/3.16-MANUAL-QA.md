## 边界

以下项目需要 owner 使用真实媒体、麦克风与重启流程体验确认。自动化通过不等于 owner
验收；执行时不要顺带重做 3.15.7/3.15.8/3.15.9 的独立 owner QA，也不要把无关 flaky
修复夹入本阶段。

## A. 内容内显式收藏

- [ ] 打开一份带英文字幕的真实媒体，进入 Reading，在某句工具条点击“保存到我的表达”。
- [ ] 创建表单带入正确的句子文本、媒体标题、时间范围；用户可修改名称、模板文本、slots
  与备注，保存后仍回到原内容上下文。
- [ ] 不点击保存时不会产生资产；embedding/production 候选不会自动收藏或自动扩写模板。
- [ ] system construction ref 缺席时可正常保存；若存在，它只显示为可选参考，不覆盖用户模板。

## B. Durable asset 与版本

- [ ] 从学习资产入口打开“我的表达”，能搜索刚保存的资产并查看来源快照。
- [ ] 编辑名称、模板、slots 或备注后生成新版本；旧版本文本、slots 与来源快照保持不变。
- [ ] 退出并重启应用，资产、全部版本与使用历史仍在。
- [ ] 导出 JSON，确认 schema、资产、版本、来源快照及 attempts 完整且不含伪造 projection。
- [ ] 显式删除资产时给出用户动作；删除后该资产、版本和 attempts 一并消失。

## C. Writing 原生练习

- [ ] 从资产详情开始 writing；分别试用模板可见、slot 提示、关键词与无文本 assistance。
- [ ] 用一段真实个人经历完成回答并选择自评；历史中显示 writing、准确 assistance、自评和文本。
- [ ] 取消或中途退出时不产生 completed attempt。
- [ ] UI 不提供把 AI/LLM 代写文本算作 learner output 的路径。

## D. Speaking 原生练习

- [ ] 从同一资产开始 speaking，进入既有 Speaking 录音/本地 ASR/corrected transcript 住户，
  而不是独立的第五 Studio。
- [ ] 完成一段真实个人表达，确认录音、raw/corrected transcript、自评进入 speaking history。
- [ ] 中断或未完成时不产生 personal-expression completed attempt；录音音频焦点与原 Speaking
  行为一致。
- [ ] Writing 成功不会让 Speaking 显示 acquired；Speaking 成功也不会推断 Writing acquired。

## E. 来源删除与诚实降级

- [ ] 记录来源句并至少完成一次 writing/speaking 后，从媒体库删除来源媒体，再重启应用。
- [ ] 模板、不可变来源文本、版本和两通道历史仍可查看、继续练习与导出。
- [ ] 来源已不可解析时回听按钮禁用或报告明确不可用，不播放当前其他媒体，也不丢失资产。
- [ ] 来源仍存在且 fingerprint 匹配时能回到正确时间范围；fingerprint 不匹配时拒绝误播。

## F. 离线与长时间复用

- [ ] 关闭网络/embedding provider 后，资产 CRUD、writing、local speaking 与 history 核心流程仍可用。
- [ ] 间隔一段时间再次使用同一模板，history 按时间保留多次独立 attempt，且都指向当时的
  immutable version。

## Owner 结论

- [ ] PASS：可将 PLAN/CLOSEOUT 状态改为 COMPLETE / OWNER ACCEPTED。
- [ ] FAIL：记录最短复现、媒体条件、版本、截图/日志；保持本阶段 owner QA pending。
