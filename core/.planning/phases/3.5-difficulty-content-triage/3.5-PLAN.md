# Phase 3.5 Plan: Difficulty & Content Triage

状态:ACTIVE(2026-07-07 立项细化;上一版为 PLANNED 粗粒度计划)

## Objective

实现双维难度(Meaning fit × Sound fit)并把它从"标签"升级为"内容分拣器":
进入的材料被路由到泛听队列 / 精听靶单 / 暂缓区。分拣只建议、不阻塞、可无视。

产品决策:双维难度直接实现,不做前置分化实验;换取条件是**每个分数必须可解释**
(点开可见依据信号),且所有参数按 `heuristic_proxy` 记录。

算法定义、研究依据、信号集与分档规则见 **ADR 0018**(本计划不重复)。

## User Value

> "这段你大概率看得懂,但会卡在弱读和 chunk 边界——适合精听,不适合今天泛听。"

用户不再纠结"今天听什么";"看得懂、听不出"的黄金靶材料被自动挑出来。

## 关键领域映射(3.4.1 之后的新事实)

- Meaning fit 输入 = reading 通道 effective assessment(词义认识与否);
- Sound fit 核心输入 = reading Acquired + listening NotAcquired(看得懂听不出);
- `unassessed ≠ not_acquired`(不变量 1):unassessed 密度单独计量,喂给
  `assessed_token_ratio` 与诚实降级,而不是混进 unknown;
- 词汇批量读取走 `read_lexical_entries_by_forms` + `entry.status`
  (= `legacy_status_view`,已是 effective assessment 的保守折叠视图);
  批量 capability profile 读取接口挂账项仅在折叠视图不够用时才做(裁剪刀)。

## Scope

### In

- 双维难度计算(**媒体级**,`ContentDifficultyProfile` v2 落地,ADR 0018 决策 1-3);
- 可解释性:结构化 `FitSignal` → UI 渲染依据文案与证据等级(初始估计 / 已校准);
- 三队列分拣(派生视图 + 用户 pin/暂缓意图,ADR 0018 决策 6);
- 反馈回流:3.3 理解度自报 + 练习表现 → 个人 sound fit 校准项(evidence_grade 升级);
- 冷启动校准:高频词快速标注流(两分钟级别,可跳过);
- 熟料回听供给:3.2 熟料标记进入泛听队列,推荐克制、可关闭;
- 词汇画像不足时的诚实降级(ADR 0018 决策 4);
- **首个证据投影算法 `listening-projection-v1`** + 移除升级确认投影直写
  (ADR 0017 决策 4 的到期义务,独立 slice + 独立决策记录)。

### Out(Non-goals)

- 句级难度画像(`subject_kind` 留 seam,等具体消费方出现,裁剪刀);
- 订阅源自动抓取/夜间批量精炼调度;
- 局部智能变速;兴趣/主题维度建模;
- 用 fit 阻塞或隐藏任何材料(P3/P5 红线);
- diagnosis 迁移到新证据存储(ADR 0017 遗留的独立后续决策)。

## Exit Signal

- 媒体库每个媒体显示双维 fit、依据可解释、证据等级诚实。
- 至少一个真实媒体被正确识别为"精听靶材料"(meaning 高 / sound 低)并经人工确认合理。
- 从队列一键开始泛听/精听;完全无视分拣时所有功能行为不变。
- **独立可用**:fit 展示对只当播放器用的用户完全无感。
- 升级确认不再直写投影;listening 投影由 `listening-projection-v1` 从证据流产生。

## Guardrails

- 分数是预期管理不是判决;文案避免"你不行/太难了"式表达。
- 所有阈值/权重记 evidence class(`heuristic_proxy`),常量单点定义,改常量必须升
  algorithm_version;预留后续校准。
- 不因 fit 低而隐藏、锁定或劝退任何材料。
- 交互层不泄漏模型精细度(不变量 18):UI 只见档位与依据文案,不见公式与原始密度。
- 每个 slice 独立提交,workspace 测试全绿 + CHANGELOG 同步。
