# 3.5 Slice 8 Closeout: 冷启动快速标注流

状态：COMPLETED
完成时间：2026-07-08 CST
Commit：0739c47c

## Summary

新材料 fit 因词汇画像覆盖不足进入诚实降级态时，提供两分钟级别快速标注流：从当前
track transcript 抽样高频未评估词，用户逐个标注（认识也听得出 / 看得懂听不出 /
不认识 / 跳过），完成后 fit 自动重算。零新写入面、零新 schema 迁移，标注复用现有
lexical entry 路径（ADR 0017 写入收敛纪律）。

## Delivered Changes
