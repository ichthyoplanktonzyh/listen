# Phase 3.0.1 Closeout: Learning Loop Backend Foundation

完成时间：2026-06-28 CST
状态：BACKEND FOUNDATION COMPLETED

## Summary

本阶段将 Phase 3.0.1 的学习行为架构从规划推进到后端代码地基：

```text
PracticeItem
  -> PracticeAttempt
  -> LexicalObservation / ReviewItem / LearningEvent
```

第一版实现刻意收在后端架构层：domain model、application repository/service、SQLite schema、
HTTP API、OpenAPI/generated client 和测试。Flutter practice UI/controller、完整 SRS、语料搜索、
难度推荐、L1-aware 规则和 shadowing 录音仍留给后续 vertical slice。

## Delivered

### Domain

- 新增 learning-loop domain 模型和 ID：
  - `PracticeSession`
  - `PracticeItem`
  - `PracticeAttempt`
  - `PracticeEvaluation`
  - `ReviewItem`
  - `ReviewAttempt`
  - `LearningEvent`
  - `CorpusOccurrence`
  - `PlayableSegment`
  - `ContentDifficultyProfile`
  - `LearnerProfile`
  - `L1L2DifficultyProfile`
  - `RecordingAsset`
  - `ShadowingComparison`

### Application

- 新增 repository traits：
  - `PracticeRepository`
  - `ReviewRepository`
  - `LearningEventRepository`
  - `CorpusIndexRepository`
  - `DifficultyRepository`
  - `LearnerProfileRepository`
  - `RecordingRepository`
- `AppServices` 支持注入 learning-loop repositories。
- 新增 practice service：
  - 创建 practice session。
  - 创建 practice item。
  - 提交 text attempt。
  - 生成 token diff evaluation。
  - 失败 lexical anchor 写入 `LexicalObservation`。
  - 可选创建 `ReviewItem`。
  - 追加 `LearningEvent`。

### Persistence

- SQLite schema 升级到 v15。
- 新增表：
  - `practice_sessions`
  - `practice_items`
  - `practice_attempts`
  - `review_items`
  - `review_attempts`
  - `learning_events`
- 当前持久化策略是 JSON snapshot + 少量查询列。

### API / Contract

- 新增 routes：
  - `POST /v1/practice/sessions`
  - `POST /v1/practice/items`
  - `POST /v1/practice/attempts`
  - `GET /v1/practice/attempts/{id}`
  - `POST /v1/review/items`
  - `GET /v1/review/items/{id}`
- OpenAPI、generated local client 和 contract validation 已同步。

## Guardrails Preserved

- Practice failure 不静默修改全局 `LearningStatus`。
- `ReviewItem` 不替代 `LexicalEntry`。
- `LearningEvent` 是 analytics fact，不替代 practice/review/status 权威记录。
- Anki 仍只是未来 adapter，不进入内部权威模型。
- Raw CTC label 没有进入教学标签路径。
