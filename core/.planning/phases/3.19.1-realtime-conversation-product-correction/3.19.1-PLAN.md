## Exit Signals

- 自由对话和显式话题锚定都有稳定、无需猜测的入口；
- 三轮以上对话按顺序保存所有 learner/assistant turns，早期轮次不丢失；
- 每个 learner turn 的 provider caption、local audio、local transcript 与状态可追踪；
- local ASR 单轮失败不抹掉同 session 其它成功 learner turns；
- personal Production Corpus 只包含 finalized local learner turns，Gap Review 自然读到多轮数据；
- barge-in、finish、cancel、断流和页面退出都释放 microphone/player/socket，且终态诚实；
- Qwen international 与 China workspace 配置均有自动回归和 owner 实测路径；
- Phase 3.19 Q9 replacement journey owner ACCEPT，P1 清零或有 defect-specific written exception。

## Non-goals

- rubric、self-assessment、自动 capability/proposal/review writer；
- agent tools、multi-agent handoff、角色扮演模板；
- 引入 LiveKit/Pipecat/OpenAI Agents SDK 作为 runtime；
- 将 assistant output 计入 learner Production Corpus；
- 在没有测量前宣称某种 turn boundary 算法已合格。
