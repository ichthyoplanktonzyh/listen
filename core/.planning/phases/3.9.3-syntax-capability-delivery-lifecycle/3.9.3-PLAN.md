# Phase 3.9.3 Plan: Syntax Capability Delivery & Lifecycle

状态：IN PROGRESS（v1，2026-07-13）

起点：Phase 3.9.2 frozen commit `71be2c20`

## Objective

把已资格化 spaCy shared syntax Provider 从开发者环境变量接线补成普通用户可选择、可恢复、
可观察的 App capability，并建立长驻 sidecar、整轨可重建 cache、自动后台分析和 Flutter 完整路径，
同时证明未安装路径零行为回归。

## Slice 0 — Contract and lifecycle skeleton

- 建立持久化 capability manifest/state：`not_installed/downloading/ready/partial/failed/stale/disabled`。
- 定义安装、取消、重试、更新、停用、卸载、校验 API 和任务进度/错误契约。
- 安装目录、runtime/model version/checksum 与资格矩阵均来自受版本控制的产品 manifest。
- 未安装默认不启动 Python，不弹窗，不影响字幕/播放/基础学习。

## Slice 1 — Managed installation and resident provider

- backend resource manager 执行 fully pinned opt-in 安装，临时目录完成后原子发布；取消/失败清理 staging。
- 校验 Python、sidecar、model metadata 和稳定 checksum；损坏映射为 partial/failed，不伪装 ready。
- Python JSONL sidecar 改为受控长驻：probe/analyze 复用同一进程，空闲释放，崩溃后单次重启。
- disable 先停止 sidecar 再保留资源；uninstall 仅删除 capability 目录和可重建 syntax cache。

## Slice 2 — Track batch cache and stale/rebuild

- 以 track 内容/token/language + provider descriptor + profile 建 fingerprint。
- 一次整轨 batch，逐句 finalise/隔离；同 fingerprint 复用，force rebuild 明确重算。
- model/capability identity 或字幕变化后旧 cache 标 stale；partial 记录成功/失败句数和 fallback reason。
- 安装完成自动分析当前轨道；打开 ready capability 下的未分析轨道后台启动；相同 fingerprint 不重复。

## Slice 3 — Flutter user path

- 设置页展示状态、磁盘/版本、进度、校验与 install/cancel/retry/update/disable/uninstall actions。
- 非打扰式当前轨道增强状态入口：未安装不显示打扰提示；后台分析不阻塞字幕与播放。
- 手写 DTO + fixture/transport/controller/widget tests，遵守 ADR 0014。

## Slice 4 — QA and closeout

- 自动化：状态迁移、取消/重试、checksum、sidecar hot reuse/idle/crash、cache hit/stale/partial、HTTP/OpenAPI、Flutter。
- 真实资源：安装、首次冷分析、后续热分析、模型移除/损坏、partial fallback、真实媒体与 UI 响应性。
- Rust workspace、contracts、Flutter analyze/test、release build；记录未执行或需要 owner 交互的项。
- 更新 ARCHITECTURE/STACK/DATA-MODEL/TESTING、STATE、CHANGELOG，撰写 QUALIFICATION/CLOSEOUT 后冻结。

## Exit Signals

- 普通用户无需环境变量即可完成安装到分析的闭环；base bundle 不含 runtime/model。
- 未安装路径无 Python、无弹窗、无阻塞、基础输出精确 fallback。
- 同进程 probe/analyze 和后续 track 分析避免重复冷启动；idle/crash 行为可测。
- 同 track fingerprint cache hit，字幕/模型变化 stale 并可 rebuild；坏句不污染整轨。
- UI 覆盖全部 lifecycle actions 和 partial/failed/stale 状态，播放响应性不依赖分析完成。
- 3.9.2 的 capability qualification 与所有 authority guardrail 保持不变。
