## 产品裁决

- capability 是可选的 App resource，不进入基础 bundle，也不成为字幕、播放或基础学习硬依赖。
- 普通用户只通过 App 设置页安装、校验、取消、重试、更新、停用和卸载；环境变量不再是最终路径。
- 安装状态与轨道分析状态分离。安装状态持久化；分析 artifact/cache 可重建。
- sidecar 在首次实际分析时启动并复用，空闲释放；崩溃或协议断裂只允许受控重启一次，随后闭合失败。
- 整轨一次 batch，逐句验证隔离。B、SenseGroup、matcher 读取同一句同一 artifact。
- cache identity 必须包含字幕内容、token snapshot、语言、provider/runtime/model/config fingerprint。
- 安装或模型 identity 变化使旧轨道结果 stale；卸载/损坏不删除基础字幕资源，只让增强能力降级。
- B 只让 `going_to`、`habitual_used_to`、`have_to` 使用 syntax gate；`want_to` 继续 fallback-only。
- syntax 不填充 C、不替代 ChunkTimeline、不创建 Construction canonical/occurrence/capability identity。

## 分发边界

完整 notarized installer/CDN 签名若要求独立发布基础设施，可拆为后续 packaging phase；本阶段仍须
交付可验证的 App 内用户闭环：后端拥有版本化 asset manifest 和安装目录，Flutter 发起并观察
安装任务，安装后可直接分析当前轨道，不要求用户设置环境变量。
