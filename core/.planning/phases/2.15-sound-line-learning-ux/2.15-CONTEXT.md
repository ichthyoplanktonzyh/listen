# Phase 2.15 Context: Sound Line Learning UX

状态：PLANNED

## Why This Phase Exists

Phase 2.14 已完成声音线的架构分离：

```text
文字线 phoneme ribbon
  -> expected phone labels
  -> optional observed timing

声音线 sound pattern ribbon
  -> SoundAnalysis.learning_phones
  -> syllables
  -> pause-based prosodic phrases
  -> evidence markers
```

但这还只是能力闭环，不等于用户学习闭环。用户需要明确知道：

- 第一条线是在看“文字/教学标签”。
- 第二条线是在看“真实声音如何组织”。
- evidence marker 是听力训练辅助，不是要求用户学习模型诊断术语。

## Product Goal

把第二条声音线做成用户能理解、能开启、能训练、能信任的学习界面。

本阶段回答：

```text
When I open the sound line, what am I supposed to learn from it?
```

## Boundaries

本阶段做：

- 真实媒体样本 QA。
- 声音线独立 UI 语义。
- 无 `sound_analysis` 时的产品状态。
- evidence marker 的学习化表达。
- 确认 raw CTC label 不会作为教学标签泄漏。

本阶段不做：

- 新增完整真实语流现象模型。
- F0 / pitch reset。
- Foot / Prosodic Word / Phonological Phrase / Intonation Phrase。
- 多语言声音线 profile。

这些进入 Phase 2.16 或后续研究增强。

## Success Criteria

- 用户能在设置中分别开启文字线和声音线。
- 两条线同时存在时视觉上不会混淆。
- 声音线只在有真实 `sound_analysis` 时显示，不做词典 fallback。
- 常见 evidence marker 有面向学习者的表达，不暴露过多内部诊断术语。
- 真实媒体 QA 能确认稳定教学标签原则仍成立。
