# Phase 3.11 Plan: Semantic Task & Evidence Foundation

状态：PLANNED

日期：2026-07-11

上游输入：`.planning/phases/3.0-english-listening-learning-loop/3.11-3.18-FOUR-CHANNEL-SHARED-CONTEXT.md`、
`.planning/discuss/four-channel-product-and-vendor-neutral-llm-final.zh.md`、ADR 0015/0017/0019。

## Objective

在接任何外部 LLM 或 Studio UI 前，固定四通道主动任务的事实层：片段级 attempt、版本化
`SemanticRubric`、逐点 `SemanticJudgment`、用户 adjudication，以及它们与 lexical /
construction observation、projection、override 的边界。

## User Value

本 phase 不以独立 UI 为价值；它保证后续用户看到的“覆盖了哪些信息”“为什么被判为遗漏”
与能力变化可追溯、可纠正，不因换模型或换 provider 改写历史。

## Scope

### In

- 定稿四通道 evidence matrix：task、channel、target kind、assistance、outcome、强度与是否
  允许进入 projection candidate。
- 新增 clip/sentence/construction 级 attempt seam，避免非 lexical 事实强塞
  `LearningObservation`。
- `SemanticRubric`：来源快照、required/optional information points、language pair、
  version、generator provenance、人工修订历史。
- `SemanticJudgment`：逐点结果、精确 transcript span、uncertain/abstain、ASR 质量、
  prompt/model/schema provenance。
- `JudgmentAdjudication`：用户对一次自动断言的确认/纠正；不复用 capability override。
- append-only persistence、repository/use case、最小 API 与 portable/export 边界裁决。
- 新 ADR：semantic attempt/judgment/observation/capability separation。

### Out

- 真实 LLM 网络调用、API key 设置、厂商 adapter（3.12）。
- Reading/Speaking/Writing UI（3.13–3.15）。
- reading/speaking/writing 自动 capability projection（3.17）。
- 将 `PracticeKind` 立刻改成无限开放 string；是否扩 enum 或新建任务族由本 phase 的
  typed contract spike 决定。

## Dependencies

- 3.10 channel-ready Coach envelope 已完成。
- ADR 0015/0017/0019 与现有 PracticeAttempt/LearningObservation 数据不破坏迁移。

## Key Work

1. 用真实例子列出至少 reading comprehension、L1/L2 retelling、role reply、dictogloss、
   summary、sentence-pattern production 的 evidence matrix。
2. Domain contract + validator：rubric point identity 稳定、span 必须落在 transcript、
   judgment 必须引用相同 rubric/source snapshot。
3. SQLite additive schema + repository/use cases；明确媒体删除后的 snapshot 存续。
4. API/OpenAPI/Dart fixture contract；只提供后续 Studio 所需的最小写读面。
5. ADR 与负向测试：L1 复述不批量写 lexical evidence、adjudication 不改 override、
   shadowing completion 不生成 constructed speaking success。

## Exit Signal

- 同一 rubric 上两个回答可以被保存、比较、人工纠正且全链路可追溯。
- 删除原媒体后，rubric/attempt/judgment 快照仍可解释历史。
- 没有任何网络或模型时 contract 测试完整成立。
- 对每类任务明确“写 clip fact / target observation / neither”，无默认批量升级。

## Guardrails

- 新抽象必须由 3.13–3.15 的具体任务消费；不建通用 LMS 或通用 AI conversation schema。
- 原始自动判断永不被 adjudication 覆盖删除。
- 未评估与失败分离；uncertain/abstain 是一等结果。
