## Module 1: Media Import And Playback

- Open local media file.
- Open online media URL.
- Drag/drop media and subtitle files.
- Download online media through yt-dlp.
- Playback controls: play/pause, stop, seek, previous/next sentence, speed, volume.
- Audio track selection.
- Playback error and unsupported-media feedback.
- Media archive and missing-media recovery states.

## Module 2: Subtitle Acquisition And Track Management

- Import SRT/VTT as primary or secondary subtitle.
- Generate subtitles with local Whisper.
- Open Transcription Center and manage transcription jobs.
- Search/download OpenSubtitles.
- Extract embedded text subtitles with ffmpeg/ffprobe.
- Select embedded subtitle tracks when available.
- Load generated subtitle track after transcription completion.
- Primary/secondary visibility, offset, no-secondary-track state.

## Module 3: Subtitle Resource And Timeline Resource Lifecycle

- View subtitle resources for current media.
- Activate a subtitle resource.
- Archive, restore and delete subtitle resources.
- Export subtitle resource as SRT or `.lltimeline.json`.
- Import / attach LLTimeline resource.
- View WordTimeline / ChunkTimeline / PhoneTimeline summaries.
- Activate/archive/delete timeline candidates.
- Manual WordTimeline review and user-adjusted timeline activation.
- Production artifact and readiness visibility.

## Module 4: Subtitle Display And Transcript Interaction

- Dual subtitle overlay.
- Subtitle presets, fonts, colors, background opacity and position.
- Subtitle visibility and status-style visibility toggles.
- Primary/secondary subtitle offsets.
- Transcript side panel, current sentence tracking and auto-scroll.
- TokenLine word interaction.
- Word status styling in overlay and transcript.
- Keyboard shortcuts for playback and quick status marking.

## Module 5: Word Sync And Chunk Replay

- Word-level highlight from active WordTimeline or legacy word timings.
- Current-word tracking during playback, seek and speed changes.
- Chunk grouping display in TokenLine.
- Current chunk highlight.
- Previous/next chunk navigation.
- Loop chunk and source loop stop.
- Expand chunk / chunk playback affordances.
- ChunkTimeline diagnostics and degraded states.

## Module 6: Listening Structure And Phone Evidence

- Listening structure layer from document-level `rhythm_frames`.
- Expected pronunciation reference.
- Stress anchors, nuclei, weak groups, compression spans, phrase boundaries and listening hotspots.
- Rhythm cue loop / evidence replay.
- Phone evidence mode from PhoneTimeline / sound analysis.
- Phoneme ribbon on the text line.
- Phone evidence / audio analysis center.
- Analyze current sentence or whole subtitle track.
- Feedback on audio findings.
- Missing evidence states: no WordTimeline, no `rhythm_frames`, no phone evidence, no energy evidence.

## Module 7: Vocabulary And Learning Assets

- Word learning panel from subtitle token click.
- Lexical entry details: definitions, pronunciation, user note, custom definition.
- LearningStatus changes and immediate UI refresh.
- Vocabulary screen with search/filter/status views.
- Vocabulary import/export.
- External word-list import.
- Phrase candidates and phrase status.
- Learning assets screen.
- Learning resources screen.
- Correct lemma / lexical identity correction.
- Source sentence replay and missing-source states.

## Module 8: Diagnosis And Practice Readiness

## Step 0 Audit Snapshot — 2026-07-01 13:22 CST

Verified against current `main` Flutter code, not the older UI worktree.

### Current Entrypoints

- Media open/playback:
  `apps/desktop/lib/main.dart` exposes local file open, URL resolve/play,
  yt-dlp download, drag/drop, playback controls, audio-track selection, embedded
  native subtitle selection, no-media center CTA, and core-starting/error/retry.
- Subtitle acquisition:
  AppBar primary/secondary subtitle menus cover SRT/VTT import, local Whisper
  generation, and OpenSubtitles search; More menu covers embedded text subtitle
  extraction and Transcription Center.
- Resource lifecycle:
  side panel Resources tab and full Subtitle Resources screen expose subtitle
  resource activation/archive/restore/delete/export plus `.lltimeline.json`
  import/export and timeline candidate actions.
- Learning overlay:
  `TokenLine` handles word click, phrase candidates, current word highlight,
  chunk grouping/highlight, chunk seek, and word status styling.
- Listening/phone layers:
  current overlay already prioritizes document-level `LLTimelineDocument.rhythmFrames`
  for Listening structure and falls back to `soundAnalysis.rhythmFrame`; Phone
  evidence still depends on active PhoneTimeline / sound analysis.
- Vocabulary/diagnosis:
  subtitle word click opens Word learning; Vocabulary screen and import/export
  exist; DiagnosisCard shows lexical/pronunciation/rhythm/phone evidence with
  analyze-current/whole-track actions.
- System/task feedback:
  backend SSE drives transcription/audio-analysis status strings; download bar
  is still driven by split `activeDownload` plus `downloadedMediaPath`; global
  status remains a free string.

### P0 Findings

- Resource panels showed raw `WordTimeline` / `ChunkTimeline` / `PhoneTimeline`
  availability but did not answer the user question: "which learning abilities
  are available now?"
- Listening structure and Phone evidence were partly correct in data flow, but
  UI labels still used stale `sound pattern` / `Listening rhythm` language and
  tooltips still implied `sound_analysis` was required for the whole layer.
- Plain SRT/VTT and missing-resource paths lacked a typed degraded/unavailable
  explanation for Word sync, Chunk replay, Listening structure, and Phone
  evidence.
- Local Whisper default path can load the generated track and refresh speech
  enhancements, but completion feedback still does not summarize generated
  subtitle + Word sync + Listening structure readiness.
- Side panel visibility is still tied to `subtitleController.visible ||
  selectedLexicalDetails != null || sidePanel == 1`, so Resources is independent
  but Transcript remains surprisingly coupled to subtitle visibility.
- Download completion/dismissal remains a P0 status debt: `activeDownload` and
  `downloadedMediaPath` can disagree, and the bar has no typed success/error
  lifecycle.

### First P0 Slice Completed

  replay, Listening structure, and Phone evidence.

- Readiness distinguishes active subtitles, audio-backed word sync, estimated
  word timing, document-level listening structure, predicted-only listening

  setting keys and advanced resource names remain stable.
