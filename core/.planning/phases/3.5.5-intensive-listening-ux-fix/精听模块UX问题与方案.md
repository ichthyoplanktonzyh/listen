## 解决方案：浮动练习小窗

### 总体设计

将精听练习从右侧面板中独立出来，改为**可拖动的浮动小窗**，配合**迷你播放器**，形成独立的练习环境。

### 入口统一

- 右侧面板顶部姿态栏保持三个按钮：**听懂了吗？/ 测一下 / 跟一下**
- 去掉右侧面板底部的"测一下"（Practice Tab）
- "测一下"为下拉菜单，包含三种练习类型：
  - 挖空（cloze）
  - 语块听写（chunk dictation）
  - 句子听写（sentence dictation）
- 选择练习类型后，浮动小窗弹出

### 浮动小窗布局

```
┌──────────────────────────────────────────────┐
│  练习面板 (可拖动)                     [×]    │
├──────────────────────┬───────────────────────┤
│                      │                       │
│  ____ 挖空文本展示   │  迷你播放画面         │
│                      │  [返回标签页]          │
│  [输入框]            │  ◀  ⏸  ▶             │
│  [提交]              │                       │
│                      │                       │
│  练习结果: ✓/✗       │                       │
│  词级差异对比         │                       │
│                      │                       │
│  [加入复习队列]       │                       │
├──────────────────────┴───────────────────────┤
│  第 3 / 15 句                                 │
└──────────────────────────────────────────────┘
```

### 组件说明

| 区域 | 内容 | 说明 |
|------|------|------|
| **标题栏** | "练习面板" + × 关闭按钮 | 可拖动区域，× 关闭小窗 |
| **左侧 - 练习区** | 挖空/听写题目、输入框、提交按钮、结果展示 | 每次展示当前句的练习题 |
| **左侧 - 结果区** | 正确/错误标识、词级 diff、加入复习队列按钮 | 提交后即时展示 |
| **右侧 - 迷你播放器** | 迷你视频画面 + 控制按钮 | 同步主播放器的当前画面 |
| **迷你播放器 - 控制** | ◀ ⏸ ▶ 三个按钮 + "返回标签页"按钮 | 按钮浮在画面上方 |
| **底部** | 第 N / 总句数 进度 | 显示整体进度 |

### 交互行为

| 操作 | 行为 |
|------|------|
| 点击"测一下"→ 选择练习类型 | 浮动小窗弹出，对当前句展示对应练习 |
| 用户输入答案 → 提交 | 即时显示结果（正确/partial/错误 + 词级差异） |
| ◀ / ▶ 或键盘快捷键（左右方向键） | 切换到上/下一句，小窗自动更新为新句同样类型的练习 |
| ⏸（或空格键） | 播放/暂停当前句 |
| "返回标签页" | 迷你播放器消失，仅保留练习面板（左侧区域） |
| 点击"加入复习队列" | 当前练习的词条加入复习队列，Toast 反馈 |
| × | 关闭浮动窗，清除播放器循环状态，无后端 session 逻辑 |

### 被移除的功能

| 原功能 | 移除原因 | 替代方案 |
|--------|---------|---------|
| 卡点标记（Mark Stuck Point） | 过度设计，用户不感知 | - |
| 跳过（Skip） | 语义混淆，无反馈 | ◀▶ 切换句子天然替代 |
| 悬案区（Open Issues） | 语义不明，增加认知负担 | - |
| Session Summary | 每句结果即时可见，无需汇总 | - |
| 精听完毕（Finish Intensive） | session 概念对用户无意义 | × 直接关闭 |

### 后端影响

- PracticeSession/PracticeItem/PracticeAttempt 数据模型**保持不变**（后端仍需记录练习数据用于复习队列和分析）
- **移除**：卡点相关 API（mark/skip/close stuck point、diagnosis viewed）
- **移除**：session 结束相关逻辑（completePracticeSession）
- **保留**："加入复习队列"调用现有的 createReviewItem API

### 后续扩展

- 跟一下（Shadowing）行为模式与测一致，入口保留禁用态，待实现后复用同一浮动小窗框架
