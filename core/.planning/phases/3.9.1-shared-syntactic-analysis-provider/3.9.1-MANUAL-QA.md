## B and SenseGroup Consumption

- B：锁定 fixture 和真实媒体 observation 验证 future/motion、habitual/state、have-to idiom
  neutral query；但 Stanza/spaCy 都未通过整套资格 gate，所以实际产品不会激活 syntax_model
  路径，仍使用现有 conservative text heuristic。
- SenseGroup：集成测试直接读取真实 Stanza development report token，调用生产
  `partition_sentence_with_syntax`，确认 3–5 教学组目标/hard max 约束以及 `New York City`
  多词短语完整性。产品默认仍为 `punctuation_length_rule_v1`，因为没有 qualified provider。
- 同一 `SyntacticAnalysis` 契约可同时传入 B context、SenseGroup 和 dependency matcher；后两者
  不会复制或改写句法 artifact。

## Install, Refresh, and Degradation Paths

1. 研究安装脚本建立独立 venv，runtime、model、treebank/license provenance 分层记录；模型需
   显式 opt-in 下载。
2. sidecar probe 只在 runtime、language、model 和 descriptor 完整时声明 available；missing、
   corrupt、unsupported、timeout、malformed protocol、invalid tree/output 都是 closed failure。
3. 刷新使用 source/provider/runtime/model/checksum/profile 隔离 fingerprint；模型变化触发新
   artifact，不原地冒充旧结果。
4. 当前没有任何 qualified provider，因此没有新增产品模型安装或激活 UI。模型缺席、研究环境
   删除或 sidecar 失败时，字幕导入/播放不依赖此能力，B 与 SenseGroup 精确保留现有 fallback。

## Boundary Audit

- 句法结果只产生 B `PossibleByRule` 预测候选，绝不填充 C 或音频证据。
- SenseGroup 仍是独立 lifecycle；ChunkTimeline 数据、边界与播放语义未改动。
- dependency matcher 只返回 rebuildable candidate；没有 `ConstructionId`、canonical key、
  occurrence identity、capability projection 或持久化 API。
- 两个候选的 validation qualification 都是 `not_qualified`。本 QA 证明 integration seam、失败
  闭合和真实字幕鲁棒性，不声称已有可分发的产品 parser 能力。
