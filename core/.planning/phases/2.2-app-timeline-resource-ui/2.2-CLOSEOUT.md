# Phase 2.2 Closeout: App Timeline Resource UI Alignment

更新时间：2026-06-19 CST

## Status

Phase 2.2 已完成。LLPlayerNext app 现在可以作为 `.lltimeline.json` 资源消费端：

- 导入 LLTimeline JSON v1 资源。
- 展示当前资源状态、active WordTimeline、候选 WordTimeline、生产 artifacts 和
  production-report readiness。
- 激活候选 WordTimeline，并刷新播放器词级高亮读取路径。
- 在没有 LLTimeline resource 时继续使用旧 word timing 降级路径。
- 提供人工复核/校正入口占位，Phase 2.3 可直接进入编辑器设计。

## Shipped

- Backend persistence:
  - 新增 SQLite migration `0011_lltimeline_resources.sql`。
  - `SubtitleRepository` 新增 LLTimeline resource metadata/artifacts 保存与读取。
  - import 保存原始 production metadata/artifacts。
  - export 回填持久化 metadata/artifacts，同时同步当前 media/track 信息。
- App client/state:
  - Flutter `LocalApi` 支持 LLTimeline import/export、WordTimeline summary、activate。
  - `SubtitleController` 持有 timeline resource 快照。
  - 新增 Flutter timeline resource model。
- UI:
  - Transcript 面板顶部新增 Timeline Resource Summary。
  - 展示 resource/fallback、generator、human reviewed、production readiness、
    active timeline、candidate list 和 artifacts。
  - 支持 candidate 激活。
  - 支持人工复核入口占位。
- Playback binding:
  - 保持 `trackWordTimings()` 为唯一高亮读取入口。
  - 后端 `word_timings_for_track` 优先返回 active WordTimeline，缺失时回落 legacy
    timings。
  - 激活 candidate 后 app 重新加载 speech enhancements，刷新当前词高亮缓存。
