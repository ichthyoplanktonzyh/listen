## Follow-up Correction: Resource Attachment Semantics

2026-06-20 发现并修正 Phase 2.2 初版的资源语义缺口：`.lltimeline.json` 作为交换
资源不应硬绑定生产端本机的 media_id / track_id / path。现在导入到 app 时会：

- 优先按当前媒体 fingerprint 自动挂载。
- fingerprint 不匹配时提示用户确认，并允许用户强制挂载。
- 挂载时重映射本机 track / sentence / WordTimeline id，避免同一数据库内资源冲突。
- 保留原始 media id / fingerprint / path / title 作为 provenance，并标记用户确认的
  mismatch attachment。
