三处血肉 THE THREE FIXES

R1 · 音频自带第二解码器(技术已验证)CLIP PLAYS ITSELF

现状 _canPlay 要求 主播放器恰好载着同一媒体(currentMediaId == source.mediaId)——不载媒体直接进复习, 整队卡显示「clip unavailable」。但复习卡的 source.mediaId + anchor 的 startMs/endMs 已经齐全,词汇本早已示范正解。

现状修正(与词汇本 _playCorpus 同路径)
onPlayRange(start,end) → 操控主播放器,仅当同媒体可用 页内第二解码器:readMedia(source.mediaId) → OccurrenceMediaResolver 解析到本地 path → SlicePlayerController.open(path, {startMs,endMs}) 循环切片。 复习卡自带音频,与主播放器状态彻底解耦——不载任何媒体也能复习。
源不可用=按钮死灰,无解释 媒体文件找不到时走 resolver 的诚实失败(showError + 一句原因), 可触发重新定位(词汇本已有动线)——不再是沉默的死按钮(P4)。

呈现≠语义护栏:此改动只换「音频从哪来」,不碰卡片生成/调度/评分; 新增测试断言「不载主媒体时切片仍可用」+「回放不触碰主播放器状态」。

R2 · 卡面接图形语言 THE CARD SPEAKS THE PORTRAIT'S LANGUAGE

训练通道标签(呈现层已有信息,零新数据):card.kind 本就隐含训练的 通道——word_recognition/chunk_cloze/phrase_presence=听,delayed_retelling/ source_sentence_recall=说。卡头的库存 Material 图标换成 通道色点+人话(「● 听 · 认词」),用 #47 的声/文语言,不再是随机图标堆。
词条三态环(需一次轻量取数,列为决策点):卡若挂在某词条上 (source.lexicalEntryId 在场),卡头可放一枚 16px 词条环显示该词四通道处境 ——「你正在复习的这个词,整体学得怎样」。代价=每卡一次 capability 取数 (或队列预取)。不做则卡面只有通道色点(仍比现状强),取数与否 owner 拍板。

R3 · delayed_retelling 卡面塌陷 FILL THE HOLLOW CARD

该卡型 prompt 区现状是 SizedBox.shrink() ——卡面只剩两个按钮悬空。修正:延迟复述本就是「听完 → 隔一会儿 → 复述」, prompt 区应有一句任务说明 + 源句遮罩提示(揭示前显示「凭记忆复述刚才那句」, 揭示后才亮出源句),与其他卡型的「揭示」动线统一,不再是空洞卡。
