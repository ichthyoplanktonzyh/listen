我的表达:把脚手架变成看得见的梯子

审计判词最轻,但埋着这五页里教学法价值最高的概念:支架渐撤 (看完整模板 → 只看槽位 → 只看关键词 → 隐藏模板)。它现在是弹窗底部一个 默认永远停在最高辅助档的下拉框,系统从不提降档,梯度沦为元数据标注(E2)。 加上用户自己的语言被当 subtitle 三行截断(E3)、删除无确认(E1)、导出零反馈(E5)。 本稿主张:梯子要看得见,而且撤掉一阶,光就多归你一分。

呈现≠语义:四档 assistance / 三档自评的后端取值不动 写作记录仍走 recordPersonalExpressionAttempt(channel=writing) 版本历史/来源链路不动 建议≠判定:降档是轻提示,用户自己决定(P3) i18n 归 #21(本页现全硬编码中文)

共享语义 SHARED SEMANTICS

梯子的光语义 THE LADDER — 与对话页 B 同宗

对话页拍板的 B 回声水面里,月白=别人给的光、信号青=你自己的回声。 写作的支架完全同构:模板是别人的语言(月白),你写的是自己的语言(青)。 撤掉一阶脚手架,月白就少一分、你的青就多一分——梯子不是设置项,是一条光的迁移。

看完整模板 模板 + 槽位全给
只看槽位 只规划内容,不给结构你在这
只看关键词 只剩词,句子归你
不看模板 全是你的语言

四阶=后端既有四取值(`template_visible` / `slot_hints` / `keywords` / `no_text`), 不新增语义,只是把下拉框换成一条能看见自己位置的梯子。

要点
E2梯子取代下拉框
四阶可见、当前档高亮、用过几次/还没试过如实标注。 换档即时改变模板区的在场程度——所见即所选。
P3建议 ≠ 判定
当上一次在某档得到「表达自然」时,下一阶显示一行轻提示 「要不要试试更少的帮助?」——只提一次、可忽略、不催; 绝不自动降档,也不把它做成任务。
P2你的句子发光
写作区文本用信号青(你的语言=光);模板区用月白且随档位递减—— 页面本身演示「撤脚手架」这件事。
诚实历史即证据
历史行=梯子微条+人话+自评,可看出「我是不是真的在往下走」; 不做进度条、不算分(P3/P4)。
窄窗
梯子横置为四段控件,其余不变。
自我证伪:①梯子把「四个下拉选项」升级成页面主结构,若用户其实只想快速记一句, 成本变高——缓解:保存按钮始终可达,梯子不挡路(不强制交互); ②「用过 N 次/还没试过」需要读既有 attempts 聚合,若历史为空则梯子只显示当前档, 不编造。

方向 B · 弹窗转页 DIALOG → PAGE — 保守案

只做最小修:弹窗改成页面、两个 Dropdown 改成分段控件、加删除确认与导出反馈、 列表卡把模板文本升为主角。不做梯子的光语义、不做降档提示。
