# MVP P0 Exceptions

The macOS Apple Silicon personal MVP closes the roadmap P0 requirements with
these written scope clarifications:

- `WORD-006` uses deterministic lowercase normalization as its safe fallback.
  Manual correction of an incorrect lemma merge remains `WORD-010` in FUTURE,
  matching the roadmap.
- Real-material acceptance used license-clear generated video, audio, overlap,
  multi-track, and 2,100-cue fixtures. A user's own CNN/NBC-style long video
  should be used for the first personal daily-training session because no
  copyrighted news material is committed or redistributed.
- The artifact is ad-hoc signed but not Apple-notarized. Notarization and App
  Sandbox hardening are required before public distribution, not for the
  personal MVP.
- Windows and Linux are intentionally MVP-postponed and do not block M0-M6.
