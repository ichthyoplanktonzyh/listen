# Milestone 1.6: Desktop Learning Experience

Milestone 1.6 improves daily desktop learning without changing the three
status-driven vocabulary books. It adds responsive subtitle presets,
Chinese/English UI switching, TXT/CSV vocabulary initialization, durable user
definitions and notes, a unified learning panel, and a provider-agnostic
dictionary aggregation boundary.

The database advances to schema v5 and vocabulary assets advance to version 2.
Version 1 vocabulary assets and schema v4 databases remain supported.

Deferred: additional dictionary providers, mobile, Windows/Linux,
OpenSubtitles, bitmap subtitles, OCR, and Anki integration.
