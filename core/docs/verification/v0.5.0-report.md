# Version 0.5.0 Verification Report

Release: 0.5.0  
Milestone: 1.7 local ASR learning subtitles  
Platform: macOS Apple Silicon

## Automated Verification

- Rust formatting, workspace tests, and clippy with warnings denied.
- Flutter analyze and tests.
- OpenAPI, generated-client experiment, player, and event contract checks.
- M1, M1.5, M1.6, MVP, and M1.7 verification scripts.
- Deterministic fake `ffmpeg` and `whisper-cli` end-to-end run verifies durable
  job execution, generated interactive subtitle persistence, provenance, and
  SRT export.
- Pinned arm64 whisper.cpp and LGPL-only FFmpeg runtime validation, including
  rejection of non-system dynamic library dependencies.
- Signed macOS application package smoke test.
- A real pinned `base.en` model transcribed a locally generated English audio
  fixture through the bundled arm64 FFmpeg and whisper.cpp executables. The job
  completed with detected language `en`, persisted a track, and exported SRT.

## Acceptance

- Model Manager supports explicit downloads, cancellation, removal, checksum
  verification, and custom model registration.
- Whole-media primary or secondary subtitle jobs remain inspectable across
  service restarts and never publish partial tracks.
- Completed generated tracks survive restart, support the existing learning
  loop, and export to equivalent SRT.
- Repeating an identical completed request is idempotent; changing model
  identity produces a separate track.

## Deferred

Incremental/current-position generation, provisional live captions, shared
dual-destination jobs, forced alignment, diarization, microphone, cloud ASR,
and non-macOS packaging remain outside Milestone 1.7.
